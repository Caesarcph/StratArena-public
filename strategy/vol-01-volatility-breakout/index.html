VOL-01 · Volatility

Volatility Breakout

The breakout compares today's closing-price return with the sample standard deviation of the last 20 daily returns. A return above 1.5 times that standard deviation signals full long exposure.

Rules

Entry

Go long when today's return exceeds 1.5 times its rolling standard deviation.

Exit

Go to cash when today's return is negative. Otherwise keep the previous target if the entry condition does not trigger.

Indicators

Daily close-to-close return and its 20-day rolling sample standard deviation.

Inputs

Fixed: volatility lookback = 20 daily returns, entry multiplier = 1.5.

Position sizing

100% long or cash.
