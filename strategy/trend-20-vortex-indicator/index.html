Rules

Entry

Go long when VI+ > VI-

Exit

Exit when VI+ < VI-

Indicators

VM+ = sum(abs(high - prev_low))
VM- = sum(abs(low - prev_high))
TR = sum(True Range)
VI+ = VM+ / TR
VI- = VM- / TR

Inputs

Period = 14

Position sizing

Fixed 100% allocation

Risk controls

Uses true range normalization
