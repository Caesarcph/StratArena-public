Rules

Entry

When flat after an exit, re-enter if the close is strictly above the re-entry threshold.

Exit

In the uptrend state, go to cash when the close is strictly below the exit threshold. Otherwise target long.

Indicators

Range proxy: the 22-bar simple average of absolute close-to-close changes.
Exit threshold: 22-bar highest close minus 3 times the range proxy. Re-entry threshold: 22-bar lowest close plus 3 times the range proxy. The windows include the current close.

Inputs

Default: atr_period = 22, multiplier = 3.

Position sizing

100% long or cash.
