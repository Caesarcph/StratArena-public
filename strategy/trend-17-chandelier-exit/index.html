TREND-17 · Trend Following

Chandelier Exit

Uses ATR-based trailing stops from recent highs. Long stop = Highest High - 3*ATR. Stays in trend until volatility-adjusted stop is hit. Designed to ride trends and protect gains.

Rules

Entry

Buy when price breaks above short stop (reversal)

Exit

Sell when price falls below long stop

Indicators

ATR = Average True Range over N periods
Long Stop = Highest High(22) - 3 * ATR
Short Stop = Lowest Low(22) + 3 * ATR

Inputs

ATR_Period = 22
Multiplier = 3.0

Position sizing

Fixed 100% allocation

Risk controls

ATR-based dynamic stop loss
