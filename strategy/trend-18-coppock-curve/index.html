Rules

Entry

Set long whenever the curve is strictly positive.

Exit

Use cash when the curve is zero, negative, or unavailable.

Indicators

ROC(n) is close divided by the close n bars earlier minus 1. Smooth the sum with linear weights 1 through wma_window.

Inputs

roc_fast = 14, roc_slow = 11, wma_window = 10.

Position sizing

100% long or cash.
