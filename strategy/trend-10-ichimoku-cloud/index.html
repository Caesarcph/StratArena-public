Ichimoku Cloud

Ichimoku Kinko Hyo (One Glance Equilibrium Chart). Uses multiple lines to identify trend, momentum, and support/resistance. Price above cloud is bullish, below is bearish.

Rules

Entry

Buy when price > Cloud AND Tenkan > Kijun
Strong signal if Chikou (lagging) also confirms

Exit

Price falls below Cloud OR Tenkan < Kijun

Indicators

Tenkan-sen = (9-day high + 9-day low) / 2
Kijun-sen = (26-day high + 26-day low) / 2
Senkou Span A = (Tenkan + Kijun) / 2, shifted 26 days forward
Senkou Span B = (52-day high + 52-day low) / 2, shifted 26 days forward

Inputs

Tenkan = 9
Kijun = 26
Senkou = 52

Position sizing

Fixed 100% allocation

Risk controls

Cloud acts as support/resistance
