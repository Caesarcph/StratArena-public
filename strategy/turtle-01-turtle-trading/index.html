TURTLE-01 · Trend Following

Turtle Trading

This Turtle-style variant runs one long-or-cash rule with separate entry and exit lookbacks. It uses the prior windows of closes.

Rules

Entry

Go long if today's close is strictly above the upper boundary.

Exit

Go to cash if today's close is strictly below the lower boundary. Otherwise keep the prior target.

Indicators

Upper boundary = prior entry_window highest close. Lower boundary = prior exit_window lowest close.

Inputs

entry_window = 20, exit_window = 10.

Position sizing

100% long or cash.
