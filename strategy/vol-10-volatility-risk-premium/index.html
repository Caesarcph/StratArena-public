Volatility Risk Premium

Volatility Risk Premium is the historical name. The strategy uses two realized-volatility windows from the tested instrument's daily returns to set long or cash targets.

Rules

Entry

After realized_lookback + 5 bars, set long when the spread exceeds 2 percentage points and longer-window volatility is below 25%.

Exit

Set cash when the spread is below −2 percentage points. Otherwise keep the last target.

Indicators

For both windows use the sample standard deviation of daily returns × √252. The spread equals longer-window volatility minus shorter-window volatility.

Inputs

realized_lookback = 20, implied_lookback = 5 (short realized window), vrp_threshold = 0.02.

Position sizing

100% long or cash.
