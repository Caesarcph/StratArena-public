RP-01 · Volatility

Volatility Target

Daily exposure increases when trailing realized volatility falls and decreases when it rises. The rule caps the target weight and realized volatility can differ from the target.

Rules

Entry

On a positive volatility estimate, divide target volatility by realized volatility and clip to the range from zero to the cap.

Exit

Set the target to cash if the volatility estimate is unavailable or zero.

Indicators

Calculate sample standard deviation of daily close-to-close returns and annualize with √252. Missing returns, including the first, are treated as zero.

Inputs

Default target volatility 10%, lookback 20 daily returns and cap 1.5×.

Position sizing

The default permits exposures above 100% up to the 150% cap.
