MR-01 · Mean Reversion

RSI Mean Reversion

Each close, the rule uses 14 daily changes in closing price to calculate RSI from simple averages. An oversold reading sets the target for the next return interval to fully long.

Rules

Entry

Set the long target whenever RSI is below 30.

Exit

Set the target to cash whenever RSI is at least 30 or unavailable.

Indicators

RSI from simple averages of positive and negative closing-price changes over 14 sessions.

Inputs

Fixed: RSI window = 14, oversold threshold = 30.

Position sizing

100% long or cash.

Notes

  • A missing RSI reading, including when average loss is zero, produces a flat target.
