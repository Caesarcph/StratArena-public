Hierarchical Risk Parity

Hierarchical Risk Parity sorts assets by the clustering tree and divides the sorted list recursively. Each split gives more weight to the lower-variance subcluster.

Rules

Entry

Split the ordered asset list in half recursively and allocate each split inversely to the estimated subcluster variances.

Exit

Recompute targets at the next eligible monthly decision.

Indicators

Convert return correlations into distances and cluster assets. Estimate subcluster variance using its internal inverse-variance weights.

Inputs

Default lookback 60 daily returns and single linkage.

Position sizing

Return a fully invested allocation with each result assigned to its original asset.

Notes

  • The basket uses the common completed sessions of SPY, GLD, USO and EURUSD=X.
  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
  • The backtest uses equal weights when covariance is unusable, any asset variance is zero, or clustering or weight calculation fails.
