Hierarchical Risk Parity

HRP by Marcos Lopez de Prado. Uses hierarchical clustering on correlation matrix to build a tree structure, then allocates weights recursively. Avoids covariance matrix inversion.

Rules

Inputs

Lookback = 60
Linkage = single

Indicators

Correlation matrix
Hierarchical clustering

Entry

1. Cluster assets by correlation distance
2. Quasi-diagonalize covariance matrix
3. Recursive bisection for weights

Exit

Monthly rebalance

Risk

No matrix inversion needed

Notes

  • Marcos Lopez de Prado (2016)
  • More stable than mean-variance optimization
  • Uses inverse variance at leaf level
