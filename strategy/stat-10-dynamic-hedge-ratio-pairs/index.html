STAT-10

Dynamic Hedge Ratio Pairs

Uses Kalman Filter to dynamically estimate the hedge ratio between two assets. More adaptive than rolling OLS regression. Trades spread z-score with time-varying parameters.

Rules

Inputs

Q = 0.001 (process noise)
R = 1.0 (measurement noise)
Entry_Z = 1.5
Exit_Z = 0.3

Indicators

Kalman-filtered hedge ratio
Dynamic spread
Spread z-score

Entry

Z < -1.5: long spread (long Y, short X)
Z > 1.5: short spread

Exit

Z crosses 0 or reverses

Position sizing

Equal dollar weights adjusted by hedge ratio

Risk controls

Max holding period
Hedge ratio stability check

Notes

  • Kalman Filter adapts to structural changes
  • No need for fixed lookback window
  • More responsive than OLS-based pairs
