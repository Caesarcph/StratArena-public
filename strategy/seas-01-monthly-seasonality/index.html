Monthly Seasonality

Rules

Entry

Set target1 when the observation is in an active month.

Exit

Set target0 in all other months.

Indicators

Month of the input date.

Inputs

Fixed active months:11,12,1,2,3,4. No configurable numeric parameters.

Position sizing

100% long or cash.
