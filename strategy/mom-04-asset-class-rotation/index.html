Rules

Entry

Select the two highest available scores and keep those with returns above zero.

Exit

Clear dropped assets at the monthly decision. Go to cash if no asset passes the filter.

Indicators

Compute each asset's trailing closing-price return on the same 126-session window.

Inputs

Default lookback 126 sessions, top 2 assets and positive-return filter enabled.

Position sizing

Divide the full target equally among the assets that pass.
