Rules

Inputs

Lookback = 126 (6 months)
Top_N = 2
Absolute_Filter = True

Indicators

N-month return for each asset

Entry

1. Rank assets by momentum
2. Select Top N with positive momentum
3. Equal weight allocation

Exit

Monthly rebalance, drop assets with negative momentum

Risk

Absolute momentum filter reduces drawdowns

Notes

  • Adapts sector rotation concept to asset classes
  • Monthly rebalancing reduces transaction costs
  • Can go to cash if no positive momentum assets
