Elder Triple Screen

Rules

Inputs

MACD_Fast = 12
MACD_Slow = 26
MACD_Signal = 9
EMA_Long = 50
Force_EMA = 13
Entry_Lookback = 20

Indicators

MACD histogram for trend filter
Force Index proxy = close.diff()
Entry breakout = recent high

Entry

Trend up AND Force Index < 0 AND close > recent high

Exit

Trend filter turns down

Position sizing

Fixed 100% allocation

Risk controls

Requires pullback before breakout entry

Notes

  • Force Index uses price-change proxy (no volume)
  • Simplified long-only version
