Multi-Factor Composite

The strategy standardizes each factor across assets, combines the scores and gives every scored asset a positive target weight. Higher composite scores get more weight.

Rules

Entry

At an eligible monthly decision, allocate to every asset with a composite score.

Exit

Recalculate targets at each eligible rebalance. Carry the previous target while no composite scores are available.

Indicators

Value is negative price divided by its SMA. Momentum is the trailing return.
Quality averages negative annualized volatility and negative absolute maximum drawdown. Compute drawdowns from rolling price peaks and take the rolling worst drawdown.
Compute cross-sectional sample z-scores before combining the factors.

Inputs

Default value and drawdown lookbacks 252 sessions, momentum lookback 126 sessions, volatility lookback 60 returns, factor weights 30% / 40% / 30%.

Position sizing

Subtract the smallest composite score, add 0.1 to each scored asset and normalize. Assets without a score receive zero weight.

Notes

  • The site backtest aligns SPY, GLD, USO, EURUSD=X, DBC, SLV, DBA, UNG, BTC-USD and ETH-USD on their common completed sessions. Its SPY display label identifies the basket.
  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
  • The default drawdown calculation uses two rolling 252-session windows. It provides its first value after 503 observations, including the first price observation.
