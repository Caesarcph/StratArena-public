Rules

Entry

At the monthly decision, divide by each asset's volatility and normalize the available weights.

Exit

Refresh the target at the next eligible monthly decision.

Indicators

Estimate annualized volatility from sample return standard deviations. In the default branch substitute the average of available volatility estimates for zero or missing estimates when that average is usable.

Inputs

Default lookback 60 daily returns, full_optimization disabled.

Position sizing

The default allocation gives larger weights to less volatile assets.

Notes

  • The basket uses the common completed sessions of SPY, GLD, USO and EURUSD=X.
  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
  • The optional covariance-based iteration is disabled by default. Its result can include short weights and can miss equal risk contributions.
