TREND-15 · Trend Following

Darvas Box

Identifies a rolling price box using recent highs and lows. Goes long on a breakout above the box and exits when price falls below the box floor.

Rules

Inputs

Box_Period = 20

Indicators

BoxHigh = rolling high
BoxLow = rolling low

Entry

Go long when close > BoxHigh

Exit

Exit when close < BoxLow

Position sizing

Fixed 100% allocation

Risk controls

Uses recent range as stop reference

Notes

  • Classic box breakout system
  • Works best after consolidation
