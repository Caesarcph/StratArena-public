Minimum Variance

First calculate the fully invested minimum-variance solution that permits negative weights. The default then clips negative weights and rescales the remaining positions, so the long-only result can differ from the constrained optimum.

Rules

Entry

Multiply its inverse by the all-ones vector and scale the result to sum to one.

Exit

Recompute at the next eligible monthly decision. Zero weights clear former positions.

Indicators

Annualize the sample covariance matrix and add 0.000001 to each diagonal entry.

Inputs

Default lookback 60 daily returns, allow_short disabled and diagonal regularization 0.000001.

Position sizing

By default, clip negative weights to zero and normalize again.

Notes

  • The basket uses the common completed sessions of SPY, GLD, USO and EURUSD=X.
  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
  • The optional allow_short setting keeps negative weights. The rule uses equal weights if covariance is unusable or inversion fails.
