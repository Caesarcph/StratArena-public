RISK-01

Drawdown Control

Monitors portfolio drawdown in real-time. When drawdown exceeds threshold, reduces position proportionally. Similar to CPPI dynamic insurance. Can be used as overlay on any strategy.

Rules

Inputs

Max_Drawdown = 0.10
Scale = 0.5
Recovery_Threshold = 0.5

Indicators

Rolling maximum price
Current drawdown

Entry

Full position when drawdown < threshold
Reduce by scale factor when drawdown exceeds

Exit

Gradually restore as drawdown recovers

Position sizing

Dynamic based on drawdown

Risk controls

Hard drawdown limit

Notes

  • Protects against tail risk
  • May reduce returns in V-shaped recoveries
  • Similar to constant proportion portfolio insurance
