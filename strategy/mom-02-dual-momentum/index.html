Dual Momentum

This dual-momentum variant ranks the risk assets by trailing return and applies a zero-return test to the winner. GLD is the default fallback.

Rules

Entry

If the highest available risk-asset return is strictly positive, set its target to 100%.

Exit

Set the target to 100% GLD when that return is zero or negative. Carry the prior target if every risk-asset score is unavailable.

Indicators

Calculate trailing closing-price returns for SPY, USO and EURUSD=X. GLD serves as the fallback and stays outside the ranking.

Inputs

Default lookback 252 sessions and safe asset GLD.

Position sizing

Hold one asset at a time after the first qualifying monthly decision.

Notes

  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
