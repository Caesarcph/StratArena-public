Dual Momentum

Gary Antonacci's Dual Momentum: select the asset with highest relative momentum, then apply absolute momentum filter. If selected asset has negative momentum, switch to safe asset.

Rules

Entry

1. Relative Momentum: Select asset with highest 12M return
2. Absolute Momentum: If selected return > 0, hold it
3. If selected return <= 0, hold safe asset (GLD)

Exit

Monthly rebalance

Indicators

12-month return for each asset

Inputs

Lookback = 252 (12 months)
Safe_Asset = GLD

Risk

Absolute momentum filter avoids drawdowns

Strategy evidence

Evidence is not available for this strategy in the current release. A displayed backtest is not a verified evidence bundle.

Notes

  • Based on Gary Antonacci's 2014 book
  • Monthly rebalancing at month-end
  • Uses GLD as safe asset proxy
