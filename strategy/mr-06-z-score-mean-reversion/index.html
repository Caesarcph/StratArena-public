Rules

Entry

After 200 observations: z<−2, enabled volatility filter strictly.10<vol<.50, and enabled trend filter distance<.10.

Exit

Exit when z>−.5; otherwise hold.

Indicators

Price z uses sample standard deviation. Annualized return volatility uses sqrt252; trend distance is abs(close/SMA200−1).

Inputs

lookback=20, entry_z=2, exit_z=.5; vol_filter=true, trend_filter=true, min_vol=.10, max_vol=.50, trend_threshold=.10.

Position sizing

100% long or cash.
