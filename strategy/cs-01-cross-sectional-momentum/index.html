Rules

Entry

Pick the highest two available returns, regardless of sign.

Exit

Clear dropped assets at rebalance. Go to cash if no selected asset has usable positive volatility.

Indicators

Calculate each asset's 252-session closing-price return and sample standard deviation of 60 daily returns.

Inputs

Default return lookback 252 sessions, volatility lookback 60 returns, top 2 assets.

Position sizing

Assign the selected assets weights proportional to 1 / volatility. Unavailable or zero estimates receive zero weight.
