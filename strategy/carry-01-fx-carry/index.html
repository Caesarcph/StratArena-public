FX Carry

Rules

Entry

At rebalance, select the two highest available returns. Returns can be negative.

Exit

At a monthly decision, go to cash if average annualized volatility exceeds 20% or there are no available ranking scores. Carry targets between monthly decisions.

Indicators

Rank trailing 20-session closing-price returns. Average the assets' 60-return sample standard deviations annualized by √252.

Inputs

Default lookback 20 sessions, top 2 assets, volatility lookback 60 sessions, volatility threshold 20%.

Position sizing

Equal long weights among selected assets.

Notes

  • The basket uses the common completed sessions of SPY, GLD, USO and EURUSD=X.
  • Set targets on the first common session observed in a new month using the preceding completed session. The target takes effect on the next available return interval.
  • Ranking can start before the volatility history is available. The filter applies when a basket-average estimate exists.
