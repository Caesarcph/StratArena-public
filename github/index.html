How this list is built

  • Candidates come from GitHub topic and keyword searches (algorithmic-trading, quantitative-finance, trading-bot, backtesting, defi, fintech, personal-finance and about 40 more), at least 200 stars each.
  • Archived repositories and forks are dropped. A repository must mention a finance term in its name, topics or description, and a short exclusion list removes known false positives.
  • Each repository gets one primary category: the first match on its topics and name, then its description. Awesome lists, courses and books go to Learning resources.
  • Stars, forks, language, license and last push are read from the GitHub API once a week. 7-day and 30-day gains compare with our own earlier snapshots, so they appear only after enough history exists.
  • Hot score = stars / (age in days + 30)^0.8, times 1.5 if pushed in the last 30 days, 1.0 within 90 days, 0.6 within a year, 0.3 older. It favours young projects with fast adoption and penalises abandoned ones.
