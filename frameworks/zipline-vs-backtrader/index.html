Strengths · Limitations

Zipline

Strengths

  • Pipeline API for factor research
  • Realistic daily equity simulation
  • Lots of historical learning material

Limitations

  • Original repository unmaintained; installation is painful
  • Data bundles need setup work
  • Not suited to crypto or forex

Backtrader

Strengths

  • Realistic event-driven simulation: orders, stops, partial fills, commissions
  • Huge amount of examples and community answers
  • Multiple data feeds and timeframes in one strategy

Limitations

  • Slow for large parameter sweeps compared with vectorized libraries
  • No longer actively developed; plotting can break with newer Matplotlib
  • Live-trading brokers are dated

Which one to choose

For a new project, Backtrader is easier to install and still works on current Python. Zipline is worth it mainly for its Pipeline API and for following books that use it, through a maintained community fork.
