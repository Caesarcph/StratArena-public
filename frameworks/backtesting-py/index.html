Overview

Backtesting.py keeps the API short: subclass Strategy, write init() and next(), and call Backtest.run(). Results come with an interactive Bokeh chart and a table of standard statistics, and optimize() searches parameters. It tests one instrument at a time.

Best for: Beginners and quick single-instrument experiments.

Strengths

  • Easiest API of the libraries here
  • Good charts out of the box
  • Built-in parameter optimization and heatmaps

Limitations

  • One instrument per backtest; no portfolio of assets
  • AGPL-3.0 license matters if you build a product on it
  • Fewer order types than event-driven engines
