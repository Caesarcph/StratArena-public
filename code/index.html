How to use the files

  • Python files run on their own: install pandas, numpy and yfinance, then run the file with a ticker or a CSV of daily prices.
  • Pine files: open TradingView, Pine Editor, paste the script, add to chart, use the daily timeframe.
  • The Python file is the reference. Pine versions were converted by hand and have not been compiled by us in TradingView; small differences in indicator smoothing are possible.
  • A position decided at today's close earns tomorrow's return. Results are before trading costs.

Free to use and modify. Provided as is, for research and education. Historical backtests do not predict future returns. Not investment advice.
