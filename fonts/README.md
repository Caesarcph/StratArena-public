# Fonts

Self-hosted copies of two Google Fonts, Latin and Latin Extended subsets only
(Chinese text uses the system font stack):

- Fraunces — Copyright 2018 The Fraunces Project Authors, https://github.com/undercasetype/Fraunces
- Space Grotesk — Copyright 2020 The Space Grotesk Project Authors, https://github.com/floriankarsten/space-grotesk

Both are licensed under the SIL Open Font License 1.1: https://openfontlicense.org

`fonts.css` is the Google Fonts stylesheet with the URLs pointed at these files.
