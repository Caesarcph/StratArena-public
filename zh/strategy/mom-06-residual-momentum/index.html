MOM-06 · 动量

残差动量

基于 Blitz 等人（2011）的研究。先把收益对市场因子（SPY）做回归，用回归残差计算动量，捕捉“纯粹”的个体动量，而不是 Beta 带来的收益。

交易规则

Entry

Buy when residual momentum > 0 (positive alpha)

Exit

Exit when residual momentum <= 0

Indicators

Rolling beta to SPY
Residual return = Actual - Beta * Market
Cumulative residual momentum

Inputs

Beta_Window = 252
Momentum_Lookback = 252
Skip_Period = 21

Position sizing

Fixed 100% allocation

Risk controls

Skip most recent month to avoid reversal

备注

  • 基于 Blitz、Huij 和 Martens（2011）的研究
  • 剔除系统性风险，捕捉个体动量
  • 用简化的 CAPM 残差（以 SPY 作为市场代理）
