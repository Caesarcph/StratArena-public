交易规则

Inputs

Hurst_Window = 120
Hurst_Threshold = 0.55
Lookback = 40
Entry_Z = 1.5

Indicators

Hurst exponent via R/S analysis
Z-score

Entry

Only trade when H < 0.55 (mean-reverting)
Buy when Z < -1.5

Exit

Exit when Z > -0.3
Or when trending and Z > 0

Position sizing

Fixed 100% allocation

Risk controls

Regime detection prevents trend-fighting

备注

  • H < 0.5：均值回归（反持续性）
  • H = 0.5：随机游走
  • H > 0.5：趋势（持续性）
  • 用 R/S 分析估计 Hurst 指数
