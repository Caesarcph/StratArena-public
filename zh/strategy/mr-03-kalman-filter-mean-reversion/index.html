交易规则

Inputs

Q = 0.001 (process noise)
R = 1.0 (observation noise)
Entry_Z = 2.0
Exit_Z = 0.5

Indicators

Kalman state estimate
Standardized residual (z-score)

Entry

Buy when z-score < -Entry_Z (price undervalued)

Exit

Exit when |z-score| < Exit_Z

Position sizing

Fixed 100% allocation

Risk controls

Adaptive Q based on recent volatility

备注

  • Rudolf Kalman 在 1960 年提出的最优状态估计算法
  • 在高斯假设下给出最优线性估计
  • Q/R 比例控制平滑度和灵敏度之间的取舍
