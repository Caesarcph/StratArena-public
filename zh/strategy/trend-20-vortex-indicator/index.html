交易规则

Inputs

Period = 14

Indicators

VM+ = sum(abs(high - prev_low))
VM- = sum(abs(low - prev_high))
TR = sum(True Range)
VI+ = VM+ / TR
VI- = VM- / TR

Entry

Go long when VI+ > VI-

Exit

Exit when VI+ < VI-

Position sizing

Fixed 100% allocation

Risk controls

Uses true range normalization

备注

  • 对波动率突增比较敏感
  • 以后可以加入做空版本
