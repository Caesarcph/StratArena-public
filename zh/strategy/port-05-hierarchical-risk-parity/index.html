交易规则

Inputs

Lookback = 60
Linkage = single

Indicators

Correlation matrix
Hierarchical clustering

Entry

1. Cluster assets by correlation distance
2. Quasi-diagonalize covariance matrix
3. Recursive bisection for weights

Exit

Monthly rebalance

Risk

No matrix inversion needed

备注

  • Marcos López de Prado（2016）
  • 比均值-方差优化更稳定
  • 叶子层使用逆方差加权
