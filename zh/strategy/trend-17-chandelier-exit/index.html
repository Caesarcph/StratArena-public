吊灯止损

交易规则

Inputs

ATR_Period = 22
Multiplier = 3.0

Indicators

ATR = Average True Range over N periods
Long Stop = Highest High(22) - 3 * ATR
Short Stop = Lowest Low(22) + 3 * ATR

Entry

Buy when price breaks above short stop (reversal)

Exit

Sell when price falls below long stop

Position sizing

Fixed 100% allocation

Risk controls

ATR-based dynamic stop loss
