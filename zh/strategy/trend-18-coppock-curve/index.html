交易规则

Inputs

ROC1 = 14
ROC2 = 11
WMA = 10

Indicators

ROC1 = (P / P[-ROC1]) - 1
ROC2 = (P / P[-ROC2]) - 1
Coppock = WMA(ROC1 + ROC2, WMA)

Entry

Go long when Coppock > 0

Exit

Exit when Coppock < 0

Position sizing

Fixed 100% allocation

Risk controls

Trend filter keeps exposure binary
