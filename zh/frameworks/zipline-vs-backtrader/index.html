Zipline 还是 Backtrader？

新项目选 Backtrader 更省事，在新版 Python 上也还能用。Zipline 主要值在它的 Pipeline API，以及跟着用它的书学习；这时建议用仍在维护的社区分支。

优点 · 局限

Zipline

优点

  • 适合因子研究的 Pipeline API
  • 对股票日线的模拟比较真实
  • 历史学习资料很多

局限

  • 原仓库无人维护，安装很麻烦
  • 数据包需要额外配置
  • 不适合加密货币和外汇

Backtrader

优点

  • 逼真的事件驱动模拟：挂单、止损、部分成交、手续费都能处理
  • 示例和社区问答非常多
  • 一个策略里可以同时用多个品种、多个周期

局限

  • 和向量化回测库比，大规模参数扫描很慢
  • 已不再积极维护；新版 Matplotlib 下画图可能出问题
  • 实盘接口比较老旧

怎么选

新项目选 Backtrader 更省事，在新版 Python 上也还能用。Zipline 主要值在它的 Pipeline API，以及跟着用它的书学习；这时建议用仍在维护的社区分支。
