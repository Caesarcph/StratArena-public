简介

Backtrader 逐根K线运行策略，和实盘的方式一样，内置经纪商模拟、仓位管理、分析器和一百多个指标。它在 2010 年代后期成了 Python 回测的首选，现在很多教程和问答仍然用它。近几年几乎没有新的开发（见上方的最近提交日期），但代码本身很稳定。

适合谁: 入门学回测、订单逻辑复杂的策略，以及移植 MT4/MT5 EA 这类规则化系统。

优点

  • 逼真的事件驱动模拟：挂单、止损、部分成交、手续费都能处理
  • 示例和社区问答非常多
  • 一个策略里可以同时用多个品种、多个周期

局限

  • 和向量化回测库比，大规模参数扫描很慢
  • 已不再积极维护；新版 Matplotlib 下画图可能出问题
  • 实盘接口比较老旧

我们自己的使用经验

Quant Arena 的 EA 竞技场就是用 Backtrader 跑的：1,063 个从 MQL5 转换来的 EA，每月在四个品种的小时线上重跑一次，每次大约 1 秒。

同类替代：回测库

9.8k ★vectorbt基于 pandas 和 NumPy 的向量化回测，专门用来快速测试成千上万组参数。9.2k ★Backtesting.py小巧好读的回测库，自带交互图表和参数优化。3.0k ★bt用可复用模块搭建的组合回测库，适合资产配置和再平衡策略。20.2k ★ZiplineQuantopian 的事件驱动回测引擎，带 Pipeline API；原仓库已不再维护。4.7k ★PyAlgoTrade较早的 Python 事件驱动回测库，作者已将其归档。
