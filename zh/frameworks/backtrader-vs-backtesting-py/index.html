Backtrader 还是 Backtesting.py？

Backtesting.py 上手更快：API 简短、图表好看，但一次只能测一个品种。Backtrader 学起来更费时间，但能处理多个品种、多个周期和细致的订单逻辑。

优点 · 局限

Backtrader

优点

  • 逼真的事件驱动模拟：挂单、止损、部分成交、手续费都能处理
  • 示例和社区问答非常多
  • 一个策略里可以同时用多个品种、多个周期

局限

  • 和向量化回测库比，大规模参数扫描很慢
  • 已不再积极维护；新版 Matplotlib 下画图可能出问题
  • 实盘接口比较老旧

Backtesting.py

优点

  • 这里所有库中 API 最简单
  • 开箱即用的图表
  • 内置参数优化和热力图

局限

  • 每次只能测一个品种，不支持多资产组合
  • AGPL-3.0 许可证，拿来做产品时要注意
  • 订单类型比事件驱动引擎少

怎么选

Backtesting.py 上手更快：API 简短、图表好看，但一次只能测一个品种。Backtrader 学起来更费时间，但能处理多个品种、多个周期和细致的订单逻辑。
