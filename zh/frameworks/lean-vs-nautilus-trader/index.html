LEAN 覆盖更广、更成熟，尤其适合期权期货，还能用 QuantConnect 的云端数据。NautilusTrader 更快、更贴近底层，面向订单簿和高频策略，学习曲线也更陡。

优点 · 局限

QuantConnect LEAN

优点

  • 资产和券商覆盖非常广
  • 研究、回测、实盘用同一套代码
  • 成熟、持续开发、用户多

局限

  • 本地搭建比纯 Python 库重得多
  • 本地数据要自己解决，方便的数据在付费云端
  • 框架约定需要时间学习

NautilusTrader

优点

  • 快速且逼真的事件驱动模拟，可以细到订单簿
  • 回测和实盘代码完全相同
  • 开发非常活跃

局限

  • 学习曲线陡，主要面向工程师
  • 版本之间 API 变化频繁
  • LGPL-3.0 许可证

怎么选

LEAN 覆盖更广、更成熟，尤其适合期权期货，还能用 QuantConnect 的云端数据。NautilusTrader 更快、更贴近底层，面向订单簿和高频策略，学习曲线也更陡。
