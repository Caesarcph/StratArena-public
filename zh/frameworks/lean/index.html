简介

LEAN 是 QuantConnect 背后的引擎。策略用 Python 或 C# 编写，可以交易股票、期权、期货、外汇和加密货币，既能回测，也能通过支持的券商实盘。可以用 LEAN CLI 在本地运行，也可以在 QuantConnect 云端运行（云端有历史数据）；本地运行则需要自己准备和整理数据。

适合谁: 要上实盘的严肃多资产策略，尤其是涉及期权、期货的。

优点

  • 资产和券商覆盖非常广
  • 研究、回测、实盘用同一套代码
  • 成熟、持续开发、用户多

局限

  • 本地搭建比纯 Python 库重得多
  • 本地数据要自己解决，方便的数据在付费云端
  • 框架约定需要时间学习
