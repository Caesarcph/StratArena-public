简介

vn.py 是一个带桌面图形界面的 Python 平台，支持回测，并有国内期货（CTP）、股票、期权和海外券商的接口。功能以应用模块的形式组织，比如 CTA 策略、价差交易、组合策略，可以按需组合。文档和社区以中文为主。

适合谁: 交易国内期货和股票，以及需要图形界面交易终端的团队。

优点

  • 对国内市场的接口最全
  • 既有图形界面也能写脚本
  • 中文社区和课程很多

局限

  • 文档以中文为主
  • 偏桌面端设计
  • 部分高级模块和课程收费
