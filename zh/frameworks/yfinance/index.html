简介

yfinance 是 Python 里获取股票、ETF、外汇和加密货币免费日线和日内历史数据最常用的方法。它不是官方接口：Yahoo 可能改版或限流，数据按 Yahoo 的条款仅供个人使用。

适合谁: 基于日线的个人研究和原型开发。

优点

  • 免费、好用
  • 覆盖的代码很多
  • 提供按分红拆股调整后的价格

局限

  • 非官方接口，可能随时失效或被限流
  • 分红后复权历史会变化，旧回测结果会有小幅变动
  • 数据不允许再分发

我们自己的使用经验

Quant Arena 的策略日线数据就来自 yfinance。我们实测过：相隔一天的两次构建之间，576 条权益曲线里有 198 条的早期历史出现了小幅变化，部分原因就是 Yahoo 在分红后会修订复权价格。
