双方的数据源、执行模型和成本不同。结果一致不能证明转换准确；单个差异也不能单独确定转换错误。

怎样理解这些差异

  • 原生侧运行原始 MQL5，使用经纪商真实 ticks、历史点差及合约限制；请求初始资金 10,000 美元、杠杆 1:400。被隔离的那组记录未能证实这套配置。
  • Python 侧运行翻译后的程序，使用 H1 数据。冻结记录声明佣金为 0.00002，没有点差模型；数据源、柱内执行、仓位规模和部分指标定义均有差异。
  • Python 文件是冻结保存的历史快照。哈希只能核对文件完整性，不能证明当时实际执行了哪些源码和输入：旧运行记录没有保存执行时哈希。
  • 零交易和超时组表示对照覆盖不足，不能视为转换验证成功，也不能当作策略质量评级。
