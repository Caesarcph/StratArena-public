Donchian 55/20 对比 Turtle 20/10：十个市场回测

在未扣交易成本的前提下，较慢的 Donchian Breakout（TREND-02，突破 55 日高点入场、跌破 20 日低点离场）在十个市场共入场 774 次，Turtle Trading（TURTLE-01，20/10）为 1,979 次；完整区间里 Donchian 在 10 个市场中有 7 个夏普更高（平均 0.38 对 0.34）。近五年差距更大：0.41 对 0.21。

DonchianTurtle TradingBreakoutTrend

代码里的两条规则

Donchian Breakout（TREND-02）在收盘价高于前 55 天最高收盘价时做多，在收盘价低于前 20 天最低收盘价时转为现金。两个信号之间保持原有仓位。Turtle Trading（TURTLE-01）逻辑相同，只是入场和离场窗口分别为 20 天和 10 天。

从代码看有三点值得注意。两者都只做多；都只使用收盘价，不用日内最高最低价；也都没有策略描述里提到的 ATR 仓位管理或止损：代码只是 100% 持仓或空仓。Donchian 没有可调参数，始终使用 55/20。Turtle 的窗口每六个月在 20 和 10 附近的一组参数里重新挑选（入场 16 到 24，离场 8 到 12），最初三年使用 20/10。

结果均未扣交易成本，统计近五年（截至 2026-11-11）和完整区间（多数市场从 2010-01-04 起，比特币 2014-09-17，以太坊 2017-11-09）。

十个市场，两个窗口

每行依次为年化收益 / 夏普 / 最大回撤，先是近五年，再是完整区间，先 Donchian 后 Turtle，最后是两者的持仓天数占比。

  • 美股：Donchian 3.6% / 0.47 / −17.6%，完整区间 4.4% / 0.55 / −17.8%；Turtle 6.0% / 0.63 / −13.3%，完整区间 6.7% / 0.78 / −13.3%。持仓天数占 54% 和 55%。
  • 黄金：Donchian 9.3% / 0.71 / −14.1%，完整区间 4.6% / 0.46 / −27.3%；Turtle 6.4% / 0.53 / −14.4%，完整区间 3.8% / 0.39 / −23.0%。36% 和 41%。
  • 白银：Donchian 11.7% / 0.57 / −36.8%，完整区间 5.8% / 0.38 / −45.1%；Turtle −1.0% / 0.11 / −45.5%，完整区间 4.5% / 0.32 / −48.8%。30% 和 36%。
  • 原油：Donchian 14.5% / 0.66 / −32.3%，完整区间 4.3% / 0.32 / −35.5%；Turtle 2.7% / 0.23 / −51.9%，完整区间 2.7% / 0.23 / −51.9%。33% 和 39%。
  • 天然气：Donchian −10.4% / −0.16 / −65.4%，完整区间 −7.9% / −0.19 / −77.4%；Turtle −21.9% / −0.42 / −85.0%，完整区间 −13.6% / −0.34 / −91.6%。20% 和 32%。
  • 综合大宗商品：Donchian 9.7% / 0.79 / −22.5%，完整区间 3.6% / 0.40 / −29.4%；Turtle 2.6% / 0.27 / −31.6%，完整区间 2.7% / 0.31 / −31.6%。34% 和 40%。
  • 农产品：Donchian 2.6% / 0.35 / −17.8%，完整区间 2.4% / 0.36 / −17.8%；Turtle 1.5% / 0.22 / −15.1%，完整区间 0.5% / 0.11 / −25.4%。28% 和 36%。
  • 欧元/美元：Donchian −0.0% / 0.01 / −8.1%，完整区间 −0.9% / −0.19 / −24.3%；Turtle 0.3% / 0.08 / −9.6%，完整区间 −1.3% / −0.24 / −36.2%。26% 和 33%。
  • 比特币：Donchian 9.4% / 0.39 / −36.2%，完整区间 48.2% / 0.98 / −56.9%；Turtle 8.0% / 0.34 / −55.0%，完整区间 54.1% / 1.05 / −63.4%。37% 和 41%。
  • 以太坊：Donchian 6.8% / 0.31 / −34.4%，完整区间 32.7% / 0.70 / −56.2%；Turtle −4.1% / 0.07 / −52.0%，完整区间 43.9% / 0.79 / −52.0%。33% 和 38%。

最好、最差与直接对比

Donchian 最好的市场，近五年是综合大宗商品（夏普 0.79），完整区间是比特币（0.98）；最差的是近五年的天然气和完整区间的欧元/美元。Turtle 最好的是近五年的美股（夏普 0.63，回撤仅 13.3%）和完整区间的比特币（1.05）；最差的是天然气，两个窗口皆然（完整区间年化 −13.6%，回撤 91.6%）。

近五年 Donchian 夏普在 10 个市场中有 8 个更高（平均 0.41 对 0.21），回撤有 8 个更浅（平均 −28.5% 对 −37.3%）。完整区间这两个数字都是 7 个，平均分别为 0.38 对 0.34 和 −38.8% 对 −43.7%。Turtle 在完整区间的胜场是美股、比特币和以太坊。Donchian 在两个窗口里都有 8 个市场年化为正；Turtle 近五年为 7 个，完整区间为 8 个。

持仓时间

慢速规则的持仓时间明显更少。Donchian 的持仓天数占比中位数为 33%（范围 20% 到 54%），Turtle 为 38%（32% 到 55%）。用持仓天数除以入场次数，平均每次持仓大约 Donchian 17.7 天，Turtle 8.3 天。两者在“持仓还是空仓”上，中位数有 77% 的交易日一致。

两个系统在趋势结束后的表现也不同。20 日离场在下跌的市场里会停留很久，10 日离场则出场更早，代价是更多的来回折腾。

每个市场的最差日历年

在每个市场自己最差的完整日历年里，两者无一例外都跑赢了市场，这些年份里市场平均下跌 42.8%。Donchian 平均为 −10.2%，10 个中有 9 个亏损；Turtle 平均为 −3.3%，10 个中有 7 个亏损。

2022 年的美股说明了离场速度的差别。市场下跌 18.2%，Donchian 那一年只有 14% 的交易日持仓，却仍亏了 12.3%；Turtle 持仓 38% 的交易日，亏 5.6%。2013 年的黄金（−28.3%）让 Donchian 亏 5.7%，Turtle 亏 4.5%，Donchian 当年只有 5% 的交易日持仓。2020 年的原油（−67.8%）对两者都有利：Donchian 盈利 7.8%，Turtle 盈利 34.0%。2023 年的天然气（−64.0%）则不然：−25.6% 和 −49.4%。2018 年的以太坊（−82.4%），Turtle 盈利 39.3%，Donchian 亏 21.0%；那一年处于 Turtle 滚动前推的默认参数阶段。

突破策略在哪里失效

突破策略要等价格创出新高才行动。在来回漂移的市场里，它们在区间上沿附近买入，在下一个区间的下沿附近卖出。欧元/美元就是例子：完整区间两个系统年化都不是正的（−0.9% 和 −1.3%），天然气在两个窗口里两者也都亏钱。

这些数字也有遗漏。Turtle 入场 1,979 次，Donchian 774 次，而结果不含任何交易成本。只做多的版本也说明不了原始海龟系统交易的空头那一侧。比特币和以太坊的结果来自较短的历史，所以只覆盖很少的市场周期。

几点结论

  • 较慢的 55/20 规则在大多数市场上风险调整后表现好于 20/10，而且交易次数只有后者的大约 39%（774 次对 1,979 次）。
  • Turtle 更快的离场在 2022 年美股和 2020 年原油上限制了损失，但在 2023 年的天然气和 2014 年的欧元/美元上表现更差。
  • 两者都远非满仓（持仓天数中位数 33% 和 38%），所以在上涨市场里收益上会落后。
  • 两者都没有仓位管理或止损：回测只是一个简单的“持仓或空仓”系统，且未扣交易成本。
