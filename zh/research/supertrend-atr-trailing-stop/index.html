Supertrend、ATR 移动止损与 Chandelier Exit 回测对比

在未扣交易成本的前提下，Supertrend（SUPER-01）、ATR 移动止损（RISK-04）和 Chandelier Exit（TREND-17）完整区间的平均夏普几乎一样（0.38、0.41 和 0.40），但入场次数分别是 1,973、4,852 和 8,320 次。差别很大程度上在于它们离场后重新入场的速度。

三种止损，同一个思路

三者都是跟随价格，在价格下方若干个平均日波幅处放一条止损线，收盘跌破就离场。在本站三者都只做多：被止损后持有现金，而不是做空。结果均未扣交易成本，统计近五年（截至 2026-11-11）和完整区间（多数市场从 2010-01-04 起，比特币 2014-09-17，以太坊 2017-11-09）。

区别在细节里，而细节决定了它们交易的频率。

每条规则实际做了什么

Supertrend（SUPER-01）使用真实的日最高价、最低价和收盘价。它围绕当天的中价建立通道，宽度为平滑后平均真实波幅（指数平均，跨度 10）的 2.5 倍。下轨只升不降。收盘跌破下轨离场，收盘突破上轨才重新入场。

ATR 移动止损（RISK-04）只要收盘价高于 20 日均线就入场。止损价为入场后最高收盘价减去 2.5 倍“ATR”，并且只上移不下移。代码里的 ATR 是收盘到收盘的版本：相邻两个收盘价之差绝对值的 14 日简单平均，不含最高价、最低价和跳空。某一天的真实波幅不会小于这个涨跌幅，所以这个版本衡量出的波幅更小，止损线往往也更近。离场后，只要收盘价重新站上均线，第二天就可以再入场。

Chandelier Exit（TREND-17）同样使用 22 日的收盘到收盘 ATR。止损价为 22 日最高收盘价减去 3 倍该 ATR。当收盘价升到 22 日最低收盘价加 3 倍 ATR 之上时重新入场，门槛很低，这与它 8,320 次入场相符。

十个市场，两个窗口

每行依次为年化收益 / 夏普 / 最大回撤，先是近五年，再是完整区间，分别给出 Supertrend 和 ATR 止损，最后是持仓天数占比。

  • 美股：Supertrend 4.0% / 0.45 / −10.9%，完整区间 7.8% / 0.85 / −12.7%；ATR 止损 4.4% / 0.46 / −14.8%，完整区间 6.8% / 0.68 / −26.2%。持仓天数占 60% 和 68%。
  • 黄金：Supertrend 9.2% / 0.72 / −17.5%，完整区间 4.4% / 0.42 / −23.4%；ATR 止损 10.0% / 0.70 / −19.8%，完整区间 5.2% / 0.46 / −29.9%。52% 和 59%。
  • 白银：Supertrend 11.8% / 0.56 / −39.9%，完整区间 8.2% / 0.46 / −40.5%；ATR 止损 13.8% / 0.61 / −39.6%，完整区间 8.2% / 0.46 / −40.9%。50% 和 53%。
  • 原油：Supertrend 5.3% / 0.33 / −49.2%，完整区间 3.7% / 0.27 / −49.8%；ATR 止损 7.0% / 0.37 / −50.2%，完整区间 1.6% / 0.19 / −57.6%。51% 和 57%。
  • 天然气：Supertrend −18.9% / −0.28 / −80.6%，完整区间 −15.3% / −0.33 / −94.2%；ATR 止损 −16.7% / −0.16 / −81.0%，完整区间 −11.3% / −0.16 / −89.5%。44% 和 47%。
  • 综合大宗商品：Supertrend 3.8% / 0.35 / −29.1%，完整区间 4.4% / 0.43 / −29.1%；ATR 止损 8.4% / 0.62 / −16.9%，完整区间 5.7% / 0.51 / −29.7%。49% 和 57%。
  • 农产品：Supertrend 2.1% / 0.27 / −16.4%，完整区间 −0.0% / 0.04 / −33.4%；ATR 止损 4.1% / 0.45 / −15.9%，完整区间 1.2% / 0.17 / −41.8%。49% 和 54%。
  • 欧元/美元：Supertrend −3.0% / −0.55 / −15.5%，完整区间 −1.5% / −0.23 / −34.7%；ATR 止损 0.6% / 0.09 / −9.6%，完整区间 −1.2% / −0.17 / −35.5%。45% 和 50%。
  • 比特币：Supertrend 6.7% / 0.30 / −52.9%，完整区间 45.0% / 0.89 / −59.6%；ATR 止损 4.4% / 0.25 / −52.6%，完整区间 64.5% / 1.09 / −61.1%。50% 和 57%。
  • 以太坊：Supertrend 6.9% / 0.31 / −55.0%，完整区间 69.5% / 1.00 / −55.0%；ATR 止损 14.5% / 0.44 / −42.5%，完整区间 61.3% / 0.91 / −68.7%。48% 和 53%。

最好、最差与三者对比

Supertrend 表现最好的市场，近五年是黄金，完整区间是以太坊（夏普 1.00）；最差的是近五年的欧元/美元和完整区间的天然气（年化 −15.3%，回撤 −94.2%）。ATR 止损最好的是近五年的黄金和完整区间的比特币（夏普 1.09），最差的分别是天然气和欧元/美元。Supertrend 近五年有 8 个市场年化为正，完整区间有 7 个；ATR 止损分别是 9 个和 8 个。

直接对比，ATR 止损近五年夏普在 10 个市场中有 8 个更高（平均 0.38 对 0.25），但完整区间差距缩小到 0.41 对 0.38，Supertrend 在 4 个市场领先。Supertrend 的优势是回撤：完整区间有 9 个市场更浅（平均 −43.2% 对 −48.1%）。Chandelier 近五年平均夏普 0.42，完整区间平均 0.40。

为什么交易次数差这么多

10 个市场自 2010 年以来的入场次数：Supertrend 为 1,973，ATR 止损为 4,852，Chandelier 为 8,320。用持仓天数除以入场次数，平均每次持仓大约 Supertrend 10.9 天、ATR 止损 4.8 天、Chandelier 2.7 天。仅黄金一个市场，Chandelier 就入场了 954 次。

原因在于重新入场的规则。Supertrend 需要收盘价突破一条位于中价上方 2.5 倍 ATR 的通道；另外两个重新入场的门槛更低，所以止损之后几天内再次入场很常见。Supertrend 与 ATR 止损在“持仓还是空仓”上，中位数有 81% 的交易日一致；ATR 止损和 Chandelier 的一致比例是 87%。

每个市场的最差日历年

在每个市场自己最差的完整日历年里，三者无一例外都跑赢了市场；这些年份里市场平均下跌 42.8%，而 Supertrend、ATR 止损和 Chandelier 的平均结果分别是 −10.0%、−15.9% 和 −3.0%。美股 2022 年市场下跌 18.2%，三者分别亏 5.1%、4.6% 和 2.8%。

2020 年的原油（−67.8%）展示了差距：ATR 止损盈利 2.4%，Chandelier 盈利 12.4%，Supertrend 却亏 28.2%。2023 年的天然气（−64.0%）对三者都不友好：−42.7%、−52.3% 和 −17.4%。2018 年的以太坊（−82.4%）最特别：Supertrend 盈利 47.8%，Chandelier 盈利 40.8%，ATR 止损却亏 38.2%。这一年处于每个市场前三年的默认参数阶段，且 Supertrend 的收益中仅 1 月份就有 30.3%。

这些数字说明不了什么

首先是成本。ATR 止损和 Chandelier 的交易远比 Supertrend 频繁（入场 4,852 次和 8,320 次，对比 1,973 次），而这些摩擦都不在结果里。平均持仓 4.8 天和 2.7 天，也意味着这两个更像快速过滤器，而不是跟随趋势。

其次，三个看上去平均水平非常接近的结果，在不同市场上可能差别很大；比特币和以太坊的历史也不长，分别始于 2014-09-17 和 2017-11-09。这些都不能保证下一段行情会怎样。

几点结论

  • 三种止损的平均夏普几乎一样，差别在于交易频率和回撤。
  • Supertrend 交易最少，完整区间回撤在 10 个市场中有 9 个比 ATR 止损更浅。
  • ATR 止损里的“ATR”是收盘到收盘的版本，所以它的止损线更近、交易更快。
  • 三者在各市场最差日历年里都减少了亏损，但多数情况下仍然亏钱。
