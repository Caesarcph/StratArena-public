未来数据改写过去：日历规则修正审计

十一项同输入旧新规则比较，与更早的 176 条已发布曲线差异严格区分。

ReproducibilityCostsFixed sample

假设：扩展历史不应改写因果目标

当输入前缀与配置不变时，添加 t 之后的观测不应改写截至 t 已确定的目标。下载数据末行不能证明月份结束。本篇用相同输入比较保留的旧实现与修正实现，不以最高收益选择规则。

替代时序规则，并非等价实现

CAL-01 的 weekday-calendar-month-turn-v2 用预先可知的周一至周五计数替代整月未来下载行数，不处理交易所节假日；周末观测仍可落入连续窗口。这是明示的规则变化。FACTOR-05 的 monthly-prior-observation-v2 在新月首个实际观测时使用上一已完成观测决策，随后由引擎应用正常的一行延迟。未完整月份的末行不再触发调仓，交易月末时序也发生变化。

不能混淆的两个分母

十一项同输入修正包括 CAL-01 的十个市场与标为 SPY 的 FACTOR-05 组合。另有 176 条曲线与更早发布快照 commit caa1d89cecb147b9acb1a99a52bebba6ac436fd6（索引 71c8e5981c86271890b0cbbe84dea0b6b5f8770694f882d6821784ccf1977a6c）不同。共同日期归一化对比可能混合供应商修订、截止日期与实现变化，不能称为 176 个已证实代码缺陷，也不能减去十一后推断其余原因。旧 sameInputAccountingCorrections 字段属于另一项核算对比。

证伪与复现边界

上述日历结果与相等输入标识是保留的历史审计记录。资料包的 72 情景成本回放仅检查修正表在包中的哈希一致性，不独立复核这些日历结果或旧新输入标识。逐运行公共收益核算复现需另行遵循各归档 manifest 的复现说明；该独立过程仍不等于使用原始私有输入重建决策。保留的发布证明记录十一项重算与 565 项未变证明复用；局部刷新没有独立重跑保留的稳健性及敏感性研究。合成前缀测试可覆盖周末、节假日、换月、不完整月末，但不能代替原始输入重算。

python -B -m unittest discover -s tests -p test_calendar_causality.py
python -B -m unittest discover -s tests -p test_multi_factor_calendar.py

在源码副本中执行以上实现测试。若输入前缀不变却改变先前目标，因果性即被证伪；输入哈希变化则不能称同输入比较。工作日近似并非经过验证的交易所假日日历，本审计也不证明 MT5 一致性。

固定证据、规则与复现

六个原始试点为 MR-01（RSI 均值回归）、MR-16（康纳斯 RSI）、TURTLE-01（海龟交易法）、TREND-14（线性回归通道）、RP-01（目标波动率）和 RISK-04（移动止损策略）。RP-01 不是另一项风险平价组合。保留全部 18 个策略市场组合、72 个费率情景；提取表格前即固定样本，但这仍是回顾性研究，不是前瞻预注册。

成本及跨市场面板使用 2021-11-05 至 2026-11-05，SPY/GLD 各有 1,255 个收盘观测，BTC-USD 有 1,827 个；收益区间数量各少一。日历审计另用各运行的完整原生日期。网站每日更新不会替换此固定证据。
