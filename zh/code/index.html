广告

文件怎么用

  • Python 文件可以单独运行：装好 pandas、numpy 和 yfinance，然后带上代码或一份日线 CSV 运行即可。
  • Pine 文件：打开 TradingView 的 Pine 编辑器，粘贴脚本，添加到图表，使用日线周期。
  • 以 Python 文件为准。Pine 版本是人工改写的，我们没有在 TradingView 里实际编译过，指标平滑方式上可能有细微差别。
  • 当天收盘决定的仓位，赚的是下一个交易日的收益。结果未扣除交易成本。

可自由使用和修改。按现状提供，仅供研究和学习。历史回测不代表未来收益，不构成投资建议。
