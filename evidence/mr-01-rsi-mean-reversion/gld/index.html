What this implementation actually does

Accounting assumptions

Each day's return uses the preceding day's target allocation. The new target is decided at the current close. This is a synthetic close-based model, not a measured execution price.

Price cutoff
Exclude the current UTC date and later; intentionally delayed, not an exchange calendar
Decision
target[t] is evaluated using observations through close t
Trading costs (bp)
0
Execution assumption
Synthetic daily allocations, not broker orders or next-open fills
Return interval
effectivePosition[t] = target[t-1]; earns close-to-close return (t-1,t]
Allocation changes
abs(target[t] - target[t-1]) at close t; initial target is zero
Walk-forward transition
Selected candidate keeps its hypothetical rule state; new target starts at the first test close
