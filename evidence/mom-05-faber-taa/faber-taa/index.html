1. Download a complete bundle

Download the Python tool above and run this command. It checks shared objects and creates replay.zip; no repository clone is needed.

python a14849c2a59ee9f76ff7a7fd7c8d2388757fa9618952a13e051fb8bbfb9481e2.py https://quantarenas.com/data/evidence/runs/1a5a93da833613679db3088060cb5b2c1949aed1e2804f85acaa445c552d3f84/manifest.json --bundle replay.zip

2. Replay the arithmetic

Extract replay.zip and run from its folder with Python. This verifies recorded weights, contributions and equity using only the standard library; it does not recalculate strategy decisions.

python scripts/replay_evidence.py data/evidence/runs/1a5a93da833613679db3088060cb5b2c1949aed1e2804f85acaa445c552d3f84/manifest.json

3. Obtain and compare inputs

In the extracted bundle, use the recorded Python version and install the pinned dependencies. This command downloads provider inputs privately and reports inputHashMatches. Only a matching hash supports exact recomputation; revised provider data may not match. You may instead supply an original matching snapshot as private-input.json.

python -m pip install -r requirements-lock.txt
python scripts/recompute_evidence.py data/evidence/runs/1a5a93da833613679db3088060cb5b2c1949aed1e2804f85acaa445c552d3f84/manifest.json --fetch-input private-input.json

4. Recompute the original strategy

With the exact original input snapshot and recorded dependencies, run the archived strategy and walk-forward selection. Original provider inputs are not public. Revised downloads fail the input-hash match and cannot establish exact reproduction.

python scripts/recompute_evidence.py data/evidence/runs/1a5a93da833613679db3088060cb5b2c1949aed1e2804f85acaa445c552d3f84/manifest.json --input private-input.json
Accounting assumptions

Each day's return uses the preceding day's target allocation. The new target is decided at the current close. This is a synthetic close-based model, not a measured execution price.

Cash residual
1 - sum(weights); residual may exceed one or be negative for shorts/leverage.
Decision
Target weights use bars through close t; previous targets earn (t-1,t].
Trading costs (bp)
0
Execution assumption
Synthetic daily target allocations, not broker orders or fills; financing/borrow costs omitted.
Synthetic rebalance turnover
Sum(abs(target[t] - target[t-1]*(1+assetReturn[t])/(1+grossReturn[t]))); one-way risky notional at close t after returns, divided by pre-trade equity.
Return interval
Sum of previous target weight times each asset close-to-close return; cash return is zero.
Target weight change
Sum(abs(target[t] - target[t-1])); changes in rule targets only.
Walk-forward transition
Candidate retains its own hypothetical state; first test return uses previous published target.
