策略分析

分析 ### 2.1 核心策略概念 这是一个**Tick级突破剥头皮策略**，基于价格在新K线开盘后的快速突破进行交易。 **核心逻辑**: 1. 每根新K线开始时，记录开盘价格到变量 `a1` 2. 在K线周期内，实时监控价格变化 3. 当价格上涨超过 `DELTA` (30点) → 触发**做空** 4. 当价格下跌超过 `DELTA` (30点) → 触发**做多** **注意**: 这是一个**逆向策略** - 价格突破后反向交易，假设突破会回落。 ### 2.2 入场条件 **做空条件**: **做多条件**: **入场特征**: - 使用 `OnTimer()` 而非 `OnTick()`，每秒检查一次 - 每根K线只交易一次 (`br` 标志控制) - 突破方向与交易方向相反（逆向交易） ### 2.3 出场条件 | 参数 | 值 | 说明 | | **止损(SL)** | 100点 | 固定止损 | | **止盈(TP)** | 700点 | 固定止盈 | | **盈亏比** | 7:1 | 极高盈亏比 | **止损止盈设置**: ### 2.4 风险管理 **手数管理**: **其他参数**:

优势

  • 代码简洁清晰
  • 仅137行代码，逻辑直观
  • 无复杂依赖，易于理解和修改
  • 新K线突破策略
  • 利用新K线开盘后的波动特征
  • 每根K线只交易一次，避免过度交易
  • 固定止损风控
  • 100点止损相对合理
  • 不会无限亏损
  • 魔数管理
  • 使用MAGIC_NUMBER标识订单
  • 便于多EA共存管理

劣势

  • 逆向交易逻辑存疑 🔴
  • 突破后反向交易假设回落
  • 强趋势行情会持续亏损
  • 缺乏趋势确认机制
  • 止盈设置不合理 🔴
  • TP=700点，盈亏比7:1
  • 逆向策略需要高胜率，但此策略可能不足30%
  • 止盈难以触及，多数交易可能止损出场
  • 缺乏持仓管理 ⚠️
  • 不检查现有持仓数量
  • 无最大持仓限制
  • 可能与手动交易或其他EA冲突
  • DELTA参数固定 ⚠️
  • 30点阈值对高波动品种可能太小
  • 对低波动品种可能太大
  • 缺乏自适应性
  • 无时间过滤 ⚠️
  • 没有交易时段限制
  • 在低流动性时段可能滑点严重
