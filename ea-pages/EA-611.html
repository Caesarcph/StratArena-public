策略分析

分析 ### 2.1 核心策略概念 这是一个基于**MACD指标的趋势跟踪策略**，具有**动态仓位管理**特性。EA使用非常规的MACD参数（Fast=30, Slow=500, Signal=36），通过零线穿越和信号线交叉双重机制产生交易信号。 **核心特点**: 1. **超慢速MACD参数**: Slow=500周期极长，过滤短期噪音 2. **动态仓位计算**: 基于账户盈亏动态调整手数 3. **双向信号机制**: 零线穿越 + 信号线交叉 4. **反向平仓开仓**: 信号反转时自动平掉反向仓位 ### 2.2 入场条件 **做多信号 (UpSignal)**: 1. **零线穿越**: `Ind[0] < 0 && Ind[1] > 0` (MACD从负穿越到正) 2. **或信号线交叉**: `Ind[1] > 0 && Sig[0] > Sig[1] && Sig[1] < Sig[2]` (在零线上方，信号线金叉) **做空信号 (DnSignal)**: 1. **零线穿越**: `Ind[0] > 0 && Ind[1] < 0` (MACD从正穿越到负) 2. **或信号线交叉**: `Ind[1] < 0 && Sig[0] < Sig[1] && Sig[1] > Sig[2]` (在零线下方，信号线死叉) **信号逻辑分析**: ### 2.3 出场条件 **止盈出场**: - 固定止盈: TP=2200点 (默认) - 计算: `takeprofit = request.price + TP*_Point` (做多) - 盈亏比: 取决于SL设置 **止损出场**: - 默认止损: SL=0 (无止损) - 风险: ⚠️⚠️ 无止损保护，依赖信号反转出场 **信号反转出场**: - 当反向信号出现时，自动平掉当前持仓并开反向仓位 - 通过`PositionSelect()`检测现有持仓 - 计算需要开仓的手数 = 新手数 -/+ 现有手数 ### 2.4 风险管理 **动态仓位管理**: **仓位逻辑特点**: - **初始资金**: 默认Deposit=5000 - **风险参数**: Risk=3 (手数=账户权益×Risk/初始资金) - **盈利加仓**: 账户盈利时手数增加 (复利效应) - **亏损减仓**: 账户亏损时手数减少 (风险控制) **交易执行保护**: - `OrderCheck()`预检查保证金 - 保证金不足时自动减少手数 - 多种错误码处理与重试机制 - 滑点保护设为当前点差值

优势

  • 完善的错误处理机制
  • 预检查保证金
  • 多种错误码分类处理
  • 自动重试与手数调整
  • 动态仓位管理
  • 基于账户盈亏自动调整手数
  • 盈利加仓实现复利效应
  • 亏损减仓控制风险敞口
  • 新K线检测机制
  • 函数避免过度交易
  • 只在新K线开盘时检测信号
  • 减少不必要的计算
  • 双向信号机制
  • 零线穿越 + 信号线交叉双重确认
  • 提高信号可靠性

劣势

  • 无止损保护: SL=0默认，极度危险
  • MACD参数极端: Slow=500信号严重滞后
  • 止盈过大: TP=2200不切实际
  • Deposit硬编码: 应设为可配置参数
  • 无趋势过滤: 震荡市场易亏损
