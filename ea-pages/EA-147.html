策略分析

分析 ### 2.1 核心策略概念 这是一个**夜间剥头皮策略**，主要特点： 1. **交易时段限制**: 仅在21:00-06:00时段交易（夜间时段） 2. **超买超卖交易**: 使用Stochastic指标的超买超卖水平 3. **固定止损止盈**: SL=40点, TP=20点（风险比2:1） 4. **动态仓位管理**: 基于账户自由保证金计算仓位 ### 2.2 入场条件 **买入条件**: 1. Stochastic主线下穿超卖线（30）下方 2. 当前时段在21:00-06:00之间 3. 当前无持仓 **卖出条件**: 1. Stochastic主线上穿超买线（70）上方 2. 当前时段在21:00-06:00之间 3. 当前无持仓 ### 2.3 出场条件 **止盈**: 20点（5位报价为200点） **止损**: 40点（5位报价为400点） 出场仅通过SL/TP触发，无追踪止损或其他出场逻辑。 ### 2.4 风险管理 #### 仓位计算公式 **仓位范围**: 0.1 - 5.0手 **计算逻辑**: 自由保证金每10000美元增加1手 #### 止损/止盈设置 | 参数 | 默认值 | 5位报价实际值 | 风险比 | | StopLoss | 40 | 400点 | - | | TakeProfit | 20 | 200点 | - | | **盈亏比** | - | - | **1:0.5 (不利)** |

Summary

优势

  • 交易时段限制: 仅在流动性较低的夜间交易，避免重大新闻影响
  • 固定止损: 每笔交易都有明确止损，不会无限亏损
  • 动态仓位: 根据账户资金自动调整仓位大小
  • 代码简洁: 179行代码，结构清晰，易于理解和修改

劣势

  • 盈亏比不利: 止损是止盈的2倍，需要67%胜率才能盈利
  • 逆势策略: 超买超卖信号可能是趋势延续而非反转
  • 无追踪止损: 价格有利时未锁定利润
  • 时段硬编码: 无法适应不同经纪商的服务器时间
  • 无多重确认: 仅依赖单一指标，缺乏信号确认
