摘要

该EA基于六种可选信号策略（MACD、支点、支撑阻力、i_Trend+RSI、i_Trend+RSI+随机指标、i_Trend+RSI+随机指标+MFI）开仓，并采用渐进加仓方案：前N次加仓手数翻倍，之后以1.5倍递增。它在固定点距处加仓并应用简单追踪止损，属于信号驱动的马丁格尔式加仓系统。

策略分析

策略概念：该EA是一个多策略信号驱动的加仓系统，用户可从六种信号类型中选择一种作为入场依据。入场条件：首次入场依赖选定信号（如MACD增长、价格突破支点、RSI与i_Trend共振等），后续加仓在价格向不利方向移动指定点数（Pips参数）后且信号仍然有效时触发。出场条件：首次开仓设置止盈，加仓后重新计算加权平均止盈；止损仅在最后一次加仓时设置；另有简单追踪止损功能。仓位管理：采用马丁格尔式递增，前DoubleCount次加仓手数乘以2，之后乘以1.5，这导致持仓量在连续加仓后迅速膨胀。资金管理：当Lots为0时，根据账户自由保证金和MaximumRisk参数计算手数，但公式固定除以1000，缺乏对杠杆和品种价值的动态适配。CSigi_TrendRSISto类存在严重Bug：m_buy被错误地赋值为卖出条件，m_sell从未被赋值，导致该信号模式完全失效。

Summary

This EA opens positions based on one of six selectable signal strategies (MACD, Pivot, Support/Resistance, i_Trend+RSI, i_Trend+RSI+Stochastic, i_Trend+RSI+Stochastic+MFI) and employs a progressive lot-sizing scheme that doubles the lot for the first N additions and then uses 1.5x multiplier thereafter. It adds to positions at fixed pip intervals and applies a simple trailing stop, making it a signal-based martingale-style grid-addition system.

Strategy Analysis

Strategy concept: This EA is a multi-strategy signal-driven position-adding system where the user selects one of six signal types as the entry basis. Entry conditions: The first entry depends on the selected signal (e.g., MACD rising, price crossing Pivot, RSI and i_Trend confluence), while subsequent additions trigger after price moves adversely by a specified pip distance (Pips parameter) and the signal remains valid. Exit conditions: The initial position uses a take-profit; after additions, a weighted average take-profit is recalculated; stop-loss is only set on the final addition; a simple trailing stop is also available. Position sizing: Uses martingale-style progression — the first DoubleCount additions multiply lots by 2, then by 1.5 thereafter, causing position size to balloon rapidly with consecutive additions. Money management: When Lots is 0, lot size is calculated from account free margin and MaximumRisk, but the formula divides by a fixed 1000 without dynamically adapting to leverage or symbol tick value. A critical bug exists in CSigi_TrendRSISto: m_buy is incorrectly assigned the sell condition and m_sell is never assigned, making that signal mode completely non-functional.

优势

  • 支持六种信号策略可选，灵活度高
  • 使用面向对象的CTradeSignals基类架构，信号模块扩展性好
  • 包含止损止盈检查和最小止损距离验证，有一定安全机制
  • 追踪止损功能可在盈利后锁定利润
  • 止损仅在最终加仓时设置，结合加权平均止盈，加仓阶段有明确出场目标

劣势

  • CSigi_TrendRSISto类存在严重Bug：m_buy被赋值为卖出条件，m_sell未被赋值，该信号模式完全失效
  • 马丁格尔式2倍加仓手数在连续亏损时导致仓位指数级增长，风险极高
  • 止损仅在最后一次加仓时设置，中间加仓阶段无止损保护，面临无限风险敞口
  • 资金管理公式固定除以1000，未考虑品种tick value和杠杆，不同品种上计算不准确
  • Pos.Select(_Symbol)仅检查当前品种是否有持仓，不支持多品种同时运行
  • 依赖自定义指标i_Trend和Pivot Lines TimeZone，这些指标需额外安装，可移植性差

改进建议

  • 修复CSigi_TrendRSISto中m_buy赋值Bug，并正确赋值m_sell变量
  • 为每次加仓设置止损而非仅最后一次，避免中间加仓无保护
  • 资金管理公式应使用SymbolInfoDouble(_Symbol,SYMBOL_TRADE_TICK_VALUE)动态计算手数
  • 限制最大总持仓手数或最大亏损金额，增加全局风险控制
  • 增加点差过滤和新闻事件过滤，避免高成本时段交易

Strengths

  • Supports six selectable signal strategies offering high flexibility
  • Uses object-oriented CTradeSignals base class architecture with good extensibility for signal modules
  • Includes stop-loss/take-profit validation against minimum stop levels providing safety checks
  • Trailing stop feature can lock in profits after positions move favorably
  • Clear exit targets for additions via weighted average take-profit calculation

Weaknesses

  • Critical bug in CSigi_TrendRSISto: m_buy is assigned the sell condition and m_sell is never assigned, making this signal mode completely non-functional
  • Martingale-style 2x lot doubling causes exponential position growth during consecutive losses, creating extreme risk
  • Stop-loss is only set on the final addition; intermediate additions have no stop-loss protection, exposing unlimited risk
  • Money management formula divides by a fixed 1000 without considering tick value or leverage, producing inaccurate sizing across instruments
  • Pos.Select(_Symbol) only checks for positions on the current symbol, preventing multi-symbol concurrent operation
  • Depends on custom indicators i_Trend and Pivot Lines TimeZone that must be installed separately, reducing portability

Improvements

  • Fix the m_buy assignment bug in CSigi_TrendRSISto and correctly assign m_sell variable
  • Set stop-loss for each addition instead of only the last one to avoid unprotected intermediate positions
  • Use SymbolInfoDouble(_Symbol,SYMBOL_TRADE_TICK_VALUE) in the money management formula for dynamic lot calculation
  • Add maximum total lot size or maximum drawdown limits for global risk control
  • Add spread filter and news event filter to avoid trading during high-cost periods

风险评估 / Risk Assessment

总体 / Overall:DANGEROUS

风险点

  • 马丁格尔2倍加仓导致仓位指数级增长，可能在强趋势中爆仓
  • 中间加仓无止损保护，最大单方向加仓10次，风险敞口巨大
  • CSigi_TrendRSISto信号Bug可能在实盘中产生错误交易方向
  • 依赖自定义指标，指标缺失时Init返回false但EA可能以默认信号继续运行
  • 止损2500点过宽且仅在最后加仓设置，实际保护效果微弱

Risk Assessment

Overall:DANGEROUS

Risk Points

  • Martingale 2x lot doubling causes exponential position growth that can blow the account in strong trends
  • Intermediate additions have no stop-loss protection; with up to 10 additions in one direction, risk exposure is enormous
  • CSigi_TrendRSISto signal bug may produce incorrect trade direction in live trading
  • Depends on custom indicators; if missing, Init returns false but EA initialization could proceed with unintended behavior
  • 2500-point stop-loss is extremely wide and only set on the final addition, providing minimal actual protection
