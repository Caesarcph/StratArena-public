摘要

一个多策略马丁格尔EA，基于六种可选信号类型之一（MACD、支点、支撑阻力、i_Trend+RSI、i_Trend+RSI+随机指标、i_Trend+RSI+随机指标+MFI）开仓。对亏损头寸以2倍/1.5倍递增手数加仓，并包含简单的移动止损功能。

策略分析

该EA的核心策略是基于多种技术指标信号开仓，包括MACD趋势、支点水平、支撑阻力突破以及i_Trend指标与RSI、随机指标和MFI的组合。入场条件取决于所选信号类型，例如MACD信号为柱值上升则买入、下降则卖出。出场条件依赖于初始止盈/止损设置以及移动止损。仓位管理采用马丁格尔式加仓，当价格朝不利方向移动指定点数后加仓，前DoubleCount次加仓手数乘以2，之后乘以1.5，最大加仓次数受MaxCount限制。资金管理支持固定手数或基于可用保证金和风险比例的动态手数计算。加仓时重新计算加权平均止盈价，最后一笔加仓时才设置止损，试图通过摊薄成本实现整体盈利。

Summary

A multi-strategy Martingale EA that opens positions based on one of six selectable signal types (MACD, Pivot, Support/Resistance, i_Trend+RSI, i_Trend+RSI+Stochastic, i_Trend+RSI+Stochastic+MFI). It adds to losing positions with increasing lot sizes using a 2x/1.5x multiplier scheme, and includes a simple trailing stop feature.

Strategy Analysis

The core strategy opens positions based on one of six selectable technical indicator signal types, including MACD trend, Pivot levels, Support/Resistance breakouts, and combinations of i_Trend with RSI, Stochastic, and MFI. Entry conditions vary by signal type; for example, MACD signals buy when the histogram rises and sell when it falls. Exit conditions rely on initial take-profit/stop-loss settings and a simple trailing stop. Position sizing employs a Martingale-style averaging-down approach: when price moves against the position by a specified number of pips, the EA adds positions with lot multipliers of 2x for the first DoubleCount additions, then 1.5x thereafter, capped by MaxCount. Money management supports fixed lots or dynamic lot sizing based on free margin and a risk percentage. When adding positions, a weighted average take-profit is recalculated, and stop-loss is only set on the final addition, attempting to profit by averaging down the entry price.

优势

  • 支持六种不同的信号策略，灵活性高
  • 使用面向对象的信号类继承架构，代码结构清晰
  • 加仓时重新计算加权平均止盈价，逻辑合理
  • 包含止损和止盈的距离检查，符合交易所最小止损要求
  • 手数规范化函数处理了最小手数、手数步长和最大手数限制

劣势

  • 马丁格尔加仓策略风险极高，在极端行情中可能爆仓
  • 仅在最后一笔加仓时设置止损，中间加仓均无止损保护
  • CSigi_TrendRSISto类中第743行存在严重bug：卖出信号覆盖了买入信号
  • 依赖自定义指标i_Trend和Pivot Lines TimeZone，部署困难
  • MaxCount为-1时无限制加仓，可能导致无限亏损
  • 没有点差过滤，在高点差环境下加仓成本增加
  • 仅检查单品种持仓，不支持多品种同时运行

改进建议

  • 修复CSigi_TrendRSISto中第743行m_buy应为m_sell的关键bug
  • 为每笔加仓设置独立止损，而非仅在最后一笔加仓设置
  • 添加点差过滤和最大回撤限制，防止极端行情下过度加仓
  • 移除对自定义指标的依赖，将i_Trend和Pivot逻辑内嵌到EA中
  • 添加整体仓位止损（账户级别最大亏损限制）作为安全网

Strengths

  • Supports six different signal strategies, offering high flexibility
  • Uses an OOP signal class hierarchy with clean inheritance structure
  • Recalculates weighted average take-profit when adding positions, which is logically sound
  • Includes stop-loss and take-profit distance validation against broker minimum stop levels
  • Lot normalization function properly handles minimum lot, lot step, and maximum lot constraints

Weaknesses

  • Martingale averaging-down strategy carries extreme risk; can blow the account in strong trends
  • Stop-loss is only set on the final addition; intermediate positions have no stop-loss protection
  • Critical bug in CSigi_TrendRSISto class line 743: sell signal overwrites the buy signal (m_buy assigned instead of m_sell)
  • Depends on custom indicators i_Trend and Pivot Lines TimeZone, making deployment difficult
  • MaxCount=-1 allows unlimited position additions, potentially leading to unlimited losses
  • No spread filter; adding positions in high-spread environments increases costs significantly
  • Only checks positions for a single symbol; cannot run multiple symbols simultaneously

Improvements

  • Fix the critical bug on line 743 where m_buy should be m_sell in CSigi_TrendRSISto
  • Set individual stop-loss for each added position instead of only on the final one
  • Add spread filter and maximum drawdown limit to prevent excessive averaging down in extreme markets
  • Remove dependency on custom indicators by embedding i_Trend and Pivot logic directly into the EA
  • Add an account-level maximum loss limit as a safety net for the overall position

Risk Assessment

Overall:DANGEROUS

Risk Points

  • Martingale averaging-down can blow the account in a sustained one-directional market move
  • Only the last addition has a stop-loss; all intermediate positions are fully exposed to risk
  • MaxCount=-1 permits unlimited position additions with no safety cap
  • Default stop-loss of 2500 points is extremely wide, offering minimal practical protection
  • CSigi_TrendRSISto has a copy-paste bug where the sell signal overwrites the buy signal
