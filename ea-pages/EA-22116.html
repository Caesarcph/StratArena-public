摘要

该EA基于MA_Rounding_Candle自定义指标进行交易，该指标对平滑移动均线应用取整系数并从取整后的K线颜色生成买卖信号。它具有自适应资金管理功能，在连续亏损后减小仓位，并对多头和空头使用独立的魔术编号。

策略分析

策略概念基于MA_Rounding_Candle指标，该指标将移动均线进行取整处理后生成K线形态信号。入场条件为：当指标缓冲区值为2时产生买入信号（如果前一个值不为2则确认新信号），当值为0时产生卖出信号（如果前一个值不为0则确认新信号）。出场条件包括：买入信号触发时平掉空头仓位，卖出信号触发时平掉多头仓位，同时设置了固定点数的止损和止盈。仓位管理采用独立的多空魔术编号，允许分别控制多空方向的开关。资金管理是此EA的核心特色——通过BuyTradeMMRecounterS和SellTradeMMRecounterS函数，根据最近N笔交易中亏损交易的数量来调整仓位大小，在连续亏损时将仓位缩小到SmallMM_比例，正常交易时使用MM比例。这种自适应资金管理机制可以有效控制回撤。

Summary

This EA trades based on the MA_Rounding_Candle custom indicator, which applies a rounding coefficient to a smoothed moving average and generates buy/sell signals from the rounded candle colors. It features adaptive money management that reduces position size after consecutive losses and uses separate magic numbers for long and short positions.

Strategy Analysis

The strategy concept is based on the MA_Rounding_Candle custom indicator, which applies a rounding coefficient to a smoothed moving average and generates candlestick-style signals from the rounded values. Entry conditions: when indicator buffer value equals 2, a buy signal is generated (confirmed if previous value was not 2); when value equals 0, a sell signal is generated (confirmed if previous value was not 0). Exit conditions include closing opposite positions on signal reversal and using fixed StopLoss and TakeProfit in points. Position management uses separate magic numbers for long and short positions, allowing independent control of each direction. Money management is the core feature — the BuyTradeMMRecounterS and SellTradeMMRecounterS functions adjust position size based on the number of losing trades among the last N trades, reducing exposure to SmallMM_ ratio during losing streaks and using MM ratio during normal trading. This adaptive money management mechanism helps effectively control drawdowns during adverse market conditions.

优势

  • 自适应资金管理：根据近期交易亏损情况动态调整仓位大小，亏损时自动缩小仓位至SmallMM_比例，有效控制回撤
  • 多空独立管理：使用独立的魔术编号和独立的MM参数，可以分别控制多空方向的交易行为和风险管理
  • 信号防重复机制：通过比较当前和前一个指标值避免重复开仓，且使用IsNewBar检查确保每根K线只计算一次信号
  • 支持多种平滑算法：提供10种不同的均线平滑方法（SMA/EMA/JJMA/JurX/T3等），策略灵活性高
  • 默认2:1盈亏比：TakeProfit为StopLoss的两倍（2000 vs 1000点），追求正期望值的交易系统

劣势

  • 依赖自定义指标：EA依赖外部MA_Rounding_Candle指标，如果指标文件缺失或版本不匹配将无法正常运行
  • 无点差过滤：EA没有点差检查机制，在高点差环境下可能造成不必要的入场成本，尤其对短线交易不利
  • 止损止盈为固定点数：使用固定点数的止损止盈而非基于ATR等动态指标，无法适应不同波动率的市场环境
  • MMMode默认为LOT：默认资金管理模式为固定手数而非基于账户余额或自由保证金的动态计算，可能未充分利用自适应MM的优势
  • 无新K线强制检查：当SignalBar为0时跳过IsNewBar检查，可能在同一根K线内反复计算信号导致逻辑混乱

改进建议

  • 增加点差过滤：在入场前检查当前点差是否超过阈值，避免在高点差时段开仓
  • 使用ATR动态止损止盈：将固定点数的止损止盈替换为基于ATR的动态计算，更好地适应市场波动率变化

Strengths

  • Adaptive money management: dynamically adjusts position size based on recent trade losses, automatically reducing exposure to SmallMM_ ratio during drawdowns, effectively controlling risk
  • Independent long/short management: uses separate magic numbers and independent MM parameters for each direction, allowing granular control over trading behavior and risk per direction
  • Signal deduplication: prevents duplicate entries by comparing current and previous indicator values, and uses IsNewBar check to ensure signals are calculated only once per bar
  • Supports 10 smoothing algorithms: offers multiple MA methods (SMA/EMA/JJMA/JurX/T3/VIDYA/AMA etc.), providing high strategy flexibility
  • Default 2:1 reward-to-risk ratio: TakeProfit is twice StopLoss (2000 vs 1000 points), pursuing a positive expectancy trading system

Weaknesses

  • Depends on custom indicator: EA relies on external MA_Rounding_Candle indicator; missing or mismatched indicator file will cause runtime failure
  • No spread filter: EA lacks spread checking, potentially causing excessive entry costs in high-spread environments, especially detrimental for shorter-term trading
  • Fixed SL/TP in points: uses fixed point-based stop loss and take profit rather than dynamic ATR-based levels, unable to adapt to varying market volatility
  • MMMode defaults to LOT: default money management mode is fixed lot rather than dynamic calculation based on account balance or free margin, potentially underutilizing the adaptive MM feature
  • No forced new bar check: when SignalBar is 0, the IsNewBar check is skipped, potentially causing repeated signal calculations within the same bar and logical confusion

Improvements

  • Add spread filter: check current spread against a threshold before entry, avoiding opening positions during high-spread periods
  • Use ATR-based dynamic SL/TP: replace fixed point-based stop loss and take profit with ATR-based dynamic calculation to better adapt to changing market volatility

  • SignalBar=0 skips IsNewBar check, potentially causing repeated signal calculation within the same bar
