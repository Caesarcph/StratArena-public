摘要

该EA是一个基于时段的突破剥头皮策略，通过比较两个偏移K线的开盘价在特定交易时间产生买卖信号。它在亏损后采用马丁格尔式加仓倍增手法，并使用硬编码的余额-手数对照表进行比例仓位管理。仓位通过止盈、止损或最大持仓时间过滤器平仓。

策略分析

策略概念基于两根不同偏移K线开盘价的差值来判断价格动量方向：当第二根K线开盘价减去第一根K线开盘价超过Delta_L个点时开多，反之超过Delta_S个点时开空。入场条件严格限定在每日TradeTime指定的整点小时，且仅在没有持仓时开仓。出场条件包括预设的止盈和止损，以及最大持仓时间MaxOpenTime（以小时计）的超时强制平仓。仓位管理采用了典型的马丁格尔策略：当全局变量记录的余额大于当前余额（即上一笔交易亏损）时，手数乘以BigLotSize倍数，且OneMult参数控制是否仅对首笔加仓还是逐笔递增加仓。资金管理使用了一个超过1000行的硬编码余额-手数阶梯对照表，将账户余额映射到具体手数，而非使用动态公式计算，这种方式极其僵化且缺乏灵活性。

Summary

This EA is a time-based breakout scalper that compares open prices of two shifted bars to generate buy/sell signals at a specific trading hour. It incorporates a Martingale-style lot multiplication after losing trades and a rigid balance-to-lot lookup table for proportional sizing. Positions are closed by take-profit, stop-loss, or a maximum holding time filter.

Strategy Analysis

The strategy concept is based on comparing the open prices of two bars at different shifts to determine price momentum direction: a buy signal triggers when bar2 open minus bar1 open exceeds Delta_L points, and a sell signal triggers when bar1 open minus bar2 open exceeds Delta_S points. Entry is strictly limited to the specific hour set by TradeTime each day, and only when no position exists. Exit conditions include preset take-profit and stop-loss levels, plus a maximum holding time filter (MaxOpenTime in hours) that forcibly closes positions. Position sizing employs a classic Martingale approach: when the globally stored balance exceeds the current balance (indicating a prior loss), the lot size is multiplied by BigLotSize, with the OneMult parameter controlling whether multiplication applies to only the first recovery trade or cascades across subsequent trades. Money management uses a hardcoded balance-to-lot lookup table spanning over 1000 lines, mapping account balances to specific lot sizes rather than using a dynamic formula, which is extremely rigid and inflexible.

优势

  • 策略逻辑简洁明了，信号生成条件清晰，易于理解和调试
  • 设有最大持仓时间过滤器，防止长期套牢
  • 使用CSymbolInfo等标准库类进行价格规范化和止损级别校验，确保订单合规
  • 仅允许每日特定时段交易，减少了噪音信号的干扰

劣势

  • 马丁格尔式加仓策略在连续亏损时会指数级放大风险，可能导致爆仓
  • LotSize函数使用超过1000行硬编码if语句替代简单公式，代码极度冗余且不可维护
  • SignalOpenSell函数存在不可达代码（第190行return(false)永远不会执行）
  • 止损远大于止盈（空头SL:TP比约8.3:1），需要极高胜率才能盈利
  • 使用全局变量持久化交易状态，在终端重启或崩溃时可能导致状态不一致

改进建议

  • 将LotSize函数替换为简单的数学公式，如 lot = floor((Balance - 300) / 273.58 * 0.01 + 0.01)，消除千行冗余代码
  • 移除马丁格尔加仓逻辑或加入最大手数和最大连续亏损次数限制，防止账户爆仓
  • 修复SignalOpenSell中的不可达代码，并添加点差过滤和滑点保护

Strengths

  • Strategy logic is simple and clear with well-defined signal generation conditions, easy to understand and debug
  • Maximum holding time filter prevents prolonged exposure in losing positions
  • Uses standard MQL5 Trade library classes for price normalization and stop-level validation, ensuring order compliance
  • Trading restricted to a specific hour each day reduces noise signal interference

Weaknesses

  • Martingale lot multiplication exponentially amplifies risk during consecutive losses, potentially leading to account blowup
  • LotSize function uses over 1000 lines of hardcoded if-statements instead of a simple formula, making code extremely redundant and unmaintainable
  • SignalOpenSell contains unreachable code (line 190 return(false) never executes due to prior return)
  • Stop-loss far exceeds take-profit (short SL:TP ratio ~8.3:1), requiring very high win rate for profitability
  • Global variables used for trade state persistence can become inconsistent on terminal restart or crash

Improvements

  • Replace LotSize with a simple mathematical formula such as lot = floor((Balance - 300) / 273.58 * 0.01 + 0.01), eliminating the thousand-line redundant code
  • Remove Martingale logic or add maximum lot cap and consecutive loss limits to prevent account blowup
  • Fix unreachable code in SignalOpenSell and add spread filter plus slippage protection
