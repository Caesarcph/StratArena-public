策略分析

### 2.1 核心理念 **BullsBearsEyes** 是 **#1102 BullsBears 的增强版本**，使用**4阶Laguerre过滤器**对多空力量指标进行多层平滑处理，减少噪音，提供更可靠的信号。"Eyes" 指的是Laguerre过滤器的4层结构(L0, L1, L2, L3)形成的"眼状"视图。 ### 2.2 与#1102的核心差异 | 特性 | #1102 BullsBears | #1103 BullsBearsEyes | | **核心算法** | 基础多空交叉 | 4阶Laguerre过滤器 | | **平滑方法** | XMA (10种可选) | Gamma平滑 (默认0.6) | | **信号模式** | 单一交叉模式 | 4种信号模式可选 | | **信号逻辑** | UpTrend/DnTrend交叉 | 极端水平突破 | | **可视化** | 双线云图 | 彩色单线 | | **缓冲器** | 2个分离缓冲 | 3个缓冲+彩色编码 | ### 2.3 Laguerre过滤器 **4阶Laguerre计算**: **Gamma参数**: - `gamma = 0.6` (默认) - 范围: 0-1 - 值越小 = 越平滑 - 值越大 = 越敏感 **Laguerre优势**: - 4阶过滤减少噪音 - 自适应平滑特性 - 比EMA更快响应 - 减少假信号 ### 2.4 信号生成模式 #### 模式1: Twist (方向改变) - 检测过滤器方向改变 - 捕捉趋势转折点 - 适合震荡市场 #### 模式2: Breakdown1 (中线突破) - 突破50中线水平 - 从超买/超卖区返回 - 确认反转信号 #### 模式3: Breakdown2 (极端水平突破) ⭐ 默认 - 突破HighLevel (75) 或 LowLevel (25) - 捕捉超买超卖反转 - **推荐模式** #### 模式4: Breakdown3 (组合逻辑) - 结合出场和突破条件 - 更复杂的信号逻辑 - 需要更多测试 ### 2.5 交易信号 #### 买入信号 **条件**: 1. Trend[0] == +2 (低于超卖水平+突破) 2. 从超卖区向上突破 3. Mode = breakdown2 (默认) **逻辑**: #### 卖出信号 **条件**: 1. Trend[0] == -2 (高于超买水平+突破) 2. 从超买区向下突破 3. Mode = breakdown2 (默认) **逻辑**: ### 2.6 出场逻辑 **反向信号平仓**: - Trend < 0 → 平多单 - Trend > 0 → 平空单 **固定SL/TP**: - StopLoss = 1000点 - TakeProfit = 2000点 ### 2.7 极端水平设置 | 水平 | 默认值 | 说明 | | **HighLevel** | 75 | 超买线 | | **MiddleLevel** | 50 | 中线 | | **LowLevel** | 25 | 超卖线 | **信号触发**: - 突破HighLevel向下 → 卖出 (超买回调) - 突破LowLevel向上 → 买入 (超卖反弹)
