策略分析

分析 ### 2.1 核心策略概念 **Continuation Factor (CF) - 延续因子趋势跟踪策略** 这是一个基于价格动量延续性的趋势跟踪策略。CF指标由Ronald Verwer/ROVERCOM开发，其核心算法分析价格变化的延续性： **算法原理**: 1. **正向累积 (x_p, y_p)**: 当价格上涨时，累积涨幅和连续涨幅 2. **负向累积 (x_n, y_n)**: 当价格下跌时，累积跌幅和连续跌幅 3. **延续因子计算**: - UpperBuffer = (chp - cffn) / Point (正因子 - 负延续累积) - LowerBuffer = (chn - cffp) / Point (负因子 - 正延续累积) 4. **趋势判断**: 当UpperBuffer > LowerBuffer时为上升趋势，反之为下降趋势 **用通俗语言描述**: 这个策略就像追踪"惯性"。当一个方向的价格运动能够持续（有延续性），说明趋势强劲。CF指标通过计算价格连续同向运动的累积值来判断趋势强度和方向。当正延续因子超过负延续因子时做多，反之做空。 ### 2.2 入场条件 **做多入场** (BUY_Open): 1. 信号线[1]处于上升趋势: `UpValue[1] > DnValue[1]` 2. 前一根K线处于下降或中性状态: `UpValue[0] <= DnValue[0]` 3. 买入权限开启: `BuyPosOpen = true` 4. 新K线检测通过 (CIsNewBar类) **做空入场** (SELL_Open): 1. 信号线[1]处于下降趋势: `UpValue[1] < DnValue[1]` 2. 前一根K线处于上升或中性状态: `UpValue[0] >= DnValue[0]` 3. 卖出权限开启: `SellPosOpen = true` 4. 新K线检测通过 (CIsNewBar类) **入场逻辑**: 趋势穿越确认 - 当趋势方向发生改变时入场（从下降转为上升做多，从上升转为下降做空） ### 2.3 出场条件 **平多仓** (BUY_Close): - 当趋势反转: `UpValue[1] < DnValue[1]` (下降趋势形成) - 平仓权限开启: `BuyPosClose = true` **平空仓** (SELL_Close): - 当趋势反转: `UpValue[1] > DnValue[1]` (上升趋势形成) - 平仓权限开启: `SellPosClose = true` **止损止盈出场**: - 固定止损: 1000点 (默认) - 固定止盈: 2000点 (默认) - 盈亏比: 2:1 (良好) ### 2.4 风险管理 **止损/止盈逻辑**: - 固定点数止损止盈 (默认SL=1000, TP=2000) - 盈亏比2:1设计合理 - 无追踪止损机制 **手数管理**: - MM参数: 负值表示固定手数，正值表示资金比例 - 默认: MM=-0.1 (固定0.1手) - 支持6种手数计算模式: - 模式0: 基于可用保证金 - 模式1: 基于账户余额 - 模式2: 基于可用保证金的亏损比例 - 模式3: 基于账户余额的亏损比例 - 模式4: 模式0和2的最小值 - 模式5: 模式1和3的最小值 **其他风控措施**: - 订单预检查机制 (OrderCheck) - 滑点控制 (Deviation_=10点) - 新K线检测避免重复交易 - 全局变量时间锁防止同一方向重复开仓

优势

  • 专业级代码架构: Nikolay Kositsin出品，代码规范、注释详尽
  • 独特的CF算法: Continuation Factor延续因子算法，不同于常规MA/MACD，具有独特的趋势识别能力
  • 完善的交易函数库: TradeAlgorithms.mqh提供完整的开仓/平仓/手数计算/错误处理机制
  • 盈亏比合理: 默认2:1盈亏比设计，有利于长期盈利
  • 双重出场机制: 既支持趋势反转信号出场，也支持固定止损止盈
  • 环形缓冲区设计: 指标使用环形缓冲区管理数据，内存效率高

劣势

  • 止损过大: 默认1000点止损在正常市场波动下可能过度承受回撤
  • 无趋势强度过滤: 仅判断趋势方向，未考虑趋势强度（如ADX）
  • 无追踪止损: 错失锁定利润的机会
  • 参数单一: CF指标只有周期参数，缺乏自适应能力
  • 缺乏多时间框架分析: 仅使用H4时间框架，未结合更高时间框架趋势
