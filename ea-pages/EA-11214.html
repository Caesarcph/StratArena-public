策略分析

### 2.1 核心理念 **TSI_MACD** 结合**TSI (True Strength Index)** 和MACD概念，使用**三重指数平滑**和**归一化**创建-100到+100范围的动量震荡指标，相比传统MACD更平滑，假信号更少。 ### 2.2 TSI (True Strength Index) 详解 **TSI vs MACD对比**: | 特性 | MACD | TSI | | 计算 | 快线-慢线 | 三重平滑动量比 | | 范围 | 无界 | -100到+100 | | 平滑 | 单层/双层 | 三重平滑 | | 滞后 | 中等 | 较高 | | 信号质量 | 假信号多 | 更平滑 | **TSI优势**: - 三重平滑减少噪音 - 归一化便于比较 - 信号更平滑可靠 - 边界清晰(-100到+100) ### 2.3 TSI计算公式 **步骤**: **可视化**: ### 2.4 交易信号 #### 买入信号 **条件**: 1. TSI线上穿信号线 2. `Ind[1] > Sign[1]` (前一根TSI > 信号) 3. `Ind[0] <= Sign[0]` (当前TSI ≤ 信号) 4. 动量由负转正 **代码逻辑**: #### 卖出信号 **条件**: 1. TSI线下穿信号线 2. `Ind[1] < Sign[1]` (前一根TSI < 信号) 3. `Ind[0] >= Sign[0]` (当前TSI ≥ 信号) 4. 动量由正转负 **代码逻辑**: ### 2.5 入场/出场逻辑 **入场**: - TSI与信号线交叉 - 捕捉动量变化 **出场**: - 反向信号触发平仓 - 固定SL/TP **示例**:
