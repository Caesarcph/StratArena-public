摘要

这是一个多货币智能交易系统，同时交易最多12个货币对，基于SMA斜率方向生成信号。当SMA连续两个周期上升时产生买入信号，SMA连续两个周期下降时产生卖出信号，每个品种独立管理仓位。

策略分析

该EA的核心策略是基于简单移动平均线（SMA）的斜率变化来判断趋势方向。入场条件为：当SMA在第2-3根K线和第1-2根K线的差值均为正时（即SMA连续上升两个周期），产生买入信号（DnSignal为true，命名反直觉）；当差值均为负时（SMA连续下降），产生卖出信号。出场条件为：当SMA在第1-2根K线的差值由正转负时关闭多头仓位，由负转正时关闭空头仓位。仓位管理方面，每个品种独立管理，同一品种最多持有一个仓位，通过PositionSelect检查是否已有持仓。资金管理采用动态手数计算（Money_M函数），根据账户可用保证金按比例计算手数，并限制在0.1到5手之间。该EA支持最多12个货币对同时运行，每个品种有独立的参数配置。

Summary

A multicurrency Expert Advisor that trades up to 12 currency pairs simultaneously using SMA slope direction. It generates buy signals when the SMA is rising for two consecutive periods and sell signals when the SMA is falling, with position management handled independently per symbol.

Strategy Analysis

The core strategy of this EA is based on the slope change of the Simple Moving Average (SMA) to determine trend direction. Entry conditions: when the SMA differences for bars 2-3 and bars 1-2 are both positive (SMA rising for two consecutive periods), a buy signal is generated; when both differences are negative (SMA falling), a sell signal is generated. Exit conditions: when the SMA difference for bars 1-2 turns negative, the long position is closed; when it turns positive, the short position is closed. Position management is handled independently per symbol, with a maximum of one position per symbol checked via PositionSelect. Money management uses dynamic lot sizing via the Money_M function, calculating lot size proportionally from free margin and clamping between 0.1 and 5 lots. The EA supports up to 12 currency pairs running simultaneously, each with independent parameter configuration for period, applied price, and MA method.

优势

  • 多货币同时运行，分散单一品种风险，提高策略多样性
  • 每个品种独立配置参数，灵活适应不同货币对特性
  • 仅在新K线时计算信号，避免逐tick重复计算，降低资源消耗
  • 使用iMA指标句柄方式，符合MQL5的标准指标调用模式

劣势

  • 止损止盈参数虽已定义但在开仓函数中硬编码为0，止损止盈形同虚设
  • Money_M函数完全覆盖了用户输入的Lots参数，导致手动手数设置无效
  • 信号命名混乱（DnSignal实际为买入信号），代码可读性差
  • 使用PositionSelect按symbol选择仓位，无法处理同品种多仓位场景
  • ORDER_FILLING_FOK硬编码可能导致某些券商拒绝订单

改进建议

  • 修复BuyPositionOpen和SellPositionOpen函数，将止损止盈参数正确传递到request.sl和request.tp中，而非硬编码为0
  • 移除Money_M动态手数函数或将其设为可选，让用户的手数参数真正生效，避免与输入参数矛盾
  • 修正信号变量命名（DnSignal改为BuySignal，UpSignal改为SellSignal），提高代码可读性
  • 添加持仓方向检查，在开仓前确认当前无同方向持仓，避免重复开仓

Strengths

  • Simultaneous multi-currency trading diversifies single-symbol risk and increases strategy variety
  • Independent parameter configuration per symbol allows flexible adaptation to different currency pair characteristics
  • Signal calculation only on new bars avoids per-tick recalculation, reducing resource consumption
  • Uses iMA indicator handle approach, conforming to MQL5 standard indicator calling pattern

Weaknesses

  • Stop loss and take profit parameters are defined but hardcoded to 0 in the open functions, making SL/TP effectively useless
  • The Money_M function completely overrides user-input Lots parameter, rendering manual lot settings ineffective
  • Signal naming is confusing (DnSignal actually triggers buy), severely hurting code readability
  • PositionSelect by symbol cannot handle multiple positions on the same symbol
  • Hardcoded ORDER_FILLING_FOK may cause order rejection by some brokers

Improvements

  • Fix BuyPositionOpen and SellPositionOpen functions to properly pass StopLoss and TakeProfit parameters to request.sl and request.tp instead of hardcoding them to 0
  • Remove the Money_M dynamic lot function or make it optional, so the user's Lots parameter actually takes effect, avoiding contradiction with input parameters
  • Fix signal variable naming (DnSignal to BuySignal, UpSignal to SellSignal) to improve code readability and maintainability
  • Add position direction checks before opening trades to confirm no same-direction position exists, preventing duplicate entries

风险评估 / Risk Assessment

总体 / Overall:HIGH

风险点

  • 止损止盈完全失效（硬编码为0），每笔交易无保护，极端行情可能导致巨大亏损
  • Money_M根据可用保证金动态计算手数，盈利时手数膨胀放大风险，可能导致爆仓
  • 多品种同时交易且无止损，在相关货币对同向波动时风险叠加

Risk Assessment

Overall:HIGH

Risk Points

  • Stop loss and take profit are completely disabled (hardcoded to 0), every trade is unprotected and extreme market moves could cause massive losses
  • Money_M calculates lots dynamically based on free margin, lot size inflates during profits amplifying risk, potentially leading to account blow-up
  • Multi-symbol simultaneous trading without stop losses creates compounded risk when correlated currency pairs move in the same direction
