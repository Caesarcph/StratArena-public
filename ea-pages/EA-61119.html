摘要

该EA自动为手动开仓的订单设置止盈和可选止损。它还提供可选的移动止损和净值保护功能，用于管理已有持仓的风险。

策略分析

该EA本身不产生任何交易信号或开仓操作，仅作为持仓管理工具使用。入场条件由交易者手动决定，EA不参与开仓逻辑。出场条件包括：自动设置固定点数的止盈目标、可选的固定点数止损、以及可选的移动止损跟踪。仓位管理方面，EA不控制下单手数，仅在持仓存在时修改止损和止盈。资金管理方面，提供了净值保护功能，当净值低于余额的一定百分比时自动平仓，但该功能仅针对特定魔术编号的持仓生效。整体策略概念是辅助手动交易者自动化管理止盈止损，减少情绪化操作带来的风险。

Summary

This EA automatically sets take-profit and optionally stop-loss on manually opened positions. It also provides optional trailing stop and equity protection features to manage risk on existing trades.

Strategy Analysis

This EA does not generate any trading signals or open positions itself; it functions purely as a position management utility. Entry conditions are entirely determined by the trader manually, with no EA involvement in opening logic. Exit conditions include automatic fixed-pip take-profit setting, optional fixed-pip stop-loss, and optional trailing stop functionality. Position sizing is not managed by the EA at all; it only modifies stop-loss and take-profit on existing positions. Money management includes an equity protection feature that closes positions when equity falls below a configurable percentage of account balance, but this only works for positions matching a specific magic number. The overall strategy concept is to assist manual traders by automating TP/SL management to reduce emotional decision-making risks.

优势

  • 自动化设置止盈止损，减少手动操作遗漏
  • 提供移动止损功能，帮助锁定浮盈
  • 净值保护机制可防止账户爆仓
  • 适用于所有时间框架和品种，包括黄金
  • 默认止损关闭，给用户灵活选择

劣势

  • 仅处理第一个持仓，使用PositionSelect按品种选择而非遍历所有持仓，多仓场景下会遗漏
  • pip计算使用point*10硬编码，对3位或5位小数报价品种不正确，对JPY对也有问题
  • 净值保护仅对MagicNumber=2025的持仓生效，但手动下单的魔术号通常为0，功能形同虚设
  • 没有检查PositionModify的返回值，修改失败时无错误处理
  • Slippage输入参数定义了但从未在代码中使用

改进建议

  • 改用PositionGetTotal遍历所有持仓而非PositionSelect按品种选择，以支持多仓管理
  • 修正pip计算逻辑，根据品种小数位数自动适配，并正确处理JPY对和不同报价精度
  • 修复净值保护中的魔术号匹配逻辑，使其能正确识别手动开仓的订单

Strengths

  • Automates TP/SL setting, reducing the risk of forgetting to set them on manual trades
  • Trailing stop feature helps lock in floating profits as price moves favorably
  • Equity protection mechanism can prevent account blowout in extreme scenarios
  • Works on all timeframes and symbols including XAUUSD
  • Stop-loss is disabled by default, giving users flexible control

Weaknesses

  • Only handles one position per symbol using PositionSelect, missing positions in multi-position scenarios
  • Pip calculation uses hardcoded point*10 which is incorrect for 3/5-digit brokers and JPY pairs
  • Equity protection only applies to MagicNumber=2025, but manual trades have magic=0, making the feature effectively useless
  • No return value check on PositionModify calls, so failed modifications go unnoticed
  • Slippage input parameter is declared but never actually used anywhere in the code

Improvements

  • Use PositionGetTotal to iterate all positions instead of PositionSelect by symbol, enabling proper multi-position management
  • Fix pip calculation logic to auto-detect digit precision, correctly handling JPY pairs and various quote formats
  • Fix the magic number matching in equity protection to properly identify manually opened trades (magic=0)

风险评估

总体:MEDIUM

风险点

  • PositionSelect仅选一个持仓，多仓时其他持仓不受管理，遗漏止损风险
  • pip硬编码为point*10，在5位小数平台上止损止盈距离会比预期小10倍
  • 净值保护因魔术号不匹配而失效，实际无法保护手动交易

Risk Assessment

Overall:MEDIUM

Risk Points

  • PositionSelect only picks one position per symbol, leaving other positions unmanaged with no SL/TP
  • Hardcoded pip=point*10 causes TP/SL distances to be 10x smaller than expected on 5-digit brokers
  • Equity protection fails to work for manual trades due to magic number mismatch
