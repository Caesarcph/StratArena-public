策略分析

分析 ### 2.1 核心策略概念 Exp_CronexAC是一个基于Cronex开发的双平滑AC(Accelerator Oscillator)指标的趋势跟踪策略。该EA利用Bill Williams的AC指标进行双重平滑处理，产生主线(快线)和信号线(慢线)两条线，通过信号线穿越模式产生交易信号。 **AC指标基础**: - AC = AO - MA(AO, 5) - AO = MA(5) - MA(34) - AC衡量动量变化的变化率(加速度) **Cronex双平滑算法**: 1. 计算标准AC指标 2. 对AC值进行快速周期平滑(FastPeriod=14) 3. 对快速平滑结果进行慢速周期平滑(SlowPeriod=25) 4. 产生两条线：主线(快线)和信号线(慢线) ### 2.2 入场条件 **做多入场**: - 主线(Ind)从上方穿越信号线(Sign)向下 - 条件：`Ind[1] > Sign[1] && Ind[0] <= Sign[0]` - 需要BuyPosOpen开关启用 **做空入场**: - 主线(Ind)从下方穿越信号线(Sign)向上 - 条件：`Ind[1] < Sign[1] && Ind[0] >= Sign[0]` - 需要SellPosOpen开关启用 **确认机制**: - 双K线确认：使用SignalBar=1作为信号K线，验证穿越 - 新K线检测：CIsNewBar类确保每根K线只处理一次 ### 2.3 出场条件 **多头平仓**: - 主线从下方穿越信号线向上 - 条件：`Ind[1] < Sign[1] && Ind[0] >= Sign[0]` - 需要SellPosClose开关启用 **空头平仓**: - 主线从上方穿越信号线向下 - 条件：`Ind[1] > Sign[1] && Ind[0] <= Sign[0]` - 需要BuyPosClose开关启用 **止损止盈**: - 固定止损：1000点(默认) - 固定止盈：2000点(默认) - 盈亏比：2:1 ### 2.4 风险管理 **手数管理模式** (MarginMode枚举): 1. **FREEMARGIN**: 基于账户可用资金计算 2. **BALANCE**: 基于账户余额计算 3. **LOSSFREEMARGIN**: 基于可用资金亏损份额计算 4. **LOSSBALANCE**: 基于余额亏损份额计算 5. **LOT**: 固定手数(默认) **默认风控参数**: - MM=0.1 (资金份额10%，较高) - StopLoss=1000点(过大) - TakeProfit=2000点 - Deviation=10点(滑点容忍)

优势

  • 双平滑降噪: Cronex双平滑算法有效过滤AC指标的短期噪音，信号更稳定
  • 盈亏比合理: 默认2:1的盈亏比设计有利于长期正期望
  • 专业代码架构: Nikolay Kositsin的专业级代码，包含完整的错误处理和新K线检测
  • 灵活的平滑算法: 支持10种平滑方法可选(SMA/EMA/SMMA/LWMA/JJMA/JurX/ParMA/T3/VIDYA/AMA)
  • 四开关交易控制: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制，支持单向交易模式
  • 多模式手数计算: 5种手数计算模式适应不同风控需求

劣势

  • 止损过大: 1000点止损风险敞口过高，单笔亏损可能超过10%
  • 缺乏趋势过滤: 纯振荡器策略，震荡市中易频繁止损
  • 无追踪止损: 固定止损无法保护浮动利润
  • 手数默认偏高: MM=0.1对新手不友好
  • 时间框架偏慢: H8响应较慢，可能错过最佳入场点
  • 无多时间框架确认: 缺乏大周期趋势方向确认
