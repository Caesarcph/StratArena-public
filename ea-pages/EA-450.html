摘要

这是一个多货币智能交易系统，利用TEMA（三重指数移动平均线）指标同时交易最多12个货币对。当TEMA斜率从负转正时产生买入信号，从正转负时产生卖出信号，并在反向斜率信号时平仓。每个货币对独立运行，拥有各自可配置的周期、止损、止盈和手数参数。

策略分析

该EA使用三重指数移动平均线（TEMA）作为核心趋势跟踪指标。入场条件为：当TEMA斜率从正转负时触发卖出信号（DnSignal），当TEMA斜率从负转正时触发买入信号（UpSignal），具体通过比较相邻两根K线的TEMA差值（dtema1和dtema2）的正负变化来判断。出场条件为：当TEMA斜率为正时触发多头止盈/止损信号（UpStop），当斜率为负时触发空头止盈/止损信号（DnStop），同时也设置了固定点数的止损和止盈。仓位管理方面，每个货币对使用固定手数（默认0.1手），没有动态仓位调整或资金管理逻辑。该EA仅在新K线开始时计算信号（IsNewBar检查），避免逐tick重复交易。支持最多12个货币对同时运行，每个货币对有独立的指标句柄和状态数组。然而，该策略缺乏对市场波动性、点差和交易时间过滤的考量，止损止盈使用固定点数而非根据ATR等动态调整。

Summary

This is a multi-currency Expert Advisor that trades up to 12 currency pairs simultaneously using the TEMA (Triple Exponential Moving Average) indicator. It generates buy signals when the TEMA slope changes from negative to positive and sell signals when it changes from positive to negative, closing positions on opposite slope signals. Each currency pair operates independently with its own configurable parameters for period, stop loss, take profit, and lot size.

Strategy Analysis

This EA uses the Triple Exponential Moving Average (TEMA) as its core trend-following indicator. Entry conditions are: a sell signal (DnSignal) is triggered when the TEMA slope changes from positive to negative, and a buy signal (UpSignal) is triggered when the slope changes from negative to positive, determined by comparing the TEMA differences of adjacent bars (dtema1 and dtema2). Exit conditions are: an UpStop signal is triggered when the TEMA slope is positive (closing longs), and a DnStop signal is triggered when the slope is negative (closing shorts), with fixed stop loss and take profit levels also set on each position. Position sizing uses fixed lots (default 0.1) per currency pair with no dynamic position adjustment or money management logic. The EA calculates signals only on new bar formation (IsNewBar check), preventing repeated trades on every tick. It supports up to 12 currency pairs running simultaneously, each with its own indicator handle and state arrays. However, the strategy lacks considerations for market volatility, spread filtering, and trading session filters, and uses fixed point-based stop loss/take profit rather than dynamic adjustments based on ATR or similar measures.

优势

  • 多货币对同时运行，分散单一货币对风险，提高交易机会
  • 使用TEMA指标比普通EMA响应更快、滞后更小，更适合趋势跟踪
  • 仅在出新K线时计算信号，避免逐tick重复交易，逻辑清晰
  • 每个货币对参数独立可配置，灵活性较高
  • 有止损止盈保护，且会检查品种的最小止损水平（stoplevel）

劣势

  • 固定手数无资金管理，无法根据账户余额动态调整仓位大小
  • 止损止盈使用固定点数而非动态计算（如ATR），不同货币对波动性差异大
  • 没有点差过滤，高波动或低流动性时段可能因大点差导致不利成交
  • 使用ORDER_FILLING_FOK填充模式，部分经纪商不支持，可能导致订单被拒
  • 代码大量重复，12个货币对的参数和调用均为手动复制，维护性差
  • PositionSelect仅按symbol选择，在hedging账户下可能出错

改进建议

  • 引入动态资金管理模块，根据账户余额和风险百分比自动计算仓位大小
  • 使用ATR或波动率指标动态调整止损止盈，替代固定点数，适应不同货币对的波动特性
  • 添加点差过滤和交易时段过滤，避免在高点差或低流动性时段交易
  • 将重复的货币对参数重构为结构体数组，使用循环处理，大幅提升代码可维护性
  • 支持多种订单填充模式（IOC/Return），自动检测经纪商支持的填充类型

Strengths

  • Simultaneous multi-currency operation diversifies single-pair risk and increases trading opportunities
  • TEMA indicator responds faster and has less lag than regular EMA, better suited for trend following
  • Signal calculation only on new bar formation avoids redundant per-tick trading, with clear logic
  • Independent configurable parameters per currency pair provide good flexibility
  • Stop loss and take profit protection with minimum stop level (stoplevel) validation

Weaknesses

  • Fixed lot sizing with no money management, unable to dynamically adjust position size based on account balance
  • Fixed point-based stop loss/take profit rather than dynamic calculation (e.g., ATR), ignoring volatility differences across pairs
  • No spread filter, high-spread periods may lead to unfavorable fills during volatile or low-liquidity sessions
  • Uses ORDER_FILLING_FOK fill mode which some brokers don't support, potentially causing order rejection
  • Highly repetitive code with 12 currency pairs manually copied for parameters and calls, poor maintainability
  • PositionSelect by symbol only may fail on hedging accounts where multiple positions per symbol exist

Improvements

  • Introduce dynamic money management module to calculate position size based on account balance and risk percentage
  • Use ATR or volatility indicators for dynamic stop loss/take profit instead of fixed points, adapting to each pair's volatility characteristics
  • Add spread filter and trading session filter to avoid trading during high-spread or low-liquidity periods
  • Refactor repetitive currency pair parameters into a struct array with loop processing, greatly improving code maintainability
  • Support multiple order filling modes (IOC/Return) with auto-detection of broker-supported fill types
