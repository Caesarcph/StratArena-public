策略分析

分析 ### 2.1 核心策略概念 这是一个基于**TEMA(Triple Exponential Moving Average)三重指数移动平均线**的多货币趋势跟踪策略。TEMA通过三重指数平滑减少滞后，比普通MA响应更快。 **TEMA算法**: **多货币设计**: - 支持同时交易12个货币对 - 每个货币对独立参数配置 - 在单个图表上运行多货币策略 ### 2.2 入场条件 **做多条件**: 1. TEMA在K线2的变化 < 0 (下降) 2. TEMA在K线1的变化 > 0 (上升) 3. 即: TEMA从下降转为上升 (转折向上) 4. dtema2 < 0 && dtema1 > 0 **做空条件**: 1. TEMA在K线2的变化 > 0 (上升) 2. TEMA在K线1的变化 < 0 (下降) 3. 即: TEMA从上升转为下降 (转折向下) 4. dtema2 > 0 && dtema1 < 0 **信号计算逻辑**: ### 2.3 出场条件 **止损止盈出场**: - 止损(StLoss): 1000点 (默认) - 止盈(TkProfit): 2000点 (默认) - 盈亏比: 2000/1000 = 2:1 (良好) **信号反转出场**: - 当TEMA方向改变时平仓 - UpStop: dtema1 > 0 时平多仓 - DnStop: dtema1 < 0 时平空仓 **出场逻辑**: ### 2.4 风险管理 **止损止盈设置**: - 默认SL = 1000点 - 默认TP = 2000点 - 盈亏比 = 2:1 - 自动检查并调整至经纪商最小止损距离 **手数管理**: - 固定手数: 0.1手 (默认) - 每个货币对独立设置 **持仓检查**: - ✅ 开仓前检查是否已有持仓 - ✅ 平仓前检查持仓方向 **其他风控措施**: - ✅ 新K线检测 (IsNewBar函数) - ✅ 止损距离验证 - ❌ 无追踪止损 - ❌ 无趋势强度过滤 - ❌ 无时间过滤

优势

  • TEMA低延迟特性 ⭐⭐⭐⭐
  • 三重指数平滑减少滞后
  • 比普通MA响应更快
  • 趋势转折信号更及时
  • 多货币架构设计 ⭐⭐⭐
  • 单图表运行多货币策略
  • 节省系统资源
  • 每个货币对独立参数
  • 完整的交易函数库 ⭐⭐⭐⭐
  • 规范的开仓/平仓函数
  • 完整的错误处理
  • 止损距离验证
  • 可复用的交易模块
  • 盈亏比良好 ⭐⭐⭐
  • 默认盈亏比2:1
  • 符合趋势跟踪策略要求
  • 单笔盈利可覆盖约2笔亏损
  • 新K线检测 ⭐⭐⭐
  • IsNewBar函数避免重复计算
  • 静态数组存储多货币时间戳
  • 提高执行效率

劣势

  • 多货币相关性风险 🔴
  • 12个货币对可能高度相关
  • 未考虑货币对间相关性
  • 可能放大整体风险敞口
  • 止损过大 ⚠️
  • 默认止损1000点
  • 对短线交易而言过大
  • 需根据品种调整
  • 无趋势强度过滤 ⚠️
  • 仅依赖TEMA方向变化
  • 震荡市频繁假信号
  • 需添加ADX/ATR过滤
  • 固定参数问题 ⚠️
  • 所有货币对使用相同参数
  • 不同品种波动性不同
  • 应根据品种特性优化
  • 信号反转出场风险 ⚠️
  • TEMA方向改变即平仓
  • 趋势中途可能被震出
  • 建议使用追踪止损
