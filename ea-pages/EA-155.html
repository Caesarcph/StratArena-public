摘要

该EA使用双MACD交叉策略产生买卖信号，并结合马丁格尔仓位管理系统，在连续亏损后加倍手数。仅在没有持仓时才开仓，采用固定止损和止盈水平。OnTester函数评估盈利能力与最大回撤的比率。

策略分析

策略概念基于双MACD指标的交叉信号进行趋势判断，使用两个不同参数的MACD指标进行共振确认入场。入场条件为：做多时要求MACD1柱状图从下穿上（t[0]>t[1]且t[1]<t[2]）且MACD2柱状图上升（k[1]>k[0]）；做空条件相反。出场条件依赖固定点数的止损和止盈，分别为Stop=500点和Tp=1500点。仓位管理采用马丁格尔策略，通过Martingail类实现，每次亏损后加倍手数，加倍次数由Ud参数控制，基础手数由DML参数设定为1000。资金管理通过全局变量保存和恢复马丁格尔状态，确保EA重启后能延续仓位倍增逻辑，但缺乏最大回撤限制和账户权益保护机制。

Summary

This EA uses a dual MACD crossover strategy to generate buy and sell signals, combined with a Martingale position-sizing system that doubles the lot size after consecutive losses. It enters trades only when no position is already open, with fixed stop-loss and take-profit levels. The OnTester function evaluates profitability relative to maximum drawdown.

Strategy Analysis

The strategy concept is based on dual MACD crossover signals for trend determination, using two MACD indicators with different parameters for confluence-confirmed entries. Entry conditions for long: MACD1 histogram turns up from below (t[0]>t[1] and t[1]<t[2]) and MACD2 histogram is rising (k[1]>k[0]); short conditions are the inverse. Exit conditions rely on fixed stop-loss and take-profit at Stop=500 points and Tp=1500 points respectively. Position sizing employs a Martingale system implemented via the Martingail class, doubling lot size after each loss with the doubling count controlled by the Ud parameter and base lot determined by DML=1000. Money management persists the Martingale state via global variables across EA restarts, but there is no maximum drawdown limit or account equity protection mechanism.

优势

  • 双MACD共振确认提高了信号可靠性，减少了虚假信号
  • 止盈距离大于止损距离（Tp=1500 vs Stop=500），盈亏比为3:1，具有正期望值潜力
  • OnTester函数考虑了最大连续亏损和盈亏比，提供了合理的策略评估框架

劣势

  • 马丁格尔仓位管理在连续亏损时会指数级放大风险，可能导致爆仓
  • 仅允许单方向持仓（PositionSelect检查），无法同时多空交易，错失反向机会
  • 缺少新K线检查，仅用tick_volume>1过滤不够可靠，可能重复入场

改进建议

  • 增加最大马丁格尔倍数限制和账户权益保护，防止连续亏损导致爆仓
  • 添加新K线检测逻辑替代tick_volume过滤，避免同一K线内重复开仓

Strengths

  • Dual MACD confluence confirmation improves signal reliability and reduces false signals
  • Take-profit exceeds stop-loss (Tp=1500 vs Stop=500), yielding a 3:1 reward-to-risk ratio with positive expectancy potential
  • OnTester function accounts for max consecutive losses and profit/loss ratio, providing a reasonable strategy evaluation framework

Weaknesses

  • Martingale position sizing exponentially amplifies risk during consecutive losses, potentially causing account blowup
  • Only allows single-direction position (PositionSelect check), cannot trade both directions simultaneously, missing counter-trend opportunities
  • Lacks new bar check; tick_volume>1 filter is unreliable and may cause duplicate entries

Improvements

  • Add maximum Martingale multiplier limit and account equity protection to prevent account blowup from consecutive losses
  • Add new bar detection logic replacing tick_volume filter to avoid duplicate entries within the same bar
