摘要

该EA使用双MACD交叉策略生成交易信号，并结合马丁格尔仓位管理系统，在连续亏损后加倍手数。它根据MACD柱状图的拐点和两个MACD指标之间的背离来开仓做多或做空，并设置固定止损和止盈。马丁格尔组件通过全局变量跟踪状态，以便在重启后保持持续。

策略分析

策略概念基于双MACD指标的交叉与背离来捕捉趋势转折点。入场条件为：买入信号要求MACD1柱状图出现谷底反转（t[0]>t[1]且t[1]<t[2]），同时MACD2当前值大于前值（k[1]>k[0]）；卖出信号反之。出场条件完全依赖固定止损（500点）和止盈（1500点）点位，没有移动止损或信号反转平仓逻辑。仓位管理采用马丁格尔策略，通过Martingail类实现，初始手数由DML参数决定，每次亏损后根据Ud参数加倍手数，状态通过全局变量持久化。资金管理方面，止损与止盈比为1:3，但马丁格尔加仓机制在连续亏损时会导致仓位指数级增长，风险极高。OnTester函数使用盈利次数除以亏损次数再除以最大连续亏损次数作为优化指标，且当止盈小于止损时返回0以排除不合理参数组合。

Summary

This EA uses a dual MACD crossover strategy to generate trade signals, combined with a Martingale position-sizing system that doubles the lot size after consecutive losses. It opens buy or sell positions based on MACD histogram turning points and divergence between two MACD indicators, with fixed stop-loss and take-profit levels. The Martingale component tracks its state via global variables to persist across restarts.

Strategy Analysis

The strategy concept is based on dual MACD indicator crossovers and divergence to capture trend reversal points. Entry conditions: a buy signal requires MACD1 histogram showing a valley reversal (t[0]>t[1] and t[1]<t[2]) while MACD2 current value exceeds its previous value (k[1]>k[0]); sell signals are the mirror opposite. Exit conditions rely entirely on fixed stop-loss (500 points) and take-profit (1500 points) levels, with no trailing stop or signal-based exit logic. Position sizing employs a Martingale system via the Martingail class, with initial lot size determined by the DML parameter and lot doubling after each loss based on the Ud parameter, with state persisted through global variables. For money management, the stop-loss to take-profit ratio is 1:3, but the Martingale lot-doubling mechanism causes position sizes to grow exponentially during consecutive losses, creating extreme risk. The OnTester function uses profit count divided by loss count divided by max consecutive losses as an optimization metric, returning 0 when take-profit is less than stop-loss to exclude unreasonable parameter combinations.

优势

  • 双MACD确认机制可以减少虚假信号，提高入场质量
  • 止盈是止损的三倍，具有正期望值的盈亏比设计
  • OnTester函数提供了合理的策略评估指标，便于参数优化
  • 通过全局变量持久化马丁格尔状态，EA重启后不会丢失加仓进度

劣势

  • 马丁格尔仓位管理在连续亏损时手数指数级增长，可能导致爆仓
  • 仅检查是否存在持仓就开新仓，不区分多空方向，多空可能互相冲突
  • 缺少新K线检查，每tick都可能尝试开仓，虽然tick_volume>1做了一定过滤但仍不够
  • 没有点差过滤，在浮动点差较大时可能造成不必要的滑点损失
  • ORDER_FILLING_AON填充模式在某些经纪商可能不支持，会导致下单失败

改进建议

  • 用固定手数或抗马丁加仓策略替换马丁格尔，降低爆仓风险
  • 添加新K线检查逻辑，确保每个K线只交易一次，避免重复入场
  • 增加点差过滤和持仓方向检查，区分多空仓位避免方向冲突

Strengths

  • Dual MACD confirmation mechanism reduces false signals and improves entry quality
  • Take-profit is three times the stop-loss, providing a positive expectancy risk-reward ratio
  • OnTester function provides a reasonable strategy evaluation metric for parameter optimization
  • Martingale state is persisted via global variables, preventing loss of progress after EA restart

Weaknesses

  • Martingale position sizing causes exponential lot growth during consecutive losses, potentially leading to account blowout
  • Only checks if a position exists without distinguishing direction, which may cause long/short conflicts
  • No new bar check; attempts to open trades every tick, and tick_volume>1 filter is insufficient
  • No spread filter, which can cause unnecessary slippage losses with variable-spread brokers
  • ORDER_FILLING_AON fill mode may not be supported by some brokers, causing order rejection

Improvements

  • Replace Martingale with fixed lot sizing or anti-Martingale progression to reduce blowout risk
  • Add new bar check logic to ensure only one trade per bar, avoiding duplicate entries
  • Add spread filter and position direction check to distinguish long/short positions and avoid directional conflicts
