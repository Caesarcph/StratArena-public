策略分析

分析 ### 2.1 核心策略概念 这是一个**趋势跟踪 + 动量过滤**策略。策略使用MA(76)判断趋势方向，同时用Stochastic(5,3,3)作为入场过滤条件。核心逻辑是： 1. **趋势识别**: 通过MA连续3根K线的方向判断趋势（递增=上升趋势，递减=下降趋势） 2. **动量过滤**: Stochastic在超卖区向上运行（做多）或在超买区向下运行（做空） 3. **价格确认**: 价格必须突破MA（做多时Ask>MA，做空时Bid<MA） ### 2.2 入场条件 **做多条件** (5个条件必须同时满足): | 条件 | 代码逻辑 | 说明 | | 1. MA趋势向上 | `maVal[0]<maVal[1] && maVal[1]<maVal[2]` | MA连续3根递增 | | 2. 价格突破MA | `Ask > maVal[0]` | Ask价格高于MA | | 3. Stochastic向上 | `stochVal[1]>stochVal[2]` | Stochastic向上运行 | | 4. Stochastic低位 | `stochVal[0]<Stoch_OverSold(30)` | Stochastic在超卖区下方 | | 5. 无持仓 | `!PositionSelect(_Symbol)` | 当前无持仓 | | 6. 资金充足 | `ACCOUNT_FREEMARGIN>5000` | 自由保证金>5000 | **做空条件** (5个条件必须同时满足): | 条件 | 代码逻辑 | 说明 | | 1. MA趋势向下 | `maVal[0]>maVal[1] && maVal[1]>maVal[2]` | MA连续3根递减 | | 2. 价格突破MA | `Bid < maVal[0]` | Bid价格低于MA | | 3. Stochastic向下 | `stochVal[1]<stochVal[2]` | Stochastic向下运行 | | 4. Stochastic高位 | `stochVal[0]>Stoch_OverBought(70)` | Stochastic在超买区上方 | | 5. 无持仓 | `!PositionSelect(_Symbol)` | 当前无持仓 | | 6. 资金充足 | `ACCOUNT_FREEMARGIN>5000` | 自由保证金>5000 | ### 2.3 出场条件 - **止盈**: 固定点数止盈 `TakeProfit = 0.007` (70点，假设5位报价) - **止损**: 固定点数止损 `StopLoss = 0.0035` (35点，假设5位报价) - **盈亏比**: 2:1 (70点止盈 / 35点止损) ### 2.4 风险管理 **手数管理 - Money_M()函数**: | 账户余额 | 计算手数 | 实际手数 | | $10,000 | 5.0 | 5.0 | | $30,000 | 15.0 | 15.0 (上限) | | $1,000 | 0.5 | 0.5 | | $200 | 0.1 | 0.1 (下限) | **风控措施**: - ✅ 自由保证金检查 (>5000) - ✅ 动态手数计算 - ✅ 手数上下限 (0.1-15手) - ⚠️ 固定止损止盈 (非ATR动态)

优势

  • 趋势确认充分
  • MA连续3根K线方向一致，有效过滤震荡行情
  • 多维度入场验证
  • 趋势(MA) + 动量(Stochastic) + 价格突破 三重确认
  • 代码简洁清晰
  • 139行代码，结构清晰，易于理解和修改
  • 使用标准库
  • 标准交易类，稳定可靠

劣势

  • 入场条件过于严格
  • 5个条件同时满足，信号稀少，可能错过很多有效机会
  • Stochastic参数过短
  • Stochastic(5,3,3)参数过短，噪音较大
  • 固定止盈止损
  • 未使用ATR动态调整，不同品种需要手动优化
  • 参数欺骗
  • 参数被定义但不使用，容易误导用户
