This is a simple utility EA that detects new bar formation on the current chart timeframe. It uses a static datetime variable to compare the current bar's open time with the previous bar's open time, printing a message whenever a new bar is detected. It does not open any trades and serves as a boilerplate template for per-bar logic execution.

摘要

这是一个简单的工具型EA，用于检测当前图表周期上新K线的形成。它使用静态datetime变量比较当前K线开盘时间与上一根K线开盘时间，检测到新K线时打印消息。该EA不执行任何交易，仅作为每根K线执行一次逻辑的模板代码。

策略分析

该EA并非交易策略，而是一个新K线检测工具。其核心概念是利用iTime函数获取当前K线的开盘时间，并通过静态变量previous_time与current_time的比较来判断是否有新K线形成。当检测到新K线时，执行一次性的代码逻辑（目前仅打印消息），然后将previous_time更新为当前时间以防止重复触发。该EA没有入场条件、出场条件、仓位管理或资金管理逻辑，仅提供K线变化检测的基础框架。开发者可以在此框架基础上添加自己的策略逻辑，实现每根K线只执行一次的操作。PERIOD_CURRENT表示使用当前图表的周期，也可以更改为任何指定周期。

Summary

This is a simple utility EA that detects new bar formation on the current chart timeframe. It uses a static datetime variable to compare the current bar's open time with the previous bar's open time, printing a message whenever a new bar is detected. It does not open any trades and serves as a boilerplate template for per-bar logic execution.

Strategy Analysis

This EA is not a trading strategy but a new bar detection utility. Its core concept uses the iTime function to retrieve the current bar's open time and compares it with a static variable previous_time against current_time to determine if a new bar has formed. When a new bar is detected, one-time-per-bar code logic is executed (currently only printing a message), and then previous_time is updated to the current time to prevent repeated triggers. There are no entry conditions, exit conditions, position sizing, or money management logic — it only provides a foundational framework for per-bar execution. Developers can add their own strategy logic on top of this framework to ensure operations execute only once per bar. PERIOD_CURRENT means it uses the current chart's timeframe, which can also be changed to any specified timeframe.

优势

  • 代码简洁明了，逻辑清晰易懂，适合初学者学习新K线检测方法
  • 使用静态变量确保只在真正新K线形成时触发，避免每个tick重复执行
  • 作为模板代码，可以方便地在此基础上扩展自定义策略逻辑
  • 支持通过更改PERIOD_CURRENT参数来适配不同时间周期

劣势

  • 功能过于简单，仅打印消息而不执行任何实际操作，实用价值有限
  • 没有错误处理机制，iTime调用失败时（如数据未加载）可能导致逻辑异常
  • 缺少输入参数配置，无法在EA设置界面中自定义时间周期或其他选项
  • 没有考虑多品种或多周期同时监控的需求，扩展性不足

改进建议

  • 添加input参数允许用户自定义监控的时间周期和交易品种，提高灵活性
  • 增加iTime返回值的有效性检查，当返回0时进行重试或错误提示，增强鲁棒性
  • 将新K线检测逻辑封装为可复用的函数或类，方便在多个EA中调用

Strengths

  • Clean and straightforward code logic, easy for beginners to learn new bar detection methods
  • Uses static variables to ensure execution only on genuine new bar formation, avoiding repeated per-tick triggers
  • Serves as a convenient boilerplate template for extending with custom strategy logic
  • Supports adaptation to different timeframes by changing the PERIOD_CURRENT parameter

Weaknesses

  • Functionality is overly simple — only prints a message without any practical action, offering limited utility
  • No error handling mechanism — iTime call failures (e.g., data not loaded) could cause logic anomalies
  • Lacks input parameters, making it impossible to customize timeframe or other options in the EA settings dialog
  • Does not account for multi-symbol or multi-timeframe monitoring needs, limiting extensibility

Improvements

  • Add input parameters to allow users to customize the monitored timeframe and symbol, improving flexibility
  • Add validity checks for iTime return values — retry or show error when it returns 0, enhancing robustness
  • Encapsulate the new bar detection logic into a reusable function or class for easy integration across multiple EAs
