策略分析

### 2.1 "Center of Gravity"含义 **⚠️ 误导性命名**: - **不是** John Ehlers经典COG指标 - **是** Nikolay Kositsin自定义公式 - **实际**: SMA × LWMA混合线 **公式**: **可视化**: ### 2.2 指标计算 **主线** (Main Line): **信号线** (Signal Line): - 对主线进行平滑 - 可配置MA方法 (SMA默认) - SmoothPeriod=3 **颜色编码**: - 主线 > 信号线 → 绿色 (多头) - 主线 < 信号线 → 红色 (空头) ### 2.3 均值回归逻辑 **策略类型**: 纯均值回归 **原理**: - 价格偏离平滑信号线时入场 - 价格回归均值时出场 - **买入**: 上穿信号线 (从下方) - **卖出**: 下穿信号线 (从上方) **适用市场**: 震荡/横盘 **失效市场**: 强趋势 ### 2.4 交易信号 #### 买入信号 **条件**: - 前一根: Value = 2 (主线<信号线，空头) - 当前: Value = 1 (主线>信号线，多头) - **从下向上穿越** **代码**: #### 卖出信号 **条件**: - 前一根: Value = 1 (主线>信号线，多头) - 当前: Value = 2 (主线<信号线，空头) - **从上向下穿越** ### 2.5 时间周期 **默认**: H4 (4小时) **推荐**: - H4: 最优平衡 - H1: 信号多但噪音多 - D1: 信号强但少 - ❌ M15以下: 假信号多
