Example1_LibCustomChart

The Expert Advisor shows the application of LibCustomChart.ex5 library. The presence of iCustomChart custom chart is checked when attaching the Expert Advisor to a chart window. In case a custom chart has been uploaded, the library functions use the data of that chart. Otherwise, the data of a standard chart is used. Therefore, the Expert Advisor can work both with custom and standard charts without the need for any changes.

摘要

该EA演示了LibCustomChart.ex5库的用法，用于通过iCustomChart访问自定义图表数据（如跳tick、Renko、Range Bar等）。它能自动检测是否存在自定义图表，若无则回退使用标准图表数据。每个tick刷新图表数据、读取最新收盘价并打印新K线提醒。

策略分析

该EA并非交易策略，而是一个工具类示例程序，用于展示LibCustomChart库的调用方法。其核心逻辑是在OnInit中通过CustomChartInit初始化与自定义图表的连接，在OnTick中通过CustomChartRefresh更新数据，然后使用CopyClose获取最后一根未完成K线的收盘价并打印。它还通过CustomChartNewBar检测是否有新K线生成并发出提醒。该EA没有入场条件、出场条件、仓位管理或资金管理逻辑，纯粹是一个数据读取和打印的演示工具。它最大的价值在于展示了如何在标准图表和自定义图表之间无缝切换数据源。

Summary

This EA demonstrates the usage of the LibCustomChart.ex5 library for accessing custom chart data (e.g., tick, renko, range bars) via iCustomChart. It automatically detects whether a custom chart is present and falls back to standard chart data if not. On each tick it refreshes chart data, reads the last Close price, and prints a new bar alert.

Strategy Analysis

This EA is not a trading strategy but a utility example demonstrating how to use the LibCustomChart library. Its core logic initializes the custom chart connection via CustomChartInit in OnInit, refreshes data via CustomChartRefresh in OnTick, then uses CopyClose to read the last unfinished bar's close price and prints it. It also detects new bar formation via CustomChartNewBar and issues an alert. There are no entry conditions, exit conditions, position sizing, or money management logic — it is purely a data reading and printing demonstration tool. Its greatest value lies in showing how to seamlessly switch data sources between standard and custom charts without modifying the EA code.

优势

  • 展示了自定义图表库的标准调用模式，便于开发者学习
  • 自动检测自定义图表存在性，实现标准与自定义图表无缝切换
  • 代码简洁清晰，注释和说明文档详尽，易于理解和扩展

劣势

  • 仅是演示示例，没有实际交易功能
  • 未包含任何错误恢复机制，若CustomChartRefresh持续失败则EA无法正常工作
  • 缺少对CopyClose失败的详细日志记录，不利于问题排查

改进建议

  • 增加更丰富的数据读取示例，如Open/High/Low/Volume和时间戳
  • 添加错误计数和重连机制，提高在自定义图表数据源异常时的鲁棒性

Strengths

  • Demonstrates the standard calling pattern for custom chart library, making it easy for developers to learn
  • Automatically detects custom chart presence, enabling seamless switching between standard and custom chart data
  • Clean and concise code with detailed comments and documentation, easy to understand and extend

Weaknesses

  • Only a demonstration example with no actual trading functionality
  • No error recovery mechanism — if CustomChartRefresh keeps failing, the EA cannot function properly
  • Lacks detailed logging for CopyClose failures, making troubleshooting difficult

Improvements

  • Add more comprehensive data reading examples such as Open/High/Low/Volume and timestamps
  • Add error counting and reconnection mechanism to improve robustness when custom chart data source is unstable
