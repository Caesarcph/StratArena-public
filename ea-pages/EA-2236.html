策略分析

分析 ### 2.1 核心策略概念 该EA基于John F. Ehlers在《Cybernetics Analysis for Stock and Futures》书中提出的**Fisher CG Oscillator**指标进行趋势跟踪。这是一种将重心(CG)指标与Fisher变换结合的科学量化方法： 1. **重心(CG)计算**：通过对价格进行加权平均(权重1到N线性递增)，计算价格的重心位置 2. **Stochastic归一化**：将CG值在Length周期内归一化到0-1范围 3. **加权平滑**：使用(4,3,2,1)权重进行四点加权平滑 4. **Fisher变换**：通过Fisher变换将归一化值转换为近似正态分布，放大极端值信号 ### 2.2 入场条件 **做多信号**： 1. 主线(Ind)在SignalBar+1位置高于触发线(Sign) 2. 在SignalBar位置主线向下穿越触发线（金叉确认） 3. `Ind[1] > Sign[1] && Ind[0] <= Sign[0]` **做空信号**： 1. 主线(Ind)在SignalBar+1位置低于触发线(Sign) 2. 在SignalBar位置主线向上穿越触发线（死叉确认） 3. `Ind[1] < Sign[1] && Ind[0] >= Sign[0]` ### 2.3 出场条件 **平多仓**：主线从上方穿越触发线向下时（`Ind[1] > Sign[1] && Ind[0] <= Sign[0]`） **平空仓**：主线从下方穿越触发线上方时（`Ind[1] < Sign[1] && Ind[0] >= Sign[0]`） ### 2.4 风险管理 - **止损**: 默认1000点（StopLoss_=1000） - **止盈**: 默认2000点（TakeProfit_=2000），盈亏比2:1 - **手数管理**: 支持5种模式（LOT/FREEMARGIN/BALANCE/LOSSFREEMARGIN/LOSSBALANCE） - **其他风控**: - 四开关交易控制（BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose） - 持仓检查（仅允许单方向持仓） - OrderCheck预检查机制 - 时间级别交易限制

优势

  • 科学量化基础：基于John Ehlers《Cybernetics Analysis》书的科学算法，Fisher变换有效放大极端值信号
  • 专业代码架构：Nikolay Kositsin专业级代码，CIsNewBar新K线检测类+TradeAlgorithms完整交易函数库
  • 完善的风控机制：5种手数计算模式+OrderCheck预检查+四开关交易控制+持仓检查
  • 盈亏比良好：默认2:1盈亏比（虽需优化止损幅度）
  • 环形缓冲区管理：高效的历史数据管理方式，避免数组移位操作

劣势

  • 止损过大：默认1000点止损极度过大，必须修改
  • 无趋势过滤：纯振荡器信号，缺少趋势强度确认机制
  • 无追踪止损：无法保护浮动盈利
  • 反转策略局限：穿越信号在强趋势行情中可能连续止损
  • 时间框架较慢：H8框架信号滞后严重
