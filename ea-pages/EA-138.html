摘要

Puria EA是一个基于三重均线交叉系统结合MACD过滤器的趋势跟踪专家顾问。当MA5上穿MA75和MA85且MACD为正时做多，当MA5下穿MA75和MA85且MACD为负时做空。通过固定止损止盈平仓，并使用单方向单笔订单标志防止重复入场。

策略分析

该EA的策略概念基于均线交叉趋势跟踪，使用三条不同周期的移动平均线（MA5、MA75、MA85）判断趋势方向，同时用MACD指标作为动量过滤器确认趋势强度。入场条件为：做多时MA5需同时位于MA75和MA85之上，前一根K线收盘价高于MA5，且MACD值大于0；做空时条件相反。出场条件完全依赖预设的固定止损（14点）和止盈（15点），没有移动止损或条件出场机制。仓位管理采用固定手数（0.1手），不根据账户余额或波动率动态调整。资金管理方面缺少最大持仓限制、回撤保护或资金比例计算，仅通过BuyOne/SellOne标志限制每个方向只开一单。整体策略逻辑简单清晰，但风险控制手段较为薄弱。

Summary

The Puria EA is a trend-following expert advisor that uses a triple moving average crossover system combined with a MACD filter. It enters long when MA5 crosses above both MA75 and MA85 with MACD positive, and enters short when MA5 crosses below both MA75 and MA85 with MACD negative. Positions are closed via fixed stop loss and take profit levels, with a one-order-per-direction flag to prevent repeated entries.

Strategy Analysis

The EA's strategy concept is based on a moving average crossover trend-following approach, using three moving averages of different periods (MA5, MA75, MA85) to determine trend direction, with the MACD indicator serving as a momentum filter to confirm trend strength. Entry conditions require: for a buy, MA5 must be above both MA75 and MA85 simultaneously, the previous bar's close price must be above MA5, and the MACD value must be greater than zero; for a sell, the conditions are the exact opposite. Exit conditions rely entirely on preset fixed stop loss (14 points) and take profit (15 points), with no trailing stop or conditional exit mechanism. Position sizing uses a fixed lot size (0.1 lots) without dynamic adjustment based on account balance or volatility. Money management lacks maximum position limits, drawdown protection, or equity percentage calculation, relying solely on the BuyOne/SellOne flags to limit one order per direction. Overall, the strategy logic is simple and clear, but risk control measures are relatively weak.

优势

  • 策略逻辑简洁清晰，三条均线配合MACD过滤能有效识别趋势
  • 有新K线检查机制，避免同一根K线内重复交易
  • 使用固定止损止盈，每笔交易都有明确的风险边界
  • 均线参数可自定义，便于优化适配不同品种和时间周期
  • 代码结构规范，包含指标句柄释放等资源管理
  • 包含5/3位数平台的点值自动调整逻辑

劣势

  • 仓位管理仅使用固定手数，无法根据账户风险动态调整
  • 缺少移动止损机制，盈利头寸无法锁定浮盈
  • BuyOne/SellOne标志在EA重启后会重置，可能造成重复入场
  • 止损止盈比率接近1:1，未考虑趋势交易中更大的波动空间
  • 没有检查OrderSend的返回结果，交易失败时无法感知和处理
  • PositionSelect仅检查当前品种，但MagicNumber过滤未应用于持仓检查

改进建议

  • 增加基于账户权益百分比或ATR的动态仓位计算，替代固定手数
  • 添加移动止损功能以保护浮盈，并检查OrderSend返回结果以处理交易失败
  • 使用持久化存储（如全局变量）保存BuyOne/SellOne状态，防止EA重启后状态丢失
  • 在持仓检查中加入MagicNumber过滤，避免与其他EA冲突

Strengths

  • Clean and straightforward strategy logic using triple MA crossover with MACD filter for effective trend identification
  • New bar check mechanism prevents repeated trading within the same bar
  • Fixed stop loss and take profit provide clear risk boundaries for each trade
  • Customizable MA parameters allow optimization for different instruments and timeframes
  • Well-structured code with proper resource management including indicator handle release
  • Automatic point value adjustment for 5/3 digit price platforms

Weaknesses

  • Position sizing uses only fixed lots with no dynamic adjustment based on account risk
  • Lacks trailing stop mechanism, profitable positions cannot lock in floating gains
  • BuyOne/SellOne flags reset on EA restart, potentially causing duplicate entries
  • Stop loss to take profit ratio is approximately 1:1, not accounting for larger trend movement potential
  • OrderSend return result is not checked, making it impossible to detect and handle trade failures
  • PositionSelect checks by symbol only but MagicNumber filtering is not applied to position checks

Improvements

  • Add dynamic position sizing based on account equity percentage or ATR to replace fixed lots
  • Implement trailing stop functionality to protect floating profits and check OrderSend return results to handle trade failures
  • Use persistent storage (e.g., global variables) to save BuyOne/SellOne state to prevent state loss on EA restart
  • Add MagicNumber filtering in position checks to avoid conflicts with other EAs
