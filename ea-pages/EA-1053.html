摘要

该EA基于每日支点位的突破进行交易。当价格收盘突破支点时开仓做多或做空，使用支点支撑/阻力位设置止损和止盈。包含连续亏损后缩减仓位的机制，以及达到第一目标后将止损移至保本的选项。

策略分析

策略概念基于经典支点计算，使用前一日的高点、低点和收盘价计算支点及三档支撑阻力位。入场条件为：前一根K线收盘价从下方穿越支点时做多，从上方穿越支点时做空。出场条件包括：触及止盈（支撑/阻力位）、触及止损（对应支撑/阻力位）、日内交易模式下23:00强制平仓。仓位管理方面，当Lots参数为0时根据账户自由保证金和最大风险比例计算仓位，连续亏损时会按DcF因子递减仓位以控制风险。止损止盈根据TgtProfit参数选择不同层级的支撑阻力位，若第一组止损止盈不满足最小止损距离要求，会尝试使用第二组参数开仓。ModSL功能允许在价格达到第一目标后将止损移至保本价位，提升风险控制能力。

Summary

This EA trades pivot point breakouts on the current symbol. It enters buy when price closes above the daily pivot and sell when it closes below, using pivot support/resistance levels for stop loss and take profit. It includes a lot reduction mechanism after consecutive losses and an optional breakeven stop loss modification when the first target is reached.

Strategy Analysis

The strategy is based on classic pivot point calculations using the previous day's high, low, and close to compute the pivot and three levels of support and resistance. Entry conditions: a buy signal is generated when the previous bar's close crosses above the pivot from below, and a sell signal when it crosses below from above. Exit conditions include hitting take profit at support/resistance levels, hitting stop loss at the corresponding opposite levels, or forced close at 23:00 when intraday-only mode is enabled. For position sizing, when the Lots parameter is 0, the lot size is calculated based on free margin and maximum risk ratio; after consecutive losses, the lot is reduced according to the DcF factor to control drawdown. Stop loss and take profit are set using different tiers of support/resistance based on the TgtProfit parameter, and if the first set fails minimum stop level checks, a second variant with wider stops is attempted. The ModSL feature moves stop loss to breakeven once the first profit target is reached, improving risk management.

优势

  • 基于经典支点策略，逻辑清晰且经过市场长期验证
  • 连续亏损后自动缩减仓位，具有基本的风险控制意识
  • 提供保本止损功能，可在第一目标达成后锁定利润
  • 对止损止盈进行最小距离校验，防止因不满足交易所要求而被拒单
  • 第一组止损止盈不满足时自动尝试第二组参数，提高开仓成功率

劣势

  • 支点策略在震荡市中容易产生频繁的虚假突破信号
  • 没有使用任何趋势过滤器，可能逆势交易导致较大亏损
  • DcF仓位缩减机制虽然不是马丁格尔，但连续亏损后的缩减逻辑较粗糙
  • 23:00平仓的日内模式过于简单，未考虑周五或节假日的特殊处理
  • 缺少点差过滤，在高位点差环境下可能不利地开仓

改进建议

  • 添加趋势过滤器（如均线或ATR方向判断），仅在趋势方向与信号一致时开仓
  • 增加点差过滤和滑点保护，避免在高点差时段交易
  • 改进仓位缩减逻辑，考虑使用固定分数或凯利公式替代简单的线性缩减

Strengths

  • Based on the classic pivot point strategy with clear logic that has been validated over time
  • Automatically reduces position size after consecutive losses, showing basic risk awareness
  • Provides breakeven stop loss feature to lock in profit after the first target is reached
  • Validates stop loss/take profit against minimum stop levels to prevent order rejection
  • Falls back to a second SL/TP variant if the first fails validation, improving trade execution rate

Weaknesses

  • Pivot breakout strategy tends to generate frequent false signals in ranging markets
  • No trend filter is applied, potentially leading to counter-trend trades with large losses
  • The DcF lot reduction mechanism, while not martingale, is crude in its loss-counting logic
  • The 23:00 forced close is oversimplified with no special handling for Fridays or holidays
  • Lacks spread filtering, which may result in unfavorable entries during high-spread conditions

Improvements

  • Add a trend filter (e.g., moving average or ATR direction) to only trade when the signal aligns with the trend
  • Add spread filtering and slippage protection to avoid trading during high-spread periods
  • Improve the lot reduction logic by using fixed fractional sizing or Kelly criterion instead of simple linear reduction
