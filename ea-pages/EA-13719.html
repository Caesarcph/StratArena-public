摘要

HVR（历史波动率比率）是一个自定义技术指标，使用对数收益率计算6周期历史波动率与100周期历史波动率的比值。它在独立窗口中显示该比率，帮助交易者识别短期波动率相对于长期波动率的扩张或收缩。HTF版本允许在低周期图表上查看高周期的指标值。

策略分析

该指标不是交易EA，而是一个波动率分析工具。其核心概念是通过对数收益率计算短期（6周期）和长期（100周期）的历史波动率，然后将两者相除得到HVR比值。短期波动率使用6根K线的对数收益率标准差（乘以sqrt(252)*100即7.2111...进行年化），长期波动率使用100根K线做同样计算。当HVR大于1时，说明短期波动率高于长期均值，市场处于剧烈波动状态；当HVR小于1时，短期波动低于长期水平，市场相对平静。入场和出场条件并不由该指标直接提供，它仅作为辅助分析工具供交易者参考。该指标支持12种不同的价格类型作为输入，包括收盘价、开盘价、最高价、最低价及多种合成价格。仓位管理和资金管理不涉及，因为这是纯分析指标而非交易系统。需要注意的是，指标使用循环数组（Count数组）管理历史数据索引，避免频繁的数组移位操作，这是一种优化技巧。

Summary

HVR (Historical Volatility Ratio) is a custom technical indicator that computes the ratio of 6-period historical volatility to 100-period historical volatility using logarithmic price returns. It displays this ratio in a separate window, helping traders identify when short-term volatility is expanding or contracting relative to long-term volatility. The HTF version allows viewing this indicator on higher timeframes from a lower timeframe chart.

Strategy Analysis

This is not a trading EA but a volatility analysis indicator. Its core concept calculates the ratio of short-term (6-period) to long-term (100-period) historical volatility using logarithmic price returns, then annualizes each by multiplying the standard deviation by sqrt(252)*100 (approximately 7.2111). When HVR exceeds 1, short-term volatility is above the long-term average, signaling an active or volatile market; when below 1, short-term volatility is subdued relative to the long-term, indicating a calmer market. Entry and exit conditions are not directly provided by this indicator — it serves purely as an analytical tool for traders to inform their own decisions. The indicator supports 12 different applied price types as input, including close, open, high, low, and various synthetic price calculations like median, typical, weighted, simpl, quarter, trend-following, and Demark prices. Position sizing and money management are not applicable since this is a purely analytical indicator, not a trading system. Notably, the indicator uses a circular array (Count array) to manage historical data indexing, which is an optimization technique to avoid frequent array shift operations.

优势

  • 使用对数收益率计算波动率，这是金融统计中的标准方法，数学上更加严谨
  • 短期与长期波动率比值能有效识别波动率体制转换，对期权交易和波动率交易具有参考价值
  • 循环数组优化避免了每次迭代的数组移位操作，提高了计算效率
  • 支持12种价格类型，灵活性高，适应不同交易风格

劣势

  • 当长期波动率hv100为零时，指标使用前一个值替代，这可能导致在极端情况下指标值不准确
  • 6周期和100周期的窗口长度硬编码，用户无法根据不同市场或交易风格调整参数
  • 指标仅提供波动率比率信息，缺少可视化辅助如超买超卖水平线或信号提示
  • 年化因子sqrt(252)假设252个交易日，对加密货币等24/7市场不适用

改进建议

  • 将N=100和6周期窗口改为可配置的输入参数，允许用户根据不同市场和策略调整波动率计算周期
  • 添加关键水平线（如1.0基准线、超买超卖阈值）和报警功能，增强指标的实用性
  • 增加对零除情况的更好处理，例如使用长期波动率的指数移动平均替代简单的向前填充

Strengths

  • Uses logarithmic returns for volatility calculation, which is the standard method in financial statistics and mathematically rigorous
  • The short-term to long-term volatility ratio effectively identifies volatility regime shifts, valuable for options trading and volatility-based strategies
  • Circular array optimization avoids array shifting on each iteration, improving computational efficiency
  • Supports 12 applied price types, offering high flexibility to accommodate different trading styles

Weaknesses

  • When long-term volatility hv100 is zero, the indicator substitutes the previous value, which may lead to inaccuracy in extreme market conditions
  • The 6-period and 100-period window lengths are hardcoded, preventing users from adjusting parameters for different markets or trading styles
  • The indicator only provides the volatility ratio without visual aids such as overbought/oversold threshold lines or signal alerts
  • The annualization factor sqrt(252) assumes 252 trading days, which is inappropriate for 24/7 markets like cryptocurrencies

Improvements

  • Make N=100 and the 6-period window configurable input parameters, allowing users to adjust volatility calculation periods for different markets and strategies
  • Add key level lines (such as the 1.0 baseline and overbought/oversold thresholds) and alert functionality to enhance the indicator's practical utility
  • Improve handling of the zero-division case, for example by using an exponential moving average of long-term volatility instead of simple forward-filling
