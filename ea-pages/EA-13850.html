策略分析

分析 ### 2.1 核心策略概念 **Schaff Trend Cycle (Schaff趋势周期)** 是一个复杂的循环振荡器，由Doug Schaff开发。该EA使用的是**JJRSX版本**，即用JurX+JMA双重平滑的RSX指标替代传统MACD作为基础。 **核心算法流程**: 1. **JJRSX计算**: 使用JurX平滑算法处理RSX(Relative Strength X)指标 2. **MACD差值**: 快速JJRSX - 慢速JJRSX = MACD 3. **双重Stochastic归一化**: - 第一重: MACD极值归一化到0-100 - 第二重: 再次极值归一化到-100到+100 4. **循环因子平滑**: 使用Cycle周期进一步平滑信号 5. **八色状态机**: 根据数值和变化率分配颜色状态 ### 2.2 入场条件 **基于八色状态机的趋势转折检测**: **做多信号**: - Color[1] > 5 (前一K线处于强势看涨区域，颜色6或7) - Color[0] < 6 (当前K线颜色低于6，表示趋势转折) **做空信号**: - Color[1] < 2 (前一K线处于强势看跌区域，颜色0或1) - Color[0] > 1 (当前K线颜色高于1，表示趋势转折) **八色状态机定义**: | 颜色值 | 趋势状态 | 条件 | | 0 | 强下降 | STC < -60 且 dSTC < 0 | | 1 | 弱下降转强 | STC < -60 且 dSTC >= 0 | | 2 | 中等下降 | -60 <= STC < 0 且 dSTC < 0 | | 3 | 弱下降转升 | -60 <= STC < 0 且 dSTC >= 0 | | 4 | 中性偏弱 | 0 <= STC < 60 且 dSTC < 0 | | 5 | 弱上升 | 0 <= STC < 60 且 dSTC >= 0 | | 6 | 强上升转弱 | STC > 60 且 dSTC < 0 | | 7 | 强上升 | STC > 60 且 dSTC >= 0 | ### 2.3 出场条件 - **止损出场**: 固定点数止损（默认1000点） - **止盈出场**: 固定点数止盈（默认2000点） - **信号反转出场**: 当颜色状态从强势转为弱势时平仓

优势

  • Schaff趋势周期算法: 双重Stochastic归一化有效识别超买超卖转折点
  • JJRSX高级平滑: JurX+JMA双重平滑减少噪音，信号更稳定
  • 八色状态机: 详细量化趋势强度，提供更精准的入场时机
  • 专业级代码架构: Nikolay Kositsin开发，代码规范、结构清晰
  • 完善的交易函数库: TradeAlgorithms包含完整的手数计算、订单预检查
  • 盈亏比良好: 默认TP=2000/SL=1000，盈亏比2:1
  • 四开关交易控制: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose灵活控制

劣势

  • 默认止损过大: 1000点止损在波动市场中可能造成较大损失
  • 无趋势方向过滤: 缺乏整体趋势确认，震荡市场可能产生假信号
  • 无追踪止损: 固定止损止盈无法保护浮动盈利
  • 参数较多: JJRSX参数+Cycle参数+颜色阈值，优化复杂度高
  • 信号滞后: 双重Stochastic+循环平滑导致信号延迟
