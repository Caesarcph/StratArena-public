摘要

该EA实现了一种适用于小资金账户的马丁格尔仓位策略。它根据15根K线的动量比较开仓，然后以固定间隔同方向加仓，同时按可配置的乘数因子指数级增加仓位手数。当所有持仓的总盈利超过阈值时，一次性全部平仓。

策略分析

策略概念基于马丁格尔加仓法：初始方向由最近15根K线收盘价趋势决定（价格上涨开空，下跌开买，即逆势入场）。入场条件为：无持仓时，比较arr_close[0]与arr_close[14]，若价格下跌则开多，上涨则开空，这实际上是一种逆势交易逻辑。加仓条件为：已有买入持仓时，若当前Ask价低于最低买入价超过InpStep距离则继续加多；卖出持仓同理。仓位管理采用指数递增方式，每次加仓手数为初始手数乘以InpIncreaseFactor的n次方（n为当前同方向持仓数），上限为InpMaxLot。出场条件仅有总盈利超过InpMinProfit时全部平仓，没有任何止损机制。资金管理方面，通过LotCheck函数规范手数，但没有考虑账户整体风险敞口，且缺少硬性止损保护，极端行情下可能爆仓。

Summary

This EA implements a martingale-style position-sizing strategy for small deposits. It opens an initial position based on a simple 15-bar momentum comparison, then adds positions in the same direction at fixed step intervals while exponentially increasing lot size by a configurable factor. When the total profit across all positions exceeds a threshold, it closes all positions simultaneously.

Strategy Analysis

The strategy concept is based on a martingale position-averaging approach: the initial direction is determined by comparing the close prices of the last 15 bars (price decline opens buy, price rise opens sell, which is a counter-trend entry logic). Entry conditions: when no positions exist, it compares arr_close[0] with arr_close[14]; if price has fallen it opens a buy, if risen it opens a sell. Additional position conditions: for existing buy positions, if the current Ask price is below the lowest buy price by more than InpStep pips, another buy is added; sells work symmetrically. Position sizing uses exponential scaling where each new position's lot equals the base lot multiplied by InpIncreaseFactor raised to the power of the current position count, capped at InpMaxLot. Exit conditions are solely based on total unrealized profit exceeding InpMinProfit, at which point all positions close simultaneously. There is no stop-loss on any individual position, meaning the strategy relies entirely on the market reverting to breakeven territory before the account is depleted. Money management normalizes lot sizes via LotCheck but does not assess overall account risk exposure, making it highly vulnerable to sustained trending markets.

优势

  • 代码结构清晰，使用了MQL5标准交易库（CTrade、CPositionInfo、CSymbolInfo），规范性好
  • 有手数规范化检查（LotCheck），确保下单手数符合经纪商要求
  • 包含点数自动调整逻辑（3/5位小数适配），兼容不同报价精度
  • 有新K线检测机制，避免同一根K线重复交易
  • 包含下单前资金检查（CheckVolume），避免余额不足报错

劣势

  • 典型马丁格尔策略，无止损保护，趋势行情中持仓会持续扩大，爆仓风险极高
  • 加仓手数呈指数增长（1.7^n），仓位膨胀速度极快，小账户极易触及保证金限制
  • 初始入场逻辑（15根K线逆势）过于简单，没有有效的市场方向判断
  • 没有任何止损机制，完全依赖价格回归来解套，单边行情可能直接爆仓
  • InpBarsSkipped跳过K线的设计意图不明，且实现逻辑有潜在Bug（CopyOpen时间范围可能不准确）

改进建议

  • 添加硬性止损机制，为每笔订单和整体持仓设置最大亏损限制
  • 改进入场逻辑，引入趋势指标（如均线、ATR）过滤，避免在强趋势中逆势加仓
  • 加入账户风险控制，根据账户余额动态调整加仓倍数和最大持仓数

Strengths

  • Clean code structure using standard MQL5 trade libraries (CTrade, CPositionInfo, CSymbolInfo) for robust order handling
  • Lot size normalization via LotCheck ensures compliance with broker volume constraints
  • Automatic point adjustment for 3/5 digit brokers provides cross-symbol compatibility
  • New bar detection prevents duplicate trades within the same bar
  • Pre-order margin check via CheckVolume helps avoid insufficient balance errors

Weaknesses

  • Classic martingale strategy with no stop-loss protection; positions expand continuously in trending markets with extreme blow-up risk
  • Exponential lot increase (1.7^n) causes position sizes to grow very rapidly, easily hitting margin limits on small accounts
  • Entry logic (15-bar counter-trend comparison) is overly simplistic with no robust directional analysis
  • Complete absence of any stop-loss mechanism relies entirely on mean reversion, which can be fatal in sustained trends
  • The InpBarsSkipped bar-counting logic has potential bugs with CopyOpen date range parameters and its design intent is unclear

Improvements

  • Add hard stop-loss mechanisms for both individual positions and overall portfolio drawdown limits
  • Improve entry logic by incorporating trend indicators (e.g., moving averages, ATR) to avoid adding positions against strong trends
  • Implement account-level risk controls that dynamically adjust the increase factor and maximum position count based on equity and margin usage

Risk Assessment

Overall:DANGEROUS

Risk Points

  • No stop-loss mechanism; sustained one-way market movement can lead to unlimited losses until margin call
  • Martingale-style exponential lot increase causes risk exposure to grow exponentially
  • Designed for small deposits but margin can be exhausted almost instantly in extreme volatility
  • No spread filter; in high-spread environments the step distance may not cover transaction costs
  • Hedging detection (both buy and sell open) triggers an immediate close-all, potentially causing unnecessary losses
