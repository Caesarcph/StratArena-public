策略分析

分析 ### 2.1 核心策略概念 这是一个**零延迟多周期DeMarker振荡器趋势跟踪策略**，核心思想是： 1. **多周期加权组合**：使用5个斐波那契周期(8/21/34/55/89)的DeMarker指标加权组合 2. **零延迟设计**：通过权重归一化消除单一周期的滞后 3. **快慢线穿越**：快线(FastTrend)穿越慢线(SlowTrend)产生交易信号 4. **新K线触发**：仅在每根新K线时计算信号，避免重复交易 ### 2.2 零延迟算法详解 **ColorZerolagDeMarker指标算法** (colorzerolagdemarker.mq5): **权重系数设计** (归一化总和=1.0): - Factor1 = 0.05 (8周期权重) - Factor2 = 0.10 (21周期权重) - Factor3 = 0.16 (34周期权重) - Factor4 = 0.26 (55周期权重) - Factor5 = 0.43 (89周期权重) 权重递增设计使长周期贡献更大，有效减少噪音。 ### 2.3 入场条件 **做多信号** (129-134行): ⚠️ **注意**：这里的逻辑是"穿越后确认"，即快线从上方穿越到下方时做多。这实际上是**动量减弱时入场**的策略。 **做空信号** (137-142行): ### 2.4 出场条件 **平多仓**：快线从下方穿越到上方时 **平空仓**：快线从上方穿越到下方时 出场逻辑与入场逻辑对称，形成完整的趋势跟踪循环。 ### 2.5 风险管理 | 参数 | 默认值 | 说明 | | StopLoss | 1000点 | 止损距离 (⚠️过大，建议150-300点) | | TakeProfit | 2000点 | 止盈距离 | | 盈亏比 | 2:1 | 良好 | | MM | 0.1 | 手数参数 | | MMMode | LOT | 手数计算模式 |
