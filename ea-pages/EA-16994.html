策略分析

分析 ### 2.1 核心策略概念 该EA是一个基于布林带(Bollinger Bands)的均值回归策略。核心思想是当价格突破布林带上轨时做空，突破下轨时做多，期待价格回归布林带中轨。这是一种典型的"逆势交易"或"均值回归"策略，假设极端价格偏离后会回归均值。 ### 2.2 入场条件 **做空入场**: - 收盘价 > 布林带上轨 + InpBDistance点 - 即 `Close[0] > UpperBand + (ExtBDistance * Point)` **做多入场**: - 收盘价 < 布林带下轨 - InpBDistance点 - 即 `Close[0] < LowerBand - (ExtBDistance * Point)` **入场模式**: - OneOrderOnly=true: 仅当无持仓时入场 - OneOrderOnly=false: 每根新K线都可以入场(受TradeAllowed控制) ### 2.3 出场条件 **止盈出场**: - 当浮盈 >= InpProfitMade点时手动平仓 - 买入仓位: `CurrentProfit >= ExtProfitMade * Point` - 卖出仓位: `CurrentProfit >= ExtProfitMade * Point` **止损出场**: - 当浮亏 >= InpLossLimit点时手动平仓 - 买入仓位: `CurrentProfit <= -ExtLossLimit * Point` - 卖出仓位: `CurrentProfit <= -ExtLossLimit * Point` **注意**: 止盈止损通过OnTick实时监控实现，不是发送订单时设置的硬性SL/TP。 ### 2.4 风险管理 - **止损**: InpLossLimit=20点(默认)，开仓时设置SL=开仓价±(ExtLossLimit+10)点 - **止盈**: InpProfitMade=3点(默认)，开仓时设置TP=开仓价±(ExtProfitMade+10)点 - **手数管理**: - 固定手数模式: InpLots=1.0(默认) - 动态手数模式: LotIncrease=true时，手数=账户余额/StartingBalance - **持仓限制**: OneOrderOnly=true(默认)限制同时只持有1个仓位

优势

  • 代码结构清晰: 标准库完整使用(CTrade/CSymbolInfo/CAccountInfo等)，易于维护
  • 完善的日志系统: 支持多种日志级别(logging/logerrs/logtick)，便于调试和监控
  • 权益统计功能: 记录最大/最小权益、正负tick统计，便于回测分析
  • 动态手数机制: LotIncrease功能可根据账户余额自动调整手数
  • 新K线检测: bartime!=iTime(0)避免同一K线重复入场

劣势

  • 盈亏比极差: 默认TP=3/SL=20，盈亏比0.15:1，无法长期盈利
  • 布林带周期过短: BB_period=4严重偏离标准，噪音过多导致假信号
  • 固定手数过大: 默认1.0手对大多数账户过于激进
  • 逆势交易无保护: 均值回归策略在趋势行情会持续亏损
  • 无时间过滤: 未限制交易时段，可能在低流动性时段交易
