策略分析

分析 ### 2.1 核心策略概念 这是一个**固定时间突破策略**，在每天指定的交易时间（默认18:00）检测特定两根K线的价格差异： 1. **交易时间窗口**: 仅在`TradeTime`(默认18:00)整点时刻执行交易 2. **突破逻辑**: 比较H1周期上`t1`(第7根)和`t2`(第2根)K线的开盘价 3. **方向判断**: - 如果`Open[t1] > Open[t2] + delta`: 价格突破向上，做空（逆向操作） - 如果`Open[t1] + delta < Open[t2]`: 价格突破向下，做多（逆向操作） 4. **每日一单**: 使用`cantrade`标志确保每天最多只交易一次 **关键特征**: 这是一个**逆向突破策略**——价格上涨突破时做空，价格下跌突破时做多。 ### 2.2 入场条件 | 条件 | 方向 | 逻辑说明 | | `Open[t1] > Open[t2] + delta*Point` | 做空(SHORT) | H1第7根K线开盘价高于第2根开盘价70点以上 | | `Open[t1] + delta*Point < Open[t2]` | 做多(LONG) | H1第7根K线开盘价低于第2根开盘价70点以上 | **时间限制**: - 仅在`mqldt.hour == TradeTime`(默认18:00)时执行 - 必须满足`cantrade=true`条件（每日重置） **持仓限制**: - 仅当`!PositionSelect(_Symbol)`时才开仓（无持仓状态） ### 2.3 出场条件 | 类型 | 设置 | 说明 | | **止盈(TP)** | 200点 | 固定止盈 | | **止损(SL)** | 2000点 | 固定止损 | | **盈亏比** | **1:10** | 极度危险! | ### 2.4 风险管理 - **止损**: 2000点（固定值，无动态调整） - **止盈**: 200点（固定值） - **手数**: 固定0.1手（可配置`lot`参数） - **每日限制**: 使用`cantrade`布尔标志限制每天只交易一次 - **滑点容忍**: 10点

优势

  • 代码结构清晰: 函数划分合理，易于理解和维护
  • 每日交易限制: 防止过度交易的简单有效机制
  • 标准MQL5交易实现: 正确使用MqlTradeRequest结构
  • 完整错误处理: 包含ResetLastError和GetLastError调用
  • 时序数组正确处理: 使用ArraySetAsSeries处理价格数组

劣势

  • 🔴 致命盈亏比1:10: 止损是止盈的10倍，数学上不可行
  • 🔴 逆向突破逻辑矛盾: 逆向策略需要小止损快速止盈，但参数设置完全相反
  • 🟠 无品种/周期验证: 可能在不适配的品种上运行
  • 🟠 固定手数无风控: 不考虑账户资金和风险承受能力
  • 🟡 全局变量存储价格: 使用全局Ask/Bid变量是不良实践
