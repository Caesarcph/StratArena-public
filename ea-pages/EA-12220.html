摘要

该EA是一个马丁格尔风格的加仓系统，根据RSI和近期价格方向开仓后，当持仓亏损超过动态点数阈值时，以递增手数加仓。每次加仓手数按指数倍增，并配备权益止损、CCI止损、追踪止损和时间止损等多种退出机制。

策略分析

策略核心是马丁格尔加仓法：首仓由RSI指标和K线方向判断入场——RSI高于下限时且价格收阳做多，RSI低于上限时且价格收阴做空。当持仓浮亏超过动态计算的点数阈值（基于近期High-Low范围除以DEL因子）时，按LotExponent的幂次递增手数加仓，实现均价摊低。出场条件包括：所有仓位加权均价达到TakeProfit点数盈利时平仓、CCI指标绝对值超过CCILevel时平仓、权益回撤超过TotalEquityRisk百分比时平仓、持仓时间超过MaxTradeOpenHours时平仓，以及可选的追踪止损。仓位管理采用指数加仓模式，手数为Lots × LotExponent^(当前持仓数+1)，加仓次数上限为MaxTrades。动态点数阈值通过最近Glubina根K线的最高最低价差计算，并以DEL因子调整，同时受DefaultPips上下限约束，使加仓间距能根据市场波动率自适应调整。

Summary

This EA is a Martingale-style averaging system that opens an initial position based on RSI and recent price direction, then opens progressively larger positions when the existing position goes into loss beyond a dynamic pip threshold. It uses a lot exponent multiplier for each subsequent averaging trade and includes multiple exit mechanisms including equity stop, CCI stop, trailing stop, and time-based closure.

Strategy Analysis

The core strategy is a Martingale averaging system: the first position is opened based on the RSI indicator and recent candle direction—buying when RSI is above the lower bound and the last candle closed up, selling when RSI is below the upper bound and the last candle closed down. When the floating loss exceeds a dynamically calculated pip threshold (based on the recent High-Low range divided by the DEL factor), a new position is opened with a lot size multiplied by LotExponent raised to the power of the current position count, effectively lowering the average entry price. Exit conditions include: closing all positions when the weighted average price reaches TakeProfit pips in profit, closing when the CCI indicator's absolute value exceeds CCILevel, closing when equity drawdown exceeds TotalEquityRisk percent of the high-water mark, closing when position holding time exceeds MaxTradeOpenHours, and an optional trailing stop. Position sizing follows an exponential progression where each new lot equals Lots × LotExponent^(current_position_count+1), with a maximum of MaxTrades positions. The dynamic pip threshold is calculated from the highest-high minus lowest-low over the last Glubina bars, adjusted by the DEL factor, and constrained by DefaultPips upper and lower bounds, allowing the grid spacing to adapt to current market volatility.

优势

  • 动态加仓间距根据市场波动率自适应调整，比固定间距的马丁格尔更灵活
  • 提供多种出场机制（权益止损、CCI止损、追踪止损、时间止损），风险控制手段较丰富
  • 代码结构清晰，模块化程度高，使用了多个自定义类（CEnvironment、CIndicators等）封装功能
  • 仅在出现新K线时执行交易逻辑，避免逐tick频繁交易
  • 图形化渲染持仓和交易历史，便于可视化回测分析

劣势

  • 马丁格尔加仓策略本质风险极高，连续加仓可导致手数指数级增长，极端行情下可能爆仓
  • 默认关闭止损(UseStopLoss=false)，首仓和加仓均无硬性止损保护
  • LotExponent=1.4在10次加仓后手数放大约28倍，资金压力巨大
  • RSI入场逻辑过于简单，仅用单周期RSI和单根K线方向判断，缺乏趋势过滤
  • 多种出场机制默认全部关闭，用户若不主动配置则几乎无风险保护
  • 短仓追踪止损逻辑存在bug：stopLevel>currStopLoss判断对短仓方向错误，应改为stopLevel<currStopLoss

改进建议

  • 修复短仓追踪止损的方向判断bug，将stopLevel>currStopLoss改为stopLevel<currStopLoss
  • 增加趋势过滤器（如多周期MA或ADX），避免在强趋势中逆势加仓导致爆仓
  • 默认启用权益止损并将TotalEquityRisk设为更保守的值，提供开箱即用的基本风险保护
  • 加入点差过滤和交易时间过滤，避免在点差过大或流动性差的时段开仓
  • 限制最大总手数而非仅限制加仓次数，防止资金占用超过账户承受能力

Strengths

  • Dynamic pip spacing adapts to market volatility, making the Martingale grid more flexible than fixed-interval versions
  • Multiple exit mechanisms (equity stop, CCI stop, trailing stop, time-based stop) provide layered risk control
  • Clean code structure with high modularity using custom classes (CEnvironment, CIndicators, etc.) for encapsulation
  • Trading logic only executes on new bars, avoiding excessive per-tick trading activity
  • Graphical rendering of positions and trade history aids visual backtesting analysis

Weaknesses

  • Martingale averaging strategy carries extreme inherent risk—consecutive additions cause exponential lot growth, potentially blowing the account in trending markets
  • Stop-loss is disabled by default (UseStopLoss=false), leaving positions without hard stop protection
  • With LotExponent=1.4 and 10 max trades, lot size amplifies ~28x, creating enormous capital pressure
  • RSI entry logic is overly simplistic—using only single-period RSI and one candle direction without trend filtering
  • All exit mechanisms are disabled by default, providing virtually no risk protection unless the user actively configures them
  • Short position trailing stop logic has a bug: the condition stopLevel>currStopLoss is incorrect for shorts and should be stopLevel<currStopLoss

Improvements

  • Fix the short position trailing stop direction bug—change stopLevel>currStopLoss to stopLevel<currStopLoss for shorts
  • Add a trend filter (e.g., multi-timeframe MA or ADX) to avoid counter-trend averaging in strong trends that leads to account blowup
  • Enable equity stop by default with a more conservative TotalEquityRisk value to provide out-of-the-box basic risk protection
  • Add spread filter and session filter to avoid opening positions during high-spread or low-liquidity periods
  • Cap maximum total lot size instead of only limiting the number of positions, preventing capital usage from exceeding account capacity
