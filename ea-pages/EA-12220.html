摘要

这是一款马丁格尔式加仓EA，根据RSI和近期价格方向开仓后，当持仓浮亏超过动态点数阈值时，按指数递增手数同方向加仓。EA提供可选的权益止损、CCI止损、追踪止损、经典止损和时间止损机制。

策略分析

该EA采用马丁格尔加仓策略，首次入场依赖RSI指标和最近两根K线的收盘价比较判断方向：RSI高于下限且价格上升时做多，RSI低于上限且价格下降时做空。当已有持仓浮亏超过动态计算的点数阈值时，EA按LotExponent的幂次递增手数进行同方向加仓，以降低均价。动态点数阈值基于最近Glubina根K线的最高价与最低价之差除以DEL计算，并限制在DefaultPips/DEL到DefaultPips*DEL之间。出场方式多样：所有持仓的加权均价达到TakeProfit点数盈利时止盈，可选经典止损、权益止损、CCI极端值止损和超时止损。追踪止损在加权均价盈利超过TrailStart点后启动，维持TrailStop点距离的止损跟随。仓位管理上，最大持仓数受MaxTrades限制，手数按Lots乘以LotExponent的(持仓数+1)次方计算，小数位数由lotdecimal控制。

Summary

A Martingale-style averaging EA that opens an initial position based on RSI and recent price direction, then progressively opens larger positions in the same direction when the existing position is in loss beyond a dynamic pip threshold. It includes optional equity stop, CCI stop, trailing stop, classic stop-loss, and time-based exit mechanisms.

Strategy Analysis

This EA employs a Martingale averaging strategy where the initial entry relies on the RSI indicator and a comparison of the last two bar closing prices: it buys when RSI is above the lower bound and price is rising, and sells when RSI is below the upper bound and price is falling. When an existing position is in loss exceeding a dynamically calculated pip threshold, the EA opens an additional position in the same direction with an exponentially increased lot size to lower the average entry price. The dynamic pip threshold is computed from the highest-high minus lowest-low over the last Glubina bars divided by DEL, clamped between DefaultPips/DEL and DefaultPips*DEL. Exit mechanisms are diversified: all positions close at take-profit when the weighted average price reaches TakeProfit pips in profit, with optional classic stop-loss, equity stop, CCI extreme level stop, and time-based stop. The trailing stop activates when the weighted average profit exceeds TrailStart pips and maintains a TrailStop pip distance from current price. Position sizing uses Lots multiplied by LotExponent raised to the power of (current position count + 1), with decimal precision controlled by lotdecimal, and maximum open positions capped by MaxTrades.

优势

  • 提供多种出场机制（止损、权益止损、CCI止损、追踪止损、时间止损），风险管理手段丰富
  • 动态点数阈值根据市场波动自动调整加仓间距，比固定间距更适应行情变化
  • 使用对冲持仓API（HedgePosition）管理仓位，支持双向持仓和精细化仓位控制
  • 代码结构清晰，模块化程度高，包含图表绘制和测试表格输出功能
  • RSI结合价格方向判断首仓入场，避免在极端超买超卖区域逆势开仓

劣势

  • 马丁格尔加仓策略在单边行情中风险极高，手数按指数增长可能导致爆仓
  • 默认未启用任何止损（UseStopLoss=false, UseEquityStop=false, UseTrailingStop=false），裸奔风险巨大
  • 追踪止损的做空方向逻辑有bug：stopLevel应小于currStopLoss才修改，但代码用了与做多相同的比较方向
  • GetLot函数中索引从GetPositionsTotal()+1开始，首次加仓时手数计算偏高
  • 缺乏点差过滤和交易时段过滤，在恶劣流动性条件下可能频繁加仓

改进建议

  • 修复做空追踪止损的比较逻辑bug，确保stopLevel低于currStopLoss时才修改止损
  • 增加最大总手数限制和账户余额百分比止损，防止马丁格尔策略无限加仓导致爆仓
  • 添加点差过滤和交易时段控制，避免在流动性差或点差过大的时段加仓

Strengths

  • Multiple exit mechanisms (stop-loss, equity stop, CCI stop, trailing stop, time stop) provide diversified risk management
  • Dynamic pip threshold adapts averaging distance to market volatility, more responsive than fixed intervals
  • Uses Hedge Position API for position management, supporting bi-directional holding and fine-grained control
  • Clean modular code structure with chart drawing and tester table output functionality
  • RSI combined with price direction for initial entry avoids counter-trend opening at extreme overbought/oversold levels

Weaknesses

  • Martingale averaging strategy carries extreme risk in trending markets; exponential lot growth can lead to account blow-up
  • No stop-loss mechanism enabled by default (UseStopLoss=false, UseEquityStop=false, UseTrailingStop=false), leaving positions unprotected
  • Trailing stop logic has a bug for short positions: stopLevel comparison uses same direction as long, should check if stopLevel is lower than current SL
  • GetLot function index starts from GetPositionsTotal()+1, causing first averaging lot to be larger than intended
  • No spread filter or trading session filter, potentially causing frequent averaging under poor liquidity conditions

Improvements

  • Fix the trailing stop comparison logic bug for short positions; stop-loss should only be modified when stopLevel is lower than current SL for shorts
  • Add maximum total lot size limit and account balance percentage stop to prevent unlimited Martingale position growth leading to margin call
  • Add spread filter and trading session control to avoid averaging during high-spread or low-liquidity periods
