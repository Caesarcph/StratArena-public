策略分析

分析 ### 2.1 核心策略概念 **CCI+感知器混合策略 (CCI + Perceptron Hybrid Strategy)** 该策略结合了传统的CCI指标和一个简单的单层感知器神经网络。基础信号来自CCI，然后使用3个不同的感知器进行过滤和增强。 ### 2.2 基础交易系统 (CCI) **信号逻辑**: **解读**: - CCI > 0 → 看涨信号 - CCI < 0 → 看跌信号 - 使用PRICE_OPEN计算CCI ### 2.3 感知器算法 **感知器计算**: **感知器结构**: - 输入层: 4个价格差值 (a1, a2, a3, a4) - 权重: w1, w2, w3, w4 - 输出: 加权求和 - 激活函数: 线性 (无阈值) ### 2.4 三个感知器 **1. 卖出感知器 (Perceptron 1)** - 权重: w11, w12, w13, w14 (来自x12-x42) - 周期: p2 - 偏移: sh11-sh15 - 用途: 检测卖出信号 **2. 买入感知器 (Perceptron 2)** - 权重: w21, w22, w23, w24 (来自x13-x43) - 周期: p3 - 偏移: sh21-sh25 - 用途: 检测买入信号 **3. 总体感知器 (Perceptron 3)** - 权重: w31, w32, w33, w34 (来自x14-x44) - 周期: p4 - 偏移: sh31-sh35 - 用途: 总体趋势判断 ### 2.5 工作模式 (pass参数) **模式选择**: | pass值 | 模式 | 说明 | | 1 | 基础CCI | 只使用CCI信号 | | 2 | 卖出感知器 | CCI + 卖出感知器过滤 | | 3 | 买入感知器 | CCI + 买入感知器过滤 | | 4 | 全部感知器 | CCI + 所有感知器 (最复杂) | **模式4详细逻辑**: ### 2.6 入场逻辑 **买入条件** (取决于pass模式): - **pass=1**: CCI > 0 - **pass=3**: CCI信号 + 买入感知器 > 0 - **pass=4**: 总体感知器 > 0 AND 买入感知器 > 0 **卖出条件**: - **pass=1**: CCI < 0 - **pass=2**: CCI信号 + 卖出感知器 < 0 - **pass=4**: 总体感知器 < 0 AND 卖出感知器 < 0 ### 2.7 出场逻辑 - **止损**: 固定点数 (sl1, sl2, sl3根据模式) - **止盈**: 固定点数 (tp1, tp2, tp3根据模式) - 无移动止损 - 无信号反转平仓
