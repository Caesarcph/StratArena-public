策略分析

分析 ### 2.1 核心策略概念 这是一个基于**双均线交叉**的经典趋势跟踪策略。EA使用两条不同周期和类型的移动平均线： - **快线MA**: LWMA(线性加权移动平均)，周期3 - **慢线MA**: EMA(指数移动平均)，周期57 策略通过检测两条MA的连续趋势方向（连续3根K线同向）和价格位置关系来确认入场时机。当两线均呈现上升趋势且价格位于慢线之上时做多；当两线均呈下降趋势且价格位于慢线之下时做空。 ### 2.2 入场条件 **做多条件（必须全部满足）：** 1. **慢线MA连续上升**: `maVal[0] > maVal[1] > maVal[2]` (57周期EMA连续3根上升) 2. **快线MA连续上升**: `ma1Val[0] > ma1Val[1] > ma1Val[2]` (3周期LWMA连续3根上升) 3. **价格在慢线之上**: `p_close > maVal[1]` (收盘价位于慢线之上) 4. **快线在慢线之上**: `maVal[0] > ma1Val[0]` (慢线值大于快线值，表示价格位于两线之间的合理位置) **做空条件（必须全部满足）：** 1. **慢线MA连续下降**: `maVal[0] < maVal[1] < maVal[2]` (57周期EMA连续3根下降) 2. **快线MA连续下降**: `ma1Val[0] < ma1Val[1] < ma1Val[2]` (3周期LWMA连续3根下降) 3. **价格在慢线之下**: `p_close < maVal[1]` (收盘价位于慢线之下) 4. **快线在慢线之下**: `maVal[0] < ma1Val[0]` (慢线值小于快线值) ### 2.3 出场条件 - **止损**: 固定点数止损 (默认100点，5位小数平台自动×10) - **止盈**: 固定点数止盈 (默认100点，5位小数平台自动×10) - **盈亏比**: 1:1 **注意**: 无追踪止损，无反转信号出场机制。 ### 2.4 风险管理 - **止损/止盈逻辑**: 固定点数止损止盈 - **手数管理**: 固定手数 (默认1.0手) - **Digits自适应**: 3/5位小数自动调整SL/TP倍数 - **持仓检查**: 使用PositionSelect()检查当前持仓，避免重复开仓 - **最小K线数检查**: 要求至少60根K线才开始交易 - **新K线检测**: 使用static Old_Time + CopyTime实现标准新K线检测

优势

  • 代码规范清晰: MetaQuotes官方示例，代码结构清晰易读
  • 完整的新K线检测: 标准static Old_Time实现，避免重复执行
  • Digits自适应: 自动适配3/5位小数平台
  • 持仓检查完善: 使用PositionSelect避免重复开仓
  • 错误处理完整: 包含指标句柄验证、数据获取验证、订单结果验证
  • 资源管理规范: OnDeinit正确释放指标句柄

劣势

  • MA参数过激进: MA_Period1=3过短，噪音干扰严重
  • 盈亏比不佳: 1:1需要高胜率，不适合趋势跟踪策略
  • 无动态仓位管理: 固定1.0手，无法适应不同账户规模
  • 无趋势强度过滤: 可能在震荡市中频繁亏损
  • 无追踪止损: 盈利后无法锁定利润
  • 入场逻辑矛盾: 条件4(maVal[0]>ma1Val[0])与做多信号不完全一致（价格在两线之间）
