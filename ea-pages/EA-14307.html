策略分析

分析 ### 2.1 核心策略概念 **市场情绪(Sentiment)突破策略** 这是一个基于市场情绪数据的独特策略，核心逻辑： 1. 监控市场中买入订单数量与卖出订单数量的比率 2. 监控买入订单总手数与卖出订单总手数的比率 3. 当买方情绪占优（买/卖比率超过阈值）时做多 4. 当卖方情绪占优（卖/买比率超过阈值）时做空 5. 当情绪逆转时平仓 **策略特点**: 不使用任何技术指标，完全依赖市场订单簿数据的情绪分析。 ### 2.2 入场条件 **做多条件**: 1. 交易时间检查通过 (周一至周五 10:15:30 - 23:35:30，周末不交易) 2. 买入订单数量/卖出订单数量 ≥ DiffTraders (默认1.5) 3. 买入订单手数/卖出订单手数 ≥ DiffVolumes (默认2.0) 4. 买入或卖出订单数量 ≥ MinTraders (默认1000) 5. 买入或卖出订单手数 ≥ MinVolume (默认20000) 6. 无持仓 (`tradeResult=false`) **做空条件**: 1. 交易时间检查通过 2. 卖出订单数量/买入订单数量 ≥ DiffTraders (默认1.5) 3. 卖出订单手数/买入订单手数 ≥ DiffVolumes (默认2.0) 4. 买入或卖出订单数量 ≥ MinTraders 5. 买入或卖出订单手数 ≥ MinVolume 6. 无持仓 ### 2.3 出场条件 **平仓条件**: - 多仓: 当卖/买订单比率逆转，卖/买手数比率下降 - 空仓: 当买/卖订单比率逆转，买/卖手数比率上升 - 非交易时间: 自动平仓 - 情绪指标低于阈值时平仓 **止损止盈**: 固定止损500点，固定止盈500点 ### 2.4 风险管理 - **止损**: SL = 500点 - **止盈**: TP = 500点 (盈亏比 1:1) - **手数**: 固定手数 Lots (默认1手) - **交易时间过滤**: 仅在特定时段交易 - **情绪阈值动态调整**: 开仓后降低阈值，更敏感地检测逆转

优势

  • 独特数据源: 使用市场情绪数据，区别于传统技术分析
  • 交易时间过滤: 避开低流动性时段
  • 动态阈值调整: 开仓后降低阈值，及时捕捉逆转
  • 数据有效性检查: 防止除零错误
  • 图表状态显示: 实时显示当前情绪状态
  • 固定止损止盈: 风险敞口明确

劣势

  • 数据源依赖: 不是所有经纪商都提供完整订单簿数据
  • 盈亏比1:1: 不利于长期稳定盈利
  • Sleep阻塞: 每次Tick阻塞5分钟，影响响应速度
  • 无技术确认: 缺少技术面验证，可能逆势交易
  • 固定参数: 止损止盈不适应不同市场条件
  • 单一品种: 仅支持当前品种
