摘要

eKeyboardTrader是一个半自动交易工具，允许交易者通过键盘快捷键（b、s、c）在MetaTrader 5图表上执行买入、卖出和平仓操作。它提供了一个交互式图表界面，可通过键盘输入修改手数、止损、止盈和滑点参数，无需使用标准交易对话框。

策略分析

此EA并非基于策略信号的自动交易系统，而是一个键盘驱动的手动交易执行工具。入场条件完全由交易者通过键盘按键决定：按'b'键买入，按's'键卖出，按'c'键平仓。出场条件同样由交易者手动设定止损和止盈点数。仓位管理方面，默认手数为品种最小交易量，可通过按'i'键进入输入模式修改手数、止损、止盈和滑点。资金管理方面，该EA未实现任何自动资金管理逻辑，所有风险控制均依赖交易者手动设置。该工具内置了1秒的交易间隔限制以防止重复触发，但除此之外没有其他风险控制机制。

Summary

eKeyboardTrader is a semi-automated trading utility that allows traders to execute buy, sell, and close operations via keyboard shortcuts (b, s, c) on the MetaTrader 5 chart. It provides an interactive on-chart interface for modifying lot size, stop loss, take profit, and slippage parameters through keyboard input without using the standard trade dialog.

Strategy Analysis

This EA is not an automated strategy-based trading system but rather a keyboard-driven manual trade execution utility. Entry conditions are entirely determined by the trader via keyboard shortcuts: 'b' for buy, 's' for sell, and 'c' for close position. Exit conditions are also manually set by the trader through configurable stop loss and take profit values in points. Position sizing defaults to the symbol's minimum volume and can be modified through the input mode accessed by pressing 'i' to change lots, stop loss, take profit, and slippage. Money management is completely absent from the EA's logic — all risk control relies on the trader's manual configuration. The tool implements a 1-second trade interval limit to prevent rapid repeated execution, but offers no other built-in risk safeguards beyond that.

优势

  • 快捷键操作简化交易执行流程，提高手动交易效率
  • 内置止损止盈计算功能，可根据品种止损级别自动修正
  • 提供图表界面直观显示当前参数和可用命令，无需打开额外窗口

劣势

  • 缺乏仓位检查，多次按键可能在1秒冷却后重复开仓
  • 未使用input变量声明参数，无法在EA属性窗口中配置，重启后参数丢失
  • ORDER_FILLING_AON填充类型硬编码，部分经纪商不支持该类型可能导致下单失败

改进建议

  • 将参数声明为input变量，使EA重启后参数持久化并可在属性窗口中配置
  • 添加持仓检查逻辑，防止重复开仓；根据品种自动选择合适的填充类型

Strengths

  • Keyboard shortcuts streamline trade execution, improving manual trading speed and efficiency
  • Built-in SL/TP calculation with optional stop level correction ensures compliance with broker stop distance requirements
  • On-chart display of current parameters and available commands provides clear visual feedback without additional windows

Weaknesses

  • No position check before opening new trades — repeated keypresses after the 1-second cooldown could open duplicate positions
  • Parameters are not declared as input variables, so they cannot be configured in the EA properties dialog and reset on restart
  • ORDER_FILLING_AON fill type is hardcoded and unsupported by some brokers, which can cause order rejection

Improvements

  • Declare parameters as input variables so they persist across restarts and are configurable via the EA properties dialog
  • Add position existence checks to prevent duplicate openings and auto-detect the appropriate order filling type per symbol
