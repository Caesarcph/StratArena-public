摘要

该EA使用CSignalCandles信号模块检测可配置K线范围内的K线形态。基于形态识别开立买入或卖出仓位，采用固定手数且无追踪止损。策略依赖影线比率分析（大影线与小影线）来识别符合条件的K线形态。

策略分析

策略概念基于K线形态识别，通过分析指定范围内K线的影线比例来发现交易信号。入场条件由CSignalCandles模块驱动，当检测到大影线超过ShadowBig阈值且小影线低于ShadowSmall阈值的K线形态时触发交易。出场条件依赖固定的止损（StopLoss=2.0）和止盈（TakeProfit=1.0）比例设置，同时订单设有4根K线的过期时间。仓位管理采用固定手数模式（CMoneyFixedLot），默认0.1手，不进行动态调整。资金管理使用MoneyFixedLot模块，Percent参数设为10%但实际采用固定手数，缺乏根据账户余额动态调整仓位的能力。整体策略属于典型的K线形态识别系统，使用MetaQuotes标准库组件构建。

Summary

This EA uses the CSignalCandles signal module to detect candlestick patterns within a configurable range of bars. It opens buy or sell positions based on pattern recognition, with fixed lot sizing and no trailing stop. The strategy relies on shadow ratio analysis (big vs small shadows) to identify qualifying candlestick formations.

Strategy Analysis

The strategy concept is based on candlestick pattern recognition, analyzing shadow ratios within a specified range of bars to discover trading signals. Entry conditions are driven by the CSignalCandles module, triggering trades when candlestick patterns with shadows exceeding the ShadowBig threshold and shadows below the ShadowSmall threshold are detected. Exit conditions rely on fixed stop-loss (StopLoss=2.0) and take-profit (TakeProfit=1.0) ratio settings, with orders having a 4-bar expiration time. Position sizing uses a fixed lot model (CMoneyFixedLot), defaulting to 0.1 lots without dynamic adjustment. Money management employs the MoneyFixedLot module where the Percent parameter is set to 10% but actual sizing uses fixed lots, lacking the ability to dynamically adjust positions based on account balance. The overall strategy is a typical candlestick pattern recognition system built using MetaQuotes standard library components.

优势

  • 使用MetaQuotes标准库组件，代码结构规范清晰，易于理解和维护
  • 具备完整的参数验证机制（ValidationSettings），防止无效参数导致运行时错误
  • 止损止盈比率可配置，且基于ATR倍数动态调整，适应不同市场波动性

劣势

  • 采用固定手数交易，无法根据账户资金动态调整仓位大小，风险控制不够灵活
  • 无追踪止损机制（CTrailingNone），可能错过锁定浮盈的机会
  • 缺少点差过滤和交易时段过滤，在流动性差或点差大的时段可能产生不利成交
  • 盈亏比为1:2（止盈:止损），需要较高胜率才能维持正期望值

改进建议

  • 增加动态仓位管理，根据账户余额和风险比例自动计算交易手数
  • 添加追踪止损模块（如CTrailingFixedPips或CTrailingMA），以在趋势延续时保护浮盈
  • 增加点差过滤和交易时段控制，避免在高点差和低流动性时段开仓

Strengths

  • Uses MetaQuotes standard library components with clean, well-structured code that is easy to understand and maintain
  • Has complete parameter validation mechanism (ValidationSettings) preventing runtime errors from invalid parameters
  • Configurable stop-loss and take-profit ratios based on ATR multiples, adapting to different market volatilities

Weaknesses

  • Uses fixed lot sizing without dynamic position adjustment based on account equity, resulting in inflexible risk control
  • No trailing stop mechanism (CTrailingNone), potentially missing opportunities to lock in floating profits
  • Lacks spread filter and trading session filter, which may lead to unfavorable fills during low-liquidity or high-spread periods
  • Risk-reward ratio of 1:2 (TP:SL) requires a high win rate to maintain positive expectancy

Improvements

  • Add dynamic position sizing that automatically calculates lot size based on account balance and risk percentage
  • Implement a trailing stop module (e.g., CTrailingFixedPips or CTrailingMA) to protect floating profits during trend continuation
  • Add spread filter and trading session control to avoid opening positions during high-spread and low-liquidity periods
