策略分析

分析 ### 2.1 核心策略概念 **Exp_ResonanceHunter** 是一个基于**多货币相关性共振**的Stochastic交易系统。其核心理念是：当三个相关货币对的Stochastic指标方向一致时，表明市场存在强烈的共振信号，此时入场成功率更高。 **核心机制**： 1. **三货币对共振分析**：同时监控三个相关货币对（如EURUSD、EURJPY、USDJPY） 2. **Stochastic差值判断**：计算K线与Signal线的差值，判断多空方向 3. **多数投票共识机制**：三个货币对中必须有2-3个方向一致才产生信号 4. **权重修正算法**：当2个看多1个看空时，如果看多方的强度（差值绝对值）更大，强制将空方转为多方 **策略创新点**： - **跨货币共振检测**：利用货币对之间的相关性增强信号可靠性 - **智能共识算法**：不只是简单多数投票，还考虑信号强度权重 - **三策略并行**：支持EUR、GBP、AUD三个货币组同时交易 ### 2.2 入场条件 #### 买入入场条件： 1. **共振确认**：三个货币对的Stochastic K线均在Signal线之上（Dif0>0, Dif1>0, Dif2>0） 2. **共识达成**：通过多数投票和权重修正后，最终判定为看多共振 3. **时间同步**：三个货币对当前K线时间戳完全一致（SynchroCheck验证） 4. **新K线确认**：仅在新K线开盘时处理信号（IsNewBar检测） 5. **无持仓**：当前货币对无持仓（PositionSelect返回false） #### 卖出入场条件： 1. **共振确认**：三个货币对的Stochastic K线均在Signal线之下（Dif0<0, Dif1<0, Dif2<0） 2. **共识达成**：通过多数投票和权重修正后，最终判定为看空共振 3. **时间同步**：同上 4. **新K线确认**：同上 5. **无持仓**：同上 **信号生成流程**： ### 2.3 出场条件 #### 买入平仓条件： - **反向信号**：SymbolA（主货币对）的Stochastic K线下穿Signal线（Up0 = false） - **指标输出**：DnEnd_Buffer值=300（表示多头信号消失） - **平仓执行**：以BID价格市价卖出平仓 #### 卖出平仓条件： - **反向信号**：SymbolA的Stochastic K线上穿Signal线（Dn0 = false） - **指标输出**：UpEnd_Buffer值=300（表示空头信号消失） - **平仓执行**：以ASK价格市价买入平仓 **出场机制特点**： - 无固定止盈目标（TakeProfit=0） - 完全依赖信号反转平仓 - 仅监控SymbolA（主货币对）的信号变化 - 平仓信号与入场信号独立（不要求三货币共识） ### 2.4 风险管理 #### 止损/止盈逻辑： - **止损**：固定点数止损（默认500点） - 买入：SL = 入场价 - StopLoss×Point - 卖出：SL = 入场价 + StopLoss×Point - 自动调整：如果SL < Broker最小距离，自动调整到最小值 - **止盈**：无（依赖信号反转平仓） #### 手数管理： - **固定手数**：默认0.1手 - **无动态计算**：不基于账户余额或风险百分比 - **独立配置**：每个策略（Trade0/1/2）可单独设置手数 #### 其他风控措施： - **单币持仓限制**：每个货币对仅允许1个持仓 - **滑点控制**：最大30点滑点（Slippage参数） - **FOK执行**：Fill-Or-Kill模式，拒绝部分成交 - **时间同步验证**：防止跨时区或数据延迟导致的错误信号

优势

  • 创新的多货币共振机制
  • 利用货币对相关性增强信号可靠性
  • 共识算法结合权重判断，减少假信号
  • 三货币确认机制降低单一货币噪音干扰
  • 完善的同步验证系统
  • SynchroCheck确保三货币时间戳一致
  • Rates_Total验证最小K线数量
  • IsNewBar防止重复信号
  • 模块化架构设计
  • 信号生成与执行分离（TradeSignalCounter + TradePerformer）
  • 三策略独立运行，互不干扰
  • 代码结构清晰，易于维护
  • 完整的交易函数封装
  • BuyPositionOpen/SellPositionOpen包含完整错误处理
  • 自动调整止损到Broker最小距离
  • FOK执行模式确保成交质量
  • 智能共识算法
  • 不只是简单多数投票
  • 考虑信号强度权重（MathAbs(Dif)）
  • 少数派可被强制转换

劣势

  • 参数默认值不合理
  • Kperiod=5远低于标准14，噪音过多
  • StopLoss=500过大，单笔风险高
  • 无TakeProfit导致盈利无法锁定
  • 缺乏动态风险管理
  • 固定手数0.1无风险百分比计算
  • 小账户可能无法承受
  • 无最大回撤保护
  • 无趋势过滤机制
  • 在盘整市容易频繁止损
  • 逆势交易风险高
  • 缺少ADX或MA200趋势判断
  • 出场机制不完善
  • 仅依赖信号反转平仓
  • 可能出现大幅盈利回撤
  • 无时间止损或追踪止损
  • 相关性假设风险
  • 货币相关性在市场异常时会失效
  • 缺少相关性系数实时计算
  • 无相关性断裂时的保护机制
