KositBablo10-1

This EA trades EURUSD using RSI and MA indicators across D1 and H1 timeframes to generate buy and sell pending stop orders. It places BuyStop/SellStop orders with a reversal (turnover) pending order in version 10-1, and uses a money management system that scales lot size based on free margin. The strategy is a multi-timeframe momentum entry system with fixed TP/SL and conditional pending order placement.

Strategy analysis

The strategy core is a multi-timeframe RSI and MA combined signal system driving pending stop orders. Buy condition: D1 RSI(15) below 60 AND H1 RSI(5) below 48 AND H1 MA(20) above MA(2), triggering a BuyStop order plus a reverse SellStop order. Sell condition: H1 RSI(15) above 55 AND H1 MA(23) above MA(2), triggering SellStop orders (looped 3 times) plus a reverse BuyStop order. Position sizing divides free margin by 6500 (v10-1) or 2000 (v10), clamped between 0.1 and 15 lots. Exits rely on fixed TP=1400 pips and SL=500 pips, with reduced TP/SL on reversal orders. The TURBO mode bypasses pending order checks to force new positions, which is a high-risk acceleration feature. The strategy critically lacks new bar checks, spread filters, slippage protection, and magic number assignment for order tracking.

Strengths

  • Multi-timeframe RSI+MA combination provides a reasonable trend confirmation framework
  • Reverse pending order mechanism offers partial hedging protection - if the main order stops out, the reversal order may still profit
  • Dynamic lot sizing based on free margin prevents excessive leverage

Weaknesses

  • No magic number assigned - cannot distinguish this EA's orders from others on the same account
  • No new bar check - logic executes on every tick, potentially flooding with duplicate pending orders
  • The 3-iteration SellStop loop is illogical - sends identical pending orders at the same price 3 times
  • No spread filter - pending orders may be invalid or too costly under high spread conditions
  • TP=1400/SL=500 ratio is favorable but the absolute SL size (500 pips) risks large drawdowns
  • TURBO mode bypassing order checks is extremely dangerous and can lead to uncontrolled position accumulation

Possible improvements

  • Add magic number for order identification and management tracking
  • Add new bar check to prevent executing pending order logic on every tick
  • Fix the SellStop 3-iteration loop bug - either place orders at different price levels or remove the loop entirely
  • Add spread filter and slippage protection mechanisms
  • Set expiration time for all pending orders to avoid stale orders

Risk assessment

Overall risk: High risk

  • No new bar check allows duplicate pending orders on every tick, causing order accumulation
  • SellStop 3-iteration loop sending 3 identical orders at the same price is a severe bug
  • TURBO mode bypassing order checks can lead to unlimited position opening
  • No magic number makes it impossible to manage this EA's orders properly
  • SL=500 pips absolute value is excessively large, single trade loss can be devastating
