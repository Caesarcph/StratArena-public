摘要

该EA使用RSI和MA指标在D1和H1周期上为EURUSD生成买卖信号，通过挂止损单（BuyStop/SellStop）入场，设有固定止盈止损。v2版本增加了反转单并调整了仓位计算（自由保证金除数从2000改为6500），TURBO模式可绕过已有持仓检查。

策略分析

策略基于多周期RSI和MA交叉的动量判断。买入条件：D1 RSI(11/15)<60且H1 RSI(5)<48且H1 MA(20)>MA(2)，此时在Ask上方挂BuyStop单。卖出条件：v1版为D1 RSI(22)>38且H1 RSI(20)>60且H1 MA(23)>MA(12)；v2版简化为H1 RSI(15)>55且H1 MA(23)>MA(2)，在Bid下方挂SellStop单。v2版本额外增加了反转单：买入信号时同时挂SellStop反转单（价格在Bid下方SL-45点），卖出信号时同时挂BuyStop反转单（价格在Ask下方SL+50点），形成对冲。仓位管理根据自由保证金计算，v1除以2000，v2除以6500（更保守），上限15手，下限0.1手，主单用volume/3，反转单用volume/2。出场依赖固定TP=1400点和SL=500点，v2版反转单的TP/SL有所调整。TURBO模式允许在已有持仓时继续下单。

Summary

This EA trades EURUSD using RSI and MA indicators across D1 and H1 timeframes to generate buy and sell signals. It places pending stop orders (BuyStop/SellStop) with fixed TP/SL, and includes a TURBO mode that bypasses existing order checks. The v2 variant adds reversal (turnover) orders and adjusts lot sizing from /2000 to /6500 free margin divisor.

Strategy Analysis

The strategy is based on multi-timeframe RSI and MA crossover momentum signals. Buy entry: D1 RSI(11/15)<60 AND H1 RSI(5)<48 AND H1 MA(20)>MA(2), then place a BuyStop order above Ask. Sell entry: v1 uses D1 RSI(22)>38 AND H1 RSI(20)>60 AND H1 MA(23)>MA(12); v2 simplifies to H1 RSI(15)>55 AND H1 MA(23)>MA(2), placing a SellStop below Bid. The v2 variant adds reversal (turnover) orders: a SellStop at Bid-(SL-45) points on buy signals, and a BuyStop at Ask-(SL+50) points on sell signals, creating a hedging structure. Position sizing is calculated from free margin divided by 2000 (v1) or 6500 (v2, more conservative), capped at 15 lots with a floor of 0.1 lots; main orders use volume/3, reversal orders use volume/2. Exits rely on fixed TP=1400 pips and SL=500 pips, with adjusted values for reversal orders in v2. TURBO mode bypasses the existing positions/orders check, allowing additional entries even when positions exist.

优势

  • 多周期确认（D1+H1）减少假信号
  • 使用挂单而非市价单，入场价格更优
  • v2版本增加反转对冲单，提供方向错误时的保护
  • 仓位计算与账户保证金挂钩，有一定自适应能力

劣势

  • 无新K线检查，每个tick都可能尝试下单导致重复请求
  • 无点差过滤，在小TP情况下点差可能吞噬利润
  • TURBO模式非常危险，可能导致无限开仓
  • 硬编码EURUSD品种，无法适用于其他交易对
  • v1版本的volume/2000杠杆比例过于激进，v2虽改善但仍有风险
  • SellStop循环发送3次相同订单是明显的逻辑错误
  • 无魔法号设置，无法区分本EA与其他EA的订单
  • 缺少指标handle有效性检查

改进建议

  • 添加新K线判断逻辑，避免每个tick重复执行交易逻辑
  • 设置magic number以便区分和管理订单，并在持仓/挂单统计中过滤
  • 添加指标handle有效性检查，防止CopyBuffer失败导致错误交易
  • 修复v1版SellStop循环3次发送相同订单的bug
  • 添加点差过滤和止损级别最小距离检查
  • 将品种名改为input参数，增加通用性

Strengths

  • Multi-timeframe confirmation (D1+H1) reduces false signals
  • Uses pending stop orders rather than market orders for better entry prices
  • v2 adds reversal hedge orders providing protection when primary direction is wrong
  • Position sizing tied to account free margin offers some self-adaptability

Weaknesses

  • No new bar check, every tick can trigger order attempts causing duplicate requests
  • No spread filter, spread can consume profits especially with adjusted TP values
  • TURBO mode is highly dangerous, potentially allowing unlimited position opening
  • Hardcoded EURUSD symbol, not applicable to other trading pairs
  • v1 volume/2000 margin divisor is overly aggressive; v2 improves but risk remains
  • SellStop loop sends the same order 3 times in v1, which is a clear logic bug
  • No magic number set, cannot distinguish this EA's orders from others
  • No indicator handle validity check after initialization

Improvements

  • Add new bar detection to prevent trade logic execution on every tick
  • Set a magic number to distinguish and manage orders, and filter positions/orders by it
  • Add indicator handle validity checks to prevent CopyBuffer failures from causing erroneous trades
  • Fix the v1 SellStop bug that sends the same identical order 3 times in a loop
  • Add spread filter and minimum stop level distance validation before placing orders
  • Make the symbol name an input parameter for broader applicability
