策略分析

分析 ### 2.1 核心策略概念 该EA使用**启明星(Morning Star)/黄昏星(Evening Star)蜡烛形态**作为反转信号，配合**Stochastic振荡器**进行确认。 **启明星**是经典看涨反转形态，由三根蜡烛组成： 1. 第一根：长阴线（下跌趋势延续） 2. 第二根：小实体（多空僵持，转折信号） 3. 第三根：长阳线（反转确认） **黄昏星**是相反的看跌反转形态。 ### 2.2 入场条件 **做多条件（80分信号）**： 1. 检测到启明星形态（`CANDLE_PATTERN_MORNING_STAR`） 2. Stochastic信号线 < 30（超卖区域） **做空条件（80分信号）**： 1. 检测到黄昏星形态（`CANDLE_PATTERN_EVENING_STAR`） 2. Stochastic信号线 > 70（超买区域） **信号阈值机制**： - `Signal_ThresholdOpen = 40`：入场阈值，信号≥40才开仓 - `Signal_ThresholdClose = 20`：出场阈值，信号≥20才平仓 ### 2.3 出场条件 **平空仓条件（40分信号）**： - Stochastic信号线从超卖区上穿20，或 - Stochastic信号线从超买区下穿80 **平多仓条件（40分信号）**： - Stochastic信号线从超买区下穿80，或 - Stochastic信号线从超卖区上穿20 **问题**：EA设置了`Signal_StopLevel = 0`和`Signal_TakeLevel = 0`，表示**无止损止盈**，完全依赖信号反转出场。 ### 2.4 风险管理 | 参数 | 默认值 | 说明 | | Signal_StopLevel | 0 | ❌ 无止损 | | Signal_TakeLevel | 0 | ❌ 无止盈 | | Signal_Expiration | 4 | 挂单有效期4根K线 | | Money_FixLot_Lots | 0.1 | 固定手数 | | Money_FixLot_Percent | 10.0 | 保证金百分比（未实际使用） | **⚠️ 风险警告**：无止损止盈，依赖信号反转出场，极端行情可能导致巨额亏损。

优势

  • 经典蜡烛形态识别框架：16种蜡烛形态检测算法完整实现，代码质量高
  • 信号评分机制：80分入场/40分出场的分级设计，避免单条件触发
  • 双重确认逻辑：形态+指标确认，减少假信号
  • 标准库架构：使用CExpert框架，代码结构清晰，易于扩展
  • 启明星/黄昏星是高可靠性反转形态：在关键支撑/阻力位效果较好

劣势

  • 无止损止盈：极端行情下风险不可控
  • 无趋势过滤：强趋势中反转形态容易失败
  • 仅支持2种形态：启明星和黄昏星，缺少其他高可靠性形态（如锤子线、吞没形态）
  • 参数偏激进：Stochastic %K=12过短，MA周期=4也过短
  • 无成交量确认：启明星/黄昏星配合成交量更可靠
