策略分析

分析 ### 2.1 核心策略概念 **Laguerre Filter (拉盖尔滤波器)** 是John Ehlers在《Cybernetics Analysis for Stock and Futures》书中介绍的自适应滤波器，特点： - 4阶段递归滤波器 - Gamma参数控制平滑度(0-1，越大越平滑) - 产生两条线：Laguerre线和FIR线 - 双线交叉产生交易信号 ### 2.2 Laguerre Filter算法 **核心公式** (来自Ehlers): ### 2.3 入场条件 **做多入场**: 1. Osc1[1] > Osc2[1] (上一根K线Laguerre>FIR) 2. Osc1[0] < Osc2[0] (当前K线Laguerre<FIR) 3. BuyPosOpen开关启用 4. 新K线触发检测 **做空入场**: 1. Osc1[1] < Osc2[1] (上一根K线Laguerre<FIR) 2. Osc1[0] > Osc2[0] (当前K线Laguerre>FIR) 3. SellPosOpen开关启用 4. 新K线触发检测 **信号类型**: 双线交叉信号 (类似于MACD信号线交叉) ### 2.4 出场条件 - 反向信号平仓 (Laguerre穿越FIR反向) - 固定止损止盈 ### 2.5 风险管理 | 参数 | 默认值 | 说明 | | MM | 0.1 | 手数管理 | | StopLoss_ | 1000 | 止损点数 | | TakeProfit_ | 2000 | 止盈点数 | | Deviation_ | 10 | 最大滑点 | | Gamma | 0.7 | Laguerre平滑参数 |

优势

  • Ehlers经典算法: Laguerre滤波器来自John Ehlers DSP著作
  • 低滞后设计: 4阶段递归结构，响应迅速
  • Gamma可调: 用户可根据市场特性调整平滑度
  • FIR对比线: 提供参考基准，确认趋势转折
  • 代码简洁: 120行EA，结构清晰
  • 无外部依赖: 指标算法可内联实现

劣势

  • 默认止损过大: 1000点需要优化
  • 无趋势过滤: 震荡市可能频繁止损
  • 固定手数: 无动态风险管理
  • 无追踪止损: 入场后止损固定
