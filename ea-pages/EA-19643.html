摘要

该EA使用名为'arrows_curves'的自定义指标，基于反转周期(SSP)及通道和偏移参数生成买卖信号。它在新K线形成时运行，无持仓时开仓，有持仓时平掉反向仓位或应用追踪止损。该策略是一个基于反转的交易系统，具有可配置的止损、止盈和追踪止损管理。

策略分析

该EA的核心策略是基于反转信号的均值回归交易，使用自定义指标'arrows_curves'检测价格反转点。入场条件为：当指标缓冲区0在索引1处非零时开多单，缓冲区1在索引1处非零时开空单。出场条件包括：固定止损和止盈、追踪止损机制、以及当出现反向信号时平掉当前持仓。仓位管理方面，支持固定手数或基于风险百分比的动态手数计算（使用CMoneyFixedMargin类）。资金管理使用风险百分比从可用保证金中计算仓位大小，并在开仓前通过CheckVolume验证手数有效性。该EA仅在新K线出生时执行交易逻辑，避免逐tick交易的过度交易问题。

Summary

This EA uses a custom indicator called 'arrows_curves' based on a reversal period (SSP) with channel and shift parameters to generate buy/sell signals. It operates on new bar formation, opening positions when no existing positions are present, and closing opposing positions or applying trailing stops when already in a position. The strategy is a reversal-based system with configurable stop loss, take profit, and trailing stop management.

Strategy Analysis

The core strategy of this EA is a mean reversion trading system based on reversal signals, using the custom indicator 'arrows_curves' to detect price reversal points. Entry conditions: open a buy when indicator buffer 0 at index 1 is non-zero, open a sell when indicator buffer 1 at index 1 is non-zero. Exit conditions include fixed stop loss and take profit, a trailing stop mechanism, and closing opposing positions when a reverse signal appears. Position sizing supports either fixed lots or dynamic lot calculation based on a risk percentage using the CMoneyFixedMargin class. Money management uses a risk percentage to calculate position size from free margin, and validates lot size via CheckVolume before order submission. The EA only executes trading logic on new bar formation, avoiding over-trading issues from tick-by-tick execution.

优势

  • 使用新K线过滤机制，避免逐tick过度交易，减少噪音干扰
  • 具备完整的止损、止盈和追踪止损功能，风险管理体系较完善
  • 支持固定手数和风险百分比两种仓位管理模式，灵活性较好
  • 开仓前进行手数验证和保证金检查，降低因资金不足导致的交易失败风险
  • 使用魔法号码区分自身仓位，支持多EA并行运行

劣势

  • 依赖外部自定义指标'arrows_curves'，若指标文件缺失则EA完全无法运行
  • 止损和止盈对称设置（均为50点），未考虑市场波动率的非对称性
  • 追踪止损默认禁用（InpTrailingStop=0），在默认配置下缺乏动态保护
  • 当已有持仓时仅在出现反向信号时平仓，没有独立的持仓时间限制或亏损阈值平仓机制
  • ClosePositions函数中使用Symbol()而非m_symbol.Name()，与其他函数不一致，可能导致多品种运行时的问题

改进建议

  • 修复ClosePositions函数中的Symbol()为m_symbol.Name()，确保多品种运行的一致性
  • 增加持仓时间限制或最大亏损阈值平仓机制，避免持仓过久导致过大亏损
  • 增加价差过滤条件，避免在点差过大时开仓，特别是对于反转类策略

Strengths

  • Uses new bar filter to avoid tick-by-tick over-trading and reduce noise
  • Complete SL/TP and trailing stop functionality with a reasonably sound risk management system
  • Supports both fixed lot and risk-percentage position sizing modes for flexibility
  • Validates lot size and margin before order submission, reducing trade failure risk from insufficient funds
  • Uses magic number to identify own positions, supporting multiple EAs running simultaneously

Weaknesses

  • Depends on external custom indicator 'arrows_curves'; EA completely fails if the indicator file is missing
  • Symmetric SL/TP configuration (both 50 pips), not accounting for market volatility asymmetry
  • Trailing stop is disabled by default (InpTrailingStop=0), lacking dynamic protection in default config
  • When already in a position, only closes on opposite signal; no independent time-based or loss-threshold exit mechanism
  • ClosePositions uses Symbol() instead of m_symbol.Name(), inconsistent with other functions, potentially causing issues in multi-symbol operation

Improvements

  • Fix Symbol() to m_symbol.Name() in ClosePositions for consistency in multi-symbol operation
  • Add maximum position duration or max-loss-threshold exit mechanism to prevent prolonged losing positions
  • Add spread filter to avoid opening positions when spread is excessively wide, especially important for reversal strategies

风险点

  • 依赖外部自定义指标，指标缺失时OnInit直接返回INIT_FAILED导致EA无法启动
  • 止损和止盈对称设置可能不适合所有市场条件，在高波动市场中止损可能过小
  • ClosePositions函数中Symbol()与m_symbol.Name()不一致的bug可能导致多品种环境下平仓失败
  • 无最大持仓数量限制，虽然CalculateAllPositions检查但仅区分0和非0，可能同时持有多个同向仓位

Risk Assessment

Overall:MEDIUM

Risk Points

  • Dependency on external custom indicator; missing indicator causes OnInit to return INIT_FAILED, preventing EA startup
  • Symmetric SL/TP may not suit all market conditions; stop loss could be too tight in high-volatility environments
  • Symbol() vs m_symbol.Name() inconsistency bug in ClosePositions may cause close failures in multi-symbol setups
  • No maximum position count limit; CalculateAllPositions only distinguishes 0 vs non-zero, potentially allowing multiple same-direction positions
