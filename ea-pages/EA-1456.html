策略分析

分析 ### 2.1 核心策略概念 **TMA (Triangular Moving Average) 三角移动平均突破策略** TMA是一种加权移动平均线，其特点是给予中间周期的价格更高权重，形成三角形权重分布。该策略利用TMA作为动态支撑/阻力线，当价格突破TMA上方或下方一定距离时入场。 **TMA算法核心公式**: - 权重计算: 从两端向中间递增，形成三角分布 [1,2,3,...,n,...,3,2,1] - TMA值 = Σ(price × weight) / Σ(weight) - 这种加权方式使中间价格数据影响最大，有效平滑价格波动 ### 2.2 入场条件 **做多入场**: 1. Close[1] > TMA[1] + dUpLevel (上一根K线收盘价突破TMA上方300点) 2. Close[0] <= TMA[0] + dUpLevel (当前K线收盘价未突破，形成"突破确认"模式) 3. BuyPosOpen开关启用 4. 新K线触发检测 (SignalBar=1或IsNewBar) **做空入场**: 1. Close[1] < TMA[1] - dDnLevel (上一根K线收盘价跌破TMA下方300点) 2. Close[0] >= TMA[0] - dDnLevel (当前K线收盘价未跌破，形成"突破确认"模式) 3. SellPosOpen开关启用 4. 新K线触发检测 ### 2.3 出场条件 **做多出场**: - SellPosClose开关启用时，当触发做空信号自动平多仓 **做空出场**: - BuyPosClose开关启用时，当触发做多信号自动平空仓 **止损止盈**: - StopLoss = 1000点 (默认值，需优化) - TakeProfit = 2000点 (默认值) - 盈亏比2:1良好，但止损过大 ### 2.4 风险管理 - **手数计算**: MM=-0.1表示固定0.1手，正值为风险百分比 - **偏差控制**: Deviation_=10点最大价格偏差 - **四开关控制**: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制 - **信号时间戳**: UpSignalTime/DnSignalTime用于防止重复入场

优势

  • TMA算法平滑有效: 三角权重分布使中间数据影响最大，有效降噪
  • 双K线确认模式: 避免单根K线假突破，提高信号可靠性
  • Nikolay Kositsin专业架构: 代码规范，使用TradeAlgorithms完整函数库
  • 四开关灵活控制: 独立控制开仓和平仓方向，可灵活配置
  • 盈亏比2:1良好: TakeProfit=2000/StopLoss=1000设计合理

劣势

  • 默认止损过大: 1000点(约100pip)对多数品种过大
  • 无趋势强度过滤: 仅突破信号，未考虑趋势强度确认
  • 固定手数模式: MM=-0.1固定0.1手，风险敞口不可控
  • 突破水平固定: UpLevel/DnLevel=300点未根据品种波动率动态调整
  • 无追踪止损: 入场后止损固定，未随价格有利方向移动
