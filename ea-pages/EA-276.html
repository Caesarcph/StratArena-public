摘要

SyncCharts是一个图表同步工具EA，它通过每秒定时器将终端中所有打开的图表与第一个（主）图表的视图设置保持一致。它同步主图表的图表模式、时间周期、缩放、偏移和滚动位置到所有其他图表。

策略分析

该EA并非交易策略EA，而是一个图表同步工具。它通过定时器（每秒触发一次）检测主图表（ChartFirst返回的图表）的当前视图状态，包括图表模式（蜡烛图/线图等）、时间周期、缩放级别、右侧偏移和首个可见柱的位置。然后将这些属性同步到当前图表，确保多个图表保持一致的视图。同步采用级联式条件判断：先检查模式，再检查周期，再检查偏移，再检查缩放，最后检查滚动位置，只有存在差异时才执行更新。该EA没有任何入场或出场逻辑，不涉及仓位管理和资金管理，仅用于多图表视图协调。它使用CExpert基类进行初始化，但实际上并未利用任何交易功能。

Summary

SyncCharts is a chart synchronization utility EA that keeps all open charts in the terminal aligned with the first (main) chart's view settings. It syncs chart mode, timeframe, scale, shift/border, and scroll position from the main chart to all other charts every second via a timer.

Strategy Analysis

This EA is not a trading strategy but a chart synchronization utility. It uses a 1-second timer to detect the main chart's (returned by ChartFirst) current view state, including chart mode (candles/line etc.), timeframe, scale level, right shift, and first visible bar position. It then synchronizes these properties to the current chart, ensuring multiple charts maintain a consistent view. The synchronization uses cascading conditional checks: first mode, then period, then border shift, then scale, and finally scroll position, only executing updates when differences are detected. The EA has no entry or exit logic, no position sizing or money management, and is purely for multi-chart view coordination. It uses the CExpert base class for initialization but does not actually utilize any trading functionality.

优势

  • 实现多图表视图同步，提升多时间周期分析效率
  • 级联式条件判断避免不必要的重复更新，逻辑清晰
  • 自动识别主图表和从图表，使用简单无需复杂配置

劣势

  • 仅同步非主图表，无法双向同步视图变化
  • 1秒定时器间隔可能导致同步延迟，快速滚动时体验不佳
  • 使用了CExpert类但不进行交易，初始化开销不必要，代码架构冗余

改进建议

  • 移除CExpert依赖，简化初始化流程，减少不必要的资源开销
  • 改用CHARTEVENT_CHART_CHANGE事件代替定时器轮询，实现实时响应式同步

Strengths

  • Implements multi-chart view synchronization, improving multi-timeframe analysis efficiency
  • Cascading conditional checks avoid unnecessary redundant updates, logic is clear
  • Automatically identifies main and secondary charts, simple to use without complex configuration

Weaknesses

  • Only synchronizes non-main charts, cannot bidirectionally sync view changes
  • 1-second timer interval may cause sync lag, poor experience during fast scrolling
  • Uses CExpert class without trading, unnecessary initialization overhead and redundant architecture

Improvements

  • Remove CExpert dependency, simplify initialization flow, and reduce unnecessary resource overhead
  • Replace timer polling with CHARTEVENT_CHART_CHANGE event for real-time responsive synchronization
