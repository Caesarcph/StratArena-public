策略分析

分析

2.1 核心策略概念

Exp_BinaryWave 使用创新的"七指标加权投票系统"，将7个经典技术指标的方向信号二值化(±Weight或0)，加权求和后经过高级平滑算法(JJMA/JurX/T3等10种可选)降噪，生成一个归一化的趋势信号。

核心创新点：

  1. 信号二值化设计：每个指标仅输出三态值(+权重/0/-权重)，简化复杂的多指标融合问题
  2. 权重灵活配置：7个指标独立权重参数，支持动态调整各指标贡献度
  3. 高级平滑算法：使用JJMA/JurX/T3等专业级数字滤波器消除噪音
  4. 双入场模式：breakdown(零轴穿越)和twist(V型反转)两种信号确认方式

2.2 七指标加权投票系统

指标1 - Moving Average (权重: WeightMA)

  • 原理：价格与MA位置关系
  • 逻辑：Close > MA → +WeightMA, Close < MA → -WeightMA
  • 参数：MAPeriod=13, MAType=EMA, MAPrice=Close

指标2 - MACD (权重: WeightMACD)

  • 原理：MACD斜率方向
  • 逻辑：MACD上升 → +WeightMACD, MACD下降 → -WeightMACD
  • 参数：FastMACD=12, SlowMACD=26, SignalMACD=9

指标3 - OsMA (权重: WeightOsMA)

  • 原理：OsMA零轴位置
  • 逻辑：OsMA > 0 → +WeightOsMA, OsMA < 0 → -WeightOsMA
  • 参数：FastPeriod=12, SlowPeriod=26, SignalPeriod=9

指标4 - CCI (权重: WeightCCI)

  • 原理：CCI零轴位置
  • 逻辑：CCI > 0 → +WeightCCI, CCI < 0 → -WeightCCI
  • 参数：CCIPeriod=14, CCIPrice=Median

指标5 - Momentum (权重: WeightMOM)

  • 原理：动量与100基准比较
  • 逻辑：MOM > 100 → +WeightMOM, MOM < 100 → -WeightMOM
  • 参数：MOMPeriod=14, MOMPrice=Close

指标6 - RSI (权重: WeightRSI)

  • 原理：RSI与50中性线比较
  • 逻辑：RSI > 50 → +WeightRSI, RSI < 50 → -WeightRSI
  • 参数：RSIPeriod=14, RSIPrice=Close

指标7 - ADX (权重: WeightADX)

  • 原理：DI+与DI-方向判断
  • 逻辑：DI+ > DI- → +WeightADX, DI+ < DI- → -WeightADX
  • 参数：ADXPeriod=14

模式1 - breakdown (零轴穿越)

模式2 - twist (方向转折)

2.4 出场条件

反向信号平仓：

  • breakdown模式：零轴反向穿越时平仓
  • twist模式：方向反向转折时平仓

止损止盈：

  • 默认止损：1000点 (⚠️过大)
  • 默认止盈：2000点
  • 盈亏比：2:1 (良好但止损过大)

2.5 风险管理

  • 新K线检测：使用CIsNewBar类避免重复交易
  • 持仓检查：BuyPositionClose/SellPositionClose独立控制
  • 四开关系统：BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制
  • 手数管理：MM参数支持固定手数(负值)或动态比例(正值)
  • OrderCheck预检查：TradeAlgorithms库提供完整订单验证
