策略分析

分析

2.1 核心策略概念

这是一个布林带与移动平均线双重过滤的趋势跟踪策略。策略使用自定义i_Trend指标作为信号源，该指标通过计算价格相对于布林带的位置与价格相对于MA的偏离度来生成交易信号。

核心算法逻辑：

  1. 指标计算（i_Trend指标）：
  • Buffer A = 价格 - 布林带值（价格偏离布林带的程度）
  • Buffer B = -(最高价+最低价-2×MA)（价格相对于MA的波动范围）
  1. 信号生成：
  • 当Buffer A > Buffer B时，市场处于上升趋势
  • 当Buffer A从上方穿越Buffer B向下时，产生买入信号（回调入场）
  • 当Buffer A从下方穿越Buffer B向上时，产生卖出信号（回调入场）

2.2 入场条件

买入条件：

  1. 前一柱：Ind[1] > Sign[1]（趋势向上）
  2. 当前柱：Ind[0] <= Sign[0]（指标线交叉确认）
  3. BuyPosOpen参数为true
  4. 没有多头持仓

卖出条件：

  1. 前一柱：Ind[1] < Sign[1]（趋势向下）
  2. 当前柱：Ind[0] >= Sign[0]（指标线交叉确认）
  3. SellPosOpen参数为true
  4. 没有空头持仓

2.3 出场条件

平多仓：

  • 当产生卖出信号时（Ind从上方穿越Sign向下）
  • SellPosClose参数为true

平空仓：

  • 当产生买入信号时（Ind从下方穿越Sign向上）
  • BuyPosClose参数为true

止损/止盈：

  • 固定止损：1000点（默认）
  • 固定止盈：2000点（默认）
  • 风险比：1:2（合理）

2.4 风险管理

  • 止损/止盈逻辑：固定点数止损止盈，风险比1:2
  • 手数管理：支持5种资金管理模式
  • FREEMARGIN：按可用保证金计算
  • BALANCE：按账户余额计算
  • LOSSFREEMARGIN：按可用保证金亏损计算
  • LOSSBALANCE：按余额亏损计算
  • LOT：固定手数
  • 其他风控：
  • 新柱检测（避免同一柱重复交易）
  • 交易时间级别检查
  • 经纪商止损级别验证

优势

  • 双重过滤机制：布林带+MA双重确认，减少假信号
  • 灵活的价格类型：12种价格类型适应不同市场环境
  • 完善的资金管理：5种MM模式满足不同风险偏好
  • 回调入场策略：不在极端位置入场，相对安全
  • 合理的风险比：1:2的止盈止损比
  • 模块化设计：使用tradealgorithms.mqh库，代码复用性好
  • 专业的交易函数：包含完整的错误处理和验证逻辑

劣势

  • 默认止损过大：1000点默认止损极度危险
  • 无趋势强度确认：缺少ADX等趋势强度指标
  • 震荡市表现差：横盘市场频繁交叉产生亏损
  • 指标逻辑复杂：两个Buffer的计算方式不够直观
  • 时间框架单一：只支持单一时间框架，无多周期确认
  • 缺少追踪止损：没有移动止损或追踪止损机制
  • 回撤可能较大：固定止损在趋势反转时可能造成连续亏损
