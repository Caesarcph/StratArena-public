摘要

该EA在H1周期交易EURUSD，使用多根K线的MACD交叉动量策略。当检测到连续4根K线的MACD直方图动量模式时开仓做多或做空，通过MACD交叉平仓和移动止损机制管理出场。仓位大小基于可用保证金的固定风险比例计算。

策略分析

策略概念基于MACD指标的动量反转模式，使用参数为快线5、慢线15、信号线3的MACD设置。入场条件非常复杂：做多需要MACD主线在柱1和柱2之间从负转正形成上穿信号线的交叉，同时柱3的主线必须为负值，且当前柱的主线值需大于0.00020，信号线柱6-8需呈现下降趋势后反转上穿的模式；做空条件为对称的反向模式，但阈值不对称（做空需mac1<-0.00035而非-0.00020），显示策略对做空更谨慎。出场条件包括MACD主线当前柱低于前一柱时平多单，或主线当前柱高于前一柱时平空单，同时实现了基于固定点数的移动止损跟踪。仓位管理使用自由保证金乘以风险比例（默认1%）计算手数，并进行最小/最大手数和步长校验。资金管理方面，没有设置止损和止盈价格（开仓时SL和TP均为0），完全依赖MACD信号平仓和移动止损保护，存在较大风险敞口。

Summary

This EA trades EURUSD on the H1 timeframe using a multi-bar MACD crossover momentum strategy. It opens buy or sell positions when specific MACD histogram momentum patterns are detected across 4 consecutive bars, and manages exits via MACD crossover close and a trailing stop mechanism. Position sizing is based on a fixed risk percentage of free margin.

Strategy Analysis

The strategy concept is based on MACD momentum reversal patterns using non-standard parameters (fast=5, slow=15, signal=3). Entry conditions are complex: a buy requires the MACD main line crossing above the signal line between bars 1 and 2 (with bar 3 main line negative), current bar main line above 0.00020, and the signal line across bars 6-8 showing a descending-then-reversing crossover pattern. Sell conditions are asymmetric, requiring mac1 below -0.00035 instead of -0.00020, indicating the strategy is more conservative on short entries. Exit conditions include closing long positions when the MACD main line current bar drops below the previous bar, and closing shorts when it rises above, along with a trailing stop mechanism that modifies stop loss at a fixed pip distance. Position sizing calculates lots from free margin multiplied by a risk ratio (default 1%), with min/max/step volume validation. Money management lacks explicit stop loss and take profit (both set to 0 on order placement), relying entirely on MACD signal exits and trailing stops, creating a significant risk exposure if signals fail or the terminal disconnects.

优势

  • 入场条件使用多根K线的MACD模式确认，比简单交叉更可靠，减少了假信号
  • 实现了移动止损机制，能够锁定已获利润并限制回撤
  • 仓位大小根据账户自由保证金动态计算，具有自适应的风险控制
  • 做空入场阈值更严格（-0.00035 vs -0.00020），体现了对市场非对称性的考量

劣势

  • 开仓时未设置止损和止盈，如果终端断开连接或MACD信号延迟，仓位将完全暴露于无限风险中
  • 入场条件的硬编码阈值（0.00020、-0.00035）仅在EURUSD上有效，无法适用于其他品种或不同点值平台
  • 没有新K线检测机制，每个tick都会执行策略逻辑，可能导致重复计算和不必要的API调用
  • 买入和卖出的阈值不对称缺乏解释，可能是回测过拟合的结果而非有意识的设计
  • iMACDGet函数每次调用都重新复制缓冲区数据，在单个tick中调用8次效率低下

改进建议

  • 为每笔订单设置合理的止损和止盈价格，避免无保护持仓的风险敞口
  • 添加新K线检测机制（如比较当前bar时间与上次处理时间），避免每个tick重复计算
  • 将硬编码的MACD阈值改为可配置的输入参数，并考虑使用归一化方式（如ATP或ATD）使策略适配不同品种
  • 优化iMACDGet函数，在单次调用中批量获取所有需要的MACD数据，减少重复的CopyBuffer调用

Strengths

  • Entry conditions use multi-bar MACD pattern confirmation, more reliable than simple crossover and reduces false signals
  • Implements a trailing stop mechanism to lock in profits and limit drawdowns
  • Dynamic position sizing based on account free margin provides adaptive risk control
  • Asymmetric sell entry threshold (-0.00035 vs -0.00020) reflects awareness of market asymmetry

Weaknesses

  • No stop loss or take profit on order placement, leaving positions fully exposed to unlimited risk if terminal disconnects or MACD signals are delayed
  • Hardcoded entry thresholds (0.00020, -0.00035) only work for EURUSD, not portable to other symbols or different pip platforms
  • No new bar detection mechanism, strategy logic runs every tick causing redundant computation and unnecessary API calls
  • Asymmetric buy/sell thresholds lack explanation, potentially overfitted from backtesting rather than conscious design
  • iMACDGet function copies buffer data on each call, called 8 times per tick which is inefficient

Improvements

  • Set reasonable stop loss and take profit for each order to avoid unprotected position exposure
  • Add new bar detection (e.g., comparing current bar time with last processed time) to avoid redundant per-tick computation
  • Convert hardcoded MACD thresholds to configurable input parameters and consider normalization (e.g., ATR-based) for cross-symbol portability
  • Optimize iMACDGet to batch-fetch all required MACD data in a single CopyBuffer call instead of 8 separate calls per tick
