摘要

该EA在H1时间周期上基于MACD动量信号交易EURUSD。当MACD主线在特定动量确认形态下上穿信号线时做多，反之做空。持仓通过移动止损管理，并在MACD主线与信号线交叉时平仓。

策略分析

策略核心基于MACD指标(5,15,3)的多周期动量确认。做多入场条件极为严格：要求MACD主线在bar3处为负、bar2处为负且低于bar3、bar1处由负转正且高于信号线，同时信号线呈收敛后发散形态，主线当前值需大于0.00020且bar2值需小于-0.00020，确保从深负区强力反弹的动量反转。做空条件类似但方向相反，要求主线从正区回落且当前值低于-0.00035。出场方面，当MACD主线与前一bar主线发生反向交叉时平仓，同时使用25点(250点/pip)的移动止损跟踪利润。仓位管理基于账户自由保证金1%的风险比例，将保证金除以100后取整作为手数，但此计算方式并非标准的风险管理方法，未考虑止损距离。整体策略属于动量反转类型，试图捕捉MACD从极端区域反转的趋势启动点。

Summary

This EA trades EURUSD on the H1 timeframe using MACD momentum signals. It enters long positions when MACD main line crosses above signal line with specific momentum confirmation patterns, and short positions on the inverse pattern. Positions are managed with a trailing stop and closed on MACD main-signal crossovers.

Strategy Analysis

The strategy core is based on multi-bar MACD(5,15,3) momentum confirmation. The long entry condition is extremely strict: it requires the MACD main line to be negative at bar3, negative and lower than bar3 at bar2, then turning positive at bar1 and above the signal line, while the signal line shows a convergence-then-divergence pattern. The current main line must exceed 0.00020 and bar2 must be below -0.00020, ensuring a strong momentum reversal from deep negative territory. The short entry mirrors this but requires the main line to drop from positive territory with the current value below -0.00035, a more aggressive threshold suggesting asymmetry in the author's view of downside momentum. Exit occurs on MACD main line crossover with the previous bar's main line, combined with a 25-point trailing stop that follows profitable positions. Position sizing uses 1% of free margin divided by 100, then normalized to one decimal place before lot validation — this is an unconventional and imprecise risk calculation that does not account for stop-loss distance. The overall strategy is a momentum reversal type, attempting to capture trend initiation points when MACD reverses from extreme zones.

优势

  • 入场条件极其严格，需要8个MACD值同时满足多重动量确认，有效过滤假信号
  • 具有移动止损机制，能够锁定已获利润，避免盈利回吐
  • 仅允许同时持有一个方向的仓位，避免了对冲和过度持仓的风险
  • 使用MagicNumber过滤持仓，支持多EA并行运行而不互相干扰

劣势

  • 仓位计算方式不合理——用自由保证金乘0.01除100的结果作为手数，未考虑止损距离，实际风险暴露不可控
  • 开仓时未设置止损和止盈（SL=0, TP=0），完全依赖移动止损和MACD交叉平仓，在极端行情下可能遭受重大损失
  • 硬编码的MACD阈值（0.00020和-0.00035）仅适用于EURUSD，无法适应其他品种或不同的波动率环境
  • 缺少新bar检测机制，每个tick都会执行逻辑判断，可能导致重复信号和不必要的计算开销
  • 做空阈值比做多更严格（-0.00035 vs 0.00020），缺乏对称性，没有作者对这种非对称设计的说明

改进建议

  • 修正仓位计算：应根据止损点数和每点价值计算手数，使每笔交易的风险金额固定为账户余额的固定百分比
  • 添加新bar检测机制，仅在新的H1 bar形成时执行交易逻辑，避免tick级别的重复计算
  • 开仓时设置合理的止损价格，而非依赖事后移动止损，确保在极端跳空行情下有基础保护
  • 将硬编码的MACD阈值改为可调参数或自适应计算，使EA能适应不同品种和波动率环境

Strengths

  • Extremely strict entry requiring 8 MACD values to satisfy multiple momentum confirmations simultaneously, effectively filtering false signals
  • Trailing stop mechanism locks in profits and prevents giving back gains on winning trades
  • Only allows one position at a time, avoiding hedging and overexposure risks
  • MagicNumber filtering enables multiple EAs to run concurrently without interference

Weaknesses

  • Position sizing is flawed — using free margin × 0.01 / 100 as lot size without considering stop-loss distance means actual risk exposure is uncontrolled
  • No stop-loss or take-profit set at order open (SL=0, TP=0), relying entirely on trailing stop and MACD crossover for exit, which risks catastrophic losses in extreme markets
  • Hardcoded MACD thresholds (0.00020 and -0.00035) only suit EURUSD and cannot adapt to other symbols or changing volatility regimes
  • No new bar detection — logic runs on every tick, causing redundant signal checks and unnecessary computational overhead
  • Asymmetric thresholds for short (-0.00035) vs long (0.00020) entries lack justification and may indicate overfitting

Improvements

  • Fix position sizing: calculate lots based on stop-loss distance and pip value so that each trade risks a fixed percentage of account balance
  • Add new bar detection to execute trading logic only when a new H1 bar forms, avoiding redundant per-tick computation
  • Set a stop-loss price at order open rather than relying solely on trailing stop, ensuring baseline protection against gap risks
  • Convert hardcoded MACD thresholds into adjustable input parameters or adaptive calculations to support multiple symbols and volatility regimes
