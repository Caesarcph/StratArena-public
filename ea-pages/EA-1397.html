摘要

该EA基于自定义指标BreakoutBarsTrend_v2检测趋势反转信号进行交易。当指标发出趋势方向变化信号时入场，可选择在连续出现指定次数的亏损反转信号后才入场。止损和止盈可按点数或百分比模式计算。

策略分析

该EA的核心策略是基于BreakoutBarsTrend_v2指标检测趋势突破与反转。入场条件为：指标值从正变负（趋势向下反转）时做空，从负变正（趋势向上反转）时做多。此外，EA提供了一个负信号过滤机制——当InpNegatives大于0时，只有在前N次趋势反转信号均为亏损（即价格未能朝预期方向运动）的情况下才会开仓，这是一种逆向入场思路，试图在连续失败后捕捉成功的反转。出场条件有两种：一是当指标再次发出反向信号时平仓，二是触发止损或止盈。仓位管理采用固定手数（InpLot），仅做成交量边界校验和步长规范化。资金管理方面，止损和止盈可按点数或百分比两种模式设定，同时考虑了经纪商的最小止损水平限制。整体策略逻辑简单直接，缺乏动态仓位调整和风险敞口控制。

Summary

This EA trades trend reversals detected by the custom BreakoutBarsTrend_v2 indicator. It enters a position when the indicator signals a trend direction change, optionally waiting for a configurable number of consecutive negative (losing) trend reversals before entering. Stop Loss and Take Profit are calculated based on either pips or percentage mode.

Strategy Analysis

The core strategy of this EA is based on detecting trend breakouts and reversals using the BreakoutBarsTrend_v2 custom indicator. Entry conditions: the EA opens a buy when the indicator value crosses from negative to positive (trend reversal upward) and opens a sell when it crosses from positive to negative (trend reversal downward). Additionally, the EA implements a negative signal filter — when InpNegatives is greater than zero, it only enters after N consecutive losing reversal signals, which is a contrarian approach attempting to catch a successful reversal after a string of failures. Exit conditions include closing the position when the indicator issues an opposing reversal signal, or when the hardcoded stop loss or take profit levels are hit. Position sizing uses a fixed lot size (InpLot) with only basic volume boundary validation and step normalization against broker limits. Money management allows stop loss and take profit to be set in either pips or percentage mode, and accounts for the broker's minimum stop level. The overall strategy logic is straightforward but lacks dynamic position sizing and overall risk exposure control.

优势

  • 策略逻辑清晰，基于趋势反转信号入场，易于理解和调试
  • 提供负信号过滤机制，可避免在震荡市中频繁假突破入场
  • 止损止盈计算考虑了经纪商最小止损水平（SYMBOL_TRADE_STOPS_LEVEL），减少订单被拒风险
  • 支持点数和百分比两种模式设置参数，适应不同交易品种和交易者偏好
  • 代码结构模块化较好，各功能函数职责单一，便于维护

劣势

  • 依赖自定义指标BreakoutBarsTrend_v2，该指标未内嵌于EA中，缺少指标则EA无法运行
  • 固定手数无动态调整机制，无法根据账户余额或风险敞口自适应调整仓位大小
  • isNegativeSeries函数中使用negatives*100作为历史数据回溯长度，当negatives较大时可能导致数据请求量过大或逻辑不合理
  • checkForClose和checkForOpen中prevTime为static局部变量，EA重启后会重置，可能导致同一根K线上重复交易
  • 缺乏点差过滤、滑点控制和交易时间限制，在高点差或低流动性时段可能产生不利成交

改进建议

  • 增加动态仓位管理，如根据账户风险百分比或ATR自动调整手数，提升资金管理能力
  • 添加点差过滤和交易时段控制，避免在不利条件下开仓
  • 将isNegativeSeries的回溯逻辑优化为基于实际趋势反转次数而非固定倍数，提高数据效率和逻辑准确性
  • EA重启时从持久化存储恢复prevTime状态，防止重复信号处理

Strengths

  • Clear and straightforward strategy logic based on trend reversal signals, easy to understand and debug
  • Negative signal filter mechanism helps avoid frequent false breakout entries in choppy markets
  • Stop loss and take profit calculations account for broker minimum stop levels, reducing order rejection risk
  • Supports both pips and percentage modes for parameter configuration, adapting to different instruments and trader preferences
  • Well-modularized code structure with single-responsibility functions, facilitating maintenance

Weaknesses

  • Depends on the custom BreakoutBarsTrend_v2 indicator which is not embedded; the EA cannot run without it
  • Fixed lot sizing with no dynamic adjustment mechanism, unable to adapt position size based on account balance or risk exposure
  • The isNegativeSeries function uses negatives*100 as historical data lookback, which can lead to excessive data requests or illogical behavior when negatives is large
  • prevTime in checkForClose and checkForOpen is a static local variable that resets on EA restart, potentially causing duplicate trades on the same bar
  • Lacks spread filter, slippage control, and trading session restrictions, which may result in unfavorable fills during high-spread or low-liquidity periods

Improvements

  • Add dynamic position sizing such as risk-percentage or ATR-based lot calculation to improve money management
  • Add spread filter and trading session controls to prevent entries under unfavorable market conditions
  • Optimize the isNegativeSeries lookback logic to be based on actual trend reversal counts rather than a fixed multiplier, improving data efficiency and logical accuracy
  • Persist prevTime state across EA restarts to prevent duplicate signal processing on the same bar
