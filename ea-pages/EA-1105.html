摘要

该EA通过检测连续N根同向K线且实体递增来产生买入或卖出信号。开仓后使用可配置的止损止盈出场，但没有任何基于信号的平仓逻辑。

策略分析

策略概念基于连续K线形态识别：当连续N根阴线且每根实体比前一根大时产生买入信号，当连续N根阳线且每根实体比前一根大时产生卖出信号，这是一种基于动能耗尽后的反转思路。入场条件为up_1==N且up_2==N-1时买入，dn_1==N且dn_2==N-1时卖出，即所有N根K线必须同向且相邻K线实体逐根递增。出场条件仅依赖止损和止盈，SignalCloseBuy和SignalCloseSell始终返回false，没有任何主动平仓逻辑。仓位管理使用固定手数Lots参数，SolveLots函数直接返回输入的Lots值，没有动态仓位计算或风险百分比模式。资金管理方面完全没有，不存在最大风险计算、账户余额比例下仓或马丁格尔机制，止损止盈为固定点数设置。

Summary

This EA detects consecutive N bearish or bullish candles with progressively increasing body sizes to generate buy or sell signals. It opens positions with configurable stop-loss and take-profit levels, but has no signal-based close logic, relying solely on SL/TP for exits.

Strategy Analysis

The strategy concept is based on consecutive candlestick pattern recognition: a buy signal is generated when N consecutive bearish candles each have a larger body than the previous one, and a sell signal is generated when N consecutive bullish candles each have a larger body than the previous one, reflecting a momentum exhaustion reversal approach. Entry conditions require up_1==N and up_2==N-1 for buys, or dn_1==N and dn_2==N-1 for sells, meaning all N candles must be unidirectional with progressively increasing body sizes. Exit conditions rely solely on stop-loss and take-profit, as both SignalCloseBuy and SignalCloseSell always return false with no active closing logic whatsoever. Position sizing uses a fixed lot size via the Lots parameter, where the SolveLots function simply returns the input value without any dynamic calculation or risk percentage mode. Money management is completely absent — there is no maximum risk calculation, account equity proportional sizing, or martingale mechanism, and stop-loss/take-profit are set as fixed point values.

优势

  • 策略逻辑简洁明了，易于理解和调优
  • 使用新K线检测避免同一根K线内重复交易
  • 包含止损止盈的最小距离校验，符合交易所规范
  • 使用标准MQL5交易类库，代码结构规范

劣势

  • 没有任何主动平仓信号逻辑，完全依赖止损止盈
  • 没有点差过滤，在高点差环境下可能频繁误触发
  • 固定手数没有风险控制，无法根据账户规模调整仓位
  • 信号逻辑过于简单，连续阴线买入缺乏市场结构确认
  • 没有回撤保护或最大亏损限制机制

改进建议

  • 添加基于信号的主动平仓逻辑，例如当形态不再满足时平仓
  • 增加点差过滤和波动率过滤以减少虚假信号
  • 实现基于账户风险百分比的动态仓位管理
  • 添加趋势过滤器（如移动平均线）以避免逆势交易

Strengths

  • Strategy logic is simple and clear, easy to understand and tune
  • Uses new bar detection to prevent repeated trades within the same bar
  • Includes minimum stop-loss/take-profit distance validation compliant with exchange rules
  • Uses standard MQL5 trade class libraries with well-structured code

Weaknesses

  • No active close signal logic at all, completely reliant on stop-loss and take-profit
  • No spread filter, may generate false signals frequently in high-spread environments
  • Fixed lot size with no risk control, cannot adjust position based on account size
  • Signal logic is overly simplistic — buying on consecutive bearish candles lacks market structure confirmation
  • No drawdown protection or maximum loss limit mechanism

Improvements

  • Add signal-based active closing logic, e.g., close when the pattern condition no longer holds
  • Add spread and volatility filters to reduce false signals
  • Implement dynamic position sizing based on account risk percentage
  • Add a trend filter (e.g., moving average) to avoid counter-trend trades
