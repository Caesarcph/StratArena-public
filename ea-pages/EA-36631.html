摘要

该EA是一个工具型程序，每周五在用户指定的结束时间之后自动平掉当前品种所有盈利仓位。它会跳过加密货币品种，仅在交易周的最后时段执行操作。该EA本身不会开立任何新仓位。

策略分析

该EA的策略概念是周末前锁定利润，属于时段管理工具而非交易策略。入场条件方面，该EA没有任何入场逻辑，不会主动开仓。出场条件是：当前品种为非加密货币、当天为周五、当前时间超过用户设定的Endtrade时间、且持仓浮盈大于零时，平掉该仓位。仓位管理方面，该EA不涉及任何仓位管理逻辑，仅对已有持仓执行平仓操作。资金管理方面，没有止损、止盈或资金管理机制，仅依据浮盈是否为正来决定平仓。整体而言，这是一个简单的周末利润保护工具，逻辑单一且不复杂。

Summary

This EA is a utility that automatically closes all profitable positions on the current symbol every Friday after a user-specified end time. It skips crypto symbols and only acts during the final session of the trading week. It does not open any new positions itself.

Strategy Analysis

The strategy concept of this EA is to lock in profits before the weekend, functioning as a session management utility rather than a trading strategy. Regarding entry conditions, the EA has no entry logic whatsoever and does not open any new positions. The exit condition triggers when the symbol is not crypto, the day is Friday, the current time exceeds the user-configured Endtrade time, and the position has a positive floating profit — at which point it closes that position. For position sizing, the EA does not involve any position sizing logic; it only executes closing operations on existing positions. Regarding money management, there is no stop-loss, take-profit, or money management mechanism — it simply closes positions based on whether the floating profit is positive. Overall, this is a straightforward weekend profit protection tool with simple, single-purpose logic.

优势

  • 逻辑简单明了，专注于周末利润保护，降低周末持仓风险
  • 排除了加密货币品种，避免7x24小时市场的不当平仓
  • 仅平掉盈利仓位，亏损仓位保留不受影响，不会扩大亏损

劣势

  • Starttrade参数声明了但从未使用，属于冗余代码
  • 在OnTimer中调用但未设置EventSetTimer，定时器可能从未触发
  • 遍历仓位时使用正向循环并调用PositionClose，可能导致跳过仓位或索引错乱

改进建议

  • 添加OnInit中调用EventSetTimer设置定时器间隔，确保OnTimer实际执行
  • 将正向循环改为反向循环（从PositionsTotal()-1到0），避免平仓后索引偏移导致跳过仓位
  • 移除未使用的Starttrade参数或实现对应功能，清理冗余代码

Strengths

  • Simple and clear logic focused on weekend profit protection, reducing weekend holding risk
  • Excludes crypto symbols to avoid improper closing on 24/7 markets
  • Only closes profitable positions, leaving losing positions untouched without expanding losses

Weaknesses

  • Starttrade parameter is declared but never used, representing redundant code
  • Called in OnTimer but EventSetTimer is never set, so the timer may never trigger
  • Forward-loop iteration with PositionClose can cause index shifting and skipped positions

Improvements

  • Add EventSetTimer call in OnInit to set the timer interval, ensuring OnTimer actually executes
  • Change forward loop to reverse loop (from PositionsTotal()-1 down to 0) to avoid index shifting after position closure
  • Remove the unused Starttrade parameter or implement its functionality to clean up redundant code

风险点

  • 定时器未初始化导致EA完全失效，用户可能误以为EA在工作
  • 正向循环平仓可能跳过部分仓位，导致周五未平掉全部盈利仓
  • 没有日志记录成功平仓操作，难以审计执行情况

Risk Assessment

Overall:SAFE

Risk Points

  • Timer not initialized causing complete EA failure; user may assume EA is working
  • Forward loop closing positions may skip some positions, leaving profitable positions open on Friday
  • No logging for successful close operations, making execution auditing difficult
