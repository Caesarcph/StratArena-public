策略分析

### 2.1 核心理念 **XMACD** (eXtended MACD) 是对传统MACD指标的增强版本，允许使用**10种不同的平滑算法**计算快线和慢线，而不仅限于标准的EMA。这种灵活性使交易者可以根据市场特性选择最合适的平滑方法。 ### 2.2 XMACD vs 标准MACD | 特性 | 标准MACD | XMACD | | 快/慢线算法 | 固定EMA | 10种可选 | | 信号线算法 | 固定EMA | 10种可选 | | 价格类型 | 5种标准 | 11种扩展 | | 相位参数 | 无 | 可调(-100到+100) | | 适应性 | 固定周期 | 自适应可选 | ### 2.3 10种平滑算法 | 算法 | 缩写 | 特点 | 适用场景 | | **SMA** | 简单移动平均 | 等权平均 | 稳定趋势 | | **EMA** | 指数移动平均 | 近期权重高 | 快速反应 | | **SMMA** | 平滑移动平均 | 延迟小 | 减少噪音 | | **LWMA** | 线性加权平均 | 线性递减权重 | 趋势确认 | | **JJMA** | Jurik移动平均 | 自适应平滑 | 减少滞后 | | **JurX** | Jurik XMA | Jurik改进版 | 快速趋势 | | **ParMA** | 抛物线移动平均 | 抛物线加权 | 动量跟踪 | | **T3** | T3移动平均 | 三重EMA | 极平滑 | | **VIDYA** | 可变指数动态平均 | 根据波动率调整 | 自适应市场 | | **AMA** | 自适应移动平均 | Kaufman AMA | 趋势市场 | ### 2.4 11种价格类型 **标准类型**: - Close, Open, High, Low - Median (中位数) - Typical (典型价格) - Weighted (加权) **扩展类型**: - Simpl (OC/2) - 开盘收盘平均 - Quarter (HLOC/4) - 四价平均 - TrendFollow_1 - 趋势跟踪变体1 - TrendFollow_2 - 趋势跟踪变体2 ### 2.5 交易模式 (4种) #### 模式1: Breakdown (零线交叉) ⭐ 经典 **买入信号**: - MACD柱线从负变正（上穿零线） - 动量由负转正 **卖出信号**: - MACD柱线从正变负（下穿零线） - 动量由正转负 **逻辑**: #### 模式2: MACDTwist (柱线方向改变) **买入信号**: - MACD柱线停止下降并开始上升 - 动量减速并反转向上 **卖出信号**: - MACD柱线停止上升并开始下降 - 动量减速并反转向下 **逻辑**: #### 模式3: SIGNALtwist (信号线方向改变) **买入信号**: - 信号线停止下降并开始上升 - 趋势确认向上 **卖出信号**: - 信号线停止上升并开始下降 - 趋势确认向下 #### 模式4: MACDdisposition (柱线交叉信号线) ⭐ 默认 **买入信号**: - MACD柱线上穿信号线 - 动能增强 **卖出信号**: - MACD柱线下穿信号线 - 动能减弱 **逻辑**: ### 2.6 交易流程
