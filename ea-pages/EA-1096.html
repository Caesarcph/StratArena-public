Exp_XMACD

This EA trades based on the XMACD custom indicator, offering four distinct signal modes: zero-line breakthrough, MACD direction change, signal line direction change, and MACD-signal line crossover. It opens and closes positions according to the selected mode with configurable money management, stop loss, and take profit settings.

Strategy analysis

This EA implements a momentum-based strategy using the XMACD indicator, which is an extended version of the traditional MACD supporting multiple smoothing algorithms (SMA, EMA, JJMA, JurX, etc.) and various price types. The strategy offers four entry modes: the zero-line breakthrough mode trades when the MACD histogram crosses zero; the MACD twist mode trades when the MACD changes direction; the signal line twist mode trades when the signal line changes direction; and the MACD crossover mode trades when the MACD histogram crosses the signal line, which is the most classic MACD trading approach. Exit conditions include closing positions on reverse signals, fixed stop loss, and take profit levels. Position sizing is controlled via the MM parameter, where negative values represent fixed lot sizes and positive values represent a percentage of the deposit. The strategy uses an IsNewBar mechanism to prevent repeated trading within the same bar and employs a Recount flag to recalculate signals when data copying fails.

Strengths

  • Offers four trading modes providing high strategic flexibility to adapt to different market conditions
  • Uses IsNewBar mechanism to prevent repeated trades within the same bar, reducing overtrading
  • Supports multiple smoothing algorithms and price types, making XMACD more powerful than standard MACD
  • Provides granular permission controls for buy/sell opening and closing positions independently
  • Fixed stop loss and take profit settings provide defined risk management

Weaknesses

  • No trailing stop mechanism, profits may be reduced by market retracements
  • No spread filter, potentially generating false signals in high-spread environments
  • The MM parameter design where negative values mean fixed lots is unintuitive and error-prone
  • Lacks position checking logic before opening trades, risking duplicate positions
  • Depends on external iCustom indicator, the EA will fail if the XMACD indicator file is missing

Possible improvements

  • Add a trailing stop feature to lock in more profits during trend continuation
  • Add spread filter and maximum position check to improve trading robustness
  • Redesign the MM parameter using an enum to distinguish between fixed lot and percentage modes, eliminating the confusing negative value convention

Risk assessment

Overall risk: Medium

  • No position count check, potentially opening duplicate positions in the same direction
  • Fixed stop loss/take profit values are large (1000/2000 points), allowing significant per-trade losses
  • Depends on external custom indicator; when missing, only a warning is printed but the EA continues running
