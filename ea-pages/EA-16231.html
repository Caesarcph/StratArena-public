摘要

该EA利用ZigZag指标识别摆动高低点，并在最近的摆动波段上绘制斐波那契回撤水平。当价格在上升趋势中突破斐波那契水平或在下降趋势中跌破斐波那契水平时，开仓买入或卖出，使用固定止损和基于斐波那契的止盈。

策略分析

策略核心是基于ZigZag指标识别的摆动高低点计算斐波那契回撤水平（23.6%、38.2%、61.8%、76.4%），并根据趋势方向在这些回撤水平附近寻找交易机会。入场条件为：在上升趋势中，当当前K线收盘价和前一根K线收盘价均突破某个斐波那契回撤水平并超过安全缓冲距离时做多；在下降趋势中，当价格跌破斐波那契水平时做空。出场条件包括固定点数的止损和基于斐波那契扩展倍数的止盈（TakeProfitAt参数控制）。仓位管理采用固定手数（TradeValue参数），没有动态仓位调整或资金管理逻辑。趋势判断通过比较最近四个ZigZag极值点的高低关系来确定，如果连续高点和低点都在抬升则为上升趋势，反之为下降趋势。此外，EA在平仓后会等待CloseBarPause根K线后才允许重新开仓，以避免频繁交易。

Summary

This EA uses ZigZag indicator to identify swing highs and lows, then draws Fibonacci retracement levels on the most recent swing leg. It enters buy or sell trades when price crosses above a Fibo level in an uptrend or below a Fibo level in a downtrend, with fixed stop-loss and Fibonacci-based take-profit.

Strategy Analysis

The strategy core is based on Fibonacci retracement levels (23.6%, 38.2%, 61.8%, 76.4%) calculated from swing highs and lows identified by the ZigZag indicator, seeking trading opportunities near these retracement levels based on trend direction. Entry conditions: in an uptrend, a buy is triggered when both the current bar close and the previous bar close cross above a Fibonacci retracement level by more than the SafetyBuffer distance; in a downtrend, a sell is triggered when price crosses below a Fibonacci level. Exit conditions include a fixed point-based stop-loss and a Fibonacci extension-based take-profit controlled by the TakeProfitAt parameter. Position sizing uses a fixed lot size (TradeValue parameter) with no dynamic position adjustment or money management logic. Trend determination compares the most recent four ZigZag extremum points — if consecutive highs and lows are rising, it is an uptrend, and vice versa. Additionally, the EA enforces a CloseBarPause bar cooldown after a position is closed before allowing a new trade, avoiding over-trading.

优势

  • 基于经典的斐波那契回撤理论，策略逻辑清晰易懂
  • 使用ZigZag指标自动识别摆动点，避免主观判断
  • 有平仓冷却期机制，防止过度频繁交易
  • 同时设置止损和止盈，具备基本的风险控制
  • 支持自动趋势判断，能适应多空两个方向

劣势

  • CheckTrend函数返回类型声明为bool但实际返回int值，存在严重的类型错误
  • TradeCheck函数中卖出条件使用deal=2但调用时传入-1，导致卖出逻辑永远不会执行
  • 没有新K线检测机制，每个tick都会执行判断，可能导致重复信号
  • 没有点差过滤，在高速行情或大点差时可能产生不利入场
  • 止损仅15点对于大多数品种来说过于紧密，容易被市场噪音触发
  • 固定手数没有资金管理，不同账户规模下风险不可控

改进建议

  • 修复CheckTrend的返回类型为int，以及TradeCheck中卖出分支的deal参数匹配问题
  • 添加新K线检测机制，避免同一根K线上重复触发交易逻辑
  • 加入点差过滤和滑点保护，提高入场质量
  • 实现基于账户余额或风险百分比的动态仓位管理
  • 增加对ZigZag指标重绘的防护机制，避免基于未来数据的虚假信号

Strengths

  • Based on classic Fibonacci retracement theory with clear and understandable strategy logic
  • Uses ZigZag indicator for automatic swing point identification, avoiding subjective judgment
  • Implements a cooldown period after closing positions to prevent over-trading
  • Sets both stop-loss and take-profit, providing basic risk control
  • Supports automatic trend detection, adaptable to both long and short directions

Weaknesses

  • CheckTrend function declares return type bool but actually returns int values — a critical type error
  • TradeCheck function uses deal=2 for sell but is called with -1, so the sell logic never executes
  • No new bar detection mechanism; logic runs on every tick, potentially causing duplicate signals
  • No spread filter; unfavorable entries may occur during fast markets or wide spreads
  • Stop-loss of only 15 points is too tight for most instruments and easily triggered by market noise
  • Fixed lot size with no money management makes risk uncontrollable across different account sizes

Improvements

  • Fix CheckTrend return type to int and align the sell branch deal parameter in TradeCheck (use -1 or change to 2)
  • Add new bar detection to avoid repeatedly triggering trade logic on the same bar
  • Add spread filter and slippage protection to improve entry quality
  • Implement dynamic position sizing based on account balance or risk percentage
  • Add protection against ZigZag indicator repainting to avoid false signals from future data
