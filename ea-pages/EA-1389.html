策略分析

分析 ### 2.1 核心策略概念 Exp_EF_distance是一个**双指标组合策略**，使用**EF_distance**作为主要信号源，配合**Flat-Trend**作为波动率过滤条件。 **EF_distance算法** (效率距离趋势指标): **Flat-Trend算法** (波动率趋势指标): ### 2.2 入场条件 **入场逻辑** (双指标确认): - **做多**: 1. EF_distance从下降转为上升: `Value[1]<Value[2] && Value[0]>Value[1]` 2. Flat-Trend波动率过滤: `Vol[0] >= Volatil` (默认V3=最高波动率) - **做空**: 1. EF_distance从上升转为下降: `Value[1]>Value[2] && Value[0]<Value[1]` 2. Flat-Trend波动率过滤: `Vol[0] >= Volatil` ### 2.3 出场条件 - **做多出场**: EF_distance转向下跌 - **做空出场**: EF_distance转向上涨 - **止损止盈**: 固定点数(SL=1000点, TP=2000点) ### 2.4 风险管理 | 参数 | 默认值 | 说明 | | StopLoss | 1000点 | 固定止损(过大需优化) | | TakeProfit | 2000点 | 固定止盈(盈亏比2:1) | | MM | -0.1 | 手数模式，负值表示固定手数0.1 | | Deviation | 10点 | 最大价格滑点 | | Volatil | V3 | 波动率阈值(最低/中/最高) |

优势

  • 创新算法: EF_distance使用距离加权平均，概念新颖
  • 双指标确认: 波动率过滤减少假信号
  • 11种价格类型: 提供丰富的价格选择
  • 多平滑方法: 支持9种平滑算法
  • 波动率自适应: 只在高波动率时入场
  • CIsNewBar类: 新K线检测避免重复信号

劣势

  • 止损过大: SL=1000点不合理
  • 波动率阈值过高: V3可能错过交易机会
  • 算法复杂: 理解难度较大
  • 无趋势过滤: 可能逆势交易
  • 参数众多: 需要调优的参数较多
