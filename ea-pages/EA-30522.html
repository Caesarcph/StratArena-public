策略分析

分析 ### 2.1 核心策略概念 EA_PotentialEntries是一个**纯价格行为(Pure Price Action)蜡烛图形态策略**，基于日本蜡烛图经典反转形态进行交易。策略不使用任何技术指标，完全依赖蜡烛图形态特征识别入场时机。支持两种模式：做多趋势(A1)和做空趋势(A2)。 ### 2.2 入场条件 **做多模式 (PA_TYPE=1 - Bullish Trend):** | 形态名称 | 条件 | 说明 | | **看涨锤子线 (HAM)** | cCS1阳线 && cCS2阴线 && 实体<下影线/2 && 下影线>上影线×3 | 经典底部反转形态，实体小、下影线长 | | **看涨倒锤子 (IVH)** | cCS1阳线 && cCS2阴线 && 实体<上影线/2 && 下影线×3<上影线 | 底部反转信号，上影线长 | | **动量建立** | cCS1阳线 && cCS2阳线 && cCS1波幅>cCS2波幅 && cCS1实体≥cCS2实体×2 | 连续阳线动量加速形态 | **做空模式 (PA_TYPE=2 - Bearish Trend):** | 形态名称 | 条件 | 说明 | | **流星线 (SHS)** | cCS1阴线 && cCS2阳线 && 实体<上影线/2 && 下影线×3<上影线 | 经典顶部反转形态 | | **上吊线 (HGM)** | cCS1阴线 && cCS2阳线 && 实体<下影线/2 && 下影线>上影线×3 | 顶部反转信号 | | **动量建立** | cCS1阴线 && cCS2阴线 && cCS1实体>cCS2实体 && cCS1波幅≥cCS2波幅×2 | 连续阴线动量加速形态 | ### 2.3 出场条件 - **止损**: 设置为前两根K线最低点(做多)或最高点(做空) - **止盈**: TP=0，无固定止盈，依赖手动管理 - **无追踪止损** ### 2.4 风险管理 - **止损逻辑**: 使用前两根K线极值作为止损位 - 做多止损: `MathMin(cCS1.dLowPrice, cCS2.dLowPrice)` - 做空止损: `MathMax(cCS1.dHighPrice, cCS2.dHighPrice)` - **手数管理**: 固定手数输入参数 `dVol` - **持仓检查**: `CountTrades()<1` 确保单一持仓 - **无动态风控**: 无止损止盈参数、无追踪止损

Summary

优势

  • 纯价格行为策略 - 不依赖滞后指标，反应灵敏
  • 经典蜡烛图形态 - 锤子线、流星线、上吊线等形态经过市场验证
  • 代码架构清晰 - cCandlestick类设计合理，封装良好
  • 止损逻辑合理 - 使用前两根K线极值，符合价格行为原理
  • 动量确认机制 - "Building Momentum"形态识别动量加速
  • 可视化标记 - 在图表上标记交易信号(HAM/IVH/SHS/HGM)

劣势

  • 无趋势过滤 - 缺乏MA或ADX趋势方向确认，可能逆势交易
  • 固定手数无风控 - 无动态仓位管理，风险不可控
  • 无止盈机制 - TP=0硬编码，无法锁定盈利
  • 模式选择局限 - 只能选择全做多或全做空，无法双向交易
  • 形态定义过于严格 - 影线比例条件过于绝对，可能错过有效信号
  • 无时间过滤 - 缺乏交易时段选择

改进建议

  • ✅ 添加固定止盈参数 (建议TP=SL×1.5)
  • ✅ 实现动态手数计算 (建议Risk=1-2%)
  • ✅ 添加ATR动态止损选项
  • ✅ 添加MA200趋势方向过滤
  • 添加魔法编号参数
  • 实现双向交易模式
  • 添加交易时段过滤
  • 增加更多蜡烛图形态
  • 添加追踪止损功能
