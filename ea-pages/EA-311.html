策略分析

分析 ### 2.1 核心策略概念 这是一个基于**哈拉米(Harami)蜡烛形态**配合**CCI指标确认**的反转交易策略。 **哈拉米形态含义**: - **看涨哈拉米(Bullish Harami)**: 出现在下跌趋势中，由一根长黑蜡烛后跟一根小白蜡烛组成，小白蜡烛完全被包含在长黑蜡烛实体内，预示下跌动能耗尽，可能反转上涨 - **看跌哈拉米(Bearish Harami)**: 出现在上涨趋势中，由一根长白蜡烛后跟一根小黑蜡烛组成，小黑蜡烛完全被包含在长白蜡烛实体内，预示上涨动能耗尽，可能反转下跌 **CCI确认逻辑**: - 做多时: CCI < -50 (超卖区域) - 做空时: CCI > 50 (超买区域) ### 2.2 入场条件 **做多入场**: 1. 检测到看涨哈拉米蜡烛形态 2. CCI(1) < -50 (确认超卖状态) 3. 形态出现在下跌趋势中 (MidPoint(2) < CloseAvg(2)) **做空入场**: 1. 检测到看跌哈拉米蜡烛形态 2. CCI(1) > 50 (确认超买状态) 3. 形态出现在上涨趋势中 (MidPoint(2) > CloseAvg(2)) ### 2.3 出场条件 **多头出场**: - CCI从-80以下回升至-80以上 (CCI(1) > -80 && CCI(2) < -80) - CCI从80以上回落至80以下 (CCI(1) < 80 && CCI(2) > 80) **空头出场**: - CCI从80以上回落至80以下 (CCI(1) < 80 && CCI(2) > 80) - CCI从-80以下回升至-80以上 (CCI(1) < -80 && CCI(2) > -80) ### 2.4 风险管理 | 参数 | 默认值 | 说明 | | Signal_StopLevel | 0 | **无止损!** | | Signal_TakeLevel | 0 | **无止盈!** | | Signal_Expiration | 4 | 挂单过期(4根K线) | | Money_FixLot_Lots | 0.1 | 固定手数 | **严重问题**: - ⚠️ **无止损止盈设置** - 完全依赖信号反转出场 - 无追踪止损机制 - 无最大亏损保护

优势

  • 16种蜡烛形态框架 - aCandlePatterns.mqh提供完整的蜡烛形态检测库，可检测三黑鸦、三白兵、乌云盖顶、刺透线、晨星、黄昏星、吞没、哈拉米等16种经典形态
  • AvgBody动态基准算法 - 使用过去N根蜡烛的平均实体大小作为判断标准，自适应不同市场波动环境
  • 80/40信号评分机制 - 入场信号80分，出场信号40分，分级机制清晰，便于与其他信号组合
  • 趋势确认逻辑完善 - 哈拉米形态检测包含趋势确认(MidPoint与CloseAvg比较)，确保形态出现在正确趋势中
  • CCI超买超卖确认 - 使用CCI±50作为超买超卖确认，减少假信号

劣势

  • 无止损止盈 - 最致命缺陷，完全依赖信号反转出场，风险不可控
  • 反转策略本质风险 - 哈拉米是反转形态，在强趋势中容易被套
  • 参数非标准 - PeriodCCI=11非常规，需要优化
  • 无追踪止损 - 无法锁定盈利
  • 出场信号弱 - CCI穿越-80/80作为出场条件，可能错过更好的出场点
