摘要

一个多品种夜间剥头皮EA，在特定时间窗口内基于布林带均值回归信号交易。当价格触及下轨时买入，触及上轨时卖出，且要求布林带宽度低于阈值。交易时段结束时平仓，仅在新K线时开仓。

策略分析

策略概念是基于布林带均值回归的夜间剥头皮策略，利用夜间市场波动率降低时价格在布林带上下轨之间回归的特性进行交易。入场条件为：当价格低于布林带下轨且布林带宽度（上轨与下轨之差）小于设定的Razmah阈值时做多，当价格高于布林带上轨且带宽小于阈值时做空。出场条件包括止损和止盈，以及当当前时间早于设定的Start时间时强制平仓所有仓位。仓位管理方面，所有品种使用固定手数Lot，没有任何动态仓位调整机制。资金管理方面，完全没有资金管理逻辑，不根据账户余额或风险比例调整仓位大小。该EA支持最多9个品种同时交易，每个品种有独立的布林带参数、止损止盈和交易时间设置。

Summary

A multi-symbol night scalping EA that trades Bollinger Band mean reversion signals during specific time windows. It opens buy positions when price touches the lower band and sell positions when price touches the upper band, provided band width is below a threshold. Positions are closed when the trading session ends and new trades are only opened on new bars.

Strategy Analysis

The strategy concept is a night scalping approach based on Bollinger Band mean reversion, exploiting the tendency of prices to revert within the bands during low-volatility nighttime sessions. Entry conditions are: go long when the Ask price is below the lower Bollinger Band and the band width (upper minus lower) is less than the Razmah threshold in points, and go short when the Bid price is above the upper band with the same band width filter. Exit conditions include fixed stop loss and take profit levels, plus a forced close of all positions on a symbol when the current time is before the Start hour (which effectively defines a time window boundary). Position sizing uses a fixed lot size for all symbols with no dynamic adjustment based on volatility or account equity. Money management is completely absent, as there is no logic to scale position size based on account balance, risk percentage, or any other equity-based metric. The EA supports up to 9 symbols simultaneously, each with independent Bollinger Band parameters, stop loss/take profit, and session start time settings.

优势

  • 多品种支持，可同时交易最多9个品种，分散风险
  • 布林带宽度过滤确保只在低波动率环境下交易，符合夜间剥头皮逻辑
  • 新K线判断机制避免重复开仓，减少过度交易
  • 每个品种参数独立可调，灵活性高
  • 有时间窗口控制，非交易时段自动平仓

劣势

  • 止损远大于止盈（如品种1止损370点对止盈20点），风险报酬比极差
  • 没有点差过滤，夜间低流动性时段点差可能很大，导致不利成交
  • 固定手数无资金管理，不根据账户规模调整仓位
  • BBHandle指标句柄在每次SymbolTrade调用时重新创建，造成资源泄漏
  • 时间逻辑有缺陷：只检查当前时间大于Start时间就开仓，没有结束时间限制，平仓条件是时间小于Start意味着只在新的一天Start之前才平仓
  • CloseAll函数在循环中按Symbol平仓但PositionClose可能改变持仓索引导致遗漏
  • 不支持魔法号(Magic Number)过滤，可能与其他EA冲突

改进建议

  • 添加点差过滤，当点差超过阈值时不开仓，避免夜间高滑点成交
  • 在OnInit中预创建所有品种的指标句柄并缓存，避免每次tick重复创建导致资源泄漏
  • 添加结束时间参数和完整的时间窗口逻辑，替代当前有缺陷的单边时间判断
  • 添加Magic Number以区分本EA的仓位与其他EA的仓位
  • 加入基于账户余额或ATR的动态仓位管理
  • 修复CloseAll函数，使用倒序遍历并在每次平仓后重新检查持仓总数

Strengths

  • Multi-symbol support for up to 9 instruments simultaneously, enabling risk diversification
  • Bollinger Band width filter ensures trading only in low-volatility environments, aligning with night scalping logic
  • New bar check prevents duplicate entries and reduces overtrading
  • Independent parameter sets per symbol offer high flexibility for optimization
  • Time window control with automatic position closure outside trading hours

Weaknesses

  • Stop loss far exceeds take profit (e.g. Symbol1: 370 vs 20 points), resulting in extremely poor risk-reward ratio
  • No spread filter, which is critical since nighttime low-liquidity sessions often have wide spreads leading to unfavorable fills
  • Fixed lot size with no money management, position size does not adapt to account equity
  • BBHandle indicator handle is recreated on every SymbolTrade call, causing resource/memory leak
  • Time logic is flawed: only checks if current time > Start for entries with no end time, and closes only when time < Start which means closures happen in the pre-Start hours of a new day
  • CloseAll function iterates positions and closes by symbol, but PositionClose may alter position indices causing skipped closures
  • No Magic Number filtering, so it may conflict with other EAs running on the same symbol

Improvements

  • Add a spread filter to prevent opening positions when spread exceeds a threshold, avoiding unfavorable fills during nighttime low liquidity
  • Pre-create and cache all indicator handles in OnInit instead of recreating them on every SymbolTrade call to prevent resource leaks
  • Add an end time parameter and implement proper time window logic to replace the flawed single-direction time check
  • Add Magic Number support to distinguish this EA's positions from other EAs running on the same symbols
  • Implement dynamic position sizing based on account equity or ATR for better risk management
  • Fix CloseAll function to properly handle position index changes after closing, using reverse iteration with re-checking of PositionsTotal

风险点

  • 止损远大于止盈，需要极高的胜率才能盈利，一次亏损可抵消多次盈利
  • 夜间交易无点差过滤，可能在高点差环境下开仓导致额外损失
  • 指标句柄泄漏可能导致终端资源耗尽
  • CloseAll函数可能遗漏平仓，导致非预期持仓过夜
  • 无Magic Number可能导致误平其他EA的仓位或误判持仓数量
  • 固定手数无资金管理，大账户小手数浪费机会，小账户大手数过度风险

Risk Assessment

Overall:CAUTION

Risk Points

  • Stop loss far exceeds take profit, requiring extremely high win rate to be profitable; one loss can wipe out many wins
  • No spread filter for night trading may result in entries during wide spreads causing additional losses
  • Indicator handle leak may exhaust terminal resources over time
  • CloseAll function may skip positions due to index shifting, leaving unintended overnight positions
  • No Magic Number may cause accidental closure of other EAs' positions or miscounting of open positions
  • Fixed lot size with no money management wastes opportunity on large accounts and over-risks small accounts
