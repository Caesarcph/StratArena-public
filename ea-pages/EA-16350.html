策略分析

分析 ### 2.1 核心策略概念 NightScalper是一个**多货币布林带突破+时间过滤策略**，专为夜间低波动时段设计。核心思想是： 1. **夜间时段交易**：在指定的开始时间(如19:00、20:00)后入场 2. **波动率收缩突破**：当布林带宽度小于阈值(Razmah参数)且价格触及上下轨时入场 3. **均值回归逻辑**：价格触及下轨做多，触及上轨做空，赌价格回归中轨 4. **时间保护机制**：交易时间结束前自动平仓 ### 2.2 入场条件 **做多条件** (同时满足): 1. 当前时间 > Start时间(如19:00) 2. Ask价格 < 布林带下轨 3. 布林带宽度(up-dn) < Razmah×Point(波动率收缩确认) 4. 当前货币对无持仓(CountTrades<1) **做空条件** (同时满足): 1. 当前时间 > Start时间(如20:00) 2. Bid价格 > 布林带上轨 3. 布林带宽度(up-dn) < Razmah×Point(波动率收缩确认) 4. 当前货币对无持仓(CountTrades<1) ### 2.3 出场条件 1. **止损**: 固定点数止损(StopLoss参数，如370点) 2. **止盈**: 固定点数止盈(TakeProfit参数，如20点) 3. **时间出场**: 当前时间 < Start时间时强制平仓所有持仓 4. **反向信号**: 无反向信号平仓机制 ### 2.4 风险管理 | 参数 | 默认值 | 分析 | | 固定手数 | Lot=1 | ⚠️ 固定手数过大，无资金管理 | | 止损 | 370-450点 | 较大止损 | | 止盈 | 20-80点 | 较小止盈 | | 盈亏比 | 0.05-0.22:1 | ❌ 极差，严重不利于长期盈利 | | 波动率过滤 | Razmah参数 | ✅ 有波动率收缩确认 | | 时间过滤 | Start参数 | ✅ 有交易时段控制 |

优势

  • 多货币架构清晰：支持9个货币对独立参数配置，代码复用性好
  • 波动率过滤机制：Razmah参数确保只在低波动时段入场
  • 代码简洁：176行代码实现多货币交易，逻辑清晰
  • 时间过滤思想：夜间剥头皮策略概念合理，低波动时段适合均值回归

劣势

  • 盈亏比灾难性：最差0.05:1，完全无法长期盈利
  • 时间逻辑错误：出场条件与入场条件矛盾
  • 固定手数过大：无资金管理，风险不可控
  • 无Magic Number：无法区分仓位，多策略运行会混乱
  • 参数过度优化：不同货币对参数差异过大，明显是曲线拟合
  • BB参数不合理：周期4-40差异太大，缺乏一致性
