策略分析

### 2.1 核心理念 **BrakeParb** (Brake Parabolic Breakout) 是一个**抛物线曲线突破策略**，使用幂函数数学公式创建动态抛物线，当价格突破抛物线时产生交易信号。与#1099的指数通道不同，此策略使用**抛物线曲线**跟踪趋势。 ### 2.2 抛物线算法 **核心公式**: **参数定义**: - `A = 1.5` - 幂因子，控制曲线加速程度 - `B = 1.0 * _Point * PeriodSeconds() * 0.1 / 60` - 比例因子 (动态计算) - `beginBar` - 抛物线起始K线 - `bar` - 当前K线 **抛物线特性**: - 曲线从起始点呈抛物线加速 - A值越大，曲线越陡峭 - B值调整曲线比例 - 自动跟踪价格极值 ### 2.3 缓冲区定义 **UpBuffer (上缓冲区)**: - 抛物线上方区域 - 多头趋势跟踪 - 价格突破 → 买入信号 **DnBuffer (下缓冲区)**: - 抛物线下方区域 - 空头趋势跟踪 - 价格突破 → 卖出信号 **BuyBuffer / SellBuffer**: - 买卖信号标记 - 在图表显示箭头 ### 2.4 入场信号 #### 买入信号 **条件**: 1. 价格突破抛物线上方 (UpSignal) 2. 从DnBuffer区域进入UpBuffer区域 3. 抛物线趋势向上 **逻辑**: #### 卖出信号 **条件**: 1. 价格突破抛物线下方 (DnSignal) 2. 从UpBuffer区域进入DnBuffer区域 3. 抛物线趋势向下 **逻辑**: ### 2.5 出场逻辑 **反向信号平仓**: - DnSignal触发 → 平多单 - UpSignal触发 → 平空单 **趋势状态平仓**: - UpTrend活跃 → 平空单 - DnTrend活跃 → 平多单 **固定SL/TP**: - StopLoss = 1000点 - TakeProfit = 2000点 ### 2.6 与BrakeExp (#1099) 对比 | 特性 | BrakeExp (#1099) | BrakeParb (#1101) | | **算法** | 指数曲线 (Exp) | 抛物线曲线 (Pow) | | **公式** | `MathExp(...)` | `MathPow(...)` | | **曲线形态** | 指数增长 | 幂函数加速 | | **信号类型** | 通道突破 | 抛物线突破 | | **视觉** | 通道线 | 抛物线点 | | **加速特性** | 平滑指数 | 幂函数加速 | ### 2.7 交易流程
