摘要

该EA通过MQL5标准库CExpert框架组合MACD和两条移动平均线信号来生成趋势跟踪的交易入场和出场。它使用固定手数进行资金管理，并使用基于MA的移动止损来保护利润。当加权综合信号超过可配置阈值时，策略开仓。

策略分析

该EA采用多信号过滤的趋势跟踪策略，核心由三个指标信号组成：MACD信号和两个不同周期的移动平均线信号（12周期SMA和26周期SMA）。入场条件是当三个信号的加权综合值超过开仓阈值（默认10）时开仓，反之超过平仓阈值时平仓。出场条件包括固定止损（1000点）和固定止盈（5500点），以及基于12周期SMA的移动止损跟踪。仓位管理采用固定手数模式（默认0.06手），不根据账户余额动态调整。资金管理使用CMoneyFixedLot类，设置10%的百分比参数但实际使用固定手数，存在参数语义不明确的问题。策略依赖MQL5标准库的CExpert信号聚合机制，各信号权重均为1.0，即三个信号同等重要。

Summary

This EA combines MACD and two Moving Average signals through the MQL5 Standard Library CExpert framework to generate trend-following trade entries and exits. It uses a fixed lot size for money management and an MA-based trailing stop to protect profits. The strategy opens positions when the weighted composite signal exceeds configurable thresholds.

Strategy Analysis

This EA employs a multi-signal filtered trend-following strategy composed of three indicator signals: a MACD signal and two Moving Average signals with different periods (12-period SMA and 26-period SMA). Entry conditions trigger when the weighted composite value of all three signals exceeds the opening threshold (default 10), and closing occurs when the composite exceeds the closing threshold. Exit conditions include a fixed stop loss at 1000 points, a fixed take profit at 5500 points, and a trailing stop based on a 12-period SMA. Position sizing uses a fixed lot mode (default 0.06 lots) without dynamic adjustment based on account balance. Money management uses the CMoneyFixedLot class with a 10% percent parameter, but actually uses fixed lots, creating a semantic ambiguity in parameter usage. The strategy relies on the MQL5 Standard Library CExpert signal aggregation mechanism where all three signal filters carry equal weight of 1.0.

优势

  • 使用MQL5标准库CExpert框架，结构规范，代码基于成熟的信号聚合体系
  • 设置了固定止损（1000点）和止盈（5500点），具备基本的风险控制
  • 多信号过滤机制（MACD+双MA）可以减少虚假信号，提高入场质量
  • 采用MA移动止损跟踪利润，能够锁定浮动盈利

劣势

  • OnInit函数中存在致命逻辑错误：第81行和第97行提前return INIT_SUCCEEDED，导致信号创建、过滤器配置、移动止损和资金管理的初始化代码永远不会执行
  • 固定手数模式缺乏自适应仓位调整，在不同账户规模下风险暴露不一致
  • 止损1000点和止盈5500点的比例虽然合理（1:5.5），但止损点数绝对值较大，在高波动品种上可能仍不足
  • 没有新增K线检查机制，在Expert_EveryTick=false时虽按新Bar交易，但缺少显式的新Bar检测逻辑
  • Money_FixLot_Percent参数在固定手数模式下语义不清，容易误导用户

改进建议

  • 修复OnInit函数中的提前return问题，删除第81行和第97行的return INIT_SUCCEEDED，确保所有初始化代码正常执行
  • 增加新Bar检测逻辑，防止同一根K线上重复开仓，提高交易效率
  • 增加点差过滤和交易时段过滤，避免在高点差和非活跃时段交易

Strengths

  • Uses the MQL5 Standard Library CExpert framework with a well-structured signal aggregation architecture
  • Implements fixed stop loss (1000 points) and take profit (5500 points) for basic risk control
  • Multi-signal filtering mechanism (MACD + dual MA) reduces false signals and improves entry quality
  • Employs MA-based trailing stop to track and lock in floating profits

Weaknesses

  • Critical logic bug in OnInit: lines 81 and 97 return INIT_SUCCEEDED prematurely, causing signal creation, filter configuration, trailing stop, and money management initialization code to never execute
  • Fixed lot sizing lacks adaptive position adjustment, resulting in inconsistent risk exposure across different account sizes
  • The stop loss of 1000 points and take profit of 5500 points have a reasonable ratio (1:5.5), but the absolute SL value may still be insufficient for high-volatility instruments
  • No explicit new bar check mechanism; while Expert_EveryTick=false trades per new bar, there is no explicit new bar detection logic
  • The Money_FixLot_Percent parameter is semantically ambiguous in fixed lot mode and can mislead users

Improvements

  • Fix the premature return statements in OnInit by removing the return INIT_SUCCEEDED on lines 81 and 97, ensuring all initialization code executes properly
  • Add explicit new bar detection logic to prevent repeated position openings on the same bar and improve trade efficiency
  • Add spread filter and trading session filter to avoid trading during high-spread and inactive market periods
