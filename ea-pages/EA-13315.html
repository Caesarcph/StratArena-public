摘要

一个基于布林带和ADX指标的均值回归EA，在低趋势强度下识别超买超卖条件入场。采用马丁格尔仓位管理策略，在亏损交易后倍增手数，并提供隐身模式将止损止盈对经纪商隐藏而在内部管理出场。

策略分析

该EA的核心策略是均值回归，利用布林带上下轨判断价格偏离，结合ADX指标确认市场处于低趋势强度状态时入场。买入条件为价格触及布林带下轨且ADX低于阈值且上一笔非卖出交易；卖出条件为价格触及布林带上轨且ADX低于阈值且上一笔非买入交易。出场方面，支持显式止损止盈和隐身模式两种方式，隐身模式下提交订单时不设SL/TP，而是通过图表标签标记并在OnTick中手动监测盈亏点数来平仓。仓位管理采用马丁格尔策略，亏损后手数乘以KLot倍数，盈利后恢复初始手数，同时设有MaxLot上限防止过度加仓。资金管理方面仅限制最大手数和最小手数，缺乏净值回撤保护、连续亏损次数限制等安全机制。

Summary

A mean-reversion EA using Bollinger Bands and ADX to identify overbought/oversold conditions with low trend strength. It employs a Martingale lot-sizing strategy that multiplies lot size after losing trades, with a configurable stealth mode that hides SL/TP from the broker while managing exits internally.

Strategy Analysis

The core strategy is mean reversion, using Bollinger Band upper and lower bands to detect price deviation, combined with the ADX indicator to confirm low trend strength before entering. Buy condition triggers when price touches the lower Bollinger Band, ADX is below the threshold, and the last deal was not a sell; sell condition triggers when price touches the upper Bollinger Band, ADX is below the threshold, and the last deal was not a buy. For exits, the EA supports both explicit stop-loss/take-profit and a stealth mode where SL/TP values are hidden from the broker by submitting orders without them, then manually monitoring profit/loss in pips via OnTick and closing positions when thresholds are reached. Position sizing follows a Martingale approach: after a loss, the lot size is multiplied by KLot; after a win, it reverts to the initial lot, with a MaxLot cap to prevent excessive sizing. Money management only enforces minimum and maximum lot limits, lacking equity drawdown protection, consecutive loss limits, or other safety mechanisms.

优势

  • 使用布林带和ADX组合过滤，避免在强趋势中逆势入场
  • 新K线检测避免同一根K线内重复开仓
  • 隐身模式可防止经纪商看到止损止盈进行猎杀
  • MaxLot上限提供了一定的仓位膨胀保护

劣势

  • 马丁格尔策略在连续亏损时手数指数增长，可能导致爆仓
  • IsNewBar函数存在逻辑Bug：m_TOld是局部变量，每次调用都重置为0，导致每次都返回true
  • PutLable函数中ObjectSetInteger等代码在return之后永远不会执行
  • 没有连续亏损次数限制，也没有净值回撤保护机制
  • PositionsTotal()检查不区分品种，多品种运行时会互相干扰

改进建议

  • 修复IsNewBar函数：将m_TOld改为static变量以正确记录上一根K线时间
  • 修复PutLable函数：将return移到函数末尾，确保ObjectSetInteger等属性设置代码能执行
  • 添加连续亏损次数限制和净值回撤保护，达到阈值后停止交易或重置手数
  • PositionsTotal检查应改为检查当前品种的持仓数量而非全局持仓数

Strengths

  • Bollinger Bands combined with ADX filtering avoids counter-trend entries during strong trends
  • New bar detection prevents duplicate position opens within the same bar
  • Stealth mode prevents brokers from seeing SL/TP levels to avoid stop hunting
  • MaxLot cap provides some protection against uncontrolled position sizing escalation

Weaknesses

  • Martingale lot sizing causes exponential growth on consecutive losses, risking account blow-up
  • IsNewBar function has a logic bug: m_TOld is a local variable reset to 0 each call, always returning true
  • PutLable function has ObjectSetInteger calls after return statement that never execute
  • No consecutive loss count limit or equity drawdown protection mechanism exists
  • PositionsTotal() check is not symbol-specific, causing interference when running on multiple instruments

Improvements

  • Fix IsNewBar function: change m_TOld to a static variable to correctly track the previous bar time
  • Fix PutLable function: move return to end of function so ObjectSetInteger property setting code actually executes
  • Add consecutive loss count limits and equity drawdown protection to stop trading or reset lots when thresholds are hit
  • Replace PositionsTotal() with symbol-specific position count check to support multi-instrument operation
