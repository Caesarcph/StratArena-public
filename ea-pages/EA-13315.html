摘要

该EA使用布林带和ADX指标识别均值回归入场信号，在价格触及下轨时买入、触及上轨时卖出，并以低ADX值过滤确认市场处于盘整状态。采用马丁格尔仓位管理，亏损后乘数加仓，达到最大手数后重置为基础手数。隐身模式可向经纪商隐藏止损止盈，由EA内部监控并手动平仓。

策略分析

策略概念是基于布林带的均值回归交易，认为价格触及布林带边界后会回归均值。入场条件为：买入要求价格低于布林带下轨且ADX低于阈值（表示市场无明确趋势），卖出要求价格高于布林带上轨且ADX低于阈值。出场条件包括固定点数的止盈和止损，或在隐身模式下由EA内部计算盈亏点数后手动平仓。仓位管理采用马丁格尔策略，上一笔交易亏损时，下一笔手数乘以KLot系数（默认2倍），若手数超过MaxLot则重置为基础手数Lot。此外，EA通过LastDealType函数判断上一笔交易方向，限制连续同向交易——上一笔买入后只允许卖出或首笔交易，上一笔卖出后只允许买入或首笔交易。资金管理方面存在明显缺陷，马丁格尔加仓在连续亏损时会导致手数指数级增长，虽然MaxLot提供了一定保护但重置为基础手数意味着放弃回本逻辑，两难困境。

Summary

This EA uses Bollinger Bands and ADX to identify mean-reversion entry signals, entering buy when price touches the lower band and sell when price touches the upper band, filtered by low ADX indicating a ranging market. It employs a Martingale position sizing system that multiplies lot size after losing trades, with a maximum lot cap that resets to the base lot. Stealth mode allows hiding SL/TP from the broker while manually monitoring and closing positions internally.

Strategy Analysis

The strategy concept is based on Bollinger Band mean reversion, expecting price to return to the mean after touching the band boundaries. Entry conditions: buy when price is below the lower Bollinger Band and ADX is below its threshold (indicating a ranging market), sell when price is above the upper Bollinger Band and ADX is below its threshold. Exit conditions include fixed pip-based take-profit and stop-loss, or in stealth mode the EA internally calculates profit in points and closes positions when TP or SL levels are hit. Position sizing uses a Martingale system: after a losing trade, the next lot size is multiplied by KLot (default 2x), and if the lot exceeds MaxLot it resets to the base Lot. Additionally, the EA uses LastDealType to restrict consecutive same-direction trades—after a buy, only a sell or first trade is allowed, and vice versa. Money management has significant flaws: Martingale scaling causes exponential lot growth during consecutive losses, and while MaxLot provides a cap, resetting to base lot abandons the recovery logic, creating a dilemma between risk control and the Martingale recovery premise.

优势

  • 布林带结合ADX过滤趋势，避免在强趋势中逆势交易
  • 隐身模式可防止经纪商看到止损止盈价位，减少被猎止损的可能
  • MaxLot参数限制最大手数，防止马丁格尔无限加仓
  • 新K线检测避免同一根K线内重复开仓
  • 交替交易方向限制减少连续同向亏损的风险

劣势

  • 马丁格尔仓位管理在连续亏损时手数指数级增长，存在爆仓风险
  • MaxLot重置为基础手数后放弃回本逻辑，马丁格尔策略自相矛盾
  • IsNewBar函数使用局部变量m_TOld，每次调用都初始化为0，新K线检测实际失效
  • PutLable函数中return后仍有代码，属于死代码，隐身模式标签设置永远不会执行
  • 没有点差过滤，在布林带边界交易时点差可能吞噬利润
  • Volume函数依赖历史交易记录，首次运行或账户无历史时可能取到无效数据

改进建议

  • 修复IsNewBar函数，将m_TOld改为静态变量或类成员变量，确保新K线检测正常工作
  • 修复PutLable函数中的死代码问题，将return移到函数末尾，使标签样式设置能够执行
  • 增加点差过滤，当点差过大时跳过交易；增加最大连续亏损次数限制，达到后暂停交易
  • 改进马丁格尔逻辑，考虑使用更温和的加仓方式或完全替换为固定比例仓位管理

Strengths

  • Bollinger Bands combined with ADX filter avoids counter-trend trading during strong trends
  • Stealth mode hides SL/TP from the broker, reducing stop-hunting risk
  • MaxLot parameter caps the maximum lot size, preventing unlimited Martingale scaling
  • New bar check prevents duplicate entries within the same candle
  • Alternating trade direction restriction reduces risk of consecutive same-direction losses

Weaknesses

  • Martingale position sizing causes exponential lot growth during consecutive losses, risking account blowup
  • MaxLot resetting to base lot abandons the recovery logic, making the Martingale approach self-contradictory
  • IsNewBar uses a local variable m_TOld initialized to 0 on every call, so the new bar detection is effectively broken
  • PutLable function has code after return statement—dead code that never executes, so stealth mode labels are never styled
  • No spread filter—spreads can consume profits when trading at Bollinger Band boundaries
  • Volume function relies on deal history and may access invalid data on first run or empty accounts

Improvements

  • Fix IsNewBar by making m_TOld a static variable or class member so new bar detection works correctly
  • Fix dead code in PutLable by moving return to end of function so label styling actually executes
  • Add spread filter to skip trades when spread is excessive; add max consecutive loss count to pause trading
  • Improve Martingale logic—consider gentler scaling or replace entirely with fixed-fraction position sizing

Risk Assessment

Overall:HIGH

Risk Points

  • Martingale position sizing causes exponential lot growth during consecutive losses, potentially draining the account rapidly
  • Critical bug in IsNewBar function causes potential entry on every tick instead of only on new bars
  • Stop-loss exceeds take-profit (SL=1400 > TP=1200), resulting in unfavorable risk-reward ratio
  • No spread filter and no maximum drawdown protection
