策略分析

分析 ### 2.1 核心策略概念 这是一个**反转交易策略**，利用日本蜡烛图中的经典形态——看涨吞没(Bullish Engulfing)和看跌吞没(Bearish Engulfing)作为主要入场信号，并结合MFI(Money Flow Index，资金流量指标)进行确认。 **策略逻辑**： - **看涨吞没做多**: 在下降趋势末端出现看涨吞没形态(阳线完全吞没前一根阴线)，且MFI<40(资金流出极限)，表明卖盘枯竭，可能反转向上 - **看跌吞没做空**: 在上升趋势末端出现看跌吞没形态(阴线完全吞没前一根阳线)，且MFI>60(资金流入极限)，表明买盘枯竭，可能反转向下 ### 2.2 入场条件 **做多条件 (LongCondition)**: 1. 检测到看涨吞没形态 (`CANDLE_PATTERN_BULLISH_ENGULFING`) 2. MFI(1) < 40 (资金流出达到极限区域) 3. 返回信号强度80分 **做空条件 (ShortCondition)**: 1. 检测到看跌吞没形态 (`CANDLE_PATTERN_BEARISH_ENGULFING`) 2. MFI(1) > 60 (资金流入达到极限区域) 3. 返回信号强度80分 ### 2.3 出场条件 **多头平仓条件 (40分信号)**: - MFI从超卖区上穿30: `(MFI(1)>30 && MFI(2)<30)` - MFI从超买区下穿70: `(MFI(1)>70 && MFI(2)<70)` **空头平仓条件 (40分信号)**: - MFI从超买区下穿70: `(MFI(1)>70 && MFI(2)<70)` - MFI从超卖区上穿30: `(MFI(1)<30 && MFI(2)>30)` ### 2.4 风险管理 | 参数 | 默认值 | 说明 | | Signal_StopLevel | 0 | **无止损** - 依赖信号反转出场 | | Signal_TakeLevel | 0 | **无止盈** - 依赖信号反转出场 | | Signal_ThresholdOpen | 40 | 开仓阈值(信号>=40才开仓) | | Signal_ThresholdClose | 20 | 平仓阈值(信号>=20才平仓) | | Money_FixLot_Lots | 0.1 | 固定手数 | **⚠️ 严重风险**: 无硬性止损止盈，完全依赖信号反转出场，极端行情可能导致巨额亏损。

优势

  • 完整的16种蜡烛形态检测框架: acandlepatterns.mqh提供16种经典蜡烛形态检测，代码规范，可复用性强
  • AvgBody动态基准算法: 使用平均K线实体大小作为形态判断基准，自适应不同品种和周期
  • 80/40信号评分机制: 入场80分/出场40分的双阈值设计，有效区分开仓和平仓条件
  • MFI成交量加权确认: 结合资金流量指标，比单纯价格形态更可靠
  • MetaQuotes标准库架构: CExpert框架结构清晰，易于扩展和维护

劣势

  • 无硬性止损止盈: 极端行情风险无限放大
  • 反转策略无趋势过滤: 强趋势中逆势交易风险高
  • MFI参数非标准: 37周期过慢，信号滞后严重
  • 吞没形态趋势确认逻辑简单: 仅用MidOpenClose与CloseAvg比较，可能误判
  • 缺乏追踪止损机制: 无法保护已有利润
