摘要

这是一个网格交易EA，当价格偏离近期最高/最低价超过设定阈值时开仓，然后在固定间距放置最多4个限价单，手数按2的幂次递增（马丁格尔-网格混合体）。当总浮盈达到目标金额时平掉所有仓位和挂单，并可选在达到LockDown阈值时将止损移至保本。

策略分析

策略概念是结合网格与马丁格尔的逆势加仓系统。入场条件为：当最高价减去当前买入价超过ExtLimit点时做多，当当前买入价减去最低价超过ExtLimit点时做空，即价格从极值大幅偏离时逆势入场。出场条件为：所有持仓总浮盈达到Amount参数设定的金额时全部平仓并删除挂单。仓位管理采用马丁格尔方式，初始手数为余额/100/1000，后续每级限价单手数为前一级的2倍（2^i倍初始手数）。资金管理方面，网格间距固定为ExtGrid点，最多布置4级限价单，整体风险随逆势层级递增。该策略没有设置止损（除非LockDown触发保本止损），在单边行情中可能面临严重的浮亏风险。

Summary

A grid trading EA that opens an initial market order when price deviates significantly from the recent high/low, then places up to 4 additional limit orders at fixed grid intervals with doubled lot sizes (martingale-grid hybrid). It closes all positions and pending orders when total floating profit reaches a target amount, and optionally moves stop loss to breakeven when a LockDown threshold is reached.

Strategy Analysis

The strategy is a counter-trend grid system combined with martingale position sizing. Entry condition: buy when the highest price minus current bid exceeds ExtLimit points, or sell when current bid minus lowest price exceeds ExtLimit points — meaning it enters against the direction when price deviates significantly from recent extremes. Exit condition: all positions and pending orders are closed when total floating profit reaches the Amount target. Position sizing follows martingale logic: initial lot size is Balance/100/1000, and each subsequent grid level doubles the volume (2^i times the initial lots) via BuyLimit/SellLimit orders. Money management uses a fixed grid interval of ExtGrid points with up to 4 additional limit orders, creating escalating exposure. The strategy lacks proper stop losses unless LockDown triggers a breakeven move, which means sustained trending markets could generate catastrophic drawdowns.

优势

  • 网格加仓能在震荡行情中通过均价降低获取利润
  • LockDown保本止损功能提供了一定程度的风险保护
  • LotCheck函数确保手数符合经纪商的最小/最大手数和步长限制
  • 代码结构清晰，模块化程度较好，函数分工明确
  • 平仓时同时删除挂单，避免遗留订单造成意外风险

劣势

  • 马丁格尔加倍手数在单边趋势中会导致指数级亏损放大
  • 没有设置真正的止损，仅依赖浮盈目标出场，极端行情风险巨大
  • iLowest/iHighest返回的是索引而非价格值，存在代码逻辑错误
  • IsTradeAllowed函数重复检查了TERMINAL_TRADE_ALLOWED，属于冗余代码
  • 限价单最多4级且手数递增，最大持仓量可达初始的31倍，风险极高

改进建议

  • 修复iLowest/iHighest的返回值问题，应使用iLow()/iHigh()获取实际价格
  • 增加真实止损保护，而非仅依赖浮盈目标或保本止损
  • 限制最大加仓层级和最大总持仓量，加入全局风险控制机制

Strengths

  • Grid averaging can profit in ranging markets by lowering average entry price
  • LockDown breakeven feature provides some risk protection
  • LotCheck function validates lot size against broker constraints (min/max/step)
  • Clean code structure with well-separated functions for open/close/refresh logic
  • CloseAll deletes both positions and pending orders, preventing orphaned orders

Weaknesses

  • Martingale lot doubling causes exponential loss amplification during strong trends
  • No real stop loss — exit depends solely on floating profit target, creating extreme risk in trending markets
  • iLowest/iHighest return bar indices not price values, representing a critical logic bug
  • IsTradeAllowed redundantly checks TERMINAL_TRADE_ALLOWED twice in succession
  • 4 grid levels with doubling lots means maximum exposure is 31x initial size, extremely risky

Improvements

  • Fix iLowest/iHighest return value bug — use iLow()/iHigh() to get actual prices instead of bar indices
  • Add genuine stop loss protection instead of relying solely on profit target or breakeven
  • Cap maximum grid levels and total exposure, implementing a global risk control mechanism
