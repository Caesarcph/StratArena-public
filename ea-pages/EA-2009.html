策略分析

分析 ### 2.1 核心策略概念 **Blau TStochI (William Blau三重平滑随机指数)** 这是William Blau开发的经典技术指标，通过三重平滑Stochastic指标来识别趋势转折。核心思想是对原始Stochastic值进行多次平滑处理，以减少噪音并保持较低滞后。 **算法流程**: 1. 计算原始Stochastic值: `Stoch = price - LL` (当前价格减去最低价) 2. 计算价格范围: `Range = HH - LL` (最高价减去最低价) 3. 三重平滑Stoch值得到`xxxStoch` 4. 三重平滑Range得到`xxxRange` 5. 归一化输出: `IndBuffer = 100 * xxxStoch / xxxRange - 50` 结果范围: [-50, +50]，零轴为中性线。 ### 2.2 入场条件 **两种入场模式**: 1. **Breakdown模式 (零轴穿越)**: - 做多: Value[1] > 0 且 Value[0] <= 0 (从正转负后确认反转) - 做空: Value[1] < 0 且 Value[0] >= 0 (从负转正后确认反转) 2. **Twist模式 (方向转折)** - 默认: - 做多: Value[1] < Value[2] 且 Value[0] >= Value[1] (V型反转) - 做空: Value[1] > Value[2] 且 Value[0] <= Value[1] (倒V型反转) ### 2.3 出场条件 - 反向信号触发平仓(通过BuyPosClose/SellPosClose开关) - 止损/止盈触发(默认SL=1000点, TP=2000点) ### 2.4 风险管理 - **止损**: 1000点 (⚠️过大，建议优化至150-300点) - **止盈**: 2000点 (盈亏比2:1良好) - **手数管理**: 5种模式(LOT/FREEMARGIN/BALANCE/PROFIT/LOSS) - **四开关交易控制**: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制

优势

  • William Blau经典算法: 三重平滑有效降噪，减少假信号
  • 双入场模式: breakdown/twist两种模式灵活选择
  • 专业级架构: Nikolay Kositsin高质量代码，结构清晰
  • 盈亏比良好: 默认2:1盈亏比有利于长期盈利
  • 四开关交易控制: 独立控制开平仓权限，灵活性高
  • 多算法平滑: 支持10种平滑算法(JJMA/JurX/T3/VIDYA/AMA等)
  • 多价格类型: 支持11种价格计算方式

劣势

  • 默认止损过大: 1000点风险敞口过大
  • 无趋势强度过滤: 容易在震荡市中产生假信号
  • 三重平滑滞后: 信号可能滞后于实际趋势转折
  • 固定手数过大: 0.1手对小账户过大
  • 依赖外部库: 需安装SmoothAlgorithms.mqh和TradeAlgorithms.mqh

改进建议

  • 短期改进 (必须)
  • 降低止损至150-300点
  • 添加ADX>25趋势强度过滤
  • 使用动态手数MM=0.01-0.02
  • 延长平滑周期参数
  • 中期改进 (建议)
  • 添加ATR追踪止损
  • 添加MA200趋势方向过滤
  • 优化入场逻辑，考虑在趋势增强时入场而非减弱时
  • 添加波动率自适应参数
  • 长期改进 (可选)
  • 开发多时间框架版本(D1趋势 + H4信号)
  • 添加信号强度分级系统
  • 整合到UltimateEA信号评分系统
