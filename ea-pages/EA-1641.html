策略分析

分析 ### 2.1 核心策略概念 **FigurelliSeries多周期MA共识趋势跟踪策略** 该EA使用Rogerio Figurelli开发的多周期移动平均共识指标(FigurelliSeries)进行趋势判断。核心思想是： 1. **多MA投票系统**: 计算从起始周期开始，按步长递增的36条移动平均线(默认6,12,18,24,...,216周期) 2. **价格位置投票**: 对每条MA，价格在MA上方则记为+1(Bid)，价格在MA下方则记为-1(Ask) 3. **共识值计算**: 将所有投票值求和，得到范围在-36到+36之间的共识值 4. **信号生成**: 共识值>0时看多(多数MA价格在上)，共识值<0时看空(多数MA价格在下) ### 2.2 入场条件 **做多条件**: 1. FigurelliSeries指标值 > 0 (多数MA价格在上方) 2. 当前时间 = StartHour:StartMinute (精确时间入场，默认08:00) 3. BuyPosOpen开关开启 4. 新K线或SignalBar触发 **做空条件**: 1. FigurelliSeries指标值 < 0 (多数MA价格在下方) 2. 当前时间 = StartHour:StartMinute (精确时间入场，默认08:00) 3. SellPosOpen开关开启 4. 新K线或SignalBar触发 **入场逻辑特点**: - 使用精确时间入场机制(tm.hour==StartHour && tm.min==StartMinute) - 信号产生后需等待指定入场时间才执行 - 指标信号与时间过滤双重确认 ### 2.3 出场条件 **信号出场**: - 做多仓位: FigurelliSeries指标值 < 0时平仓(多数MA转空) - 做空仓位: FigurelliSeries指标值 > 0时平仓(多数MA转多) **时间出场**: - 超过StopHour:StopMinute时强制平仓(默认23:59) - 早于StartHour时也强制平仓(防止隔夜持仓) **出场逻辑特点**: - 双重出场机制: 指标反转信号 + 时间强制退出 - 时间出场确保不持仓过夜 ### 2.4 风险管理 **止损/止盈逻辑**: - 固定止损: StopLoss_ = 1000点 (极度过大) - 固定止盈: TakeProfit_ = 2000点 - 盈亏比: 2:1 (良好) **手数管理**: - 5种手数计算模式(MMMode): - LOT: 固定手数 - FREEMARGIN: 基于可用保证金 - BALANCE: 基于账户余额 - LOSSFREEMARGIN: 亏损占可用保证金比例 - LOSSBALANCE: 亏损占余额比例 - MM参数控制风险敞口比例(默认0.1 = 10%) **其他风控措施**: - Deviation_=10 滑点控制 - 四开关交易控制(BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose) - 时间段交易限制(StartHour到StopHour) - CIsNewBar新K线检测类

优势

  • 多MA共识投票算法: 36条MA投票产生稳健趋势信号，有效过滤单一MA噪音
  • 专业级代码架构: Nikolay Kositsin标准架构，包含完整的TradeAlgorithms交易函数库
  • 时间段交易控制: 精确的入场/出场时间控制，避免隔夜持仓风险
  • 盈亏比2:1良好: 止盈2000/止损1000的设置提供合理的风险回报比
  • 灵活的手数管理: 5种手数计算模式满足不同风险管理需求

劣势

  • 默认止损过大: 1000点止损可能导致单笔巨额亏损
  • 精确时间入场限制: 必须在08:00整入场，可能错过最佳价格
  • 无趋势强度确认: 没有ADX或类似指标确认趋势强度
  • MA周期过短: 起始6周期产生大量噪音信号
  • 无追踪止损机制: 无法锁定浮动利润
