摘要

这个EA通过监控MT5公共文件夹中的命令文本文件(buy.txt, sell.txt, close.txt)来实现策略测试器上的手动练习交易。当检测到命令文件时，它会按照指定手数执行相应交易。该EA专为策略测试器模拟设计，不适用于实盘交易。

策略分析

该EA的策略概念是基于外部文件触发手动交易信号，属于半自动化交易工具。入场条件是当MT5公共文件夹中出现buy.txt或sell.txt文件时，EA检测到文件后立即执行买入或卖出操作，手数为用户设定的固定手数DLot。出场条件是当检测到close.txt文件时，EA会读取当前持仓的方向和手数，然后以相同手数执行反向交易来平仓。仓位管理非常简单，开仓使用固定手数参数，平仓则读取当前持仓的实际手数进行反向操作。资金管理几乎不存在，没有止损、止盈、追踪止损等任何风险控制机制，也没有资金百分比计算手数的功能。整个策略依赖于外部文件系统的轮询来驱动交易，本质上是一个桥接工具，将外部信号转化为MT5交易指令。

Summary

This EA enables manual practice trading on the MT5 Strategy Tester by monitoring the Common folder for command text files (buy.txt, sell.txt, close.txt). When a command file is detected, it executes the corresponding trade at the specified lot size. It is designed specifically for strategy tester simulation and not for live trading.

Strategy Analysis

The strategy concept of this EA is based on external file-triggered manual trading signals, functioning as a semi-automated trading bridge. Entry conditions are triggered when buy.txt or sell.txt files appear in the MT5 Common folder; upon detection, the EA immediately executes a buy or sell order at the user-specified fixed lot size (DLot). Exit conditions are triggered when close.txt is detected; the EA reads the current position direction and volume, then executes a reverse trade with the same volume to close the position. Position sizing is very basic, using a fixed lot size parameter for opening trades and reading the actual position volume for closing trades. Money management is virtually non-existent, with no stop loss, take profit, trailing stop, or any risk control mechanism, nor any percentage-based lot calculation. The entire strategy relies on polling the external file system to drive trades, essentially serving as a bridge tool that converts external signals into MT5 trade instructions.

优势

  • 允许在策略测试器中进行手动练习交易，填补了MT5策略测试器无法手动交易的空白
  • 使用文件系统作为信号传递机制，简单直观，外部程序可以轻松集成
  • 界面上实时显示账户权益和持仓盈亏，方便交易者监控
  • 代码结构清晰，功能模块划分合理，易于理解和修改

劣势

  • 完全没有风险控制机制，没有止损、止盈或追踪止损功能
  • 文件轮询机制不可靠，在快速市场条件下可能错过信号或产生延迟
  • 关闭仓位的方式是通过反向开仓而非真正的平仓操作，可能在某些账户类型上产生问题
  • ExecuteTrade函数中成功检查使用了错误的大小写比较(Entry=='SELL'而非'sell')，导致成功交易时不会打印确认信息
  • 不支持多品种交易，只能处理当前图表品种的单个持仓

改进建议

  • 添加止损和止盈参数，并在ExecuteTrade函数中设置SL/TP字段
  • 修复ExecuteTrade函数中的大小写比较bug，将'SELL'和'BUY'改为'sell'和'buy'
  • 添加新K线检查机制，避免每个tick都执行文件系统检查，提高性能
  • 改用POSITION_IDENTIFIER进行真正的平仓操作而非反向开仓

Strengths

  • Enables manual practice trading in the strategy tester, filling a gap where MT5 strategy tester does not support manual trading
  • Uses the file system as a signal mechanism, which is simple and intuitive, allowing easy integration with external programs
  • Displays real-time account equity and position profit on the chart for convenient monitoring
  • Clean code structure with well-separated functional modules, easy to understand and modify

Weaknesses

  • No risk control mechanism at all — no stop loss, take profit, or trailing stop functionality
  • File polling mechanism is unreliable and may miss signals or introduce latency in fast market conditions
  • Closing positions via reverse opening instead of actual position closing may cause issues with certain account types
  • Bug in ExecuteTrade: success check uses wrong case comparison (Entry=='SELL' instead of 'sell'), so successful trade confirmation is never printed
  • Does not support multi-symbol trading; can only handle a single position on the current chart symbol

Improvements

  • Add stop loss and take profit parameters and populate the SL/TP fields in the ExecuteTrade function
  • Fix the case-sensitivity bug in ExecuteTrade where 'SELL'/'BUY' should be 'sell'/'buy' for success message printing
  • Add a new bar check mechanism to avoid file system polling on every tick, improving performance
  • Use proper position closing via POSITION_IDENTIFIER instead of reverse opening to close positions
