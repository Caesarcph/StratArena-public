摘要

这个EA通过监测MT5公共文件夹中的命令文本文件（buy.txt、sell.txt、close.txt）来实现策略测试器上的手动练习交易。当检测到命令文件时，EA执行相应的交易操作并删除文件，使用户能够在回测模式下模拟自主交易。

策略分析

该EA并非基于任何技术指标或价格策略的自动化交易系统，而是一个半自动化工具，通过外部文件触发交易指令。入场条件完全取决于用户手动在MT5公共文件夹中创建buy.txt或sell.txt文件，EA在每tick检测文件存在后立即执行对应的买入或卖出市价单。出场条件通过close.txt文件触发，EA会读取当前持仓方向和手数，以反向订单平仓。仓位管理方面，买入和卖出的手数由输入参数DLot固定为0.01，平仓时则使用当前持仓的手数进行反向对冲。资金管理几乎没有，没有止损、止盈、追踪止损或任何风险控制机制。整体策略逻辑极其简单，仅作为策略测试器中手动交易练习的桥梁工具，不包含任何市场分析能力。

Summary

This EA enables manual practice trading on the MT5 Strategy Tester by monitoring the MT5 Common folder for command text files (buy.txt, sell.txt, close.txt). When a command file is detected, the EA executes the corresponding trade action and deletes the file, allowing users to simulate discretionary trading in backtest mode.

Strategy Analysis

This EA is not an automated trading system based on any technical indicators or price strategies; it is a semi-automated tool that triggers trade orders through external file commands. Entry conditions depend entirely on the user manually creating a buy.txt or sell.txt file in the MT5 Common folder, and the EA immediately executes the corresponding market order upon detecting the file on each tick. Exit conditions are triggered by a close.txt file, where the EA reads the current position direction and volume, then places a reverse order to close. Position sizing for new entries is fixed at the input parameter DLot defaulting to 0.01 lots, while closing uses the exact volume of the existing position for the reverse trade. Money management is virtually non-existent — there are no stop-loss, take-profit, trailing stop, or any risk control mechanisms whatsoever. The overall strategy logic is extremely simple, serving merely as a bridge tool for manual trading practice within the Strategy Tester, with no market analysis capabilities at all.

优势

  • 允许用户在策略测试器中进行手动交易练习，解决了MT5回测模式不支持手动下单的限制
  • 使用文件检测机制与MT5进程解耦，外部程序或脚本可以轻松集成触发交易
  • UI显示实时利润和净值信息，方便练习者观察账户状态

劣势

  • 没有任何止损、止盈或风险控制机制，实盘使用将面临巨大亏损风险
  • 订单成功检查逻辑有bug——使用大写'SELL'和'BUY'比较，但传入的是小写'sell'和'buy'，导致成功日志永远不会打印
  • 每tick都执行FileIsExist检查和图表重绘，可能造成不必要的性能开销；同时缺少新bar检测机制

改进建议

  • 添加止损和止盈参数，至少提供基本的风险保护机制
  • 修复ExecuteTrade函数中大小写比较的bug，统一使用小写或大写进行字符串比较
  • 添加新bar检测机制以减少每tick的文件检查频率，并添加文件检查的时间间隔控制

Strengths

  • Enables manual trading practice in the Strategy Tester, solving the limitation that MT5 backtest mode does not support manual order placement
  • File-detection mechanism is decoupled from the MT5 process, allowing easy integration with external programs or scripts to trigger trades
  • UI displays real-time profit and equity information, making it convenient for practitioners to monitor account status

Weaknesses

  • No stop-loss, take-profit, or any risk control mechanism — using this on a live account would face enormous loss risk
  • Order success check logic has a bug — compares uppercase 'SELL' and 'BUY' but passes lowercase 'sell' and 'buy', so success logs are never printed
  • FileIsExist checks and chart redraws execute on every tick, causing unnecessary performance overhead; also lacks new bar detection

Improvements

  • Add stop-loss and take-profit parameters to provide at least basic risk protection
  • Fix the case-sensitivity bug in the ExecuteTrade function — standardize string comparisons to lowercase or uppercase
  • Add new bar detection to reduce file check frequency per tick, and add a time interval control for file checking

Overall:HIGH

Risk Points

  • No stop-loss or take-profit mechanism — position risk is fully exposed, which could cause major losses during extreme market volatility
  • ExecuteTrade function does not set SL/TP fields, and OrderSend requests lack price protection
  • File detection mechanism has no duplicate execution protection — repeated orders may occur in fast-tick environments
