摘要

该EA使用RSI指标输入到一个3输入小型神经网络来生成交易信号。它读取三个不同回溯周期的RSI值，归一化到0-1范围，通过8个可调权重(x0-x7)的加权二叉树计算概率，再经线性Sigmoid变换产生买卖信号，每次只持有一个仓位，支持可配置的止损止盈。

策略分析

策略概念：该EA基于Reshetov的RNN（随机神经网络）概念，使用RSI指标作为3个输入信号源，分别取当前RSI、RSI周期前和2倍RSI周期前的值，归一化到0-1范围。入场条件：当神经网络输出概率经过线性Sigmoid变换后(result=result*2.0-1.0)，如果结果小于0则开多单，如果结果大于等于0则开空单。出场条件：通过固定点数的止损和止盈来退出，止损和止盈距离相同（InpSLTP参数，默认100点），也支持设置为0取消止损止盈。仓位管理：固定手数交易(InpLots默认1.0手)，每次只允许持有一个仓位(IsPositionExists检查)，新K线触发机制避免重复开仓。资金管理：通过FreeMarginCheck检查可用保证金是否充足，但没有动态手数调整或风险百分比计算。神经网络核心是GetProbability函数，8个权重参数x0-x7通过优化获得，使用加权概率二叉树结构计算空头概率，多头概率为1减去空头概率。

Summary

This EA uses an RSI indicator feeding into a small 3-input neural network to generate trading signals. It reads three RSI values at different lookback periods, normalizes them to 0-1, and computes a probability via a weighted binary tree with 8 tunable weights (x0-x7). The probability is then transformed via linear sigmoid to produce a buy or sell signal, opening one position at a time with configurable SL/TP.

Strategy Analysis

The strategy concept is based on Reshetov's RNN (Random Neural Network) approach, using three RSI values at different lookback periods as inputs, normalized to the 0-1 range. Entry conditions: after the neural network output probability is transformed via linear sigmoid (result=result*2.0-1.0), if the result is less than 0 a buy position is opened, and if the result is greater than or equal to 0 a sell position is opened. Exit conditions: positions are closed via fixed-pip stop loss and take profit (InpSLTP parameter, default 100 pips), with equal SL and TP distances; setting InpSLTP to 0 disables SL/TP. Position sizing: fixed lot size trading (InpLots default 1.0 lots), only one position allowed at a time via IsPositionExists check, with new-bar trigger mechanism to avoid duplicate entries. Money management: FreeMarginCheck verifies sufficient free margin before order placement, but there is no dynamic lot sizing or risk-percentage calculation. The neural network core is the GetProbability function with 8 weight parameters (x0-x7) obtained through optimization, using a weighted probability binary tree structure to compute the short position probability, with the long probability being 1 minus the short probability.

优势

  • 使用神经网络概率模型进行交易决策，比简单阈值信号更具适应性
  • 每次只持有一个仓位并使用新K线触发，避免了过度交易和重复开仓
  • 包含完善的保证金检查和手数验证机制，防止资金不足时下单失败

劣势

  • 神经网络权重x0-x7含义不直观，需要大量优化且极易过拟合
  • 止损止盈距离相同缺乏非对称风险回报设计，不符合专业交易实践
  • 固定手数交易无动态仓位管理，无法根据账户风险或波动率调整仓位大小

改进建议

  • 增加动态仓位管理，根据账户风险比例和ATR波动率自动计算手数
  • 引入非对称止损止盈和移动止损机制，提高风险回报比
  • 增加多时间框架确认和交易量/波动率过滤，减少虚假信号

Strengths

  • Uses a neural network probability model for trading decisions, more adaptive than simple threshold signals
  • Maintains only one position at a time with new-bar trigger, avoiding overtrading and duplicate entries
  • Includes thorough margin checking and lot validation to prevent order failures due to insufficient funds

Weaknesses

  • Neural network weights x0-x7 are unintuitive, require extensive optimization and are highly prone to overfitting
  • Equal stop loss and take profit distances lack asymmetric risk-reward design, not aligned with professional trading practices
  • Fixed lot trading with no dynamic position sizing, unable to adjust lot size based on account risk or volatility

Improvements

  • Add dynamic position sizing that automatically calculates lot size based on account risk percentage and ATR volatility
  • Introduce asymmetric stop loss/take profit and trailing stop mechanisms to improve risk-reward ratio
  • Add multi-timeframe confirmation and volume/volatility filters to reduce false signals

风险评估 / Risk Assessment

总体 / Overall:MEDIUM

风险点

  • 神经网络权重参数高度依赖历史优化，存在严重过拟合风险，实盘表现可能大幅偏离回测
  • 止损止盈距离相等意味着风险回报比为1:1，需要较高胜率才能盈利
  • 固定1.0手默认手数较大，小账户可能承受过高风险

Risk Assessment

Overall:MEDIUM

Risk Points

  • Neural network weight parameters are highly dependent on historical optimization, posing significant overfitting risk; live performance may deviate substantially from backtesting
  • Equal stop loss and take profit distances imply a 1:1 risk-reward ratio, requiring a high win rate to be profitable
  • Fixed 1.0 lot default size is large and may expose small accounts to excessive risk
