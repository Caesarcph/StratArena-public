摘要

该EA基于H1周期上快速EMA(2)穿越基于慢速EMA(220)的包络线(Envelopes)通道进行突破交易。当快速EMA(收盘价)上穿包络线下轨或上轨时开多仓，当快速EMA(开盘价)下穿包络线上轨或下轨时开空仓。持仓通过可配置的移动止损和可选的时段过滤进行管理。

策略分析

策略概念基于包络线通道突破，使用三条不同偏差(0.3%、0.7%、1.0%)的Envelopes指标构建多层通道，配合EMA(2)作为快速信号线和EMA(220)作为中线基准。入场条件方面，做多信号包括EMA(2,Close)上穿任一Envelopes下轨、上穿任一Envelopes上轨、或上穿EMA(220)；做空信号为EMA(2,Open)下穿任一Envelopes上轨、下穿任一下轨、或下穿EMA(220)，均采用穿越确认。出场条件仅依赖移动止损机制，当浮盈超过移动止损距离加步长时，将止损调整至当前价格减去移动止损距离(多仓)或加上移动止损距离(空仓)，无固定止盈止损的强制出场(输入默认为0)。仓位管理采用固定手数(InpLots)，无加仓减仓逻辑，同时只持有一个方向的头寸(total==0时才开仓)。资金管理方面没有动态仓位计算或风险百分比控制，仅做最小/最大手数和手数步长的合规性检查。

Summary

This EA trades channel breakouts using a fast EMA(2) crossing Envelopes bands based on a slow EMA(220) on the H1 timeframe. It opens BUY when the fast EMA(Close) crosses above an Envelope lower or upper band, and SELL when the fast EMA(Open) crosses below an Envelope upper or lower band. Positions are managed with configurable trailing stops and optional time-based session filtering.

Strategy Analysis

The strategy concept is based on Envelopes channel breakouts, using three Envelopes indicators with different deviations (0.3%, 0.7%, 1.0%) to construct multi-layer channels, combined with EMA(2) as the fast signal line and EMA(220) as the midline baseline. Entry conditions for BUY signals include EMA(2,Close) crossing above any Envelopes lower band, any upper band, or the EMA(220) itself; SELL signals are triggered when EMA(2,Open) crosses below any Envelopes upper band, any lower band, or the EMA(220), all using crossover confirmation. Exit conditions rely solely on trailing stop mechanisms — when floating profit exceeds the trailing stop distance plus step, the stop loss is adjusted to current price minus trailing stop (for buys) or plus trailing stop (for sells), with no mandatory fixed take-profit or stop-loss exits (input defaults are 0). Position sizing uses a fixed lot size (InpLots) with no pyramiding or position reduction logic, and only one position direction is held at a time (new entries only when total==0). Money management lacks dynamic lot calculation or risk-percentage controls, only performing compliance checks for minimum/maximum lots and lot step granularity.

优势

  • 多层包络线通道设计(0.3%/0.7%/1.0%)提供多级别突破信号，增加入场灵活性
  • 做多使用收盘价EMA、做空使用开盘价EMA，区分了多空信号的价格基准，逻辑有一定合理性
  • 包含移动止损管理机制，能够锁定浮盈保护利润
  • 时段过滤功能可避免在不活跃时段交易
  • 手数合规性检查(LotsMin/LotsMax/LotsStep)防止无效下单

劣势

  • 止损和止盈默认值为0，在没有移动止损触发的情况下持仓完全无保护，风险极大
  • 同时只允许持有0个仓位(total==0)才能开新仓，但无新K线检测，同一根K线上可能反复触发信号导致逻辑混乱
  • 做多条件中包含一个非穿越逻辑(MA<下轨且前值也<下轨)，与其他穿越条件不一致，可能产生持续信号
  • 使用非常短的EMA(2)作为信号线，对价格噪声极为敏感，容易产生频繁的虚假突破信号
  • 没有点差过滤，在点差较大时突破信号可能已被点差吞噬
  • InpTrailingStep缺少input关键字，用户无法在参数面板中调整

改进建议

  • 添加新K线检测机制(IsNewBar)，避免同一根K线内重复计算信号和重复开仓
  • 设置合理的非零默认止损止盈值，并添加点差过滤条件，在点差过大时暂停交易
  • 将做多条件中非穿越的逻辑修正为穿越条件，保持策略一致性，或单独标注为独立信号类型
  • 将InpTrailingStep添加input关键字使其可配置，并增加最大持仓数控制参数
  • 增加指标数据有效性检查(iMAGet/iEnvelopesGet返回0时跳过本轮逻辑)，避免用无效数据做决策

Strengths

  • Multi-layer Envelopes channel design (0.3%/0.7%/1.0%) provides breakout signals at multiple levels, increasing entry flexibility
  • BUY uses Close price EMA while SELL uses Open price EMA, differentiating price bases for long/short signals with reasonable logic
  • Trailing stop mechanism locks in floating profits and protects gains
  • Session time filter helps avoid trading during inactive hours
  • Lot validation (LotsMin/LotsMax/LotsStep) prevents invalid order placement

Weaknesses

  • Stop loss and take profit default to 0, leaving positions completely unprotected if trailing stops don't trigger — extremely risky
  • Only allows new entries when total positions==0, but lacks new bar detection, so the same bar may repeatedly trigger signals causing logic confusion
  • BUY conditions include a non-crossover logic (MA<lower band AND previous also<lower band), inconsistent with other crossover conditions, potentially generating persistent signals
  • Very short EMA(2) as signal line is extremely sensitive to price noise, prone to frequent false breakout signals
  • No spread filter — large spreads may already consume the breakout signal margin
  • InpTrailingStep is missing the 'input' keyword, so users cannot adjust it from the parameter panel

Improvements

  • Add new bar detection (IsNewBar) to prevent repeated signal calculation and duplicate entries within the same bar
  • Set reasonable non-zero default stop loss/take profit values and add spread filter to pause trading when spreads are excessive
  • Correct the non-crossover BUY condition to a crossover condition for strategy consistency, or label it as a separate signal type
  • Add 'input' keyword to InpTrailingStep for configurability, and add maximum position count control parameter
  • Add indicator data validity checks (skip current tick when iMAGet/iEnvelopesGet returns 0) to avoid decisions based on invalid data

风险评估 / Risk Assessment

总体 / Overall:MEDIUM

风险点

  • 止损止盈默认为0，若移动止损未及时触发，持仓面临无限亏损风险
  • 无新K线检测，同一K线可能重复触发信号但被total==0逻辑部分缓解
  • EMA(2)信号线噪声敏感度高，可能产生虚假突破导致频繁亏损交易
  • 指标数据读取失败时返回0.0而非报错中断，可能用错误数据触发交易信号

Risk Assessment

Overall:MEDIUM

Risk Points

  • Default SL/TP of 0 means unlimited loss risk if trailing stop doesn't trigger in time
  • No new bar detection allows repeated signal triggers on the same bar, partially mitigated by total==0 check
  • EMA(2) signal line has high noise sensitivity, potentially generating false breakouts and frequent losing trades
  • Indicator read failures return 0.0 instead of aborting, potentially triggering trades with invalid data
