策略分析

分析 ### 2.1 核心策略概念 这是一个**多周期加权振荡器穿越策略**，由Nikolay Kositsin开发。策略使用"零延迟"技术，通过加权组合5个不同周期的JJRSX指标来创建一个复合振荡器。 **零延迟算法原理**: 其中权重系数为斐波那契数列比: 0.05, 0.10, 0.16, 0.26, 0.43（和为1.0） **核心特点**: 1. **JJRSX** = Jurik平滑的RSX振荡器（RSX是RSI的改进版本，更平滑） 2. **零延迟设计** = 多周期加权组合减少滞后 3. **快慢线穿越** = FastTrend穿越SlowTrend产生信号 4. **颜色填充** = 快线>慢线显示青色（多头），快线<慢线显示粉色（空头） ### 2.2 入场条件 **做多条件**: 1. Osc1[1] > Osc2[1]（上一根K线快线在慢线之下） 2. Osc1[0] < Osc2[0]（当前K线快线穿越到慢线之上） 3. BuyPosOpen = true（允许做多开关打开） 4. 信号时间戳记录：UpSignalTime **做空条件**: 1. Osc1[1] < Osc2[1]（上一根K线快线在慢线之上） 2. Osc1[0] > Osc2[0]（当前K线快线穿越到慢线之下） 3. SellPosOpen = true（允许做空开关打开） 4. 信号时间戳记录：DnSignalTime ### 2.3 出场条件 **平多仓**: - 当做空信号触发时，如果BuyPosClose=true，则平掉所有多头仓位 **平空仓**: - 当做多信号触发时，如果SellPosClose=true，则平掉所有空头仓位 **默认设置**: - StopLoss = 1000点（⚠️ 过大） - TakeProfit = 2000点 - 盈亏比 = 2:1（良好） ### 2.4 风险管理 **止损止盈**: - 固定止损：1000点（需要根据品种调整） - 固定止盈：2000点 - 盈亏比：2:1（合理） **手数管理**: - MM=0.1（每笔交易使用10%保证金） - 支持多种手数模式：LOT（固定手数）、MARGIN（保证金百分比）等 **新K线检测**: - 使用CIsNewBar类进行新K线检测 - 可选择实时检测（SignalBar=0）或新K线检测

优势

  • 零延迟设计理念 - 多周期加权组合减少单一周期滞后，算法设计精妙
  • 专业级代码架构 - Nikolay Kositsin专业代码风格，TradeAlgorithms库完整可复用
  • 四开关交易控制 - BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose灵活控制交易方向
  • 斐波那契周期设计 - 8/21/34/55/89使用斐波那契数列，周期选择科学
  • CIsNewBar新K线检测 - 避免同一K线重复交易
  • 盈亏比2:1良好 - 默认TP/SL比例合理
  • 权重系数归一化 - 五个因子和为1.0，避免数值失真

劣势

  • 🟡 止损过大 - 默认1000点对多数品种不适用
  • 🟡 无趋势强度过滤 - 可能在震荡市中频繁交易
  • 🟡 手数参数激进 - MM=0.1保证金使用率过高
  • 🟡 无追踪止损 - 无法锁定浮动盈利
  • 🟡 出场逻辑单一 - 仅靠反向穿越信号出场，缺乏独立止损触发
