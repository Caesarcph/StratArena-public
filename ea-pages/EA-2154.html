摘要

该EA使用MACD柱状图交叉信号结合EMA趋势过滤来产生买卖信号。它实现了移动止损管理和止盈目标来管理仓位出场。策略仅在MACD信号确认动量且EMA确认当前趋势方向时才进场交易。

策略分析

该EA的核心策略是基于MACD指标的信号线交叉进行交易，同时使用EMA作为趋势方向过滤器。做多入场条件为：MACD主线在零轴下方、MACD主线从下方穿越信号线上方、MACD绝对值大于开仓阈值、且当前EMA值大于前一根EMA值（确认上升趋势）。做空入场条件对称相反：MACD主线在零轴上方、MACD主线从上方穿越信号线下方、MACD值大于开仓阈值、且当前EMA值小于前一根EMA值（确认下降趋势）。出场方面，做多平仓条件为MACD在零轴上方发生死叉且MACD值大于平仓阈值；做空平仓条件为MACD在零轴下方发生金叉且MACD绝对值大于平仓阈值。仓位管理采用固定手数（InpLots=0.1），没有加仓或减仓逻辑。资金管理方面仅有自由保证金检查，无最大亏损限制或权益保护机制。移动止损在盈利超过设定点数后将止损跟随至当前价格减去 trailing stop 值的位置，但未设置初始止损。

Summary

This EA uses MACD histogram crossovers combined with an EMA trend filter to generate buy and sell signals. It implements trailing stop management and take profit targets for position exits. The strategy only enters trades when the MACD signal confirms momentum and the EMA confirms the prevailing trend direction.

Strategy Analysis

The core strategy of this EA is based on MACD signal line crossovers for trade entries, with an EMA acting as a trend direction filter. Long entry conditions require: MACD main line below zero, MACD main line crossing above signal line from below, MACD absolute value exceeding the open level threshold, and current EMA greater than previous EMA (confirming uptrend). Short entry conditions are symmetrically opposite: MACD main line above zero, MACD main line crossing below signal line from above, MACD value exceeding the open level threshold, and current EMA less than previous EMA (confirming downtrend). For exits, long positions close when MACD bearish crossover occurs above zero with MACD value above close level; short positions close when MACD bullish crossover occurs below zero with MACD absolute value above close level. Position sizing uses a fixed lot size (InpLots=0.1) with no scaling or position accumulation logic. Money management includes only a free margin check before opening positions, with no maximum drawdown limit or equity protection mechanism. The trailing stop moves the stop loss to follow price once profit exceeds the trailing stop threshold, but no initial stop loss is set on position open.

优势

  • 策略逻辑清晰，使用经典的MACD交叉加EMA趋势过滤组合，易于理解和验证
  • 实现了移动止损功能，可以在盈利仓位上锁定部分利润，降低回撤风险
  • 包含完整的参数校验（手数范围、止盈止损与StopsLevel关系），防止因参数错误导致异常交易
  • 使用面向对象封装，代码结构良好，便于维护和扩展

劣势

  • 开仓时不设置初始止损（SL=0.0），仅依赖移动止损，如果市场快速反转可能造成巨额亏损
  • 固定手数交易，没有根据账户权益或波动率进行仓位调整，缺乏动态资金管理
  • 没有新K线检测机制，每个tick都可能触发交易逻辑，在快速行情中可能重复开仓或频繁修改
  • 没有点差过滤，在高点差环境下MACD阈值可能被点差吞噬导致亏损交易
  • 平仓后立即可以重新开仓，缺少冷却期外的方向判断保护，可能在震荡行情中反复亏损

改进建议

  • 在开仓时设置初始止损，而不是仅依赖移动止损，以限制最大单笔亏损
  • 添加新K线检测逻辑，避免同一根K线内多次触发交易信号，减少不必要的交易成本
  • 引入基于ATR的动态仓位管理和阈值设定，使策略能适应不同波动率的市场环境

Strengths

  • Clear strategy logic using the classic MACD crossover with EMA trend filter combination, easy to understand and verify
  • Implements trailing stop functionality to lock in partial profits on winning positions and reduce drawdown risk
  • Includes comprehensive parameter validation (lot size range, take profit/trailing stop vs StopsLevel) preventing abnormal trades from misconfigured inputs
  • Well-structured OOP encapsulation makes the code maintainable and extensible

Weaknesses

  • No initial stop loss is set on position open (SL=0.0), relying solely on trailing stop which can lead to catastrophic losses during sharp market reversals
  • Fixed lot sizing without equity-based or volatility-based position adjustment lacks dynamic money management
  • No new bar detection mechanism; trade logic can trigger on every tick, potentially causing repeated entries or frequent modifications during fast markets
  • No spread filter; in high-spread environments the MACD threshold values may be consumed by spread costs leading to losing trades
  • Positions can be reopened immediately after closing without directional confirmation protection, potentially causing repeated losses in choppy markets

Improvements

  • Set an initial stop loss on position open instead of relying solely on trailing stop, to limit maximum per-trade loss
  • Add new bar detection logic to prevent multiple signal triggers within the same bar, reducing unnecessary trading costs
  • Introduce ATR-based dynamic position sizing and threshold settings to adapt the strategy to different market volatility environments
