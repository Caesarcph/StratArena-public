策略分析

分析 ### 2.1 核心策略概念 MACD Sample是MetaQuotes官方提供的经典MACD趋势跟踪策略示例，展示了MQL5标准库的完整使用架构。策略使用MACD指标的信号线穿越作为主要入场信号，配合EMA趋势过滤，实现趋势跟踪交易。 **策略类型**: 趋势跟踪策略 **核心逻辑**: 1. 使用MACD(12,26,9)指标检测动量变化 2. 使用EMA(26)作为趋势方向过滤器 3. 当MACD从下方穿越信号线且趋势向上时做多 4. 当MACD从上方穿越信号线且趋势向下时做空 5. 使用追踪止损保护盈利 ### 2.2 入场条件 **做多条件** (LongOpened函数): 1. MACD在零轴下方 (m_macd_current < 0) 2. MACD从下方穿越信号线 (m_macd_current > m_signal_current && m_macd_previous < m_signal_previous) 3. MACD绝对值超过开仓阈值 (|m_macd_current| > m_macd_open_level) 4. EMA趋势向上 (m_ema_current > m_ema_previous) 5. 账户有足够保证金 **做空条件** (ShortOpened函数): 1. MACD在零轴上方 (m_macd_current > 0) 2. MACD从上方穿越信号线 (m_macd_current < m_signal_current && m_macd_previous > m_signal_previous) 3. MACD超过开仓阈值 (m_macd_current > m_macd_open_level) 4. EMA趋势向下 (m_ema_current < m_ema_previous) 5. 账户有足够保证金 ### 2.3 出场条件 **平多仓条件** (LongClosed函数): 1. MACD在零轴上方 (m_macd_current > 0) 2. MACD从上方穿越信号线 (m_macd_current < m_signal_current && m_macd_previous > m_signal_previous) 3. MACD超过平仓阈值 (m_macd_current > m_macd_close_level) **平空仓条件** (ShortClosed函数): 1. MACD在零轴下方 (m_macd_current < 0) 2. MACD从下方穿越信号线 (m_macd_current > m_signal_current && m_macd_previous < m_signal_previous) 3. MACD绝对值超过平仓阈值 (|m_macd_current| > m_macd_close_level) **追踪止损**: - 当盈利超过TrailingStop时，移动止损到当前价格-TrailingStop距离 - 止损只向盈利方向移动，不会回撤 ### 2.4 风险管理 **止损/止盈逻辑**: - **入场止损**: 无固定止损（SL=0），仅依赖追踪止损和信号反转出场 - **止盈**: 固定点数止盈 (默认50点) - **追踪止损**: 默认30点追踪止损 **手数管理**: - 固定手数模式（默认0.1手） - 无动态仓位管理 - 入场前检查保证金充足性 **其他风控措施**: 1. 参数校验机制（InitCheckParameters） 2. StopsLevel合法性检查 3. 手数范围和步长验证 4. 交易时间间隔限制（ExtTimeOut=10秒） 5. 保证金预检查（FreeMarginCheck）

优势

  • 专业级代码架构: MetaQuotes官方示例，展示完整的MQL5标准库使用模式，包括CTrade、CSymbolInfo、CPositionInfo、CAccountInfo四大核心类
  • 完善的参数校验: InitCheckParameters函数实现完整的参数合法性验证（StopsLevel检查、手数范围和步长验证、止盈追踪止损关系检查）
  • 良好的Digits自适应: 自动检测3位/5位小数并进行点值调整（digits_adjust机制），适配不同报价精度
  • 追踪止损实现: 完整的追踪止损逻辑，止损只向盈利方向移动，有效保护浮盈
  • OOP封装设计: CSampleExpert类封装所有交易逻辑，职责清晰，便于扩展和维护

劣势

  • 无固定止损: 入场时SL=0硬编码，极端行情下风险暴露无上限
  • 固定手数无风控: 默认0.1手固定手数，无动态仓位管理，无法适应不同账户规模
  • MACD参数硬编码: 12/26/9参数固定，无法通过输入参数调整，限制了策略灵活性
  • 盈亏比不佳: 默认止盈50点/追踪止损30点，盈亏比仅约1.67:1
  • 无趋势强度过滤: 缺少ADX或MA200等趋势强度过滤，震荡市易磨损
