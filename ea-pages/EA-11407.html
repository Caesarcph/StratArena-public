策略分析

### 2.1 "BnB"含义 **BnB = Bulls 'n Bears** (多头与空头) 基于OHLC数据计算多空压力，成交量加权平滑。 ### 2.2 指标计算 **Tick Size计算**: **多头力量 (Bulls)**: **空头力量 (Bears)**: **平滑处理**: - 使用CXMA (通用移动平均) - 默认: T3平滑 - 周期: XLength=14 **可视化**: ### 2.3 交易信号 #### 买入信号 **条件**: - Bulls从上方下穿Bears - `Ind[1] > Sign[1]` (前一根Bulls > Bears) - `Ind[0] <= Sign[0]` (当前Bulls <= Bears) - 多头力量减弱，空头增强 → **买入?** **⚠️ 注意**: 这里信号逻辑可能有疑问 #### 卖出信号 **条件**: - Bears从下方上穿Bulls - `Ind[1] < Sign[1]` (前一根Bulls < Bears) - `Ind[0] >= Sign[0]` (当前Bulls >= Bears) - 空头力量减弱，多头增强 → **卖出?** ### 2.4 多空力量解读 **Bulls > Bears**: 多头主导 **Bears > Bulls**: 空头主导 **交叉信号**: - Bulls下穿Bears → 空头转强 → 卖出? - Bulls上穿Bears → 多头转强 → 买入?
