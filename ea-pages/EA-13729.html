策略分析

分析 ### 2.1 核心策略概念 **Exp_i-BandsPrice** 是一个基于**布林带价格相对位置**的均值回归策略。 核心思想是： 1. 计算价格相对于布林带下轨的百分比位置 2. 将这个位置值标准化到[-50, +50]范围 3. 使用JJMA平滑器进行最终平滑 4. 根据指标值的状态(5种颜色)判断入场时机 **指标计算公式**: 当价格触及布林带下轨时，指标值为-50；触及上轨时为+50；在中轨附近时约为0。 ### 2.2 入场条件 **买入信号** (Value从4变为<4): - 指标值从极度超卖区域(值=4，对应颜色Lime)下跌 - 表示价格从布林带下轨开始反弹 - 条件: `Value[1]==4 && Value[0]<4` **卖出信号** (Value从0变为>0): - 指标值从极度超买区域(值=0，对应颜色Magenta)上涨 - 表示价格从布林带上轨开始回落 - 条件: `Value[1]==0 && Value[0]>0` **颜色状态编码**: | 值 | 颜色 | 含义 | 布林带位置 | | 0 | Magenta | 极度超买 | 上轨附近(jres<-25) | | 1 | Maroon | 超买 | 上半区(jres<0) | | 2 | Gray | 中性 | 中轨附近 | | 3 | Teal | 超卖 | 下半区(jres>0) | | 4 | Lime | 极度超卖 | 下轨附近(jres>25) | ### 2.3 出场条件 **买入平仓**: `Value[1] < 2` (离开超卖/极度超卖区域) **卖出平仓**: `Value[1] > 1` (离开超买/极度超买区域) 这表明策略采用**部分平仓逻辑**，在价格回归到正常区域时退出。 ### 2.4 风险管理 **止损/止盈设置**: - 默认止损: 1000点 (⚠️ 极度过大) - 默认止盈: 2000点 (风险回报比1:2) - 滑点容忍: 10点 **手数管理**: - 支持多种资金管理模式: - LOT: 固定手数 - FREEMARGIN: 基于可用保证金 - BALANCE: 基于账户余额 - LOSSFREEMARGIN/LOSSBALANCE: 考虑浮动亏损

  • 将布林带位置标准化为振荡器形式
  • 直观的视觉表达(5色直方图)
  • 清晰的超买超卖区域定义
  • 模块化代码设计
  • 使用独立的SmoothAlgorithms和TradeAlgorithms库
  • 易于维护和扩展
  • 代码结构清晰
  • 灵活的平滑算法选择
  • 支持9种平滑方法(SMA/EMA/JJMA/JurX/T3/VIDYA/AMA等)
  • 可根据市场特性调整
  • 完善的手数管理系统
  • 5种资金管理模式
  • 支持基于风险动态计算
  • 可配置的交易开关
  • 可独立控制买卖开仓/平仓
  • 便于组合其他策略

劣势

  • 极端的默认参数
  • 止损1000点过大
  • 三重100期平滑产生极端滞后
  • 参数未针对实盘优化
  • 无趋势过滤机制
  • 纯均值回归策略
  • 在趋势市场容易连续亏损
  • 信号生成逻辑单一
  • 仅依赖指标颜色变化
  • 缺乏多重确认机制
  • 缺乏波动率自适应
  • 固定的UpLevel/DnLevel阈值
  • 不适应市场波动变化
  • 回撤可能较大
  • 长周期参数导致信号延迟
  • 可能错过最佳出场时机
