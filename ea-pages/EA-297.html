策略分析

分析 ### 2.1 核心策略概念 该EA采用**日本蜡烛图反转形态**作为主要信号源，配合**随机指标(Stochastic)**进行动量确认： - **多头信号**: 刺透线(Piercing Line)形态 + Stochastic信号线<30(超卖区) - **空头信号**: 乌云盖顶(Dark Cloud Cover)形态 + Stochastic信号线>70(超买区) 策略本质是**均值回归类**策略，在市场出现极端超买/超卖后，通过经典蜡烛图反转形态捕捉价格修正机会。 ### 2.2 入场条件 #### 做多条件 (LongCondition): 1. **主要入场信号** (信号强度80分): - 检测到刺透线形态 `CANDLE_PATTERN_PIERCING_LINE` - Stochastic信号线(1号柱) < 30 (超卖确认) 2. **次要出场信号** (信号强度40分): - Stochastic信号线从下方穿越20线 - 或Stochastic信号线从下方穿越80线 #### 做空条件 (ShortCondition): 1. **主要入场信号** (信号强度80分): - 检测到乌云盖顶形态 `CANDLE_PATTERN_DARK_CLOUD_COVER` - Stochastic信号线(1号柱) > 70 (超买确认) 2. **次要出场信号** (信号强度40分): - Stochastic信号线从上方穿越80线 - 或Stochastic信号线从上方穿越20线 #### 蜡烛图形态定义: **刺透线(Piercing Line) - 看涨反转**: **乌云盖顶(Dark Cloud Cover) - 看跌反转**: ### 2.3 出场条件 - **信号阈值出场**: 当信号强度低于`Signal_ThresholdClose=20`时自动平仓 - **无固定止损止盈**: 默认SL=0, TP=0，完全依赖信号反转出场 - **无追踪止损**: 使用`TrailingNone`，无动态止损机制 ### 2.4 风险管理 #### 止损/止盈逻辑: | 参数 | 默认值 | 说明 | | Signal_StopLevel | 0 | **无固定止损** | | Signal_TakeLevel | 0 | **无固定止盈** | | Signal_ThresholdClose | 20 | 信号强度低于此值时平仓 | #### 手数管理: | 参数 | 默认值 | 说明 | | Money_FixLot_Percent | 10.0 | 账户百分比 | | Money_FixLot_Lots | 0.1 | 固定手数 | 实际使用两者中较大值。 #### 其他风控措施: - **MagicNumber**: 17690 (订单唯一标识) - **EveryTick**: false (仅在K线收盘时处理，避免噪音)

优势

  • 经典蜡烛图形态 - 使用成熟的日本蜡烛图反转形态(乌云盖顶/刺透线)，形态定义严谨
  • 双确认机制 - 蜡烛形态 + Stochastic超买超卖确认，减少假信号
  • MetaQuotes标准库架构 - 采用CExpert框架，代码结构清晰，易于扩展和维护
  • 信号评分系统 - 80分强信号/40分弱信号分级，可根据阈值灵活控制入场
  • 完整的蜡烛形态库 - acandlepatterns.mqh提供16种形态检测，可扩展性强

劣势

  • 无止损止盈 - 完全依赖信号反转出场，风险敞口无限
  • 单一形态策略 - 仅使用乌云盖顶/刺透线两种形态，信号频率可能不足
  • 缺乏趋势过滤 - 在强趋势中逆势交易，容易连续止损
  • 无追踪止损 - 盈利后无法锁定利润
  • 参数未优化 - Stochastic参数(K=47)偏大，可能错过快速机会
