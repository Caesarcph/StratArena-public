TrendlineCrossAlert

Horizontal and Trendlines cross detection on any pair/timeframe good for scalping on small timeframes (M1 to M15) and trend following on bigger ones. It send notifications when price crosses trendlines and horizontal lines of specified color and when it happens, it change its color to CrossedColor input parameter to be sure not to send multiple notifications for same line

摘要

该EA监控图表上指定颜色的水平线和趋势线，当价格穿越这些线时发送提醒（弹窗、推送通知或邮件）。穿越后，它会将线条颜色改为'已穿越'颜色，以防止对同一条线重复发送通知。该EA不执行任何交易操作。

策略分析

这是一个纯通知工具，不具备任何交易策略逻辑。它的核心概念是监控用户手动绘制的趋势线和水平线，通过比较当前K线的开盘价和收盘价与线的价格来判断价格穿越。入场条件不适用，因为该EA不开仓；出场条件也不适用。仓位管理和资金管理均不存在，因为这是一个不执行交易的工具。该工具的唯一逻辑是在每个tick上检测价格是否从一侧穿越到另一侧，并在穿越发生时通过多种渠道发送通知。它使用颜色变化机制来避免重复通知，这是一种简单但有效的去重策略。

Summary

This EA monitors horizontal and trendlines of a specified color on the chart and sends alerts (popup, push notification, or email) when price crosses them. Upon crossing, it changes the line color to a 'crossed' color to prevent duplicate notifications for the same line. It does not open or manage any trades.

Strategy Analysis

This is a pure notification utility with no trading strategy logic whatsoever. Its core concept is monitoring user-drawn trendlines and horizontal lines, detecting price crossovers by comparing the current bar's open and close prices against the line's price value. Entry conditions are not applicable since this EA does not open positions; exit conditions are also not applicable. Position sizing and money management are entirely absent as this is a non-trading tool. The sole logic is checking on every tick whether price has crossed from one side of a line to the other, and sending notifications through multiple channels when a crossover occurs. It uses a color-change mechanism to avoid duplicate notifications, which is a simple but effective deduplication strategy.

优势

  • 颜色变化去重机制简单有效，避免同一条线重复发送通知
  • 支持多种通知渠道（弹窗、推送、邮件），灵活性高
  • 同时支持水平线和趋势线，覆盖常见绘图对象类型
  • 使用sinput声明参数，防止优化器误修改这些设置
  • 代码结构清晰，采用面向对象封装，可维护性较好

劣势

  • 依赖手动绘制线条，无法自动生成监控对象，效率较低
  • 价格穿越检测基于当前K线开收盘价，可能在新K线首tick时误判或漏判
  • 没有IsNewBar过滤，每个tick都执行全量扫描，在高频品种上可能消耗较多资源
  • 不处理射线型趋势线(OBJ_TREND)右端延伸的价格计算边界情况
  • 缺少对线条对象被删除或修改的异常处理

改进建议

  • 添加IsNewBar过滤，仅在 新K线 时执行检测，减少不必要的计算开销
  • 增加对OBJ_RAY（射线趋势线）的支持，扩大监控对象覆盖范围
  • 添加线条删除和修改的事件监听(CHARTEVENT_OBJECT_DELETE/CHANGE)，提高健壮性
  • 可增加声音提醒选项和自定义提示音功能

Strengths

  • Color-change deduplication mechanism is simple and effective, preventing duplicate notifications for the same line
  • Supports multiple notification channels (alert, push, email), offering good flexibility
  • Handles both horizontal lines and trendlines, covering common chart object types
  • Uses sinput for parameters, preventing the optimizer from modifying these settings
  • Clean code structure with OOP encapsulation, decent maintainability

Weaknesses

  • Relies on manually drawn lines, cannot auto-generate monitoring objects, limiting efficiency
  • Price crossover detection based on current bar open/close may cause false positives or missed detections on the first tick of a new bar
  • No IsNewBar filter, performs full scan on every tick, potentially consuming excessive resources on high-frequency instruments
  • Does not handle edge cases for ray-extended trendlines' right-side price calculation
  • Missing exception handling for when line objects are deleted or modified mid-scan

Improvements

  • Add IsNewBar filter to only perform detection on new bars, reducing unnecessary computational overhead
  • Add support for OBJ_RAY (ray trendlines) to expand the range of monitorable chart objects
  • Add event listeners for line deletion and modification (CHARTEVENT_OBJECT_DELETE/CHANGE) to improve robustness
  • Add sound alert option with custom notification sound functionality
