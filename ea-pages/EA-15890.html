摘要

一个半自动交易面板EA，结合了手动交易按钮与自动驾驶模式。自动驾驶模式使用多周期价格比较信号（跨越20个时间周期的开盘价、最高价、最低价、收盘价）来生成买入/卖出百分比信号，当信号超过阈值时自动开仓或平仓。还具备基于分形的止损功能。

策略分析

策略概念基于多周期价格动量比较，通过比较当前K线与前一根K线的开盘价、最高价、最低价、收盘价及其组合均值来判断市场方向。入场条件为：当买入信号百分比超过开仓阈值（默认85%）时开多仓，当卖出信号百分比超过开仓阈值时开空仓，且当前无持仓。出场条件为：当持仓方向对应的信号百分比低于平仓阈值（默认55%）时自动平仓，或通过面板手动平仓。仓位管理支持固定手数和权益百分比两种模式，最小手数为0.01。止损管理使用Fractals分形指标，在买入持仓时寻找最近的下分形作为止损位，卖出持仓时寻找最近的上分形作为止损位。策略遍历20个时间周期（M1到MN1）进行信号聚合计算，最终以百分比形式展示多空信号强度。

Summary

A semi-automated trade panel EA that combines manual trading buttons with an autopilot mode. The autopilot uses a multi-timeframe price comparison signal (Open, High, Low, Close across 20 timeframes) to generate buy/sell percentage signals and automatically opens or closes positions when thresholds are breached. It also features an optional fractal-based stop loss mechanism.

Strategy Analysis

The strategy concept is based on multi-timeframe price momentum comparison, judging market direction by comparing the current bar's Open, High, Low, Close and their composite averages against the previous bar across 20 timeframes. Entry conditions: a buy position is opened when the buy signal percentage exceeds the opening threshold (default 85%), and a sell position is opened when the sell signal percentage exceeds the threshold, provided no position currently exists. Exit conditions: the position is automatically closed when the signal percentage for the held direction falls below the closing threshold (default 55%), or manually via the panel's CLOSE button. Position sizing supports both fixed lot and equity percentage modes, with a minimum lot of 0.01. Stop loss management uses the Fractals indicator: for buy positions, the nearest lower fractal below current price is set as SL; for sell positions, the nearest upper fractal above current price is set as SL. The strategy iterates across 20 timeframes (M1 through MN1) for signal aggregation, ultimately displaying long/short signal strength as percentages.

优势

  • 多周期信号聚合提高了方向判断的可靠性，减少单一时间周期的噪音干扰
  • 半自动设计兼顾了手动交易的灵活性和自动交易的纪律性
  • 分形止损自适应市场波动结构，比固定点数止损更合理
  • 信号百分比可视化（进度条和颜色变化）直观展示市场状态
  • 面板界面友好，支持一键买卖和快速切换自动驾驶模式

劣势

  • 信号计算方法过于简单，仅比较相邻两根K线的OHLC，缺乏对趋势强度和波动率的考量
  • 无新K线检查机制，每个tick都重新计算全部20个周期的信号，计算效率低且可能频繁触发交易
  • 开仓时未设置止损和止盈（SL=0, TP=0），分形止损仅在OnTrade回调中延迟设置，存在风险窗口
  • 平仓阈值55%意味着信号只需略低于一半即平仓，可能导致过早退出盈利仓位
  • 无法同时处理多品种，仅针对当前图表品种交易

改进建议

  • 增加新K线检查机制，避免每个tick重复计算信号和重复触发交易逻辑
  • 开仓时立即设置初始止损，而不是依赖OnTrade回调延迟设置分形止损
  • 增加信号过滤条件，如加入ATR波动率过滤或趋势强度确认，提高信号质量

Strengths

  • Multi-timeframe signal aggregation improves directional reliability and reduces single-timeframe noise
  • Semi-automated design balances manual trading flexibility with automated trading discipline
  • Fractal-based stop loss adapts to market volatility structure, more rational than fixed-pip SL
  • Visual signal percentage display (progress bar and color changes) intuitively shows market state
  • User-friendly panel interface supports one-click buy/sell and quick autopilot mode switching

Weaknesses

  • Signal calculation is overly simplistic, only comparing two adjacent bars' OHLC without considering trend strength or volatility
  • No new bar check mechanism; recalculates all 20 timeframes every tick, causing inefficiency and potential frequent trade triggers
  • No SL/TP set at position opening (SL=0, TP=0); fractal SL is set with delay in OnTrade callback, creating a risk window
  • Closing threshold of 55% means position closes when signal is just below half, potentially causing premature exits from profitable trades
  • Cannot handle multiple symbols simultaneously; only trades the current chart symbol

Improvements

  • Add new bar check mechanism to avoid recalculating signals and triggering trade logic on every tick
  • Set initial stop loss immediately at position opening instead of relying on delayed fractal SL in OnTrade callback
  • Add signal filtering conditions such as ATR volatility filter or trend strength confirmation to improve signal quality

风险评估 / Risk Assessment

总体 / Overall:MEDIUM

风险点

  • 开仓时止损和止盈均为0，存在无保护持仓的风险窗口
  • 每个tick都执行交易逻辑且无新K线检查，可能在短时间内反复开平仓
  • 仅依赖简单OHLC比较产生信号，在震荡市中容易产生虚假信号导致频繁亏损
  • POSITION_SL与NULL比较的方式不规范，应使用0而非NULL检查止损是否设置

Risk Assessment

Overall:MEDIUM

Risk Points

  • SL and TP are both 0 at position opening, creating an unprotected position risk window
  • Trade logic executes every tick without new bar check, potentially causing rapid repeated open/close cycles
  • Signals based solely on simple OHLC comparison are prone to false signals in ranging markets, leading to frequent losses
  • Comparing POSITION_SL with NULL is non-standard; should use 0 instead of NULL to check if SL is set
