摘要

该EA从Google Finance抓取实时股票报价，并与可配置时间窗口前的历史价格进行比较。当当前价格与历史参考价格的偏差超过可配置的阈值时，开立买入或卖出仓位，试图从网络报价与经纪商价格之间的短期价格错位中获利。

策略分析

策略概念：该EA利用Google Finance的网络报价作为外部参考数据源，与自身记录的历史报价进行对比，寻找价格偏差机会。入场条件：当当前价格与历史价格（默认75分钟前）的差值超过BarSize阈值时，若DiffPrice大于HistoryPrice+BarSize则买入，若DiffPrice小于HistoryPrice-BarSize则卖出。出场条件：通过DeelayPosition（历史时间延迟）计算持仓时间，到达延迟时间后平仓；同时设置了TakeProfit和StopLoss。仓位管理：使用固定手数（Lots参数），每次交易手数不变，通过Count参数限制最大交易次数。资金管理：没有动态资金管理机制，固定手数交易，止损设为5000个tick点差，风险较大。整体策略依赖外部数据源的准确性和可用性，存在数据获取失败的风险。

Summary

This EA scrapes real-time stock quotes from Google Finance and compares them against historical prices from a configurable time window (e.g., 75 minutes ago). It opens BUY or SELL positions when the current price deviation from the historical reference exceeds a configurable bar size threshold, aiming to profit from short-term price dislocations between the web-based quote and the broker's price.

Strategy Analysis

Strategy concept: This EA uses Google Finance web quotes as an external reference data source and compares them against its own recorded historical quotes to find price deviation opportunities. Entry conditions: When the difference between the current price and the historical price (default 75 minutes ago) exceeds the BarSize threshold, it buys if DiffPrice is greater than HistoryPrice+BarSize, and sells if DiffPrice is less than HistoryPrice-BarSize. Exit conditions: Positions are closed after a delay calculated from DeelayPosition (the historical time offset), and both TakeProfit and StopLoss are configured. Position sizing: Uses a fixed lot size (Lots parameter) with no dynamic adjustment, and limits the maximum number of trades via the Count parameter. Money management: There is no dynamic money management mechanism; trading uses fixed lots with a stop loss of 5000 tick points, which represents significant risk. The overall strategy relies heavily on the accuracy and availability of the external data source, posing risks of data fetch failures.

优势

  • 利用外部数据源进行跨市场价差分析，思路独特
  • 支持按星期筛选交易日，灵活性较好
  • 有交易次数限制和止盈止损设置，具备基本风险控制

劣势

  • 依赖Google Finance网页抓取，该API已失效且HTML结构已变更，EA完全无法运行
  • 止损设为5000个tick点差而止盈仅10个，风险收益比极差（1:500）
  • 代码中存在自赋值bug（sessionOpened=sessionOpened）和全局变量滥用问题
  • 没有检查现有持仓，可能重复开仓
  • FIFO函数中的数组管理效率低下，每次增加两个元素

改进建议

  • 替换Google Finance数据源为可用的金融API（如Yahoo Finance、Alpha Vantage等），并增加数据获取失败的健壮处理
  • 修正风险收益比，将止损缩小或止盈放大，并添加持仓检查和资金管理逻辑
  • 修复sessionOpened自赋值bug，重构全局变量为类成员变量以提高代码可维护性

Strengths

  • Utilizes an external data source for cross-market price spread analysis, offering a unique approach
  • Supports day-of-week filtering for trading sessions, providing good flexibility
  • Has trade count limits and take-profit/stop-loss settings, providing basic risk control

Weaknesses

  • Relies on Google Finance web scraping which is defunct and whose HTML structure has changed, making the EA completely non-functional
  • Stop loss is set to 5000 ticks while take profit is only 10 ticks, resulting in an extremely poor risk-reward ratio (1:500)
  • Contains a self-assignment bug (sessionOpened=sessionOpened) and excessive use of global variables
  • No check for existing positions, potentially leading to duplicate trades
  • FIFO function has inefficient array management, incrementing by two elements each time

Improvements

  • Replace Google Finance data source with a functional financial API (e.g., Yahoo Finance, Alpha Vantage) and add robust error handling for data fetch failures
  • Fix the risk-reward ratio by reducing stop loss or increasing take profit, and add position checking and money management logic
  • Fix the sessionOpened self-assignment bug and refactor global variables into class members for better code maintainability
