策略分析

分析 ### 2.1 核心策略概念 Exp_RMACD是一个基于**成交量加权RVI(Relative Vigor Index)与TRVI(True RVI)差异**的趋势跟踪策略。 **核心算法创新**：将传统MACD的概念应用到RVI指标上，创建"Relative MACD"： - **RMACD主线** = RVI指标值 - TRVI指标值 - **信号线** = 对RMACD主线进行高级平滑(JJMA/JurX/T3等10种算法可选) **RVI vs TRVI的区别**： - **RVI**：标准Relative Vigor Index，使用固定的加权系数计算价格动能 - **TRVI (True RVI)**：使用**成交量加权**的创新RVI算法，公式为： TRVI将成交量纳入计算，比标准RVI更能反映市场真实资金流向。 ### 2.2 入场条件 EA提供**四种入场模式**(通过`Mode`参数选择)： #### 模式1: breakdown (零轴穿越) - 做多：Value[1] > 0 且 Value[0] <= 0 (RMACD从正转负) - 做空：Value[1] < 0 且 Value[0] >= 0 (RMACD从负转正) - **特点**：捕捉趋势反转信号 #### 模式2: MACDtwist (MACD方向转折) - 做多：Value[1] < Value[2] 且 Value[0] > Value[1] (V型反转) - 做空：Value[1] > Value[2] 且 Value[0] < Value[1] (倒V型反转) - **特点**：三值序列确认，捕捉动量转折点 #### 模式3: SIGNALtwist (信号线方向转折) - 做多：信号线V型反转 - 做空：信号线倒V型反转 - **特点**：信号线平滑后更稳定 #### 模式4: MACDdisposition (MACD穿越信号线) - 默认模式 - 做多：MACD[1] > Signal[1] 且 MACD[0] <= Signal[0] (金叉后确认) - 做空：MACD[1] < Signal[1] 且 MACD[0] >= Signal[0] (死叉后确认) - **特点**：经典的MACD穿越策略 ### 2.3 出场条件 - 止损触发：固定点数止损(默认1000点) - 止盈触发：固定点数止盈(默认2000点，盈亏比2:1良好) - 反向信号平仓：根据入场模式对应的反向信号 ### 2.4 风险管理 - **止损止盈**: StopLoss=1000点/TakeProfit=2000点(盈亏比2:1良好但止损过大) - **手数管理**: MM参数控制，负值为固定手数(默认-0.1=0.1手)，正值为账户比例 - **四开关交易控制**: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制开平仓权限 - **信号时间戳**: UpSignalTime/DnSignalTime确保信号不被重复执行

优势

  • 创新的成交量加权RVI算法: TRVI指标将成交量纳入计算，比传统RVI更能反映市场资金流向
  • 四种入场模式灵活选择: breakdown/MACDtwist/SIGNALtwist/MACDdisposition覆盖不同交易场景
  • 盈亏比2:1设计良好: TakeProfit=2000/StopLoss=1000提供有利风险回报
  • Nikolay Kositsin专业级代码架构: 代码结构清晰，依赖库完善，错误处理全面
  • 多算法平滑库支持: 10种平滑算法可选(JJMA/JurX/T3/VIDYA/AMA等)

劣势

  • 默认止损过大(1000点): 风险敞口过大，需大幅优化
  • 固定手数过大: 无资金管理，MM=-0.1开仓0.1手风险偏高
  • 无趋势强度过滤: 缺乏ADX或MA200确认，震荡市可能频繁亏损
  • 四重平滑严重滞后: RVI→TRVI→RMACD→Signal线，信号响应慢
  • 依赖外部指标: ColorRMACD和TRVI需正确安装到Indicators文件夹
