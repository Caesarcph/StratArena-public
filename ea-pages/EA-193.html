The synaptic weights are adjusted online using a simple reward/punishment mechanism based on whether the last trade was profitable or not.

摘要

一个基于感知器神经网络的EA，使用5个技术指标（MA交叉、RSI、CCI、MA斜率、动量震荡器）作为5个子神经网络的输入，再由元网络组合产生买卖信号。突触权重根据上一笔交易是否盈利进行简单的奖惩在线调整。

策略分析

该EA采用多层感知器架构，由5个子神经网络和一个元网络组成。每个子神经网络接收4个指标信号作为输入（留一法），通过加权求和产生中间输出，元网络再将5个子网络输出加权求和得到最终决策值。入场条件为：元网络输出大于0时买入，小于0时卖出，同时要求无持仓且与上一交易方向不同。出场条件依赖固定的止损和止盈，止损默认100点，止盈默认40点。仓位管理为固定0.1手，没有根据账户资金或风险动态调整。突触权重调整采用简单的奖惩机制：盈利时增强正确方向的权重，亏损时反向调整，权重被限制在SinMin到SinMax范围内。

Summary

A perceptron-based neural network EA that uses 5 technical indicators (MA crossover, RSI, CCI, MA slope, Awesome Oscillator) as inputs to 5 sub-neural-networks, which are then combined by a meta-network to produce buy/sell signals. The synaptic weights are adjusted online using a simple reward/punishment mechanism based on whether the last trade was profitable or not.

Strategy Analysis

This EA employs a multi-layer perceptron architecture consisting of 5 sub-neural-networks and one meta-network. Each sub-network takes 4 out of 5 indicator signals as input using a leave-one-out scheme, producing intermediate outputs via weighted summation, and the meta-network combines all 5 sub-network outputs into a final decision value. Entry conditions: buy when meta-network output is positive, sell when negative, with the additional constraint that no position is open and the trade direction differs from the last trade. Exit relies on fixed stop loss (default 100 points) and take profit (default 40 points). Position sizing is fixed at 0.1 lots with no dynamic adjustment based on account equity or risk. The synaptic weight adjustment uses a simple reward/punishment mechanism: profitable trades strengthen weights in the correct direction while losing trades reverse-adjust, with weights clamped between SinMin and SinMax bounds.

优势

  • 在线学习能力，权重根据交易结果动态调整，具有自适应性
  • 多指标融合决策，5个指标从不同维度提供信号，减少单一指标偏差
  • 留一法网络架构设计，每个子网络缺少一个指标的输入，增加模型鲁棒性
  • 权重有上下限约束，防止权重无限增长导致过拟合
  • 使用多个指标信号（-1/0/1）离散化，降低了噪声干扰

劣势

  • 感知器仅有线性加权求和，没有激活函数和非线性变换，表达能力极其有限
  • SinapticsAjust函数从未被调用，权重调整逻辑实际上是死代码，网络无法真正学习
  • NN4的权重调整中存在严重BUG，错误修改了NN3的权重（NNS3IND2而非NNS4IND2），多处NNS2IND4被误修改
  • 固定0.1手仓位，无资金管理策略，不适应不同账户规模
  • 没有新柱检测，每个tick都会重新计算指标和尝试下单，可能频繁触发交易
  • 止损大于止盈（100:40），盈亏比仅0.4，需要极高胜率才能盈利

改进建议

  • 修复死代码问题：在OnTick中交易平仓后调用SinapticsAjust()，使权重调整逻辑真正生效
  • 修复权重BUG：NN4中应修改NNS4IND2而非NNS3IND2，NN3中应修改NNS3IND4而非NNS2IND4
  • 添加激活函数（如tanh或sigmoid）使网络具备非线性表达能力
  • 添加新柱检测避免每个tick重复计算，添加持仓检查和开仓时间间隔限制
  • 实现动态仓位管理，根据账户余额或风险百分比调整手数

Strengths

  • Online learning capability with weights dynamically adjusted based on trade results, providing adaptability
  • Multi-indicator fusion decision making with 5 indicators providing signals from different dimensions, reducing single-indicator bias
  • Leave-one-out network architecture where each sub-network omits one indicator, increasing model robustness
  • Weight bounds (SinMin/SinMax) prevent unbounded weight growth and overfitting
  • Discrete indicator signals (-1/0/1) reduce noise interference from raw indicator values

Weaknesses

  • The perceptron only performs linear weighted summation without activation functions or nonlinear transformations, severely limiting representational capacity
  • SinapticsAjust() is never called anywhere in the code, making the entire weight adjustment logic dead code — the network cannot actually learn
  • Critical bugs in NN4 weight adjustment: incorrectly modifies NN3 weights (NNS3IND2 instead of NNS4IND2), and NNS2IND4 is mistakenly modified in NN3 sections at multiple locations
  • Fixed 0.1 lot position sizing with no money management strategy, unsuitable for varying account sizes
  • No new bar detection, causing recalculation and potential order attempts on every tick
  • Stop loss exceeds take profit (100:40), giving a risk-reward ratio of only 0.4, requiring extremely high win rate to be profitable

Improvements

  • Fix dead code: call SinapticsAjust() in OnTick after trade closure to activate the weight adjustment logic
  • Fix weight bugs: NN4 should modify NNS4IND2 not NNS3IND2, NN3 should modify NNS3IND4 not NNS2IND4
  • Add activation functions (e.g., tanh or sigmoid) to give the network nonlinear representational capacity
  • Add new bar detection to avoid recalculating every tick, add position checks and minimum trade interval
  • Implement dynamic position sizing based on account balance or risk percentage

风险评估 / Risk Assessment

总体 / Overall:HIGH

风险点

  • 核心学习函数SinapticsAjust从未被调用，网络权重始终为初始值1，EA实际上不具备学习能力
  • 多个权重调整存在复制粘贴BUG，错误修改其他神经网络的权重
  • 无新柱检测，每个tick都会尝试交易逻辑
  • 无点差过滤，在点差较大时仍可能开仓
  • 固定仓位无资金管理，盈亏比仅0.4需要极高胜率

Risk Assessment

Overall:HIGH

Risk Points

  • Core learning function SinapticsAjust() is never called, weights remain at initial value 1, the EA has no actual learning capability
  • Multiple copy-paste bugs in weight adjustment incorrectly modify other neural networks' weights
  • No new bar detection, trade logic runs on every tick
  • No spread filter, may open positions during high-spread conditions
  • Fixed lot size with no money management, risk-reward ratio of 0.4 requires very high win rate
