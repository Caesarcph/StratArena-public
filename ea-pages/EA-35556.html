摘要

该EA使用威廉姆斯百分比范围(WPR)交叉结合ADX方向指标(DI+/DI-)交叉作为入场信号。出场由资金流量指数(MFI)超买/超卖水平和随机指标交叉模式管理。包含基于前一根K线高低价的可选追踪止损功能。

策略分析

策略概念基于多指标动量确认系统，结合威廉姆斯百分比范围(WPR)和ADX方向指标(DI+/DI-)产生入场信号。入场条件为：做多需WPR从低位上穿且DI+从下方穿越DI-（由负转正）；做空需WPR从高位下穿且DI+从上方穿越DI-（由正转负）。出场条件分为两层：持仓管理出场使用MFI超买/超卖水平（多头持仓时MFI超过79水平则平仓，空头持仓时MFI低于21水平则平仓）和随机指标交叉（主线上穿信号线平多单，主线下穿信号线平空单）。仓位管理采用固定手数入场，仅允许单持仓交易。资金管理方面，止损和止盈基于点数计算并考虑了止损水平限制，追踪止损以前一根K线高低价为基准进行跟踪。整体策略属于动量确认型系统，通过多指标交叉过滤降低假信号。

Summary

This EA uses Williams' Percent Range (WPR) crossover combined with ADX directional indicator crossover (DI+/DI-) for entry signals. Exits are managed by Money Flow Index (MFI) overbought/oversold levels and Stochastic oscillator crossover patterns. It includes optional trailing stop functionality based on the previous bar's high/low.

Strategy Analysis

The strategy concept is a multi-indicator momentum confirmation system combining Williams' Percent Range (WPR) and ADX directional indicators (DI+/DI-) for entry signals. Entry conditions: long requires WPR crossing upward from oversold and DI+ crossing above DI- (shifting from negative to positive difference); short requires WPR crossing downward from overbought and DI+ crossing below DI- (shifting from positive to negative difference). Exit conditions operate on two layers: position management exits use MFI overbought/oversold levels (close long when MFI exceeds 79, close short when MFI falls below 21) and Stochastic crossover patterns (main line crossing above signal line closes longs, main line crossing below signal line closes shorts). Position sizing uses fixed lot sizing with single-position-only trading logic. Money management includes pip-based stop loss and take profit calculation accounting for the broker's stop level, and a trailing stop mechanism referencing the previous bar's high/low. The overall strategy is a momentum-confirmation system using multi-indicator crossover filtering to reduce false signals.

优势

  • 多指标确认入场，WPR与ADX双重过滤减少假信号
  • 止损止盈考虑了经纪商止损水平限制，避免订单被拒
  • 订单发送有重试机制和订单检查，增强交易执行可靠性
  • 新K线检测机制避免同一K线重复交易
  • 订单填充类型自动适配（FOK/IOC/RETURN），提高兼容性

劣势

  • 默认止损和止盈均为0，实际运行时可能无任何风险保护
  • 追踪止损变量isTrailingStop初始化为false且无输入参数可开启，功能形同虚设
  • 仅支持单持仓模式，无法加仓或分批建仓
  • MFI出场水平硬编码为100-Level对称计算，未考虑不同市场特性
  • GetPipValue函数不支持6位小数（如日元交叉盘）或特殊品种
  • 无点差过滤，在高位差情况下仍可能入场

改进建议

  • 添加可配置的追踪止损开关输入参数，使追踪止损功能可用
  • 增加点差过滤，当点差过大时禁止开仓以避免滑点损失
  • 为MFI和随机指标出场水平添加可配置的输入参数而非硬编码对称计算

Strengths

  • Multi-indicator confirmation entry with WPR and ADX dual filtering reduces false signals
  • Stop loss and take profit account for broker stop level requirements, preventing order rejection
  • Order sending includes retry mechanism and order checking, enhancing trade execution reliability
  • New bar detection prevents duplicate trading on the same bar
  • Automatic order filling type adaptation (FOK/IOC/RETURN) improves broker compatibility

Weaknesses

  • Default stop loss and take profit are both 0, potentially running without any risk protection
  • Trailing stop variable isTrailingStop initializes to false with no input parameter to enable it, making the feature effectively unusable
  • Single-position-only mode, unable to scale in or build positions in batches
  • MFI exit levels use hardcoded symmetric calculation (100-Level), not accounting for different market characteristics
  • GetPipValue function does not support 6-digit decimals or special instrument types
  • No spread filter, may enter trades even during high-spread conditions

Improvements

  • Add a configurable trailing stop toggle input parameter to make the trailing stop feature accessible
  • Add a spread filter to prevent opening positions when spread is excessively wide, avoiding slippage losses
  • Make MFI and Stochastic exit levels configurable input parameters instead of hardcoded symmetric calculations
