策略分析

分析 ### 2.1 核心策略概念 **这是一个半自动交易GUI面板工具，不是自动化交易EA。** 该EA提供了一个专业的交易控制面板，包含以下核心功能： 1. **主面板**: 显示实时Bid/Ask价格、持仓信息、风险/回报计算、波动性指标 2. **交易计划Tab**: 创建和管理交易计划，设置入场点、止损、止盈 3. **支点计算Tab**: 三种支点公式(Classic/Woodie/Camarilla)，多时间框架支持 4. **多时间框架指标Tab**: 9个时间框架的7种指标实时监控表 ### 2.2 入场条件 **手动触发，非自动入场。** - 点击"Buy"按钮 → 执行市价买入 - 点击"Sell"按钮 → 执行市价卖出 - 支持手数(Spinner控制)、滑点设置 - 反向操作时自动清除原有止损止盈 ### 2.3 出场条件 **手动触发，非自动出场。** - 点击"REVERSE"按钮 → 反转仓位(2倍仓位) - 点击"CLOSE"按钮 → 平仓 - 点击"Quit"按钮 → 移除面板并退出EA ### 2.4 风险管理 - **手数控制**: Spinner控件(最小0.01，最大为品种上限) - **滑点控制**: 可调节滑点容忍度(默认0.00050) - **止损/止盈**: - 主面板显示当前持仓的止损/止盈 - 自动计算风险/回报比 - Tab0支持拖拽水平线设置SL/TP - **波动性监控**: 显示最近N分钟的价格范围(pips)

优势

  • 完善的GUI架构:
  • 自定义控件系统(Spinner、ProgressBar、EditTable、Listbox)
  • 面板显示/隐藏动画效果
  • 多标签页管理系统
  • 多时间框架指标聚合:
  • 9个时间框架(M1~MN)的7种指标实时显示
  • 颜色编码快速识别趋势状态
  • 单表聚合所有数据
  • 专业支点计算系统:
  • 3种支点公式(Classic/Woodie/Camarilla)
  • 可视化支点线绘制
  • 多时间框架切换
  • 实时风险管理显示:
  • 自动计算风险/回报比
  • Bid/Ask颜色变化显示价格动量
  • 波动性实时监控
  • 交易计划管理:
  • 可视化入场点、SL、TP设置
  • 拖拽式价格线调整
  • 计划列表增删改查

劣势

  • 无自动交易逻辑: 纯手动工具，无法自动化执行策略
  • 代码过时(2010年):
  • MQL5语法可能需要更新
  • 依赖旧版标准库
  • 缺少现代错误处理
  • 单品种限制: 仅支持当前图表品种，无法多品种管理
  • 无账户保护机制:
  • 无最大亏损限制
  • 无日内交易次数限制
  • 无保证金比例警告
  • 配置不持久化:
  • 每次启动需重新设置
  • 交易计划不保存到文件
