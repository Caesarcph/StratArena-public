策略分析

分析 ### 2.1 核心策略概念 该EA使用JMA(Jurik Moving Average)斜率指标进行趋势跟踪交易。JMA是由Mark Jurik开发的高级平滑算法，以其低延迟和低噪声特性著称。JMASlope计算JMA的变化率(斜率)，通过斜率的符号和方向变化来识别趋势转折点。 核心算法： - JMA平滑：使用JJMA算法对价格进行平滑处理 - 斜率计算：Slope = (JMA当前值 - JMA前值) / _Point - 归一化输出：斜率值以点数为单位，便于跨品种比较 ### 2.2 入场条件 **两种入场模式**： 1. **Breakdown模式(零轴穿越)**： - 做多：Value[1] > 0 且 Value[0] <= 0 (从负穿越到正) - 做空：Value[1] < 0 且 Value[0] >= 0 (从正穿越到负) 2. **Twist模式(方向转折)**： - 做多：Value[1] < Value[2] 且 Value[0] > Value[1] (V型反转) - 做空：Value[1] > Value[2] 且 Value[0] < Value[1] (倒V型反转) ### 2.3 出场条件 - 反向信号触发平仓 - 固定止损止盈(SL=1000点/TP=2000点) ### 2.4 风险管理 - 止损：1000点(默认) - 止盈：2000点(默认) - 盈亏比：2:1良好 - 手数管理：MM参数支持动态手数(负值=固定手数，正值=账户百分比)

优势

  • JJMA高级平滑算法：Mark Jurik开发的低延迟平滑算法，有效降噪同时保持趋势敏感性
  • 双入场模式设计：提供breakdown(穿越)和twist(转折)两种灵活入场方式
  • 完整交易框架：Nikolay Kositsin专业级代码架构，包含CIsNewBar新K线检测+TradeAlgorithms完整交易函数库
  • 良好的盈亏比：默认SL=1000/TP=2000，盈亏比2:1合理
  • 11种价格类型支持：从Close到Demark多种价格计算方式
  • 四开关交易控制：独立控制买入开仓/卖出开仓/买入平仓/卖出平仓

劣势

  • 默认止损过大：1000点对多数品种来说过大
  • 无趋势强度过滤：可能在震荡市场频繁交易
  • 固定手数模式：默认MM=-0.1对小额账户不友好
  • 参数未优化：jLength=14可能不适合所有品种
  • 依赖外部指标：需要JMASlope指标文件
