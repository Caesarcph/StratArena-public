摘要

该EA基于RSI超买超卖阈值的交叉信号进行交易，RSI上穿下限时做多，下穿上限时做空。支持固定和ATR动态止损止盈、风险比例或固定手数计算、交易时段过滤以及部分减仓功能。出场条件与入场相反，在RSI反向穿越阈值时平仓。

策略分析

策略概念基于RSI动量指标的超买超卖区域交叉信号，属于典型的动量反转混合策略。入场条件为RSI从下方穿越LowerThreshold（默认20）时做多，从上方穿越UpperThreshold（默认80）时做空，即信号线穿越阈值线而非简单的超买超卖判定。出场条件与入场对称，当持仓方向对应的反向信号出现时平仓，例如多头在RSI下穿上限时平仓。仓位管理支持固定手数和基于风险的自动计算两种模式，自动模式下根据账户余额/净值/可用保证金的一定比例与止损距离计算手数。止损止盈支持固定点数和基于ATR波动率的动态计算，动态模式利用ATR值乘以相应系数确定止损止盈距离。此外还提供交易时段过滤和部分减仓（Scale Out）功能，部分减仓在价格达到ATR倍数盈利时按比例平仓一半仓位。

Summary

This EA trades RSI crossover signals at overbought/oversold thresholds, entering long when RSI crosses above the lower threshold and short when it crosses below the upper threshold. It supports both fixed and ATR-based dynamic stop-loss/take-profit, risk-based or fixed lot sizing, session filtering, and partial scale-out. Exit conditions mirror entries, closing positions on opposite RSI threshold crossovers.

Strategy Analysis

The strategy concept is based on RSI momentum indicator crossover signals at overbought/oversold thresholds, representing a hybrid momentum-reversal approach. Entry conditions trigger a long position when RSI crosses above the LowerThreshold (default 20) and a short position when RSI crosses below the UpperThreshold (default 80), meaning the signal line crosses the threshold level rather than a simple overbought/oversold determination. Exit conditions are symmetric to entries, closing positions when the opposite RSI threshold crossover occurs, e.g., long positions close when RSI crosses below the upper threshold. Position sizing supports both fixed lot size and risk-based auto-calculation modes, where the auto mode calculates lot size based on a percentage of account balance/equity/free margin relative to the stop-loss distance. Stop-loss and take-profit support both fixed point values and ATR-volatility-based dynamic calculation, with the dynamic mode using ATR values multiplied by configured factors. Additionally, the EA provides session time filtering and partial scale-out functionality, where scale-out reduces the position by a configured percentage when price profit exceeds an ATR-based threshold.

优势

  • 支持固定和ATR动态止损止盈，适应不同市场波动环境
  • 具备风险比例自动计算仓位功能，资金管理较为完善
  • 提供交易时段过滤和部分减仓功能，增加策略灵活性
  • 新K线检测机制避免同一根K线重复开仓
  • 平仓重试机制（最多10次）提高了订单执行的可靠性

劣势

  • AccountBalance/AccountEquity/AccountFreeMargin函数返回类型为bool而非double，存在严重类型错误
  • 默认止损止盈均为0，不设止损直接交易风险极大
  • MinimumStopLoss和MaximumStopLoss参数定义了但从未在止损计算中使用，形同虚设
  • MaxSpreadAllowed参数定义了但入场条件中未检查点差，该参数完全未生效
  • LoadIndicatorData中ATR和RSI的CopyBuffer起始索引不一致，ATR从0开始而RSI从1开始，可能导致数据对齐问题

改进建议

  • 修复AccountBalance/AccountEquity/AccountFreeMargin的返回类型为double，否则风险仓位计算将完全错误
  • 在入场条件中加入MaxSpreadAllowed点差检查，使已有参数真正生效
  • 在CalculateStopLoss和CalculateTakeProfit中实际使用MinimumStopLoss/MaximumStopLoss/MinimumTakeProfit/MaximumTakeProfit参数进行范围校验
  • 统一LoadIndicatorData中CopyBuffer的起始索引，确保ATR和RSI数据时间对齐
  • OnDeinit中应释放指标句柄（IndicatorRelease），避免资源泄漏

Strengths

  • Supports both fixed and ATR-based dynamic stop-loss/take-profit, adapting to different market volatility environments
  • Risk-based auto position sizing provides solid money management capabilities
  • Session filtering and partial scale-out features add strategy flexibility
  • New bar detection mechanism prevents duplicate entries on the same bar
  • Position close retry mechanism (up to 10 attempts) improves order execution reliability

Weaknesses

  • AccountBalance/AccountEquity/AccountFreeMargin functions return bool instead of double, causing critical type errors that will corrupt position size calculations
  • Default stop-loss and take-profit are both 0, trading without stop-loss poses extreme risk
  • MinimumStopLoss and MaximumStopLoss parameters are defined but never used in stop-loss calculation, making them dead code
  • MaxSpreadAllowed parameter is defined but never checked before entry, rendering it completely ineffective
  • Inconsistent CopyBuffer start indices between ATR (start=0) and RSI (start=1) in LoadIndicatorData may cause data alignment issues

Improvements

  • Fix AccountBalance/AccountEquity/AccountFreeMargin return types to double, otherwise risk-based position sizing will be completely wrong
  • Add MaxSpreadAllowed spread check in entry conditions to make the existing parameter functional
  • Actually use MinimumStopLoss/MaximumStopLoss/MinimumTakeProfit/MaximumTakeProfit parameters for range validation in CalculateStopLoss and CalculateTakeProfit
  • Unify CopyBuffer start indices in LoadIndicatorData to ensure ATR and RSI data are temporally aligned
  • Release indicator handles via IndicatorRelease in OnDeinit to prevent resource leaks

风险评估 / Risk Assessment

总体 / Overall:HIGH

风险点

  • AccountBalance等函数返回bool类型导致自动仓位计算完全错误，可能产生0手或极端手数
  • 默认止损止盈均为0，用户若不修改参数将以无止损状态交易
  • MaxSpreadAllowed参数未生效，高波动时可能在极大点差下开仓
  • MinimumStopLoss/MaximumStopLoss未实际约束止损范围，可能导致过小或过大止损

Risk Assessment

Overall:HIGH

Risk Points

  • AccountBalance etc. return bool type causing completely wrong auto position sizing, potentially resulting in 0-lot or extreme lot sizes
  • Default stop-loss and take-profit are both 0, users who don't modify parameters will trade without any stop-loss
  • MaxSpreadAllowed parameter is not enforced, potentially opening positions during extremely wide spreads in high volatility
  • MinimumStopLoss/MaximumStopLoss are not actually constraining stop-loss range, potentially allowing too small or too large stops
