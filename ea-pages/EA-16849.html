摘要

该EA基于短期和长期EMA交叉信号进行交易。短期EMA上穿长期EMA时开多仓，下穿时开空仓，设有固定止盈止损和追踪止损功能。

策略分析

策略概念基于双指数移动平均线(EMA)交叉，属于经典的趋势跟踪策略。入场条件为短期EMA与长期EMA发生交叉：短期上穿长期时做多，短期下穿长期时做空，且支持Reverse参数反转信号方向。出场条件包括固定止盈和止损，以及追踪止损——当持仓浮盈超过追踪止损距离时，将止损移动至保本位附近。仓位管理采用固定手数(Lots参数)，没有根据账户资金动态调整仓位大小的资金管理模块，代码中也有TODO注释表明这一点。追踪止损仅调整止损位，不修改止盈位，对多头和空头分别处理。策略没有加仓、减仓或分批进场的逻辑，每次仅持有单边仓位。

Summary

This EA trades EMA crossover signals between a short-period and long-period EMA. It opens buy positions when the short EMA crosses above the long EMA and sell positions on the opposite cross, with fixed take-profit, stop-loss, and a trailing stop for open position management.

Strategy Analysis

The strategy is based on a dual Exponential Moving Average (EMA) crossover, a classic trend-following approach. Entry conditions trigger when the short-period EMA crosses the long-period EMA: a buy signal occurs on an upward cross and a sell signal on a downward cross, with a Reverse parameter to invert signal direction. Exit conditions include fixed take-profit and stop-loss levels, plus a trailing stop that moves the stop-loss to lock in profits when the position's floating profit exceeds the trailing distance. Position sizing uses a fixed lot size (Lots parameter) with no dynamic money management based on account equity — a TODO comment in the code explicitly acknowledges this gap. The trailing stop only adjusts the stop-loss without modifying take-profit, handling long and short positions separately. The strategy has no pyramiding, partial close, or scaled entry logic, and only holds a single-direction position at a time.

优势

  • 策略逻辑简洁清晰，EMA交叉是经过验证的趋势跟踪方法
  • 包含追踪止损功能，能有效锁定浮动盈利
  • 支持信号反转(Reverse参数)，灵活适应不同行情
  • 使用标准MT5交易类库(CTrade/CPositionInfo/CSymbolInfo)，代码规范

劣势

  • 没有资金管理模块，固定手数不根据账户余额动态调整，风险暴露不可控
  • 没有新K线检查(new bar check)，每个tick都会计算交叉信号，可能导致重复交易或信号漂移
  • 止盈25点远小于止损105点，盈亏比约0.24:1，需要极高胜率才能盈利
  • Crossed函数使用静态变量存储状态，EA重启后会丢失历史方向信息
  • 没有点差过滤，在小周期或高波动时段可能因点差过大而亏损

改进建议

  • 添加资金管理模块，根据账户余额和风险比例动态计算手数
  • 添加新K线检查，确保每个信号仅在一个完整K线上触发一次
  • 优化盈亏比，考虑将止盈扩大或使用动态止盈策略
  • 添加点差过滤，避免高点差时段入场
  • 将Crossed函数的状态持久化或在OnInit中重建初始方向

Strengths

  • Simple and clear strategy logic — EMA crossover is a proven trend-following method
  • Includes a trailing stop feature that effectively locks in floating profits
  • Supports signal reversal via the Reverse parameter for flexible market adaptation
  • Uses standard MT5 trade class libraries (CTrade/CPositionInfo/CSymbolInfo) for clean code structure

Weaknesses

  • No money management module — fixed lot size does not adapt to account balance, making risk exposure uncontrollable
  • No new bar check — the crossover is recalculated every tick, risking signal drift and redundant trade attempts
  • Take-profit of 25 points is far smaller than stop-loss of 105 points, yielding a risk-reward ratio of ~0.24:1 which requires very high win rate
  • Crossed() function relies on static variables for state, losing directional history on EA restart
  • No spread filter — trades can be opened during high-spread periods, eroding small take-profit targets

Improvements

  • Add a money management module that dynamically calculates lot size based on account balance and risk percentage
  • Add a new bar check to ensure each signal triggers only once per completed bar
  • Optimize risk-reward ratio — consider widening take-profit or using a dynamic take-profit strategy
  • Add a spread filter to prevent entries during high-spread periods
  • Persist the Crossed() function state or rebuild initial direction in OnInit() to survive restarts
