摘要

该EA基于平滑ADX指标的DI+和DI-线交叉信号进行交易。当DI+上穿DI-时做多，DI-上穿DI+时做空，可配置开仓和平仓权限。仓位管理使用资金管理参数，可设定固定手数或存款比例。

策略分析

该策略基于平滑版ADX指标的DI+与DI-线交叉来判断趋势方向。入场条件为：当DI+从下方穿越DI-时产生买入信号并开多仓，同时平掉空头仓位；当DI+从上方穿越DI-时产生卖出信号并开空仓，同时平掉多头仓位。出场条件包括固定的止损和止盈点数设置，以及反向信号触发时的仓位平仓。仓位管理通过MM参数控制，负值表示固定手数，正值表示存款比例。策略在每个新K线形成时检测信号，避免逐Tick重复计算，使用SignalBar参数指定信号获取的K线索引。该策略属于典型的趋势跟踪系统，依靠方向性指标交叉捕捉趋势启动点。

Summary

This EA trades based on crossover signals from the smoothed ADX indicator's DI+ and DI- lines. It enters long when DI+ crosses above DI- and short when DI- crosses above DI+, with configurable permissions for opening and closing positions. Position sizing uses a money management parameter that can represent either a fixed lot size or a percentage of the deposit.

Strategy Analysis

This strategy uses the crossover of smoothed ADX indicator's DI+ and DI- lines to determine trend direction. Entry conditions: a buy signal is generated when DI+ crosses above DI-, opening a long position and closing any existing short position; a sell signal is generated when DI+ crosses below DI-, opening a short position and closing any existing long position. Exit conditions include fixed Stop Loss and Take Profit in points, as well as position closure triggered by opposing crossover signals. Position sizing is controlled by the MM parameter, where negative values represent a fixed lot size and positive values represent a share of the deposit. The strategy checks for signals on each new bar formation to avoid redundant per-tick calculations, using the SignalBar parameter to specify the bar index for signal retrieval. This is a classic trend-following system that relies on directional indicator crossovers to capture trend initiation points.

优势

  • 使用新K线检测机制避免逐Tick重复计算，减少资源消耗
  • 提供灵活的仓位管理参数，支持固定手数和存款比例两种模式
  • 买卖开仓和平仓权限可独立控制，策略配置灵活度高
  • 使用平滑ADX指标减少信号噪音，交叉信号更可靠

劣势

  • 缺少止损止盈为0时的保护机制，可能导致无止损的无限风险
  • 没有点差过滤，在行情点差较大时可能造成不利入场
  • 策略仅依赖DI+/DI-交叉，在震荡行情中容易产生频繁的虚假信号
  • 缺少最大持仓数量和资金回撤控制机制

改进建议

  • 增加ADX强度阈值过滤，仅在ADX值超过某阈值时才入场，避免震荡市中的虚假信号
  • 添加点差过滤和最大回撤限制，提升风险控制能力

Strengths

  • New bar detection mechanism avoids redundant per-tick calculations, reducing resource consumption
  • Flexible position sizing parameter supports both fixed lot size and deposit share modes
  • Buy/sell open and close permissions can be independently controlled for high configuration flexibility
  • Smoothed ADX indicator reduces signal noise, making crossover signals more reliable

Weaknesses

  • No protection when StopLoss or TakeProfit is set to zero, potentially leading to unlimited risk exposure
  • No spread filter, which may cause unfavorable entries during wide spread conditions
  • Strategy relies solely on DI+/DI- crossover, prone to frequent false signals in ranging markets
  • Lacks maximum position count and drawdown control mechanisms

Improvements

  • Add an ADX strength threshold filter to only enter trades when the ADX value exceeds a certain level, avoiding false signals in ranging markets
  • Add spread filtering and maximum drawdown limits to improve risk management capabilities
