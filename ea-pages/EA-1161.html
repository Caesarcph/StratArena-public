策略分析

分析 ### 2.1 核心策略概念 **三指标确认策略 (Triple Indicator Confirmation)** Kloss策略使用三个经典技术指标进行信号确认： 1. **MA**: 判断趋势方向 2. **CCI**: 判断超买超卖 3. **Stochastic**: 判断动量强度 只有三个指标同时满足条件时才产生交易信号。 ### 2.2 信号逻辑 **买入条件**: **卖出条件**: **解读**: - **买入**: CCI超卖 + Stochastic超卖 + 价格突破MA = 趋势反转向上 - **卖出**: CCI超买 + Stochastic超买 + 价格跌破MA = 趋势反转向下 - **本质**: 三指标共振的**逆势反转**策略 ### 2.3 指标参数 | 指标 | 周期 | 价格类型 | 阈值 | | MA | MAPeriod=1 | PRICE_TYPICAL | MAShift=5 | | CCI | CCIPeriod=10 | PRICE_WEIGHTED | CCIDiffer=120 | | Stochastic K | StKPeriod=5 | STO_LOWHIGH | StDiffer=20 | | Stochastic D | StDPeriod=3 | - | 50±20 | | Stochastic S | StSPeriod=3 | - | - | **指标组合说明**: - MA周期=1实际上是当前价格 - MAShift=5意味着比较5根K线前的MA值 - CCI阈值120非常宽 (通常±100) - Stochastic 50±20对应30/70阈值 ### 2.4 MWMode (Market Watch模式) **工作原理**: 1. **MWMode_F1()**: 开仓时不设置SL/TP (设为0) 2. **MWMode_F2()**: 开仓成功后修改持仓，添加SL/TP **目的**: 避免开仓时因SL/TP距离过近被broker拒绝 ### 2.5 入场逻辑 **开仓流程**: 1. 检查三个指标条件 2. 如果满足条件且无持仓 3. 开仓 (Buy/Sell) 4. 使用MWMode设置SL/TP **持仓时间**: - 无最大持仓时间限制 - 完全依赖SL/TP平仓 ### 2.6 出场逻辑 **方式1: 固定SL/TP** - StopLoss: 550点 - TakeProfit: 550点 - 1:1盈亏比 **方式2: 信号反转平仓 (RevClose)** ### 2.7 资金管理 **手数计算**: **解读**: - Lots>0: 使用固定手数 - Lots=0: 使用风险百分比计算 - MaximumRisk=0.05表示用5%的保证金开仓

劣势

  • 1. 止损过大
  • 550点风险过高
  • 2. 信号过于严格
  • 三指标同时满足难度高
  • 交易频率可能过低
  • 3. MA设置不当
  • Period=1不是真正的MA
  • Shift=5导致比较历史
  • 4. CCI阈值过宽
  • ±120很少触及
  • 错过入场机会
  • 5. 无趋势过滤
  • 没有ADX等趋势指标
  • 在趋势中逆势交易
  • 6. 固定SL/TP
  • 没有移动止损
  • 无法保护利润

  • 减小止损: StopLoss从550改为150-200

  • 添加移动止损: 盈利后移动到保本

  • 优化手数计算: 根据ATR动态调整

  • 在模拟账户测试3个月
