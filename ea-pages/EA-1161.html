EA-1161 · Mean Reversion

Kloss

The Kloss EA is a mean-reversion trading system that uses CCI, Stochastic, and LWMA to identify overbought/oversold conditions for entry. It opens buy positions when CCI is deeply oversold, Stochastic main is below a threshold, and price is above the MA, and vice versa for sell signals. It features an MWMode mechanism that defers SL/TP placement until after position open to avoid broker rejection on tight stops.

Strategy analysis

This strategy is based on the mean reversion concept, assuming that prices will revert to the mean after deviating. Entry conditions: a buy signal requires CCI below -CCIDiffer (default -120), Stochastic main line below 50-StDiffer (default 30), and close price above the LWMA; sell signals are the mirror opposite with CCI above +CCIDiffer, Stochastic above 50+StDiffer, and close below the MA. Exit conditions come in two forms: stop loss/take profit triggers (default 550 points each), or reverse signal closure when RevClose is enabled. Position sizing supports both fixed lots and risk-based dynamic lot calculation, where Lots=0 triggers calculation using account free margin multiplied by MaximumRisk divided by 1000. Money management is handled by fLotsNormalize which rounds lot size to conform with broker minimum volume and step requirements. The MWMode mechanism is a clever design that opens positions with zero SL/TP first, then modifies them on subsequent ticks via PositionModify, adjusting to satisfy StopsLevel requirements and avoiding rejection for stops being too close at order time.

Strengths

  • Triple indicator filter (CCI + Stochastic + MA) reduces false signals with strict entry conditions
  • The MWMode mechanism cleverly solves the problem of broker rejection for stops being too close, improving order fill rates
  • Position sizing supports both fixed lots and dynamic risk-based calculation, offering good flexibility
  • Symmetric SL/TP that can each be set to 0 to disable, giving traders ample parameter tuning space
  • All indicator parameters and shift offsets are adjustable, facilitating optimization and backtesting across timeframes

Weaknesses

  • MAPeriod defaults to 1, making the LWMA essentially the price itself, which severely weakens its filtering purpose
  • The dynamic lot formula (FreeMargin * MaximumRisk / 1000) lacks theoretical basis and does not account for stop loss distance
  • The rv variable in SolveLots is always true with no actual lot validity verification, making the return value meaningless
  • No proper new bar check mechanism; when ZeroBar is true, trading logic may execute on every tick
  • No spread filter — entries can occur during wide spreads, which is detrimental for a mean reversion strategy

Possible improvements

  • Change MAPeriod default from 1 to a reasonable period (e.g., 14-20) so the MA actually serves as a trend filter
  • Improve dynamic lot calculation to risk-based sizing: lots = risk amount / (stop loss points * point value), which is the standard position sizing approach
  • Add a spread filter to prevent entries when the spread exceeds a threshold, avoiding excessive slippage

Risk assessment

Overall risk: Medium

  • MAPeriod=1 disables the MA filter, leaving the strategy without trend direction confirmation and potentially causing frequent counter-trend entries
  • Lot calculation ignores stop loss distance, which can lead to excessive per-trade risk on volatile instruments
  • When ZeroBar is true, there is no effective new bar check, potentially causing repeated trades within the same bar
