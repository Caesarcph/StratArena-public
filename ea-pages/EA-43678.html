摘要

这是一个简单的指标工具，用于识别并在图表上通过Comment显示最近的威廉分形（上线）。它遍历最近10根K线，检查iFractals上轨缓冲区，并打印归一化后的分形高值。该程序不执行任何交易或生成交易信号。

策略分析

该程序并非交易EA，而是一个分形识别工具。其核心概念是利用MT5内置的iFractals指标来检测威廉分形（上分形）。程序在OnTick中遍历最近10根K线，通过CopyBuffer读取分形指标的上轨缓冲区数据。如果某根K线的分形值不为EMPTY_VALUE，则确认该位置存在上分形，并通过Comment函数在图表左上角显示最近分形的价格。程序仅识别上分形（UPPER_LINE），完全忽略了下分形（LOWER_LINE）。仓位管理和资金管理均不存在，因为程序不执行任何交易操作。出场条件同样不适用，因为没有任何入场逻辑。

Summary

This is a simple indicator utility that identifies and displays the most recent Williams Fractal (upper line) on the chart using a Comment overlay. It loops through the last 10 bars, checks the iFractals upper buffer, and prints the normalized fractal high value. It does not execute any trades or generate trading signals.

Strategy Analysis

This program is not a trading EA but rather a fractal identification utility. Its core concept uses MT5's built-in iFractals indicator to detect Williams Fractals (upper fractals). The program loops through the last 10 bars in OnTick, reading the upper line buffer data via CopyBuffer. If a bar's fractal value is not EMPTY_VALUE, it confirms an upper fractal exists at that position and displays the fractal price via the Comment function on the chart's upper-left corner. The program only identifies upper fractals (UPPER_LINE) and completely ignores lower fractals (LOWER_LINE). Position sizing and money management are nonexistent since the program executes no trades. Exit conditions are similarly inapplicable as there is no entry logic whatsoever.

优势

  • 代码简洁明了，逻辑简单易懂
  • 使用MT5内置iFractals指标，分形识别准确可靠
  • 实时更新显示最近的分形价格，方便交易者快速参考

劣势

  • 仅识别上分形，完全忽略下分形，功能不完整
  • 每次OnTick都重新CopyBuffer全部数据，效率低下且造成不必要的资源消耗
  • 数组声明在循环内部导致每轮迭代都重新声明和复制，存在严重的性能问题
  • 使用Comment显示信息不够专业，应使用OBJ_TEXT或Label对象
  • 缺少输入参数验证，bars值可能导致CopyBuffer越界

改进建议

  • 将数组和CopyBuffer移至循环外部，避免每次迭代重复声明和复制数据
  • 增加下分形（LOWER_LINE）的识别和显示功能，使工具更加完整实用
  • 改用新K线检测机制，仅在新K线形成时执行一次分形扫描，而非每Tick都执行
  • 使用图表对象（如Label或箭头）替代Comment来显示分形信息，提升用户体验

Strengths

  • Clean and straightforward code with easy-to-understand logic
  • Uses MT5's built-in iFractals indicator for accurate and reliable fractal detection
  • Real-time updates displaying the most recent fractal price for quick trader reference

Weaknesses

  • Only identifies upper fractals while completely ignoring lower fractals, making the functionality incomplete
  • Recopies the entire buffer via CopyBuffer on every OnTick call, which is highly inefficient and wastes resources
  • Array declaration inside the loop causes re-declaration and re-copy on every iteration, a serious performance issue
  • Using Comment for display is unprofessional; should use OBJ_TEXT or Label objects instead
  • Lacks input parameter validation; the bars value could cause CopyBuffer out-of-bounds errors

Improvements

  • Move array declaration and CopyBuffer call outside the loop to avoid redundant re-declaration and data copying on every iteration
  • Add lower fractal (LOWER_LINE) identification and display to make the tool more complete and useful
  • Implement a new bar detection mechanism so fractal scanning runs only once per new bar instead of every tick
  • Replace Comment with chart objects (such as Label or Arrow) for displaying fractal information to improve user experience
