策略分析

分析 ### 2.1 核心策略概念 **RD-TrendTrigger** 是基于 **Trend Trigger Factor (TTF)** 指标的趋势跟踪策略。该指标由 Paul Y. Shimada 于 2007 年开发，是 M. H. Pee 的 Trend Trigger Factor 的改进版本。 **TTF核心算法原理**: 1. 计算**近期(Recent)**和**早期(Older)**两个时间窗口的最高价和最低价 2. 计算**买入力量(BuyPower)** = 近期最高价 - 早期最低价 3. 计算**卖出力量(SellPower)** = 早期最高价 - 近期最低价 4. 计算 **TTF** = (BuyPower - SellPower) / (0.5 × (BuyPower + SellPower)) × 100 **TTF值解读**: - TTF > 0: 买入力量大于卖出力量，趋势向上 - TTF < 0: 卖出力量大于买入力量，趋势向下 - TTF > +50: 强势上涨趋势 - TTF < -50: 强势下跌趋势 **策略特点**: - 使用 T3 平滑算法进一步降噪 - 提供两种入场模式: **twist**(方向改变) 和 **disposition**(水平突破) - 支持做多/做空双向交易 - 默认止损1000点/止盈2000点(盈亏比2:1) ### 2.2 入场条件 **模式1: twist (振荡器方向改变)** **模式2: disposition (水平突破)** ### 2.3 出场条件 **twist模式出场**: - 做多平仓: Value[2] < Value[1] (方向向下改变) - 做空平仓: Value[2] > Value[1] (方向向上改变) **disposition模式出场**: - 做空平仓: Value[1] > LowLevel (-50) (回到低水平线上方) - 注意: 该模式下做多平仓信号缺失，需补充 **止损止盈**: - 固定止损: 1000点 - 固定止盈: 2000点 - 盈亏比: 2:1 ### 2.4 风险管理 1. **动态手数管理**: - MM > 0: 保证金百分比模式 - MM < 0: 固定手数模式 (如 -0.1 = 0.1手) 2. **交易权限控制**: - BuyPosOpen/SellPosOpen: 控制开仓方向 - BuyPosClose/SellPosClose: 控制平仓方向 3. **新K线检测**: - 使用 CIsNewBar 类避免重复开仓 - SignalBar = 1 时可在同K线内重复检测 4. **滑点控制**: - Deviation_ = 10点 最大价格偏差

优势

  • 创新算法设计
  • TTF指标通过买卖力量对比判断趋势
  • 双时间窗口比较，有效识别趋势强度
  • 比传统振荡器更具前瞻性
  • 专业代码架构
  • Nikolay Kositsin 专业级代码风格
  • CIsNewBar 新K线检测类避免重复开仓
  • TradeAlgorithms 完整交易函数库
  • 完善的订单修改重试机制
  • 双模式灵活性
  • twist模式: 捕捉趋势转折点
  • disposition模式: 捕捉强势突破
  • 用户可根据市场状态选择
  • 盈亏比合理
  • 默认SL=1000/TP=2000 (盈亏比2:1)
  • 止损优化后盈亏比更佳
  • T3高级平滑算法
  • T3平滑比普通MA滞后更小
  • 有效过滤噪音同时保持响应性

劣势

  • 止损过大
  • 默认1000点止损风险过高
  • 需手动优化至合理范围
  • 平仓逻辑不完整
  • disposition模式缺少做多平仓逻辑
  • 可能导致多头无法及时出场
  • 无趋势方向过滤
  • 缺少ADX或MA200等趋势方向确认
  • 逆势交易风险增加
  • 无追踪止损
  • 固定止盈止损无法锁定浮动盈利
  • 趋势行情中可能过早出场
  • 依赖外部库
  • SmoothAlgorithms.mqh 和 TradeAlgorithms.mqh 缺失时无法编译
  • 需要额外安装依赖
