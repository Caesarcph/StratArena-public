策略分析

分析 ### 2.1 核心策略概念 Exp_BlauCMomentum 使用 William Blau 开发的 **Candle Momentum Index (CMI)** 指标进行趋势跟踪。该指标基于蜡烛动量（Candle Momentum），通过计算收盘价与开盘价的差值，经过三重平滑处理后归一化到固定区间 [-∞, +∞]（通过除以Point转换为点数）。 **核心算法**： 1. **原始动量**: `Mom = PriceSeries(IPC1,bar) - PriceSeries(IPC2,bar-XLength+1)` - 可配置两种价格常量（IPC1/IPC2），默认为CLOSE和OPEN - XLength=1时计算单根K线内部动量（Close-Open） 2. **三重平滑**: - 第一重: XMA1平滑(XLength1=20) - 第二重: XMA2平滑(XLength2=5) - 第三重: XMA3平滑(XLength3=3) - 支持SMA/EMA/SMMA/LWMA/JJMA/JurX/ParMA/T3/VIDYA/AMA等10种平滑算法 3. **归一化输出**: `CMI = 100 × XXXMom / _Point` - 将动量值转换为以点数为单位的标准化值 - 五色状态机量化趋势强度（0-4级） ### 2.2 入场条件 EA提供两种入场模式： **模式1: breakdown（零线突破）** **模式2: twist（方向改变）- 默认模式** ### 2.3 出场条件 - **开仓**: 基于CMI指标信号 - **平仓**: 使用对应的反向信号 - 做多后，当出现做空信号时自动平多仓 - 做空后，当出现做多信号时自动平空仓 - **止损/止盈**: 固定点数止损止盈 - 默认SL=1000点（极度过大） - 默认TP=2000点 - 盈亏比2:1（良好） ### 2.4 风险管理 **止损止盈逻辑**: - 固定点数止损止盈（StopLoss_=1000, TakeProfit_=2000） - 点数转换为价格时考虑Digits自适应 - 使用StopCorrect()验证最小止损距离（SYMBOL_TRADE_STOPS_LEVEL） **手数管理**: - 5种手数计算模式（MarginMode枚举）: - Mode 0: 基于自由保证金 - Mode 1: 基于账户余额 - Mode 2: 基于风险比例（自由保证金） - Mode 3: 基于风险比例（账户余额） - Mode 4: Mode 0和Mode 2的最小值（双重风控） - Mode 5: Mode 1和Mode 3的最小值（双重风控） - MM=0.1表示10%资金（默认值过大，需降低） **其他风控措施**: - OrderCheck预检查机制 - PositionSelect持仓检查（同方向只能持有一仓） - GlobalVariable时间级别控制（防止重复入场） - LoadHistory历史数据预加载

劣势

  • 默认参数风险极大
  • SL=1000点过大致命风险
  • MM=0.1过度杠杆

  • 缺少趋势过滤
  • 无ADX或MA200方向过滤
  • 可能在震荡市中频繁止损
  • 无追踪止损
  • 固定止盈止损，无法保护浮盈
  • 错过趋势延续的额外利润
  • 单一指标依赖
  • 仅依赖CMI指标
  • 缺少多维度信号确认
