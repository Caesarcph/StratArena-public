策略分析

分析 ### 2.1 核心策略概念 这是一个**纯止损管理工具**，不执行任何开仓操作。核心功能： 1. **保本功能（BreakEven）**：当持仓盈利达到PlusPoints_breakeven点数时，将止损移动到开仓价+StepSL_plus_breakeven点数，锁定部分利润 2. **追踪止损功能（Trailing）**：当价格继续有利方向移动时，按StepSL_plus_trail步长持续追踪止损 **⚠️ 重要说明**：这是一个**辅助风控工具**，需要配合其他开仓策略使用，本身不进行交易。 ### 2.2 保本逻辑 **多头保本**： 1. 检查持仓盈利：`Bid >= OpenPrice + PlusPoints_breakeven * Point` 2. 移动止损到：`OpenPrice + StepSL_plus_breakeven * Point` 3. 确保新止损距离Bid大于SYMBOL_TRADE_STOPS_LEVEL **空头保本**： 1. 检查持仓盈利：`Ask <= OpenPrice - PlusPoints_breakeven * Point` 2. 移动止损到：`OpenPrice - StepSL_plus_breakeven * Point` 3. 确保新止损距离Ask大于SYMBOL_TRADE_STOPS_LEVEL ### 2.3 追踪止损逻辑 **多头追踪**： 1. 条件：止损已在保本位置或更好（`SL >= OpenPrice + StepSL_plus_breakeven * Point`） 2. 触发：`SL + PlusPoints_trail * Point <= Bid` 3. 新止损：`Bid - PlusPoints_trail * Point + StepSL_plus_trail * Point` 4. 验证：新止损必须大于当前止损（只朝有利方向移动） **空头追踪**： 1. 条件：止损已在保本位置或更好（`SL <= OpenPrice - StepSL_plus_breakeven * Point`） 2. 触发：`SL - PlusPoints_trail * Point >= Ask` 3. 新止损：`Ask + PlusPoints_trail * Point - StepSL_plus_trail * Point` 4. 验证：新止损必须小于当前止损（只朝有利方向移动） ### 2.4 风险管理 **多品种支持**： - WorkSymb: CurrentSymbol（仅当前品种）/ AllSymbols（所有品种） - MagicNumber过滤：-1=所有仓位, 0=用户仓位, >0=特定EA仓位 **参数验证**： - PlusPoints必须大于StepSL，否则返回INIT_FAILED - 参数<=0时禁用对应功能

优势

  • 双重保护机制：保本+追踪止损组合，逐步锁定利润
  • 多品种管理：支持管理所有品种的仓位
  • Magic过滤：可精确管理特定EA的仓位
  • 参数验证完善：OnInit中验证参数有效性
  • 止损只优不劣：确保止损只朝有利方向移动
  • StopLevel验证：确保满足交易所最小距离要求
  • 实时状态显示：Comment显示当前管理状态

劣势

  • 不开仓：纯管理工具，需要配合其他策略使用
  • 无ATR自适应：使用固定点数，不适应不同品种波动率
  • 无新K线检测：每个Tick都执行，可能产生不必要的计算
  • 无日志记录：缺少修改记录便于回测分析
