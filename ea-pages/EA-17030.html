摘要

该EA基于ADX指标交叉进行交易，当+DI上穿ADX且ADX上升时开多仓，当-DI上穿ADX且ADX上升时开空仓。它使用移动止损管理持仓，并在反向DI交叉信号出现时平仓，采用固定手数和可配置的止盈止损。

策略分析

策略概念基于ADX趋势强度指标的方向性交叉信号。入场条件：做多要求ADX前值小于当前值（ADX上升）、+DI前值低于ADX前值且+DI当前值高于ADX当前值（+DI上穿ADX）；做空要求ADX上升且-DI上穿ADX。出场条件包括两种：一是反向DI交叉信号平仓（做多持仓时+DI下穿ADX则平仓，做空持仓时-DI下穿ADX则平仓），二是移动止损跟踪利润保护。仓位管理采用固定手数，无动态调整机制。资金管理仅检查可用保证金是否足够开仓，未设置最大持仓数量限制或风险比例控制。止盈止损使用点数乘以调整系数（3/5位小数乘10），但止损默认值100点相对较大，止盈15点相对较小，风险回报比约1:0.15，偏向高风险低回报。

Summary

This EA trades based on ADX indicator crossovers, opening buy positions when +DI crosses above ADX while ADX is rising, and sell positions when -DI crosses above ADX while ADX is rising. It manages positions with a trailing stop and closes them on opposing DI crossover signals, using fixed lot sizing with configurable take-profit and stop-loss levels.

Strategy Analysis

The strategy concept is based on directional crossover signals from the ADX trend strength indicator. Entry conditions: a long position requires ADX rising (previous value less than current), +DI previously below ADX and currently above ADX (+DI crossing above ADX); a short position requires ADX rising and -DI crossing above ADX. Exit conditions include two types: first, closing on opposing DI crossover signals (close long when +DI crosses below ADX, close short when -DI crosses below ADX), and second, trailing stop for profit protection. Position sizing uses fixed lots with no dynamic adjustment mechanism. Money management only checks whether free margin is sufficient to open a position, without setting maximum position count limits or risk ratio controls. Take-profit and stop-loss use point values multiplied by an adjustment factor (10x for 3/5 digit brokers), but the default stop-loss of 100 points is relatively large while take-profit is only 15 points, resulting in a risk-reward ratio of approximately 1:0.15, favoring high risk and low reward.

优势

  • 使用ADX指标确认趋势强度，避免在震荡行情中频繁交易
  • 具备移动止损功能，能够锁定已有利润
  • 有反向信号平仓机制，不仅依赖止损止盈
  • 代码结构清晰，使用MQL5标准交易类库便于维护
  • 对3/5位小数报价自动调整点数，适应不同经纪商

劣势

  • 风险回报比极差，止盈15点而止损100点，盈亏比仅0.15:1
  • 无新K线检查机制，每个tick都可能触发交易信号导致重复入场
  • 固定手数无资金比例管理，在不同账户规模下风险不一致
  • 仅允许同时持有一个仓位，限制了策略的灵活性
  • iADXGet函数在复制失败时返回0.0，可能被误判为有效信号值

改进建议

  • 添加新K线检查机制，避免同一根K线内重复触发信号
  • 改善风险回报比，将止盈提高或止损缩小至至少1:1的比例
  • 加入资金比例仓位管理，根据账户余额动态计算手数
  • 在iADXGet中添加数据有效性验证，失败时跳过该tick而非返回0
  • 增加最大持仓数量和最大回撤限制的风险控制参数

Strengths

  • Uses ADX indicator to confirm trend strength, avoiding frequent trades in ranging markets
  • Includes trailing stop functionality to lock in existing profits
  • Has opposing signal exit mechanism, not relying solely on stop-loss and take-profit
  • Clean code structure using MQL5 standard trade libraries for maintainability
  • Auto-adjusts points for 3/5 digit brokers, adapting to different brokers

Weaknesses

  • Extremely poor risk-reward ratio: 15-point take-profit vs 100-point stop-loss, only 0.15:1
  • No new bar check mechanism, every tick can trigger trade signals causing repeated entries
  • Fixed lot sizing without percentage-based money management, risk inconsistent across account sizes
  • Only allows one position at a time, limiting strategy flexibility
  • iADXGet function returns 0.0 on copy failure, which could be misinterpreted as a valid signal value

Improvements

  • Add new bar check mechanism to avoid repeated signal triggers within the same bar
  • Improve risk-reward ratio by increasing take-profit or reducing stop-loss to at least 1:1
  • Add percentage-based position sizing that dynamically calculates lots based on account balance
  • Add data validity check in iADXGet, skipping the tick on failure instead of returning 0
  • Add risk control parameters for maximum position count and maximum drawdown limits
