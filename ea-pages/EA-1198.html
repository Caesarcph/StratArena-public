摘要

该EA使用自定义指标MALR（均线反转线）进行通道突破和反转交易。当价格上穿MALR下通道时买入，当价格下穿上通道时卖出，支持仓位反转、加仓摊平、移动止损以及基于权益的动态手数调整。

策略分析

策略概念基于MALR自定义指标的通道突破与反转信号。入场条件为：当收盘价从下方穿越MALR下通道线时开多单，当收盘价从上方穿越MALR上通道线时开空单。出场条件包括固定止损止盈、移动止损追踪以及仓位反转机制——当已有持仓方向与新信号相反时，先平仓再按反转手数（乘以倍数系数）反向开仓。仓位管理支持三种模式：主单（mode=1）使用基础手数或动态手数，加仓摊平（mode=2）在浮亏达到设定点数时以之前手数加仓，反转（mode=3）以原手数乘以倍数系数反向开仓。资金管理方面，启用了use_increase时，主单手数根据账户权益与最大回撤比例动态计算，即Lot*Equity/Max_drawdown，这使得资金利用效率更高但也可能导致过度仓位。移动止损功能可在盈利达到指定点数后激活，以trail点数距离追踪止损保护利润。整体策略结合了突破入场、反转操作和加仓摊平，属于激进型交易系统。

Summary

This EA trades channel breakouts and reversals using a custom indicator called MALR (Moving Average Line Reversal). It enters buy when price crosses above the MALR lower channel and sell when price crosses below the upper channel, with optional position overturn (reversal), averaging, trailing stop, and dynamic lot sizing based on equity.

Strategy Analysis

The strategy concept is based on channel breakout and reversal signals from the MALR custom indicator, which provides upper and lower channel boundaries around a moving average. Entry conditions: a buy signal triggers when the previous close was below the lower channel and the current close crosses above it; a sell signal triggers when the previous close was above the upper channel and the current close crosses below it. Exit conditions include fixed stop-loss and take-profit, a trailing stop mechanism that activates after a specified profit threshold is reached, and a position overturn feature that closes the existing position and opens a reverse position with multiplied lot size. Position management supports three modes: Main (mode=1) uses base or dynamic lot sizing, Averaging (mode=2) adds to a losing position when floating loss exceeds a configured point threshold using the previous averaging lot, and Overturn (mode=3) opens a reverse position with the previous lot multiplied by koff_multiplication. Money management uses a dynamic lot calculation when use_increase is enabled, computing lot size as Lot*Equity/Max_drawdown, which scales exposure with account growth but risks over-leveraging during equity spikes. The trailing stop only activates after a profit threshold is met, then trails by a fixed point distance. Overall, this is an aggressive trading system combining breakout entries with position reversal and loss averaging mechanisms.

优势

  • 策略逻辑清晰，基于通道突破与反转的混合交易系统，兼具趋势跟踪与反转能力
  • 提供仓位反转功能，能在趋势反转时快速调整方向，避免单边持仓亏损扩大
  • 支持基于权益的动态手数调整，资金利用率随账户增长而提升
  • 移动止损功能有盈利阈值激活机制，避免在刚开仓时被小幅波动止损出局
  • 开仓后修改止损止盈有重试机制，增强了订单执行的可靠性

劣势

  • 加仓摊平机制本质上是马丁格尔式策略，浮亏时加仓可能导致风险指数级放大
  • 仓位反转时手数乘以倍数系数（默认2倍），连续反转会急剧增大仓位，存在爆仓风险
  • 仅支持单品种单持仓，无法实现多品种分散化，且加仓和反转逻辑冲突可能产生意外行为
  • close()函数在PositionSelect后使用PositionGetInteger给magic赋值时类型不匹配（ulong vs long），存在潜在编译或运行时问题
  • 缺少点差过滤、时间过滤和隔夜风险控制，在剧烈波动时段或高点差环境下可能产生不利成交

改进建议

  • 添加最大持仓手数限制和连续反转次数限制，防止仓位在多次反转后无限膨胀
  • 增加点差过滤和时间交易过滤，避免在高点差和不利时段开仓，并添加隔夜利息风险监控
  • 加仓摊平应设置最大加仓次数和累计最大仓位限制，并考虑使用反向马丁格尔（盈利加仓）替代亏损加仓
  • 修复close()函数中magic字段的类型转换问题，并统一使用ulong类型处理魔术编号

Strengths

  • Clear strategy logic combining channel breakout and reversal in a hybrid trading system with both trend-following and reversal capabilities
  • Position overturn feature allows quick direction adjustment when trend reverses, avoiding extended drawdowns on wrong-sided positions
  • Equity-based dynamic lot sizing scales position size with account growth for better capital utilization
  • Trailing stop activates only after reaching a profit threshold, preventing premature stop-outs from minor price fluctuations
  • Retry mechanism for SL/TP modification after opening improves order execution reliability

Weaknesses

  • The averaging mechanism is essentially a martingale-style strategy where adding to losing positions can exponentially amplify risk
  • Position overturn multiplies lot size by a coefficient (default 2x), and consecutive overturns can rapidly escalate position size to dangerous levels
  • Only supports single-symbol single-position trading with no diversification, and the averaging and overturn logic can conflict producing unexpected behavior
  • Type mismatch in close() function where PositionGetInteger returns long but is assigned to mrequest.magic which expects ulong, posing potential compilation or runtime issues
  • Lacks spread filter, time filter, and overnight risk controls, which may lead to unfavorable fills during high-volatility or wide-spread periods

Improvements

  • Add maximum position lot limit and consecutive overturn count limit to prevent uncontrolled position escalation after multiple reversals
  • Add spread filter and time-based trading filter to avoid opening positions during wide-spread or unfavorable sessions, plus overnight swap risk monitoring
  • Averaging should have a maximum averaging count and cumulative position cap; consider replacing loss-averaging with profit-adding (reverse martingale)
  • Fix the type conversion issue in close() where magic field uses long instead of ulong, and standardize all magic number handling to ulong type

风险点

  • 仓位反转时手数倍增（默认2倍），连续反转可能导致仓位急剧膨胀至爆仓风险

  • 止损和止盈点数设置极大（2550/2578点），实际止损效果可能被大幅滑点削弱

Risk Assessment

Overall:HIGH

Risk Points

  • Position overturn with lot multiplication (default 2x) can cause position size to escalate dangerously with consecutive reversals
  • The averaging mechanism adds to losing positions, a martingale variant that can produce catastrophic losses in sustained trends
  • No hard cap on maximum lot size or maximum averaging count, leaving risk exposure effectively uncapped
  • SL/TP values are extremely large (2550/2578 points), meaning actual stop-loss effectiveness may be severely undermined by slippage
  • Dynamic lot calculation Lot*Equity/Max_drawdown can produce oversized positions during equity spikes or volatility
