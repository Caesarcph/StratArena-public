摘要

该EA使用自定义MALR（移动平均线性回归）指标进行通道突破交易。价格突破上轨时做多，突破下轨时做空。支持仓位反转、加仓摊平、基于权益的仓位增加以及移动止损功能。

策略分析

该EA的核心策略基于自定义MALR指标的通道突破。入场条件为：当收盘价从前一根K线低于上轨变为当前K线高于上轨时做多，反之当收盘价从前一根K线高于下轨变为当前K线低于下轨时做空。出场条件包括固定止损/止盈、移动止损以及仓位反转时平仓。仓位管理方面，支持三种模式：主单开仓（mode=1）、加仓摊平（mode=2，在浮亏达到指定点数时以相同手数加仓）和仓位反转（mode=3，平掉当前仓位后以乘数倍手数反向开仓）。资金管理方面，当启用use_increase时，手数根据账户权益与最大回撤的比值动态调整，即手数=Lot×权益/Max_drawdown。移动止损功能可在盈利达到指定点数后激活，按trail点数跟踪止损。整体策略存在马丁格尔倾向，尤其是反转模式下手数乘以koff_multiplication，可能导致仓位快速放大。

Summary

This EA trades channel breakouts using a custom MALR (Moving Average Linear Regression) indicator. It enters buy when price breaks above the upper channel and sell when price breaks below the lower channel. It supports position overturn (reversal), averaging down, lot increase based on equity, and trailing stop functionality.

Strategy Analysis

The core strategy of this EA is based on channel breakouts from the custom MALR indicator. Entry conditions: a buy signal is triggered when the close price transitions from below the upper channel on the previous bar to above it on the current bar; a sell signal is the reverse with the lower channel. Exit conditions include fixed stop-loss/take-profit, trailing stop, and position closure during overturn. Position sizing supports three modes: main entry (mode=1) with standard or equity-scaled lots, averaging (mode=2) which adds same-size positions when floating loss reaches a threshold, and overturn (mode=3) which closes the current position and opens a reverse position with multiplied lot size (lot × koff_multiplication). Money management scales the base lot by AccountEquity/Max_drawdown when use_increase is enabled, creating a proportional relationship between equity and position size. The trailing stop activates after a profit threshold is reached and then follows price by the trail distance. The overturn mechanism combined with lot multiplication introduces Martingale-like risk, as repeated reversals can exponentially increase position size.

优势

  • 支持多种仓位管理模式（主单、摊平、反转），策略灵活度高
  • 基于权益的动态手数调整有助于在盈利时放大收益、亏损时缩减仓位
  • 移动止损功能可保护已实现利润，降低回撤风险
  • 新K线检测机制避免同一根K线重复开仓

劣势

  • 仓位反转模式下手数乘以2倍，连续反转会导致马丁格尔式仓位膨胀，风险极高
  • 仅支持单品种单仓位（使用Symbol()选择），无法多品种交易
  • 加仓摊平功能在单边行情中会不断加仓导致严重浮亏
  • 使用PositionSelect(Symbol())而非遍历所有仓位，在hedging账户模式下可能选错仓位
  • SL/TP修改重试机制使用Sleep(1000)阻塞，在实时交易中可能错过行情

改进建议

  • 移除或限制仓位反转的手数乘数增长，设置最大反转次数或最大手数上限
  • 增加点差过滤和波动率过滤，避免在极端行情下盲目开仓
  • 改用PositionGetTicket遍历仓位而非PositionSelect，兼容对冲账户模式
  • 将Sleep阻塞改为事件驱动方式修改止损止盈

Strengths

  • Multiple position management modes (main, averaging, overturn) provide high strategic flexibility
  • Equity-based dynamic lot sizing helps amplify gains during winning streaks and reduce exposure during drawdowns
  • Trailing stop functionality protects realized profits and reduces drawdown risk
  • New bar detection mechanism prevents duplicate entries within the same bar

Weaknesses

  • Overturn mode doubles lot size on each reversal, leading to dangerous Martingale-like exponential position growth
  • Only supports single-symbol single-position trading via Symbol(), incapable of multi-instrument operation
  • Averaging function continuously adds positions in trending markets, potentially causing severe floating losses
  • Uses PositionSelect(Symbol()) instead of iterating all positions, which may select wrong position on hedging accounts
  • SL/TP modification retry uses Sleep(1000) which blocks execution and may miss trading opportunities

Improvements

  • Remove or cap the lot multiplication in overturn mode, set maximum reversal count or maximum lot ceiling
  • Add spread filter and volatility filter to avoid opening positions during extreme market conditions
  • Replace PositionSelect(Symbol()) with PositionGetTicket iteration for hedging account compatibility
  • Replace Sleep-blocking SL/TP modification with event-driven approach
