策略分析

分析 ### 2.1 核心策略概念 这是一个多货币对布林带突破策略，核心逻辑是： 1. **布林带突破检测**: 价格从布林带下轨下方突破到上方时做多，从上轨上方突破到下方时做空 2. **DEMA趋势过滤**: 使用双重指数移动平均(DEMA)确认趋势方向，只有当DEMA连续3根上升时才做多，连续3根下降时才做空 3. **Higher Low/Lower High确认**: 入场时需要额外的K线形态确认（做多需要Higher Low，做空需要Lower High） 4. **账户级止盈**: 当权益达到初始余额的1.2倍时全部平仓 ### 2.2 入场条件 **做多条件（BuySig1）**: 1. K线开盘价在布林带下轨下方：`Mrate[1].open < BBLow[1]` 2. K线收盘价在布林带下轨上方：`Mrate[1].close > BBLow[1]` (布林带下轨突破) 3. 当前K线最低价高于前一根K线最低价：`Mrate[1].low > Mrate[2].low` (Higher Low) 4. 前一根K线最低价低于更前一根：`Mrate[2].low < Mrate[3].low` (形成上升结构) 5. DEMA连续3根上升：`DemaVal[0]>DemaVal[1] && DemaVal[1]>DemaVal[2]` **做空条件（SellSig1）**: 1. K线开盘价在布林带上轨上方：`Mrate[1].open > BBUp[1]` 2. K线收盘价在布林带上轨下方：`Mrate[1].close < BBUp[1]` (布林带上轨突破) 3. 当前K线最高价低于前一根K线最高价：`Mrate[1].high < Mrate[2].high` (Lower High) 4. 前一根K线最高价高于更前一根：`Mrate[2].high > Mrate[3].high` (形成下降结构) 5. DEMA连续3根下降：`DemaVal[0]<DemaVal[1] && DemaVal[1]<DemaVal[2]` ### 2.3 出场条件 1. **止损止盈**: 固定止损(默认100-300点)和止盈(默认100-300点)，各货币对可独立设置 2. **追踪止损**: 可选，步进默认10点 3. **账户级止盈**: EquityTakeProfit=1.2，当权益>1.2×余额时全部平仓 4. **信号反向平仓**: CloseOnSignal=true时，新信号会平掉反向持仓 ### 2.4 风险管理 - **止损止盈逻辑**: 固定点数止损止盈，每个货币对可独立配置 - **手数管理**: - RiskMax>0: 动态风险比例手数 `(RiskMax/100 × FreeMargin / Pips) / (Pip/Point)` - RiskMax=0且LotSize>0: 固定手数 - RiskMax=0且LotSize=0: 余额比例手数 `Equity / LotBalanceDivider` - **追踪止损**: 固定步进模式，只向盈利方向移动 - **单一持仓限制**: 每个货币对最多持有1个仓位

优势

  • 多货币架构优秀: 使用CCoensioClass类封装，支持6个货币对独立运行，架构清晰
  • 信号确认机制完善: 布林带突破+DEMA趋势+K线形态(Higher Low/Lower High)三重确认
  • 风险管理灵活: 支持固定手数、动态风险比例、余额比例三种手数模式
  • 账户级保护: EquityTakeProfit机制保护整体账户盈利
  • 定时器驱动: 使用OnTimer替代OnTick，避免tick阻塞，适合多货币运行
  • 优化数据挖掘: 内置优化结果上传机制，支持CoensioIndex评估指标

劣势

  • 网络依赖严重: 依赖wininet.dll和coensio.com服务器，服务器可能已下线
  • 版权保护限制: 硬编码用户名验证，影响EA可用性
  • 相关性风险: 6个货币对高度相关（全部含USD），分散风险效果有限
  • 固定止损止盈: 未考虑波动率变化，止损可能过小或过大
  • 代码冗余: BarLogic()中大量重复的if-else判断，可优化为数组循环
  • 头文件加密: coensiotrader1v06.mqh为二进制文件，无法审查核心逻辑
