策略分析

分析 ### 2.1 核心策略概念 该EA使用**Jurik Moving Average (JMA)** 算法创建"JMA蜡烛图"系统，通过检测JMA平滑后的开盘价和收盘价关系变化来判断趋势转折。 **核心创新**: 对Open和Close价格分别应用JMA平滑，构建"虚拟蜡烛"： - 当JMA(Open) ≥ JMA(Close) 前一根，且 JMA(Open) < JMA(Close) 当前根 → **做多信号** (阳线转阴线转阳线) - 当JMA(Open) ≤ JMA(Close) 前一根，且 JMA(Open) > JMA(Close) 当前根 → **做空信号** (阴线转阳线转阴线) ### 2.2 入场条件 **做多入场**: 1. 前一根K线: JMA(Open) ≥ JMA(Close) → 虚拟阴线 2. 当前K线: JMA(Open) < JMA(Close) → 虚拟阳线 3. 检测到方向转换时入场 **做空入场**: 1. 前一根K线: JMA(Open) ≤ JMA(Close) → 虚拟阳线 2. 当前K线: JMA(Open) > JMA(Close) → 虚拟阴线 3. 检测到方向转换时入场 ### 2.3 出场条件 1. **反向信号平仓**: 当出现反向信号时平仓 2. **止损触发**: 默认1000点止损 3. **止盈触发**: 默认2000点止盈 4. **四开关控制**: BuyPosClose/SellPosClose独立控制是否启用反向平仓 ### 2.4 风险管理 - **止损/止盈**: 默认SL=1000/TP=2000 (盈亏比2:1良好) - **手数管理**: 支持5种模式 (LOT固定/FREEMARGIN/BALANCE/LOSSFREEMARGIN/LOSSBALANCE) - **滑点控制**: Deviation_=10 - **信号时间戳**: UpSignalTime/DnSignalTime记录信号时间

优势

  • JMA低延迟算法: Jurik算法业界顶级，有效降噪同时保持低滞后
  • 创新的双JMA蜡烛图设计: 分别对Open和Close平滑，构建虚拟蜡烛判断趋势
  • 完整交易框架: CIsNewBar新K线检测+TradeAlgorithms完整函数库+四开关交易控制
  • 良好盈亏比: 默认TP/SL=2:1设置合理
  • 历史信号恢复机制: EA重启后向后搜索恢复信号状态
  • ATR自适应箭头位置: 信号箭头位置根据波动率调整，避免遮挡

劣势

  • 默认止损过大: 1000点对多数品种不适用
  • 无趋势强度过滤: 震荡市场会产生假信号
  • 参数偏短: JLength=7噪音过多
  • 固定手数过大: MM=0.1对小账户激进
  • 依赖外部指标: 需单独安装JMA指标
  • 非标准出场逻辑: 完全依赖反向信号或固定止损止盈
