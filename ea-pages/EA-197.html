摘要

该EA使用ADX Wilder指标生成交易信号。当+DI线从下方突破配置的水平时开多仓，当-DI线从下方突破配置的水平时开空仓。每个品种同一时间只允许持有一个仓位，通过魔术编号进行过滤。

策略分析

该EA的核心策略基于ADX Wilder指标的DI线穿越水平线的信号。入场条件为：当+DI线在指定shift根K线前从下方突破level_p水平时，产生买入信号(+1)；当-DI线在指定shift根K线前从下方突破level_m水平时，产生卖出信号(-1)。出场条件仅依赖固定止损和止盈，分别为SL和TP点数，没有移动止损或部分平仓机制。仓位管理采用固定手数(Lots参数)，不考虑账户余额或风险比例的动态调整。资金管理方面，EA通过ExtPos函数检查是否已有同魔术编号的持仓，避免重复开仓，但只允许单方向持仓，即有仓时不允许反向开仓。整体策略逻辑简单直接，属于典型的趋势跟踪型EA，依赖DI线突破水平来判断趋势启动。

Summary

This EA uses the ADX Wilder indicator to generate trading signals. It opens a buy position when the +DI line crosses above a configurable level and a sell position when the -DI line crosses above its level. Only one position per symbol is allowed at a time, controlled by magic number filtering.

Strategy Analysis

The core strategy of this EA is based on the ADX Wilder indicator's DI lines crossing above configurable threshold levels. Entry conditions: a buy signal (+1) is generated when the +DI line crosses above the level_p threshold from below at the specified shift bars ago; a sell signal (-1) is generated when the -DI line crosses above the level_m threshold from below. Exit conditions rely solely on fixed stop loss and take profit values (SL and TP in points), with no trailing stop or partial closing mechanism. Position sizing uses a fixed lot size (Lots parameter) without any dynamic adjustment based on account balance or risk percentage. In terms of money management, the EA checks for existing positions with the same magic number via the ExtPos function to prevent duplicate entries, but only allows one position at a time per symbol regardless of direction. The overall strategy logic is simple and straightforward, representing a typical trend-following EA that relies on DI line breakouts above threshold levels to identify trend initiation.

优势

  • 策略逻辑清晰简洁，基于ADX DI线突破信号，易于理解和验证
  • 有魔术编号过滤机制，避免与其他EA的仓位冲突
  • 使用ExtPos函数检查持仓状态，防止重复开仓
  • 止损止盈参数可配置，提供基本的风险控制框架

劣势

  • 固定手数不考虑账户资金变化，缺乏动态仓位管理
  • 没有新K线检查机制，每个tick都会计算信号，可能导致重复触发
  • 止损止盈使用Point()计算但在非5位报价平台上可能不准确
  • 没有移动止损机制，盈利头寸可能在回撤中转为亏损
  • DI线突破低水平阈值(5)可能产生大量假信号
  • 持仓检查不允许反向开仓，错过趋势反转机会

改进建议

  • 添加新K线检查机制，避免每个tick重复计算信号和重复下单
  • 实现动态仓位管理，根据账户余额和风险比例自动调整手数
  • 添加移动止损功能，保护已有盈利并在趋势延续时追踪利润
  • 使用SymbolInfoDouble获取点值进行止损止盈计算，提高不同报价精度的兼容性
  • 添加ADX主线过滤条件，仅在趋势强度足够时才开仓以减少假信号

Strengths

  • Clear and concise strategy logic based on ADX DI line breakout signals, easy to understand and verify
  • Magic number filtering prevents position conflicts with other EAs
  • ExtPos function checks existing positions to prevent duplicate entries
  • Configurable stop loss and take profit parameters provide a basic risk control framework

Weaknesses

  • Fixed lot sizing ignores account equity changes and lacks dynamic position management
  • No new bar check mechanism, signal is calculated every tick which may cause redundant triggers
  • SL/TP calculation using Point() may be inaccurate on non-5-digit broker platforms
  • No trailing stop mechanism, profitable positions may turn into losses during pullbacks
  • DI line crossing a low threshold level (5) can generate many false signals
  • Position check prevents opposite direction entry, missing trend reversal opportunities

Improvements

  • Add new bar check mechanism to avoid recalculating signals and redundant orders on every tick
  • Implement dynamic position sizing based on account balance and risk percentage
  • Add trailing stop functionality to protect profits and trail gains during trend continuation
  • Use SymbolInfoDouble for point value in SL/TP calculation to improve compatibility across different quote precision brokers
  • Add ADX main line filter to only enter trades when trend strength is sufficient, reducing false signals

风险评估 / Risk Assessment

总体 / Overall:MEDIUM

风险点

  • 没有新K线检查，每个tick都会触发信号判断，可能在同一根K线上多次尝试开仓
  • DI线突破低水平阈值(level_p=5, level_m=5)容易产生假信号导致频繁亏损
  • 固定手数不随账户资金变化调整，在亏损后可能导致过度暴露风险
  • 使用ORDER_FILLING_FOK填充类型，部分券商可能不支持该类型导致下单失败

Risk Assessment

Overall:MEDIUM

Risk Points

  • No new bar check, signal evaluation runs every tick which may attempt multiple entries on the same bar
  • DI line crossing low threshold levels (level_p=5, level_m=5) easily produces false signals leading to frequent losses
  • Fixed lot size does not adjust with account equity changes, potentially leading to excessive risk exposure after losses
  • Using ORDER_FILLING_FOK fill type may not be supported by some brokers, causing order rejection
