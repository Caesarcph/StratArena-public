摘要

该EA演示了如何使用MQL5的全局变量函数（GlobalVariableSet、GlobalVariableGet、GlobalVariableCheck）来创建、读取和更新终端级别的持久化变量。初始化时生成随机值并存储，去初始化时更新该值，OnTick中不执行任何交易逻辑。

策略分析

该EA并非交易策略，而是一个全局变量操作的工具示例。策略概念是演示MQL5终端全局变量的持久化机制，通过GlobalVariableCheck检查变量是否存在，不存在则创建并设置初始值，存在则读取已有值。入场条件不适用，因为该EA不进行任何交易操作。出场条件同样不适用，没有平仓逻辑。仓位管理完全缺失，没有手数计算或仓位控制。资金管理也未实现，没有任何风险控制或资金分配逻辑。OnTick函数仅打印日志，没有利用tick数据做任何处理。去初始化函数中会重新计算随机值并更新全局变量，展示了变量的更新操作方式。

Summary

This EA demonstrates how to create, read, and update MQL5 global variables (terminal-level persistent variables) using GlobalVariableSet, GlobalVariableGet, and GlobalVariableCheck. It generates a random value, stores it in a named global variable on init, and updates it on deinit. The OnTick handler does nothing beyond printing the function name.

Strategy Analysis

This EA is not a trading strategy but a utility example demonstrating MQL5 terminal global variable persistence. The concept is to showcase how GlobalVariableCheck, GlobalVariableSet, and GlobalVariableGet work together to manage persistent data across EA instances. There are no entry conditions since the EA does not open any trades. Exit conditions are also not applicable as there is no position management. Position sizing is completely absent with no lot calculation or position control. Money management is not implemented with no risk control or capital allocation logic. The OnTick function merely prints a log message and does not process tick data. The OnDeinit function recalculates a random value and updates the global variable, demonstrating the variable update operation pattern.

优势

  • 清晰演示了MQL5全局变量的创建、检查、读取和更新操作流程
  • 使用GetFullName函数将变量名与魔术数字组合，避免命名冲突，设计合理
  • 代码结构简洁，函数职责分明，易于理解和学习
  • 在关键操作处调用ResetLastError和GetLastError进行错误处理

劣势

  • OnTick函数完全空转，仅打印日志，没有实际功能实现
  • variable_rezult作为全局变量声明但缺乏封装，不利于代码维护
  • 缺少对GlobalVariableDel的演示，未展示全局变量的删除操作
  • CalculateValueGlobalVariable仅生成随机数，缺乏实际业务逻辑参考价值
  • OnDeinit中重复了OnInit的逻辑，未抽象为共用函数，存在代码冗余

改进建议

  • 将OnInit和OnDeinit中重复的全局变量操作逻辑提取为共用函数，减少代码冗余
  • 增加GlobalVariableDel的演示以及全局变量过期时间的设置（GlobalVariableSetOnCondition）
  • 在OnTick中添加实际用途的示例，如基于全局变量的跨EA通信或状态共享

Strengths

  • Clearly demonstrates the full workflow of MQL5 global variable creation, checking, reading, and updating
  • Uses GetFullName to combine variable name with magic number, avoiding naming conflicts with a reasonable design
  • Clean code structure with well-separated function responsibilities, easy to understand and learn from
  • Implements error handling with ResetLastError and GetLastError at critical operations

Weaknesses

  • OnTick function is completely idle, only printing logs with no actual functionality implemented
  • variable_rezult is declared as a global variable without encapsulation, hurting code maintainability
  • Missing demonstration of GlobalVariableDel, does not show the deletion operation for global variables
  • CalculateValueGlobalVariable only generates random numbers, lacking practical business logic reference value
  • OnDeinit duplicates OnInit logic without abstracting into a shared function, causing code redundancy

Improvements

  • Extract the duplicated global variable operation logic from OnInit and OnDeinit into a shared function to reduce code redundancy
  • Add demonstration of GlobalVariableDel and global variable expiration time settings (GlobalVariableSetOnCondition)
  • Add practical use cases in OnTick, such as cross-EA communication or state sharing based on global variables
