摘要

这个EA是一个追踪止损工具，基于CandleStop指标值修改已有持仓的止损价位。它本身不建仓也不平仓，仅在趋势运行时跟踪移动止损以锁定利润。CandleStop指标通过可配置的回溯周期内的最高价和最低价来计算追踪止损水平。

策略分析

该EA的核心策略概念是利用CandleStop指标计算动态追踪止损位，而非自主产生交易信号入场。入场条件方面，EA完全不负责开仓，仅要求已有持仓存在（通过PositionSelect检测）。出场条件由追踪止损触发——当价格触及移动后的止损位时由市场平仓。对于多头仓位，止损依据CandleStop下轨线的最小值下移；对于空头仓位，止损依据CandleStop上轨线的最大值上移。仓位管理方面，EA不涉及建仓手数计算，仅修改已有仓位的止损和止盈。资金管理同样不在此EA职责范围内，它假设仓位已经由其他策略或手动建立。止损只能在有利于交易者的方向移动（多头止损只能上移，空头止损只能下移），确保不会扩大风险。EA每根新K线才重新计算止损值，避免频繁修改订单。

Summary

This EA is a trailing stop utility that modifies the stop loss of an existing position based on the CandleStop indicator values. It does not open or close positions itself — it only trails the stop loss to lock in profits as the trend progresses. The CandleStop indicator uses the highest high and lowest low over configurable lookback periods to compute trailing stop levels.

Strategy Analysis

The core concept of this EA is to use the CandleStop indicator to compute a dynamic trailing stop level, rather than generating its own trade entry signals. Regarding entry conditions, the EA does not open positions at all — it only requires that a position already exists (checked via PositionSelect). Exit conditions are triggered when price hits the trailed stop loss, at which point the market closes the position. For long positions, the stop loss is moved downward based on the minimum of the CandleStop lower band values; for short positions, it is moved upward based on the maximum of the CandleStop upper band values. Position sizing is entirely outside this EA's scope — it only modifies the stop loss and take profit of existing positions. Money management is similarly not handled; the EA assumes positions have already been established by another strategy or manually. The stop loss is only allowed to move in the favorable direction (up for longs, down for shorts), ensuring risk is never increased. The EA recalculates stop values only on new bars to avoid excessive order modifications.

优势

  • 止损仅朝有利方向移动，逻辑严谨，不会扩大已有风险
  • 每根新K线才重新计算并修改止损，避免高频下单造成服务器拒绝或延迟
  • 内置StopCorrect函数校正止损距离至交易所最小止损水平，减少无效订单提交
  • 代码结构清晰，买入和卖出仓位修改逻辑分离为独立函数，便于维护

劣势

  • 当持仓没有止损时（LastStop==0），EA会使用两根K线中的较大/较小值设止损，但未做充分的合理性校验
  • dSellPositionModify中使用Ask价格计算止损距离而非Bid，对空头仓位来说逻辑不够精确
  • ORDER_FILLING_FOK填充模式硬编码，不同券商可能不支持该模式导致修改失败
  • 缺少对CandleStop指标加载失败的健壮处理，OnInit仅打印警告但未阻止EA继续运行

改进建议

  • 在OnInit中指标句柄获取失败时返回INIT_FAILED而非继续运行，避免无指标时的无效计算
  • 将ORDER_FILLING_FOK改为根据券商支持的填充模式动态选择，或提供参数让用户选择填充类型
  • dSellPositionModify中应使用Bid而非Ask来计算空头仓位的止损距离

Strengths

  • Stop loss only moves in the favorable direction, ensuring risk is never increased after initial placement
  • Recalculates and modifies stop only on new bars, avoiding high-frequency order modifications that servers may reject
  • Built-in StopCorrect function adjusts stop distance to the exchange minimum stops level, reducing invalid order submissions
  • Clean code structure with separate functions for buy and sell position modification, making maintenance easier

Weaknesses

  • When a position has no stop loss (LastStop==0), the EA uses the larger/smaller of two bars' values without sufficient validity checks
  • dSellPositionModify uses Ask price instead of Bid for calculating stop distance on short positions, which is imprecise for sell-side logic
  • ORDER_FILLING_FOK filling mode is hardcoded; some brokers do not support this mode, causing modification failures
  • Insufficient robustness when the CandleStop indicator handle fails to load — OnInit only prints a warning but does not prevent the EA from continuing

Improvements

  • Return INIT_FAILED in OnInit when the indicator handle is invalid, rather than continuing to run with a broken handle
  • Replace the hardcoded ORDER_FILLING_FOK with dynamic broker-supported filling mode detection or a user-selectable parameter
  • Use Bid instead of Ask in dSellPositionModify when calculating stop distance for short positions
