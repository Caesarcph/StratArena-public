摘要

该EA是一个追踪止损工具，基于CandleStop指标的值来修改已有持仓的止损价位。它本身不开仓，仅为交易者或其他EA已持有的仓位提供追踪止损功能。追踪逻辑使用可配置回溯周期内的最高价或最低价来设置动态止损水平。

策略分析

该EA的核心策略概念是利用K线极值进行追踪止损，属于趋势跟踪的辅助工具而非独立交易策略。入场条件方面，该EA不执行任何开仓操作，仅在检测到已有持仓时开始工作。出场条件方面，当没有止损时（LastStop为0），EA会根据CandleStop指标的上轨或下轨设置初始止损；当已有止损时，在新K线出现时检查是否需要将止损向有利方向移动——多头止损只能上移、空头止损只能下移。仓位管理方面，该EA不涉及仓位大小计算，仅修改已有仓位的止损和止盈水平。资金管理方面，该EA没有独立的资金管理逻辑，也没有最大亏损限制或风险百分比控制，完全依赖用户自行控制仓位。EA在每根新K线时重新计算止损值，避免频繁修改带来的交易成本。

Summary

This EA is a trailing stop utility that modifies the stop-loss of an existing open position based on the CandleStop indicator values. It does not open new positions itself; it only trails stops for positions already opened by the trader or another EA. The trailing logic uses the highest high or lowest low over a configurable lookback period to set dynamic stop-loss levels.

Strategy Analysis

The core strategy concept of this EA is trailing stops based on candlestick extremes, functioning as a trend-following辅助tool rather than an independent trading strategy. Regarding entry conditions, the EA does not execute any position opening; it only activates when it detects an already open position on the current symbol. For exit conditions, when there is no stop-loss set (LastStop equals zero), the EA initializes the stop using the CandleStop indicator's upper or lower band; when a stop already exists, it checks on each new bar whether the stop can be moved in a favorable direction — long stops can only be tightened upward and short stops can only be tightened downward. In terms of position sizing, the EA does not calculate lot sizes at all; it only modifies the stop-loss and take-profit of existing positions. Regarding money management, the EA has no independent money management logic, no maximum drawdown limit, and no risk percentage controls, relying entirely on the user to manage position sizes. The EA recalculates stop values only on new bars to avoid excessive modification requests and associated trading costs.

优势

  • 逻辑简洁明了，仅追踪止损不干扰交易决策，适合作为辅助工具使用
  • 基于K线极值的追踪止损方法直观有效，能很好地保护趋势利润
  • 新K线判断机制避免了逐tick修改止损的频繁操作，降低了交易成本和服务器负载
  • 止损只能向有利方向移动的约束防止了止损回撤，保护了已获得的利润

劣势

  • 不开仓也不平仓，只能修改已有仓位的止损，功能单一
  • 使用ORDER_FILLING_FOK填充模式可能导致在某些流动性不足的市场中修改失败
  • dSellPositionModify函数中使用Ask而非Bid来计算空头止损距离，存在逻辑错误
  • 没有持仓时直接return，无法在没有仓位时提供信号提示或自动开仓
  • 缺少止损追踪步长参数，无法控制止损移动的最小幅度，可能产生过多不必要的修改请求

改进建议

  • 修复dSellPositionModify中价格引用错误，空头止损计算应使用Bid而非Ask
  • 增加追踪步长参数（Trailing Step），只有止损变动超过最小步长时才发送修改请求，减少无效操作
  • 增加对ORDER_FILLING_IOC和ORDER_FILLING_RETURN的支持，根据经纪商允许的填充模式自动选择
  • 增加持仓检测和信号提示功能，当没有仓位时可以发出提醒而非静默返回

Strengths

  • Clean and straightforward logic that only trails stops without interfering with trade decisions, making it suitable as a supplementary tool
  • Candle-extreme-based trailing stop method is intuitive and effective at protecting trend profits
  • New bar detection mechanism avoids per-tick stop modifications, reducing trading costs and server load
  • The constraint that stops can only move in a favorable direction prevents stop rollback and protects accumulated profits

Weaknesses

  • Does not open or close positions, only modifies stop-loss of existing positions, resulting in limited single-purpose functionality
  • Uses ORDER_FILLING_FOK fill mode which may cause modification failures in markets with insufficient liquidity
  • The dSellPositionModify function uses Ask instead of Bid to calculate short position stop distance, which is a logical error
  • Returns immediately when no position exists, unable to provide signal alerts or auto-entry when there is no position
  • Lacks a trailing step parameter to control the minimum stop movement increment, potentially generating excessive unnecessary modification requests

Improvements

  • Fix the price reference error in dSellPositionModify — short position stop calculation should use Bid instead of Ask
  • Add a trailing step parameter so that modification requests are only sent when the stop change exceeds a minimum threshold, reducing unnecessary operations
  • Add support for ORDER_FILLING_IOC and ORDER_FILLING_RETURN fill modes, automatically selecting based on broker-permitted filling types
  • Add position detection and signal notification functionality, providing alerts instead of silently returning when no position exists

Overall:LOW

Risk Points

  • The dSellPositionModify function uses Ask to calculate short position stop distance, which may result in incorrectly set stop-losses due to a price reference error
  • Only modifies stops of existing positions without actively closing them; in extreme market volatility, the stop-loss may not trigger in time
