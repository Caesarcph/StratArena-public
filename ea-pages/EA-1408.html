摘要

这是一个追踪止损工具EA，基于CandleStop指标值来修改已有持仓的止损位。它本身不开仓，仅对已存在的仓位根据最近K线的高低点进行止损追踪。

策略分析

策略概念：该EA是一个纯止损追踪工具，不负责开仓，仅对已有持仓进行止损管理。入场条件：EA本身不产生入场信号，它依赖于用户或其他EA已经建立的仓位。出场条件：通过CandleStop指标计算的上轨（UpValue）和下轨（DnValue）来动态调整止损位，对于多头仓位使用下轨作为止损参考，对于空头仓位使用上轨作为止损参考。仓位管理：不涉及开仓仓位管理，仅修改已有仓位的止损和止盈。资金管理：无资金管理逻辑，不计算仓位大小。当仓位的当前止损为零时，EA会取最近两根K线的指标值中的极值来设置初始止损；当已有止损时，仅在新K线出现时根据最新指标值更新止损，且只允许止损向有利方向移动（多头止损上移、空头止损下移）。

Summary

This EA is a trailing stop utility that modifies the stop-loss of an existing open position based on the CandleStop indicator values. It does not open positions itself; it only trails the stop-loss of manually or externally opened positions using the high/low of recent candles as determined by the CandleStop custom indicator.

Strategy Analysis

Strategy concept: This EA is a pure trailing stop utility that does not handle position opening; it only manages stop-loss levels for existing positions. Entry conditions: The EA does not generate entry signals; it relies on positions already opened by the user or another EA. Exit conditions: It dynamically adjusts stop-loss using the CandleStop indicator's upper band (UpValue) for sell positions and lower band (DnValue) for buy positions, which are derived from recent candle highs and lows over configurable lookback periods. Position sizing: Not applicable — the EA does not open positions, only modifies stop-loss and take-profit of existing ones. Money management: No money management logic is present; the EA does not calculate lot sizes. When the position has no stop-loss set, the EA initializes it using the more conservative of the two latest indicator values; when a stop-loss already exists, it only updates on new bars and only allows the stop to move in the favorable direction (up for buys, down for sells).

优势

  • 逻辑简洁清晰，专注于止损追踪，功能单一明确
  • 止损只允许朝有利方向移动，防止止损回退造成不必要的损失
  • 使用新K线检测机制避免频繁修改，减少交易请求次数
  • 内置止损距离合规性检查（StopCorrect），确保止损满足经纪商最小距离要求
  • 初始止损和追踪止损分开处理，逻辑层次分明

劣势

  • 不开仓也不平仓，完全依赖外部仓位，独立性差
  • ORDER_FILLING_FOK硬编码，部分经纪商不支持此成交模式，会导致修改失败
  • dSellPositionModify中使用Ask而非Bid作为参考价格，与卖单逻辑不完全匹配
  • OnDeinit中未释放指标句柄，可能造成资源泄漏
  • 缺少对多仓位的支持，只能处理当前品种的单个仓位

改进建议

  • 在OnDeinit中添加IndicatorRelease()释放指标句柄，避免资源泄漏
  • 将ORDER_FILLING_FOK改为根据经纪商支持动态选择成交模式，提高兼容性

Strengths

  • Clean and focused logic — the EA does one thing well: trailing stop management
  • Stop-loss only moves in the favorable direction, preventing adverse rollback
  • New bar detection mechanism reduces unnecessary trade requests and server load
  • Built-in StopCorrect function ensures stop distance meets broker minimum requirements
  • Separate handling of initial stop-loss placement vs. trailing updates provides clear logic layers

Weaknesses

  • No position opening or closing capability — entirely dependent on external positions, limiting standalone usability
  • ORDER_FILLING_FOK is hardcoded; some brokers do not support this fill mode, causing modification failures
  • dSellPositionModify uses Ask price instead of Bid as reference, which is inconsistent with sell position logic
  • OnDeinit does not release the indicator handle, potentially causing resource leaks
  • No support for multiple positions — can only handle a single position on the current symbol

Improvements

  • Add IndicatorRelease() in OnDeinit to properly free the indicator handle and prevent resource leaks
  • Replace hardcoded ORDER_FILLING_FOK with dynamic fill mode selection based on broker support for better compatibility

风险评估

总体:LOW

风险点

  • 仅修改止损不开仓，风险暴露由外部仓位决定
  • 硬编码FOK成交模式在部分经纪商可能导致止损修改失败，使仓位处于无保护状态

Risk Assessment

Overall:LOW

Risk Points

  • Risk exposure is determined by external positions since the EA only modifies stops without opening trades
  • Hardcoded FOK fill mode may cause stop modification failures on some brokers, leaving positions unprotected
