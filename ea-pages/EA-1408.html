摘要

该EA是一个追踪止损工具，根据CandleStop指标的值修改已有持仓的止损。它不开仓新仓位，仅为已存在的买入或卖出持仓移动止损。追踪逻辑使用可配置回溯周期内的最高价和最低价来确定新的止损水平。

策略分析

策略概念：该EA基于CandleStop指标实现追踪止损，CandleStop指标本质上是根据N根K线的最高价和最低价来计算止损位。入场条件：该EA本身不开仓，仅在有持仓时激活，当持仓没有止损时会根据指标值设置初始止损。出场条件：通过不断将止损向有利方向移动来实现追踪止损——买单止损上移至指标下轨值，卖单止损下移至指标上轨值。仓位管理：该EA不涉及仓位管理，仅修改已有仓位的止损和止盈。资金管理：无资金管理逻辑，不控制仓位大小。新K线检测机制确保每根K线只计算一次，避免频繁修改；当已有止损时，仅在新的止损比当前止损更有利时才执行修改。

Summary

This EA is a trailing stop utility that modifies the stop-loss of an existing position based on the CandleStop indicator values. It does not open new positions—it only trails the stop-loss for buy or sell positions already opened. The trailing logic uses the highest high and lowest low over configurable lookback periods to determine new stop levels.

Strategy Analysis

Strategy concept: This EA implements a trailing stop based on the CandleStop indicator, which calculates stop levels from the highest high and lowest low over N candle periods. Entry conditions: The EA does not open positions itself; it activates only when an existing position is detected, setting an initial stop-loss from indicator values when none exists. Exit conditions: Trailing is achieved by progressively moving the stop-loss in the favorable direction—buy position stops are raised to the indicator's lower band, and sell position stops are lowered to the indicator's upper band. Position sizing: The EA does not manage position sizes; it only modifies the stop-loss and take-profit of existing positions. Money management: No money management logic is present; lot sizes are not controlled. The new bar detection mechanism ensures calculations occur only once per bar, preventing excessive modifications; when a stop-loss already exists, modifications are only made when the new stop is more favorable than the current one.

优势

  • 逻辑简洁明了，仅做追踪止损不涉及开仓，风险可控
  • 使用新K线检测机制避免每tick重复计算和修改，减少交易请求频率
  • 止损修正函数StopCorrect确保止损距离满足经纪商最小止损级别要求

劣势

  • 不开仓仅修改仓位，依赖外部信号或其他EA先开仓，独立使用场景有限
  • ORDER_FILLING_FOK硬编码可能不兼容所有经纪商，应使用动态填充模式
  • dSellPositionModify中使用Ask而非Bid计算卖单止损距离，逻辑不够严谨

改进建议

  • 使用SymbolInfoInteger(symbol,SYMBOL_TRADE_FILLING_FLAGS)动态确定订单填充类型，替代硬编码的FOK
  • 在dSellPositionModify中使用Bid而非Ask来计算卖单止损距离，确保价格计算正确

Strengths

  • Simple and clear logic—only trails stops without opening positions, keeping risk controlled
  • New bar detection prevents redundant per-tick calculations and modifications, reducing trade request frequency
  • StopCorrect function ensures stop distances meet broker minimum stop-level requirements

Weaknesses

  • Does not open positions, relying on external signals or another EA to open first—limited standalone use
  • ORDER_FILLING_FOK is hardcoded and may not be compatible with all brokers; dynamic fill mode should be used
  • dSellPositionModify uses Ask instead of Bid for sell stop-loss distance calculation, which is logically imprecise

Improvements

  • Use SymbolInfoInteger(symbol,SYMBOL_TRADE_FILLING_FLAGS) to dynamically determine order filling type instead of hardcoding FOK
  • Use Bid instead of Ask in dSellPositionModify for calculating sell position stop-loss distance to ensure correct price calculation

风险评估

总体:SAFE

风险点

  • 卖单修改函数中使用Ask而非Bid计算止损距离，可能导致止损位置偏差
  • ORDER_FILLING_FOK硬编码在某些经纪商可能导致修改请求被拒绝

Risk Assessment

Overall:SAFE

Risk Points

  • Using Ask instead of Bid in sell modification function may cause stop-loss placement deviation
  • Hardcoded ORDER_FILLING_FOK may cause modification requests to be rejected by some brokers
