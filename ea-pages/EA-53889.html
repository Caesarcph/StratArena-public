摘要

CloseAgent是一个半自动化工具型EA，基于布林带和RSI超买超卖信号来关闭已有持仓。它不开仓新交易，而是监控已有头寸并在价格触及布林带上下轨且RSI确认极端值时平仓。可选的全局盈利目标可在账户利润达到阈值时一键平掉所有持仓。

策略分析

策略概念：该EA是一个纯平仓工具，不涉及任何开仓逻辑，仅用于管理已有持仓的退出。出场条件：对于多头仓位，当Bid价突破上轨(UBB)且RSI大于70且当前价高于开仓价时平仓；对于空头仓位，当Ask价跌破下轨(LBB)且RSI小于30且当前价低于开仓价时平仓。此外还有全局盈利平仓功能：当账户总利润超过CloseAll设定值时关闭所有仓位。仓位管理：该EA完全不涉及开仓和仓位管理，仅负责平仓操作。资金管理：唯一的资金管理手段是CloseAll参数，可在账户整体盈利达标时全部平仓，但没有单笔止损或追踪止损机制。指标使用：布林带(周期21，偏差2)判断价格极端位置，RSI(周期13)确认超买超卖，两者结合作为均值回归的出场信号。

Summary

CloseAgent is a semi-automated utility EA that closes existing positions based on Bollinger Bands and RSI overbought/oversold signals. It does not open new trades but monitors open positions and exits them when price hits the upper/lower Bollinger Band with confirming RSI extremes. An optional global profit target can close all positions at once when account profit reaches a threshold.

Strategy Analysis

Strategy concept: This EA is a pure closing utility with no entry logic whatsoever, designed solely to manage exits of existing positions. Exit conditions: For long positions, it closes when Bid exceeds the upper Bollinger Band, RSI is above 70, and the current price is above the entry price; for short positions, it closes when Ask falls below the lower Bollinger Band, RSI is below 30, and the current price is below the entry price. Additionally, a global profit-close feature closes all positions when total account profit exceeds the CloseAll threshold. Position sizing: The EA has no position sizing logic as it never opens trades, only closes them. Money management: The only money management mechanism is the CloseAll parameter for account-level profit taking, but there is no per-position stop loss or trailing stop. Indicator usage: Bollinger Bands (period 21, deviation 2) identify price extremes, RSI (period 13) confirms overbought/oversold conditions, and the combination serves as a mean-reversion exit signal.

优势

  • 结合布林带和RSI双确认，避免单一指标误判导致的过早平仓
  • 支持手动交易和算法交易的筛选，灵活控制平仓范围
  • 全局盈利平仓功能可作为账户级别的资金保护机制
  • LiveBar和NewBar两种操作模式适应不同交易场景的需求

劣势

  • 没有任何止损机制，若市场单边剧烈波动，持仓可能遭受巨大亏损而无法自动平仓
  • 指标句柄在每次循环迭代中重复创建但从未释放，会造成严重的内存泄漏和资源浪费
  • 账户利润变量acp在全局作用域初始化后永不更新，导致CloseAll功能完全失效
  • 缺少点差过滤，在M5小周期上布林带突破信号可能被点差噪音干扰

改进建议

  • 将指标句柄创建移至OnInit()中，在OnDeinit()中释放，避免内存泄漏并提升性能
  • 修复acp变量，在MyAlgo()每次调用时重新获取AccountInfoDouble(ACCOUNT_PROFIT)以确保CloseAll功能生效
  • 添加单笔持仓止损和追踪止损功能，增强风险控制能力
  • 添加点差过滤和滑点保护，提高在小周期和低流动性环境下的可靠性

Strengths

  • Dual confirmation with Bollinger Bands and RSI reduces the risk of premature exits from single-indicator false signals
  • Magic number filtering allows selective closing of manual vs algo trades, giving flexible control over position scope
  • The global profit-close feature serves as an account-level money management safeguard
  • LiveBar and NewBar operation modes adapt to different trading scenarios and resource usage needs

Weaknesses

  • No stop loss mechanism exists; if the market moves violently in one direction, positions can suffer massive losses without automatic closing
  • Indicator handles are created inside every loop iteration but never released, causing severe memory leaks and resource waste
  • The account profit variable acp is initialized at global scope and never updated, rendering the CloseAll feature completely non-functional
  • No spread filter is implemented, so on M5 timeframe Bollinger Band breakout signals can be corrupted by spread noise

Improvements

  • Move indicator handle creation to OnInit() and release them in OnDeinit() to prevent memory leaks and improve performance
  • Fix the acp variable by refreshing AccountInfoDouble(ACCOUNT_PROFIT) inside MyAlgo() on each call so the CloseAll feature actually works
  • Add per-position stop loss and trailing stop functionality to strengthen risk management capabilities
  • Add spread filter and slippage protection to improve reliability on low timeframes and in low-liquidity environments

风险评估

总体:MEDIUM

风险点

  • acp变量从未更新导致CloseAll全局盈利平仓功能完全失效，可能误导用户依赖一个不工作的安全机制
  • 没有单笔止损，在布林带和RSI信号未触发前市场极端波动可能导致巨大亏损
  • 指标句柄内存泄漏在长时间运行或持仓较多时会逐渐耗尽系统资源

Risk Assessment

Overall:MEDIUM

Risk Points

  • The acp variable is never updated, making the CloseAll global profit-close feature completely non-functional and potentially misleading users who rely on this safety mechanism
  • No per-position stop loss means extreme market moves can cause massive losses before Bollinger/RSI signals trigger
  • Indicator handle memory leaks can gradually exhaust system resources during long-running sessions or with many open positions
