策略分析

分析 ### 2.1 核心策略概念 这是一个**连续同向K线趋势跟踪策略**。核心思想是：当市场出现连续N根同向K线（连续更高高点+更高低点，或连续更低高点+更低低点）时，判定趋势形成并跟随入场。 **HighsLowsSignal指标算法**: 1. 统计最近HowManyCandles根K线的高点和低点变化方向 2. 计算`HigherHighs`: 当前高点>前一根高点的次数 3. 计算`HigherLows`: 当前低点>前一根低点的次数 4. 计算`LowerHighs`: 当前高点<前一根高点的次数 5. 计算`LowerLows`: 当前低点<前一根低点的次数 6. **做多信号**: HigherHighs==N 且 HigherLows==N (连续N根K线形成更高高点+更高低点) 7. **做空信号**: LowerHighs==N 且 LowerLows==N (连续N根K线形成更低高点+更低低点) **信号位置**: ATR×3/8距离作为入场信号显示位置（在最低点下方显示做多箭头，在最高点上方显示做空箭头） ### 2.2 入场条件 **做多入场**: 1. UpValue[0] != 0 且 UpValue[0] != EMPTY_VALUE (指标发出做多箭头) 2. BuyPosOpen开关为true 3. 当前无持仓（PositionSelect检查） 4. 通过TradeTimeLevelCheck时间间隔检查 **做空入场**: 1. DnValue[0] != 0 且 DnValue[0] != EMPTY_VALUE (指标发出做空箭头) 2. SellPosOpen开关为true 3. 当前无持仓（PositionSelect检查） 4. 通过TradeTimeLevelCheck时间间隔检查 ### 2.3 出场条件 **做多出场**: - 收到做空信号且BuyPosClose=true时平仓 - 历史信号搜索：向后遍历寻找最近一个做空信号作为平仓依据 **做空出场**: - 收到做多信号且SellPosClose=true时平仓 - 历史信号搜索：向后遍历寻找最近一个做多信号作为平仓依据 ### 2.4 风险管理 - **止损**: StopLoss_=1000点（硬编码） - **止盈**: TakeProfit_=2000点（硬编码） - **手数管理**: 5种模式可选 - FREEMARGIN: 基于自由保证金计算 - BALANCE: 基于账户余额计算 - LOSSFREEMARGIN: 基于自由保证金的风险亏损比例 - LOSSBALANCE: 基于余额的风险亏损比例 - LOT: 固定手数 - **时间间隔控制**: 通过GlobalVariable持久化实现交易冷却期 - **OrderCheck预检查**: 下单前验证订单合法性

优势

  • 策略逻辑简洁清晰: 连续同向K线是经典趋势确认方法，易于理解和验证
  • 专业级代码架构: Nikolay Kositsin标准代码风格，CIsNewBar新K线检测类+TradeAlgorithms完整交易函数库
  • 盈亏比2:1良好: TakeProfit_=2000/StopLoss_=1000提供正向盈亏比
  • 四开关交易控制: BuyPosOpen/SellPosOpen/BuyPosClose/SellPosClose独立控制，灵活性高
  • 完整风控机制: OrderCheck预检查+止损止盈合法性验证+时间间隔控制
  • 5种手数计算模式: 支持多种资金管理策略

劣势

  • HowManyCandles=3阈值过小: 震荡市场假信号多，胜率可能较低
  • 默认止损1000点过大: 风险敞口不合理，需大幅优化
  • 无趋势强度过滤: 纯K线结构信号在弱趋势或震荡中表现差
  • 无追踪止损: 无法动态保护盈利，回撤可能较大
  • 无多时间框架确认: 单一H4时间框架信号可靠性不足
