摘要

该EA基于Fisher_org_v1_Sign自定义指标的交易信号进行操作，该指标使用Fisher变换结合ATR归一化来识别动量买卖信号。在上升信号时开多仓，下降信号时开空仓，支持可配置的止损止盈水平，并提供包括固定手数和百分比在内的多种资金管理模式。

策略分析

该EA的核心策略基于Fisher变换指标的动量信号，Fisher变换将价格数据转换为近似正态分布，从而更清晰地识别价格拐点。入场条件为：当指标上轨（UpValue）在指定信号K线上产生非零且非空值时开多仓，当指标下轨（DnValue）产生非零且非空值时开空仓。出场条件包括：固定点数的止损和止盈（默认1000点止损和2000点止盈），以及反向信号触发的平仓——当持有多仓时出现下轨信号则平多仓，持有空仓时出现上轨信号则平空仓。仓位管理支持五种模式：基于可用保证金、余额、亏损后可用保证金、亏损后余额和固定手数。EA还实现了新K栏检测机制以避免重复交易，并在反向信号未触发平仓时会回溯历史K栏寻找之前的平仓信号，这是一个相对独特的逻辑设计。

Summary

This EA trades based on signals from the Fisher_org_v1_Sign custom indicator, which uses a Fisher Transform with ATR normalization to identify momentum-based buy and sell signals. It opens buy positions on upward signals and sell positions on downward signals, with configurable stop-loss and take-profit levels, and supports multiple money management modes including lot-based and percentage-based sizing.

Strategy Analysis

The core strategy of this EA is based on momentum signals from the Fisher Transform indicator, which converts price data into an approximately normal distribution to more clearly identify price turning points. Entry conditions: a buy position is opened when the indicator's upper buffer (UpValue) produces a non-zero, non-empty value on the specified signal bar, and a sell position is opened when the lower buffer (DnValue) produces a non-zero, non-empty value. Exit conditions include fixed stop-loss and take-profit levels (default 1000 points SL and 2000 points TP), plus reverse-signal-based closing — closing longs when a lower buffer signal appears and closing shorts when an upper buffer signal appears. Position sizing supports five modes: free margin-based, balance-based, loss-adjusted free margin, loss-adjusted balance, and fixed lot size. The EA implements a new bar detection mechanism to avoid duplicate trades, and when a reverse signal hasn't triggered a close, it retrospectively scans historical bars to find prior closing signals, which is a relatively unique logic design.

优势

  • 策略逻辑清晰，基于Fisher变换的动量信号具有良好的统计学理论基础，能有效识别价格拐点
  • 资金管理模式丰富，提供五种不同的仓位计算方式，适应不同风险偏好和账户规模
  • 实现了新K栏检测机制（CIsNewBar），避免在同一根K线上重复开仓，减少过度交易风险
  • 支持独立控制开仓和平仓的开关，灵活性高，可以仅使用信号平仓而用其他方式开仓

劣势

  • 缺少持仓检查逻辑，在已有同方向持仓时仍会重复开仓，可能导致仓位叠加过大
  • ATR_Period变量未声明为input类型，无法在策略测试器中进行优化，属于代码缺陷
  • 止损和止盈使用固定点数而非基于ATR的动态计算，无法适应不同波动率环境
  • 回溯扫描历史K线寻找平仓信号的逻辑可能在数据量大时造成性能问题，且没有设置合理的回溯上限
  • 缺少点差过滤，在高点差环境下可能频繁触发止损或开仓失败

改进建议

  • 添加持仓检查逻辑，在开仓前检测是否已有同方向持仓，避免重复开仓导致风险暴露过大
  • 将ATR_Period改为input类型以便策略优化，并考虑使用ATR动态计算止损止盈点数以适应市场波动率变化
  • 添加点差过滤和最大持仓限制，提高在不同市场条件下的鲁棒性

Strengths

  • Clear strategy logic based on the Fisher Transform momentum signal, which has solid statistical theory foundation and can effectively identify price turning points
  • Rich money management modes offering five different position sizing methods, adaptable to various risk preferences and account sizes
  • Implements new bar detection mechanism (CIsNewBar) to avoid duplicate position openings on the same bar, reducing overtrading risk
  • Supports independent control switches for opening and closing positions, providing high flexibility — can use signal-based closing only while opening positions via other methods

Weaknesses

  • Missing position check logic — will repeatedly open positions in the same direction when an existing position exists, potentially leading to excessive position stacking
  • ATR_Period variable is not declared as input type, preventing optimization in the strategy tester, which is a code defect
  • Stop-loss and take-profit use fixed point values rather than ATR-based dynamic calculation, unable to adapt to different volatility environments
  • The retrospective historical bar scanning logic for finding closing signals may cause performance issues with large data volumes and has no reasonable lookback limit
  • Missing spread filter, which may cause frequent stop-loss triggers or failed order openings in high-spread environments

Improvements

  • Add position check logic to detect existing same-direction positions before opening new ones, avoiding duplicate entries that lead to excessive risk exposure
  • Change ATR_Period to input type for strategy optimization, and consider using ATR-based dynamic stop-loss and take-profit calculation to adapt to market volatility changes
  • Add spread filter and maximum position limits to improve robustness under different market conditions
