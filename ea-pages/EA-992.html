摘要

该EA基于CCI T3平滑指标的零线交叉进行交易。当CCIT3从负转正时开多仓，从正转负时开空仓。可选的反转交易模式在出现反向信号时翻转仓位，并附带移动止损功能管理持仓。

策略分析

策略概念基于CCI（商品通道指数）经过T3双重平滑处理后的零线交叉信号进行动量交易。入场条件为：当CCIT3指标值从正值穿越到负值时开空单，从负值穿越到正值时开多单，仅在无持仓时开仓。出场条件包括：固定止盈TP（默认1750点）、可选止损SL（默认0即无止损）、以及移动止损trail功能。当启用Trade_overturn模式时，持仓遇到反向信号会先平仓再反向开仓。仓位管理方面，Lots参数固定手数，若启用Max_drawdown则根据账户余额与最大回撤比例动态调整手数。资金管理存在明显缺陷：默认SL=0意味着没有止损保护，风险极大。移动止损逻辑在多头时以Bid减去trail点数作为止损位，空头时以Ask加上trail点数作为止损位，逐步跟进盈利仓位。

Summary

This EA trades based on zero-line crossovers of a CCI T3 smoothed indicator. It opens a buy when CCIT3 crosses above zero and a sell when it crosses below zero. An optional trade overturn mode reverses positions on opposite signals, and a trailing stop feature manages open positions.

Strategy Analysis

The strategy concept is based on momentum trading using zero-line crossovers of a CCI indicator smoothed with the T3 moving average algorithm. Entry conditions: open a buy when CCIT3 crosses above zero (previous bar > 0, current bar <= 0 is the signal check reversed — CCIT3[0]<=0 && CCIT3[1]>0 triggers buy, CCIT3[0]>=0 && CCIT3[1]<0 triggers sell), only when no position exists. Exit conditions include a fixed TP of 1750 points, an optional SL which defaults to 0 (no stop loss), and a trailing stop feature. When Trade_overturn is enabled, the EA closes and reverses the position upon receiving an opposite crossover signal. Position sizing uses a fixed lot size by default, but if Max_drawdown is set above zero, the lot size scales proportionally to Account Balance divided by Max_drawdown, capped at the symbol's maximum volume. A critical money management flaw is the default SL=0, leaving positions without any hard stop loss protection. The trailing stop logic adjusts the stop loss level as price moves favorably, tracking by a fixed number of points behind the current price.

优势

  • 使用T3平滑算法处理CCI信号，减少虚假交叉和噪音
  • 提供两种指标模式（Simple和noReCalc），增加策略灵活性
  • 支持移动止损功能，能够锁定浮盈
  • 有新K线判断逻辑，避免同根K线重复交易
  • 修改止损止盈有重试机制，提高订单修改成功率

劣势

  • 默认SL=0，没有止损保护，风险极高
  • 仅支持单品种单持仓交易，无法多品种运行
  • 移动止损使用全局变量Trail_stop，EA重启后会丢失状态
  • close()函数中调用GetLastError()但未使用返回值，错误处理不完善
  • SLTP修改请求缺少position ticket，在多仓位环境下可能失败
  • noReCalc版本指标的循环方向为正向（i=0到start），T3递推计算顺序错误导致指标值不准确

改进建议

  • 添加默认止损值，避免无止损风险敞口
  • 修复noReCalc版本的正向循环问题，应改为从历史到当前逐根递推
  • 在SLTP修改请求中添加position ticket字段，确保修改正确仓位
  • 增加持仓检查的magic number过滤，避免干扰其他EA的仓位
  • Trail_stop应持久化存储或从当前仓位SL重新计算，避免重启丢失

Strengths

  • Uses T3 smoothing algorithm on CCI signals, reducing false crossovers and noise
  • Provides two indicator modes (Simple and noReCalc) for strategy flexibility
  • Supports trailing stop functionality to lock in floating profits
  • Has new bar detection logic to prevent repeated trades on the same bar
  • Retry mechanism for SL/TP modification increases order modification success rate

Weaknesses

  • Default SL=0 provides no stop loss protection, creating extreme risk exposure
  • Only supports single symbol single position trading, cannot run on multiple symbols
  • Trailing stop uses a global variable Trail_stop that resets on EA restart
  • close() function calls GetLastError() without using the return value, poor error handling
  • SLTP modification request lacks position ticket, may fail in multi-position environments
  • noReCalc version loops forward (i=0 to start) which is wrong for T3 sequential calculation, producing inaccurate indicator values

Improvements

  • Add a default stop loss value to avoid unprotected risk exposure
  • Fix the noReCalc version's forward loop issue — should iterate from oldest to newest bar for correct T3 sequential calculation
  • Add position ticket to SLTP modification requests to ensure the correct position is modified
  • Add magic number filtering in position checks to avoid interfering with other EAs' positions
  • Trail_stop should be persisted or recalculated from current position SL to survive EA restarts
