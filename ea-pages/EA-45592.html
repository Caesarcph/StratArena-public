摘要

这不是交易EA，而是一组MQL5教学演示脚本。ShapesCasting演示MQL5类层次结构中的类型转换（向上转型、向下转型、dynamic_cast）。Shapes5stats扩展了形状层次结构，使用注册器模式统计各类型实例化数量。EnvSignature是一个服务，用于生成和验证基于SHA256的环境签名，将程序绑定到特定终端环境。

策略分析

这些文件不包含任何交易策略。ShapesCasting展示了MQL5面向对象编程中的类型转换机制：基类指针可以指向派生类对象（向上转型），派生类指针赋值基类指针需要dynamic_cast（向下转型），失败返回NULL。Shapes5stats在Shape基类中嵌入了Registrator内部类，通过静态数组和静态方法追踪每种形状类型的实例数量，使用了宏REGISTRATOR自动生成派生注册器类。EnvSignature实现了环境绑定保护机制：收集终端属性（语言、路径、CPU核心数、内存、屏幕分辨率等），拼接密钥和胡椒值后进行SHA256哈希，再用Base64编码生成签名，开发者生成验证字符串后分发给用户，用户运行时比对签名验证运行环境是否被篡改。这三种代码纯粹是MQL5语言特性的教学演示，不涉及任何入场条件、出场条件或仓位管理逻辑。

Summary

This is not a trading EA but a collection of MQL5 educational demonstration scripts. ShapesCasting demonstrates OOP type casting (upcast, downcast, dynamic_cast) in MQL5 class hierarchies. Shapes5stats extends the shape hierarchy with a Registrator pattern to count instantiated shapes per type. EnvSignature is a service that generates and validates SHA256-based environment signatures to bind a program to a specific terminal environment.

Strategy Analysis

These files contain no trading strategy whatsoever. ShapesCasting demonstrates MQL5 OOP type casting: base class pointers can reference derived objects (upcasting), assigning base to derived requires dynamic_cast (downcasting) which returns NULL on failure, and void* pointers need dynamic_cast to recover type info. Shapes5stats embeds a Registrator inner class inside Shape, using a static array and static methods to track per-type instantiation counts, with a REGISTRATOR macro that auto-generates derived registrator classes. EnvSignature implements an environment-binding protection scheme: it collects terminal properties (language, path, CPU cores, memory, screen resolution, VPS status, program type), concatenates them with a secret and pepper string, hashes with SHA256, encodes with Base64 to produce a signature; the developer generates a validation string and distributes it to users, who at runtime compare the signature to verify the environment hasn't been tampered with. All three files are purely educational demonstrations of MQL5 language features with no entry conditions, exit conditions, or position management logic.

优势

  • 展示了MQL5面向对象编程的核心机制，包括继承、多态和类型转换，教学价值高
  • EnvSignature环境签名方案设计巧妙，利用SHA256+Base64实现程序绑定到特定终端环境，有一定实用价值
  • Registrator模式使用宏自动生成子类，展示了MQL5元编程技巧和静态成员管理方案

劣势

  • 不包含任何交易逻辑，无法直接用于实盘或策略研究
  • EnvSignature中密钥和胡椒值以宏定义硬编码，安全性依赖于编译后二进制的不可逆性，存在被逆向工程的风险
  • ShapesCasting中const成员导致默认赋值运算符被删除的问题虽有注释说明，但未给出完整的推荐解决方案

改进建议

  • EnvSignature应将密钥从源码中移除，改为运行时输入或加密配置文件读取，增强防逆向能力
  • 可以增加环境属性变化的容忍机制（如允许CPU核心数±1），避免合法硬件升级导致验证失败

Strengths

  • Demonstrates core MQL5 OOP mechanisms including inheritance, polymorphism, and type casting with high educational value
  • EnvSignature's environment binding scheme is cleverly designed, using SHA256+Base64 to bind programs to specific terminal environments with practical utility
  • The Registrator pattern uses macros to auto-generate subclasses, showcasing MQL5 metaprogramming techniques and static member management

Weaknesses

  • Contains no trading logic whatsoever, cannot be directly used for live trading or strategy research
  • EnvSignature hardcodes the secret and pepper as macro definitions, relying on binary irreversibility for security, which risks reverse engineering exposure
  • ShapesCasting documents the deleted operator= issue caused by const members but does not provide a complete recommended solution

Improvements

  • EnvSignature should remove secrets from source code and read them at runtime via encrypted config files or secure input to enhance anti-reverse-engineering protection
  • Add a tolerance mechanism for environment property changes (e.g., allow CPU cores ±1) to prevent validation failures from legitimate hardware upgrades
