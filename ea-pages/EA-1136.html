摘要

该EA基于内包线（Insider Bar）K线形态结合Zigzag突破确认进行交易。当价格突破前一根K线高点且看涨确认条件满足时开多仓，突破低点且看跌确认条件满足时开空仓。仓位管理包含可选的止损止盈，并使用全局变量实现每根K线仅交易一次的过滤机制。

策略分析

策略核心是基于内包线（Inside Bar）形态识别，即当前K线完全被前一根K线包含的形态。入场条件方面，做多需要价格突破前高（Buy_signal）且满足确认条件（Confirm_buy），确认条件包括当前低价触及Zig_level_buy或时间超过8点，同时排除黑鸟形态和白色内包线；做空反之。出场条件是当出现反向信号时平仓，例如持多仓时出现看跌确认信号且价格跌破前高。仓位管理使用固定手数（Lots参数），没有动态仓位或资金管理逻辑。止损止盈为可选参数，以点数计算并根据买卖方向分别基于Ask/Bid价格设置。策略还包含信号反转功能（InvertSignals），可将买卖信号互换使用。时间过滤方面，8点以后自动确认信号有效，作为时间兜底机制。

Summary

This EA trades based on inside bar (insider) candlestick patterns combined with zigzag breakout confirmation. It enters buy positions when price breaks above the prior bar's high with a confirmed bullish setup, and sells on breaks below the prior low with bearish confirmation. Position management includes optional stop loss/take profit and a one-trade-per-bar filter using global variables.

Strategy Analysis

The strategy core is based on Inside Bar candlestick pattern recognition, where the current bar is completely contained within the previous bar's range. For entry, a buy requires price breaking above the prior high (Buy_signal) with confirmation (Confirm_buy), which includes the current low touching Zig_level_buy or time past 8:00, while excluding Black_bird and White_insider patterns; sell conditions are symmetrical. Exit conditions trigger when a reverse signal appears - for example, a long position closes when a bearish confirmation signal occurs and price falls below the prior bar's high. Position sizing uses a fixed lot size (Lots parameter) with no dynamic position or money management logic. Stop loss and take profit are optional parameters, calculated in points based on Ask/Bid prices depending on trade direction. The strategy includes a signal inversion feature (InvertSignals) that swaps buy and sell signals. A time filter automatically confirms signals as valid after hour 8, serving as a fallback confirmation mechanism.

优势

  • 策略逻辑基于经典的内包线形态，具有明确的技术分析依据
  • 使用全局变量实现每根K线仅交易一次的过滤，避免同一K线重复开仓
  • 止损止盈检查考虑了品种的StopsLevel最小距离限制，符合交易所规范
  • 信号反转参数提供了灵活性，可用于测试或适配不同市场环境
  • 平仓逻辑与开仓信号联动，形成了相对完整的交易闭环

劣势

  • 没有动态资金管理，固定手数无法根据账户余额或风险自动调整
  • 默认止损止盈为零，在无止损情况下风险敞口无限
  • 使用当前K线（r[0]）的数据进行信号判断，尚未收盘的K线数据会频繁变化导致信号闪烁
  • 没有点差过滤，在内包线形态这类小波动策略中，高点差可能吞噬利润
  • SolveLots函数仅返回固定手数，代码中保留了参数但未实现任何动态计算逻辑

改进建议

  • 应实现基于账户风险比例的动态仓位计算，替代固定手数
  • 应添加新K线检测逻辑，仅在新K线形成时计算信号，避免信号闪烁和重复交易
  • 应增加点差过滤条件，当点差过大时暂停交易以保护利润空间
  • 应强制要求设置止损或提供最小止损保护，防止无止损交易导致巨额亏损

Strengths

  • Strategy logic is based on the classic Inside Bar pattern with clear technical analysis foundation
  • Uses global variables to implement one-trade-per-bar filter, preventing repeated entries on the same bar
  • Stop loss/take profit validation considers the symbol's StopsLevel minimum distance, complying with exchange rules
  • Signal inversion parameter provides flexibility for testing or adapting to different market conditions
  • Exit logic is linked to entry signals, forming a relatively complete trading loop

Weaknesses

  • No dynamic money management - fixed lot size cannot adjust based on account balance or risk
  • Default stop loss and take profit are zero, creating unlimited risk exposure without protection
  • Uses current bar (r[0]) data for signal calculation, uncompleted bar data changes frequently causing signal flickering
  • No spread filter - for small volatility patterns like Inside Bar, high spreads can easily erode profits
  • SolveLots function only returns fixed lots, retaining the parameter structure but implementing no dynamic calculation logic

Improvements

  • Implement dynamic position sizing based on account risk percentage instead of fixed lots
  • Add new bar detection logic to calculate signals only when a new bar forms, avoiding signal flickering and repeated trades
  • Add spread filter condition to pause trading when spread is too wide, protecting profit margins
  • Mandate stop loss or provide minimum stop loss protection to prevent catastrophic losses from unprotected trades
