EA-726 · Hedging

eq3-06 / e04lc07-v4

This EA implements a D'Alembert betting system for forex trading, managing a portfolio of currency pairs by tracking per-currency net exposure in EUR-terms. It opens positions based on exposure limits, scales in when price moves against the position (increasing lots after losses), and partially closes profitable positions. A Hamiltonian (closed-loop) currency pair set ensures net zero exposure across all value currencies.

Strategy analysis

This EA implements a D'Alembert betting system — decreasing stakes after wins and increasing after losses — by tracking net exposure per currency in EUR terms. Entry conditions: when no position exists for a symbol and the corresponding currency exposures are within limits, it opens a position in the direction specified by array A; when price moves adversely beyond a TP threshold, it adds to the position in LotMin increments. Exit conditions: when price moves favorably beyond a threshold, it partially closes the position (reducing to LotMin then relying on TP for final exit), or the CleanBad function forces a reduction at an acceptable loss. Position sizing uses a stepwise add/reduce approach, adding or closing LotMin lots each time, with maximum position capped by Limit_Position_Lot and maximum per-currency exposure capped by Limit_Exposure_Lot. Money management controls loss-closing pace via FreeBalance and BestBallance, with a MinMargin threshold and an emergency 123.4% margin level check. The ManageTP feature moves take-profit levels when unexpected profit occurs to lock in gains. The core strategy exploits the natural hedging property of multi-currency portfolios through a Hamiltonian set (e.g., EURUSD-EURGBP-GBPUSD triangular relationship) to maintain low net exposure, then uses the D'Alembert approach to gradually build and reduce positions during price fluctuations.

Strengths

  • Uses Hamiltonian currency pair sets for natural hedging, reducing overall net exposure risk
  • D'Alembert position sizing improves average entry price effectively during mean-reverting markets
  • Dual exposure limits (per-currency and per-symbol) effectively prevent risk concentration
  • ManageTP feature locks in gains during unexpected profits, avoiding profit giveback
  • Margin level checks and emergency threshold (123.4%) provide capital safety floor

Weaknesses

  • D'Alembert system continuously adds positions during trending markets, amplifying losses indefinitely
  • No stop-loss (SL=0), relying entirely on gradual reduction mechanism — margin call possible in extreme moves
  • Global variables I/J used across all functions create severe state coupling and reentrancy risks
  • Exposure() function assumes EUR+XXX symbols always exist for currency conversion, no error handling for missing symbols
  • Messy code structure with extensive global variables and implicit dependencies, poor readability and maintainability

Possible improvements

  • Add hard stop-loss (SL) as a last line of defense against extreme market moves to prevent margin calls
  • Refactor global variables I/J into function parameters to eliminate state coupling and reentrancy hazards
  • Add return value checks in Exposure() for SymbolInfoDouble calls to prevent division-by-zero when EUR+XXX symbols are missing

Risk assessment

Overall risk: High risk

  • No hard stop-loss (SL=0) — sustained adverse moves can lead to continuous position additions and margin call
  • D'Alembert position sizing causes exponentially growing losses during sustained trending markets
  • Global variable state coupling can produce incorrect trade orders during function reentrancy
  • Exposure() currency conversion lacks error handling — SymbolInfoDouble returning 0 causes division-by-zero
